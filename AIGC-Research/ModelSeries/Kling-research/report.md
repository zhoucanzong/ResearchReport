## 1. 概述

可灵（Kling）是由快手（Kuaishou）自主研发的视频生成大模型系列，自 2024 年 6 月首次发布以来，迅速成为全球视频生成领域的重要参与者。与 OpenAI 的 Sora、Google 的 Veo 等竞品相比，可灵在中文语义理解、长视频生成能力、人物表情细腻度以及消费级产品化方面展现出显著优势。

可灵的技术路线核心围绕 **DiT（Diffusion Transformer）架构** 展开，从早期的 3D 时空扩散模型逐步演进至统一多模态 Transformer，体现了中国本土大模型团队在视频生成领域的深度技术积累与快速迭代能力。

本报告系统梳理可灵从 1.0 到 3.0 / O1 的完整演进脉络，重点分析其架构变化、技术特点、与竞品的差异化优势，以及未来发展方向。

## 3. 每代模型架构详解与推测

### 3.1 可灵 1.0（2024.06）

#### 3.1.1 背景与定位

可灵 1.0 是快手在视频生成领域的首次大规模公开亮相。2024 年 6 月，快手通过「可灵 AI」平台向用户开放内测，迅速引发行业关注。其定位是**面向消费级和专业级用户的长视频生成大模型**。

#### 3.1.2 架构推测：基于 DiT 的 3D 时空扩散模型

可灵 1.0 的架构推测如下：

```
输入: 文本提示词 (Text Prompt) + 可选图像条件
        ↓
[文本编码器] → Text Embeddings (如 CLIP / T5 / 自研中文编码器)
        ↓
[3D 变分自编码器] → 将视频压缩至 Latent Space (时空联合压缩)
        ↓
[3D DiT 骨干网络] → 空间注意力 + 时序注意力联合建模
        ↓
[扩散采样器] → DDPM / DPM-Solver++ 多步去噪
        ↓
[3D VAE 解码器] → 重建像素空间视频
        ↓
输出: 1080p 视频，最长 2 分钟
```

**核心组件分析**：

- **3D 变分自编码器（3D VAE）**：将视频在时空维度上联合压缩至 Latent Space。相比 2D VAE（仅压缩空间），3D VAE 同时压缩时间维度，显著降低 DiT 的计算负担。推测采用时空分离或时空联合的卷积结构，下采样因子可能在空间上为 8×，时间上为 4× 或 8×。

- **3D DiT 骨干网络**：基于 Diffusion Transformer 的架构，将视频 Latent 切分为 3D Spatio-Temporal Patches。每个 Patch 包含空间信息（H×W）和时序信息（T）。注意力机制采用 **3D 全注意力（Full 3D Attention）** 或 **分解注意力（Factorized Attention）**，即先进行空间自注意力，再进行时序自注意力。

- **文本条件注入**：通过 Cross-Attention 或 AdaLN（Adaptive Layer Normalization）将文本 Embedding 注入 DiT 块。考虑到中文优化需求，快手可能采用了自研的中文文本编码器或在 T5/CLIP 基础上进行了中文语料微调。

#### 3.1.3 技术特点

- **长视频生成**：支持最长 2 分钟（约 3000 帧 @ 25fps）的视频生成，这在 2024 年中期的视频生成模型中处于领先地位。
- **运动幅度大**：相比早期视频生成模型（如 Runway Gen-2）的轻微运动，可灵 1.0 能生成大幅度、高动态的运动场景。
- **物理规律合理**：在人物运动、物体交互、重力模拟等方面表现出较好的物理一致性。
- **中文优化**：对中文提示词的理解优于同期基于英文训练的模型。

#### 3.1.4 局限性

- 生成速度较慢，长视频需要较长的推理时间。
- 复杂场景下偶尔出现时间不一致（Temporal Inconsistency）。
- 人物手指、面部细节在部分生成结果中仍有瑕疵。

### 3.2 可灵 1.5 / 1.6（2024-2025）

#### 3.2.1 演进方向

可灵 1.5 和 1.6 属于**渐进式改进**，重点在于画质提升、生成速度优化以及用户可控性增强。

#### 3.2.2 架构变化推测

| 组件 | 1.0 | 1.5 / 1.6 推测变化 |
|------|-----|-------------------|
| DiT 规模 | 基础规模 | 可能扩大 1.5-2 倍 |
| 注意力机制 | 基础 3D 注意力 | 引入局部窗口注意力加速 |
| 采样步数 | 约 50 步 | 优化至 30-40 步 |
| 条件控制 | 仅文本 | 新增图像条件、运动笔刷、首尾帧 |
| VAE | 基础 3D VAE | 可能微调以提升重建质量 |

#### 3.2.3 新增功能详解

- **运动笔刷（Motion Brush）**：用户可在参考图像上涂抹区域并指定运动方向，模型据此生成对应运动。推测实现方式：将用户涂抹的 mask 和运动向量编码为额外的条件 Embedding，通过 Cross-Attention 或专门的 ControlNet 风格分支注入 DiT。

- **首尾帧控制（First/Last Frame Control）**：用户指定视频的起始帧和结束帧，模型生成中间过渡内容。推测实现：将首尾帧通过 VAE 编码为 Latent 条件，在扩散过程中通过 Partial Attention Mask 或 Inpainting 风格的条件注入机制约束生成结果。

#### 3.2.4 性能提升

- 生成速度提升约 30-50%。
- 1080p 视频的细节锐度改善。
- 运镜稳定性增强，减少画面抖动。

### 3.3 可灵 2.0（2025.04）

#### 3.3.1 重大升级

可灵 2.0 于 2025 年 4 月发布，被快手定义为**重大版本升级**。据公开信息，可灵 2.0 在多个全球视频生成评测中位居榜首，标志着其技术实力获得国际认可。

#### 3.3.2 架构推测：更大规模 DiT + 改进时序建模

```
输入: 文本 + 图像/视频条件
        ↓
[增强文本编码器] → 更强大的语义理解
        ↓
[改进 3D VAE] → 更高压缩率，更好重建质量
        ↓
[大规模 3D DiT] → 参数量显著扩大，可能采用混合专家（MoE）或更深层网络
        ↓
    ├─ 空间注意力: 全局 + 局部窗口混合
    ├─ 时序注意力: 改进的时序建模（可能引入 RoPE 时序位置编码）
    └─ 文本-视频交叉注意力: 更精细的对齐
        ↓
[高效采样器] → 可能引入 Flow Matching 或改进的 ODE 求解器
        ↓
输出: 电影级画质，2分钟长视频
```

**关键架构改进推测**：

- **更大规模的 DiT**：参数量可能从 1.0 的数亿级别扩展至数十亿级别，以提升模型的表达能力。
- **改进的时序建模**：引入更精细的时序位置编码（如 RoPE 的时序扩展）或时序卷积辅助，以解决长视频的时间一致性问题。
- **Flow Matching 可能性**：2025 年视频生成领域开始从传统扩散模型向 Flow Matching（如 Stable Diffusion 3、Flux 采用的路线）迁移。可灵 2.0 可能已部分引入 Flow Matching 以提升采样效率和生成质量。
- **更强大的 VAE**：改进的 3D VAE 可能支持更高的空间分辨率和更长的时序上下文。

#### 3.3.3 核心能力提升

- **电影级画质**：色彩、光影、纹理细节达到电影级别。
- **人物表情细腻**：面部微表情、眼神交流、口型同步精度显著提升。
- **运镜稳定性**：相机运动（推、拉、摇、移）更加平滑专业。
- **物理仿真增强**：流体、布料、刚体碰撞等物理效果更真实。

### 3.4 可灵 3.0（2026.02）

#### 3.4.1 架构重构：原生 4K + 多模态统一

可灵 3.0 于 2026 年 2 月发布，标志着可灵系列从**纯视频生成模型**向**多模态内容创作平台**的转型。

#### 3.4.2 架构推测：统一多模态 DiT

```
输入: 文本 / 图像 / 视频 / 音频 / 故事板 等多模态条件
        ↓
[统一多模态编码器] → 将所有模态编码为统一 Token 序列
        ↓
[统一多模态 DiT] → 视频+音频联合生成
    ├─ 视频分支: 4K Latent 空间建模
    ├─ 音频分支: 音频 Token 建模（可能基于 SoundStream/EnCodec）
    └─ 跨模态注意力: 视频-音频对齐
        ↓
[多模态解码器] → 视频 VAE + 音频 Codec
        ↓
输出: 4K 视频 + 同步音频
```

**关键架构创新推测**：

- **原生 4K 输出**：DiT 直接在 4K 分辨率对应的 Latent 空间上操作。考虑到计算成本，可能采用**级联生成（Cascade Generation）**或**分块处理（Tiled Processing）**策略。
- **统一多模态 DiT**：视频和音频不再由独立模型生成，而是在同一个 DiT 框架内联合建模。视频 Patch 和音频 Token 被统一为序列输入，通过跨模态注意力实现精确对齐。
- **故事板工具（Storyboard Tool）**：用户可通过分镜头脚本（Storyboard）控制视频的叙事节奏、相机运动和场景切换。推测实现：将故事板信息（镜头类型、时长、转场效果）编码为结构化条件 Token，注入 DiT 的特定层。
- **单管道唇形同步音频系统**：在统一 DiT 内实现视频与音频的唇形同步，而非后期对口型。推测通过跨模态注意力强制视频面部区域与音频 phoneme Token 对齐。

#### 3.4.3 产品化特性

- **分镜头相机控制**：支持专业级的镜头语言（特写、中景、全景、跟拍等）。
- **节奏控制**：通过音乐节拍或叙事节奏控制画面切换和运动速度。
- **4K 原生输出**：无需后期上采样，直接生成 4K 分辨率视频。

### 3.5 可灵 O1（2026）

#### 3.5.1 架构创新：All-in-One 统一多模态视频模型

可灵 O1 是可灵系列的最新旗舰模型，代表了快手在视频生成领域的最高技术水准。其核心理念是**一个模型处理所有视频相关任务**。

#### 3.5.2 架构推测：类似 GPT-4o 的统一 Transformer

```
输入: 任意模态组合 (文本 / 图像 / 视频 / 音频 / Mask / 风格参考)
        ↓
[统一 Tokenizer] → 多模态统一 Token 空间
    ├─ 文本 → Text Tokens
    ├─ 图像 → Visual Tokens (ViT-style Patch)
    ├─ 视频 → Spatio-Temporal Video Tokens
    ├─ 音频 → Audio Tokens
    └─ 任务指令 → Task Tokens (如 [GENERATE], [EDIT], [INPAINT])
        ↓
[统一 Transformer 骨干] → 类似 GPT-4o 的任意-to-任意架构
    ├─ 自注意力: 所有 Token 统一处理
    ├─ 任务路由: 通过 Task Token 隐式路由至不同功能
    └─ 长上下文: 支持 2 分钟视频片段的全上下文建模
        ↓
[统一解码器] → 根据任务输出对应模态
        ↓
输出: 视频 / 图像 / 音频 / 编辑后的视频 / 风格迁移结果 等
```

**关键架构特征推测**：

- **统一 Token 空间**：所有模态被编码为同一维度的 Token，消除模态间的不一致性。视频可能采用 3D Patch 作为基本单元，音频采用压缩 Codec Token，文本采用 BPE Token。
- **任务统一**：通过特殊的 Task Token（如 `[GENERATE]`、`[EDIT]`、`[INPAINT]`、`[STYLE_TRANSFER]`）指定任务类型，模型在同一套参数下完成不同任务。这类似于 NLP 中的指令微调（Instruction Tuning），但扩展至多模态视频领域。
- **18+ 任务统一覆盖**：
  - **生成类**：文本生成视频、图像生成视频、视频生成视频。
  - **编辑类**：视频 inpainting、outpainting、对象移除、对象替换。
  - **风格类**：风格迁移、色彩调整、老视频修复。
  - **理解类**：视频描述、关键帧提取、视频摘要。
  - **音频类**：唇形同步、背景音乐生成、音效生成。
- **2 分钟片段生成**：在统一架构下保持长视频生成能力，推测通过**滑动窗口注意力**或**分层时序建模**实现长上下文处理。

#### 3.5.3 与 GPT-4o 的类比

| 维度 | GPT-4o | 可灵 O1 推测 |
|------|--------|-------------|
| 统一性 | 文本、图像、音频统一 | 视频、图像、音频、文本统一 |
| Token 类型 | Text + Image + Audio Tokens | Video + Image + Audio + Text Tokens |
| 任务范围 | 对话、推理、生成 | 视频生成、编辑、理解、音频同步 |
| 架构核心 | Transformer Decoder | 统一 Transformer（可能融合 DiT 思想） |
| 端到端 | 是 | 是 |

可灵 O1 可被视为**视频领域的 GPT-4o**，其核心突破在于将视频生成从专用扩散模型范式转向统一 Transformer 范式。

## 5. 技术特点深度分析

### 5.1 3D 变分自编码器：时空联合压缩

可灵系列的核心基础之一是 **3D VAE**，它将原始视频在时空维度上联合压缩至 Latent Space。

**技术细节推测**：

- **时空联合编码**：传统 2D VAE 仅对每帧图像独立编码，忽略时序冗余。3D VAE 通过 3D 卷积（或伪 3D 卷积，即 2D 空间卷积 + 1D 时序卷积）同时压缩空间和时间维度。
- **压缩率**：推测空间压缩因子为 8×（如 1080p → 135×76 Latent），时序压缩因子为 4× 或 8×（如 25fps → 6.25fps 或 3.125fps Latent）。
- **重建质量**：3D VAE 的重建质量直接影响最终视频画质。可灵 2.0/3.0 的画质提升很可能伴随 VAE 的显著改进，包括更深的网络、更大的 Latent 通道数（如 16 通道 → 32 通道）。
- **4K 挑战**：4K 视频（3840×2160）的像素量是 1080p 的 4 倍，对 VAE 的内存和计算压力巨大。可灵 3.0 的 4K 支持可能采用**分块 VAE 编码**或**级联 VAE**（先粗编码再精修）。

### 5.2 3D DiT：空间注意力 + 时序注意力

DiT 架构将 Transformer 引入扩散模型，以替代传统的 U-Net 骨干。可灵的 3D DiT 在此基础上扩展至时空维度。

**注意力机制演进推测**：

| 版本 | 空间注意力 | 时序注意力 | 特点 |
|------|-----------|-----------|------|
| 1.0 | 全局自注意力 | 全局时序自注意力 | 计算成本高，长视频受限 |
| 1.5/1.6 | 全局 + 局部窗口 | 全局/局部混合 | 引入局部窗口加速 |
| 2.0 | 全局 + 局部 + 稀疏 | 改进时序建模 | 可能引入 Swin-Transformer 风格的窗口移位 |
| 3.0 | 分块处理（Tiled） | 分层时序注意力 | 支持 4K 分辨率 |
| O1 | 统一自注意力 | 统一自注意力 | 视频作为统一 Token 序列处理 |

**关键问题**：

- **时序一致性**：时序注意力确保相邻帧的内容连贯。可灵 1.0 的「运动幅度大」特性表明其时序注意力可能更关注运动建模而非静态保持。
- **长视频处理**：2 分钟视频约 3000 帧，全局时序注意力的复杂度为 O(T²)，计算不可行。推测采用**分段时序注意力**或**分层时序建模**（如先处理短片段再全局对齐）。

### 5.3 长视频生成：分段生成 + 条件重叠

可灵系列支持 2 分钟长视频，这在技术上极具挑战性。

**推测实现方案**：

```
总时长: 2 分钟 = 3000 帧 @ 25fps

方案 A: 分段生成 + 条件重叠
    - 将 3000 帧分为 N 个片段（如每段 150 帧，共 20 段）
    - 每段独立生成，但相邻段在边界处重叠（如重叠 30 帧）
    - 通过 VAE 或 DiT 的条件注入确保重叠区域一致
    - 后处理：在重叠区域进行平滑融合

方案 B: 分层时序建模
    - 底层: 关键帧生成（如每 30 帧一个关键帧，共 100 个关键帧）
    - 中层: 关键帧插值（每两个关键帧之间生成中间帧）
    - 顶层: 细节精修（局部运动细化）

方案 C: 滑动窗口生成
    - DiT 的时序注意力仅在固定窗口内计算（如 64 帧窗口）
    - 通过缓存先前窗口的 Key/Value 实现长时序依赖
    - 类似 LLM 的 KV Cache 机制扩展至视频领域
```

可灵可能采用了**方案 A 与方案 C 的混合策略**：粗粒度分段生成保证整体叙事连贯，细粒度滑动窗口保证局部运动平滑。

### 5.4 中文优化：中文提示词理解

可灵作为本土模型，在中文语义理解方面具有天然优势。

**推测优化策略**：

- **中文文本编码器**：可能基于自研的中文 BERT/T5 模型，或在多语言 T5 基础上增加中文语料预训练。
- **文化语境理解**：对中国文化元素（如汉服、京剧、春节、武侠动作）的理解和生成更准确。
- **中文数据优势**：快手平台拥有海量中文短视频数据，为可灵提供了丰富的训练语料。

## 7. 应用场景

### 7.1 消费级场景

- **短视频创作**：快手平台创作者使用可灵生成创意视频内容。
- **社交媒体**：生成个性化视频用于微博、抖音、朋友圈分享。
- **个人纪念**：将照片转化为动态视频，生成家庭影像。

- **广告营销**：中小商家快速生成产品宣传视频。

- **视频修复与再创作**：老视频上色、修复、风格迁移。

## 8. 挑战与未来方向

### 8.1 当前挑战

- **计算成本**：4K 视频生成和统一多模态 Transformer 的推理成本极高，限制大规模普及。
- **实时性**：当前生成 2 分钟视频仍需数分钟至数十分钟，无法实现实时交互。
- **可控性**：尽管控制工具不断丰富，但精确到像素级的控制仍有差距。
- **版权与伦理**：训练数据来源、生成内容的版权归属、深度伪造（Deepfake）风险。
- **长视频叙事**：2 分钟以上的复杂叙事（如 10 分钟短片）仍面临时间一致性和逻辑连贯性挑战。

### 8.2 未来方向推测

- **实时视频生成**：通过模型蒸馏、量化、专用硬件加速，实现秒级甚至实时生成。
- **更长视频**：从 2 分钟扩展至 10 分钟、30 分钟，支持短片级创作。
- **世界模型（World Model）**：从视频生成迈向交互式世界模拟，支持可交互的 3D 环境生成。
- **端侧部署**：通过模型压缩和边缘计算，在手机端实现视频生成。
- **与快手生态深度融合**：与快手直播、电商、社交场景深度结合，形成闭环。
