## 1. 概述

Midjourney 是由独立研究实验室 Midjourney Inc. 开发的文本到图像（Text-to-Image）生成模型系列。自 2022 年 3 月首次公开测试以来，Midjourney 凭借其卓越的美学质量、独特的社区驱动模式和完全闭源的商业策略，迅速成为 AI 图像生成领域最具影响力的产品之一。

与 OpenAI 的 DALL-E 系列、Stability AI 的 Stable Diffusion 开源生态以及 2024 年崛起的 Black Forest Labs FLUX 系列相比，Midjourney 的核心差异化在于：**不追求通用性和技术透明性，而是将"美学上限"作为唯一优化目标**。这一策略使其在艺术创作、概念设计和视觉叙事领域建立了难以复制的护城河。

本报告基于公开发布会信息、Discord 社区讨论、行业分析师推测以及社区逆向工程成果，系统梳理 Midjourney 从 V1 到 V7 的技术演进路径，重点分析其可能的架构变迁、训练策略创新以及对整个生成式 AI 领域的深远影响。

## 2. 公司背景与商业模式

### 2.1 公司概况

| 项目 | 内容 |
|------|------|
| **公司全称** | Midjourney Inc. |
| **成立时间** | 2021年（美国旧金山） |
| **创始人** | David Holz（前 Leap Motion 联合创始人） |
| **团队规模** | 约 40-50 人（截至 2025 年），无外部融资 |
| **定位** | 独立研究实验室，非传统创业公司 |
| **核心产品** | Midjourney 图像生成模型 + 社区平台 |

David Holz 在多次公开采访中强调，Midjourney 的目标是"扩展人类的想象力"（expand the imaginative powers of the human species），而非单纯追求技术性能指标。这一哲学深刻影响了产品的技术路线和商业决策。

### 2.2 商业模式特点

**闭源策略**：Midjourney 从未开源任何模型权重、训练代码或技术细节。这与 Stability AI 的完全开源策略形成鲜明对比，也使社区对其架构的推测主要依赖输出行为分析和有限的官方披露。

**Discord 优先**：早期完全依托 Discord 平台提供服务，用户通过 Bot 交互生成图像。这一选择不仅降低了基础设施成本，更重要的是**将社区互动直接嵌入产品核心**——用户实时看到他人的创作、提示词（prompt）和参数设置，形成了强大的网络效应和学习效应。

**订阅制收费**：采用分层订阅模式（Basic/Standard/Pro/Mega），按 GPU 计算时间计费。无免费 tier（早期曾有有限免费试用），确保用户质量并覆盖高昂的推理成本。

**网页版扩展**：2023 年底逐步推出独立网页版，降低使用门槛，但 Discord 社区仍是核心生态。

## 4. 各代模型特点与架构推测

> ⚠️ **重要提示**：以下所有架构描述均为推测。Midjourney 官方从未公开模型结构、参数量、训练数据规模或训练代码。推测依据包括：输出图像特征分析、生成速度变化、功能新增时的行为模式、David Holz 的公开讲话片段，以及社区逆向工程（如通过 API 响应时间、图像元数据、输出风格一致性等进行的间接推断）。

### 4.1 V1–V3（2022年3月–8月）：基于 Stable Diffusion 的早期改进

#### 背景

Midjourney V1 发布时，Stable Diffusion（SD）v1.1 刚刚开源不久。Midjourney 团队很可能基于 SD 的早期版本进行了深度定制和微调，而非从头训练全新模型。

#### 架构推测

| 组件 | 推测配置 | 推测依据 |
|------|----------|----------|
| **基础框架** | Latent Diffusion Model (LDM) | 与 SD 同期发布，输出特征高度相似 |
| **VAE** | SD 预训练 VAE（f8 下采样） | 早期版本的 latent 空间特征与 SD 一致 |
| **U-Net** | SD v1.x 标准 U-Net（约 860M 参数） | 生成速度和图像分辨率与 SD v1.4 接近 |
| **文本编码器** | CLIP ViT-L/14 | 提示词理解能力与 CLIP 对齐 |
| **调度器** | DDIM / PNDM | 生成步数约 50-100 步 |
| **分辨率** | 512×512（默认） | 与 SD v1.x 训练分辨率一致 |

#### 关键改进点

尽管基础架构可能基于 SD，Midjourney V1-V3 在以下方面进行了显著差异化：

1. **美学微调（Aesthetic Fine-tuning）**：使用高质量艺术数据集进行额外微调，使输出默认偏向"精美插画"风格，而非 SD 的通用照片风格。

2. **社区投票数据筛选**：建立了大规模人工反馈机制。用户每天对生成的图像对进行投票（"哪张更好看"），这些偏好数据用于训练奖励模型或直接筛选训练数据。这是 Midjourney 早期即建立的**核心竞争壁垒**。

3. **默认参数优化**：精心调整的 guidance scale、采样步数和负面提示词（negative prompt）默认值，使普通用户无需复杂提示工程即可获得高质量结果。

4. **后处理增强**：内置自动 upscaling 和轻度细节增强，输出图像比原始 SD 更"精致"。

#### 局限性

- 多主体构图容易混乱
- 文本渲染能力几乎为零（生成文字为无意义符号）
- 人体解剖结构错误频发（手指、肢体扭曲）
- 对复杂提示词的遵循度有限

### 4.2 V4（2022年11月）：全新架构的重大升级

#### 发布背景

V4 的发布被社区普遍认为是 Midjourney 的"iPhone 时刻"。图像质量、构图能力和细节精度相比 V3 实现了跨越式提升，官方也明确暗示这是"全新架构"。

#### 架构推测

| 组件 | 推测配置 | 推测依据 |
|------|----------|----------|
| **基础框架** | 自研扩散模型（可能参考 NovelAI 改进） | 输出特征与 SD 系显著不同 |
| **U-Net** | 更大更深的 U-Net（推测 1B-2B 参数） | 生成时间增加，细节大幅提升 |
| **文本编码器** | 改进的 CLIP 或早期 T5 集成 | 提示词理解显著改善 |
| **训练分辨率** | 可能提升至 768×768 或更高 | 细节精度质变 |
| **条件机制** | 增强的文本-图像对齐机制 | 多主体构图能力跃升 |

#### 关键技术推测

**可能基于 NovelAI 的改进路线**：

2022 年 10 月，NovelAI 发布了基于 SD 但深度改进的 NAI Diffusion 模型，展示了通过以下手段可以大幅提升质量：
- 更大规模的 U-Net
- 更精细的文本编码器集成
- 高质量动漫/插画数据集的清洗和筛选

Midjourney V4 的发布时间（2022 年 11 月）与 NovelAI 的发布接近，且两者都展示了远超 SD v1.4 的质量。社区推测 Midjourney 可能采用了类似的技术路线：**以 SD 的 LDM 框架为起点，但替换了核心组件（更大的 U-Net、更好的文本编码器、更严格的数据筛选）**。

另一种可能是 Midjourney 团队自研了全新的扩散模型架构，但保留了 LDM 的基本范式（latent 空间扩散）。

#### V4 的核心突破

1. **多主体构图**：能够相对可靠地处理"一个红发女孩站在蓝色汽车旁边"这类包含多个独立主体的场景。

2. **细节精度**：皮肤纹理、织物褶皱、金属反射等细节显著改善。

3. **艺术风格多样性**：不再局限于默认插画风格，能更好地响应风格关键词（如"oil painting"、"anime"、"cinematic"）。

4. **更好的深度和透视**：三维空间感增强，构图更"有层次"。

#### 局限性

- 照片级真实感仍有限，存在"塑料感"
- 文本渲染依然不可靠
- 极端比例构图（如全景、竖长图）容易变形

### 4.3 V5 系列（2023年3月–6月）：照片级真实感的突破

#### 发布背景

V5 的发布标志着 Midjourney 从"艺术生成工具"向"通用视觉合成引擎"的转型。照片级真实感（photorealism）达到了前所未有的高度，开始被专业摄影师、广告设计师和电影制作人用于实际工作流。

#### 架构推测

| 组件 | 推测配置 | 推测依据 |
|------|----------|----------|
| **基础框架** | 自研扩散模型（LDM 范式延续） | 输出特征与 V4 有连续性 |
| **U-Net / 主干网络** | 进一步扩大的 U-Net（推测 2B+ 参数） | 生成时间继续增加 |
| **文本编码器** | 可能引入 T5-XXL 或改进版 CLIP | 复杂提示词遵循度提升 |
| **训练分辨率** | 可能达到 1024×1024 或更高 | 照片级细节需要高分辨率训练 |
| **数据规模** | 更大规模、更高质量的数据集 | 真实感质变需要数据支撑 |
| **数据清洗** | 更严格的去重、过滤、质量筛选 | 输出一致性显著提升 |

#### V5 的核心突破

1. **照片级真实感**：生成的肖像、风景、产品照片在缩略图级别难以与真实照片区分。

2. **人体结构改善**：手指、面部、肢体比例的错误率大幅下降（虽未完全解决）。

3. **更好的材质表现**：皮肤、头发、玻璃、水、金属等材质的物理正确性提升。

4. **自然语言理解**：对复杂描述性提示词的理解能力增强，如"a tired old man sitting on a wooden bench in autumn light, shallow depth of field"。

#### V5.1 / V5.2 渐进改进

| 版本 | 关键改进 | 推测技术原因 |
|------|----------|--------------|
| **V5.1** | 更连贯的图像、更自然的边缘、更少的伪影 | 微调优化，可能改进了 VAE 或调度器 |
| **V5.2** | Zoom Out（画面扩展）、变体控制增强 | 后处理管线升级，可能引入 outpainting 专用模块 |

**Zoom Out** 功能的引入特别值得关注——它允许用户将生成的图像"缩小"并自动填充周围画面，保持主体一致性。这暗示 Midjourney 可能开发了专门的 **outpainting / 图像扩展模型**，或在其扩散模型中集成了更强的全局-局部一致性机制。

### 4.4 V6（2023年12月）：文本渲染与提示遵循的飞跃

#### 发布背景

V6 是 Midjourney 历史上最受期待的版本之一，开发周期长达约 9 个月。官方在发布前多次强调这是"从头重建"的系统。

#### 架构推测：可能引入 Transformer 组件

| 组件 | 推测配置 | 推测依据 |
|------|----------|----------|
| **基础框架** | 混合架构：扩散模型 + Transformer 组件 | 文本渲染和复杂提示遵循需要更强的序列建模能力 |
| **文本编码器** | 大幅升级的文本编码器（可能为 T5-XXL 级别或自研） | 精确文本渲染需要字符级理解 |
| **主干网络** | 可能开始测试 U-Net 替代方案 | 生成时间模式变化 |
| **训练数据** | 包含带文本的图像数据，可能 OCR 辅助 | 可读文本生成需要文本-图像对齐数据 |
| **分辨率** | 可能支持原生更高分辨率生成 | 默认输出质量提升 |

#### 关键技术突破分析

**可读文本渲染**：

V6 最引人注目的新功能是能够在图像中生成**可读、可理解的文本**（如招牌、T恤上的文字、书本封面）。这在扩散模型中一直是难题，因为：
- 标准 U-Net 对字符级细节的空间定位能力有限
- CLIP 等文本编码器在词级别操作，不保留字符信息

社区推测 V6 可能采用了以下一种或多种技术：
1. **字符级文本编码器**：将文本提示中的引号内容以字符序列形式注入模型
2. **Layout / 位置条件**：允许用户指定文本在图像中的大致位置
3. **OCR 辅助训练**：在训练数据中使用 OCR 标注，强制模型学习文本-图像对应
4. **Transformer-based 文本渲染模块**：在扩散框架中引入 Transformer 处理文本区域

**精确提示遵循**：

V6 对复杂、长提示词的遵循度显著提升。例如：
```
a red vintage car parked in front of a blue Victorian house, 
white picket fence, golden hour lighting, 35mm film grain
```

V6 能更可靠地同时满足"红色汽车"、"蓝色房子"、"白色栅栏"、"金色时光"等多个独立条件。这暗示：
- 文本编码器的容量和细粒度对齐能力大幅提升
- 可能引入了 **attention-based 多条件融合机制**
- 训练数据中的文本-图像对齐质量更高

#### V6 的其他改进

- **更好的物理一致性**：物体间的空间关系、遮挡、光影更合理
- **更自然的皮肤纹理**：肖像生成达到商业摄影级别
- **改进的 upscaler**：默认输出分辨率提升

### 4.5 V6.5 / V7（2024–2025）：一致性、速度与参考系统

#### 发布背景

2024 年至 2025 年初，Midjourney 的迭代重点从"单张图像质量"转向"系列一致性"和"用户可控性"。这一转变反映了产品从"玩具"向"专业工具"的成熟。

#### 架构推测：可能向 DiT 或混合架构迁移

| 组件 | 推测配置 | 推测依据 |
|------|----------|----------|
| **基础框架** | 可能测试 Diffusion Transformer (DiT) 或混合架构 | 生成速度提升与质量并进的行业趋势 |
| **一致性机制** | 引入参考图像编码器（Reference Image Encoder） | Character Reference / Style Reference 功能 |
| **推理优化** | 可能引入蒸馏、量化或更高效的采样器 | 速度提升明显 |
| **多模态扩展** | 可能开始测试视频生成架构 | 行业竞争压力（Sora、Runway、Pika） |

#### 新功能的技术分析

**Character Reference（`--cref`）**：

允许用户上传参考图像，生成保持同一角色形象的新图像。这要求模型具备：
- **身份保持（Identity Preservation）**：提取并锁定面部/身体特征
- **视角/姿态变化**：在保持身份的同时改变角度、动作、服装
- **与文本提示的融合**：参考图像信息与文本提示的协调

技术推测：Midjourney 可能开发了专门的 **身份编码器（Identity Encoder）**，类似于 InsightFace 的面部识别模型或 IP-Adapter 的图像条件机制，但深度集成到主扩散模型中。

**Style Reference（`--sref`）**：

允许用户上传风格参考图像，提取其艺术风格并应用到新内容。这要求模型：
- **风格与内容的解耦**：分离参考图像的"风格"和"内容"
- **风格迁移的泛化**：将提取的风格应用到完全不同的主题

技术推测：可能基于 **StyleGAN** 或 **AdaIN** 风格的风格迁移技术，或更先进的 **attention-based 风格注入**（如 Reference-only ControlNet 的变体）。

#### 速度与一致性改进

V6.5 和 V7 的生成速度相比 V6 有可观提升，同时保持甚至改善了质量。在行业整体向 **Diffusion Transformer (DiT)** 和 **一致性模型（Consistency Models）** 迁移的背景下，社区推测 Midjourney 可能：
- 测试了 DiT 架构（如 Stable Diffusion 3 的路线）
- 采用了 **adversarial diffusion distillation** 或类似技术加速推理
- 优化了推理基础设施（更好的 GPU 调度、缓存机制）

## 6. 美学优先的训练策略

Midjourney 的核心竞争力不仅来自模型架构，更来自其**独特的训练策略和数据文化**。这是闭源模型最难被复制的部分。

### 6.1 社区投票与人工排序（Human Preference Data）

Midjourney 建立了可能是业界最大规模的**实时人工反馈系统**：

- **日常投票任务**：用户每天被展示成对的生成图像，选择"哪张更好看"
- **排名数据积累**：自 2022 年以来，累计收集了数亿次人工偏好判断
- **奖励模型训练**：这些偏好数据用于训练奖励模型（Reward Model），或直接用于筛选/加权训练数据
- **RLHF 或类似技术**：可能采用类似 InstructGPT / RLHF 的范式，用人类偏好优化生成策略

这一机制的效果是：**模型不仅学习"什么样的图像符合提示词"，更学习"什么样的图像人类觉得好看"**。这解释了为什么 Midjourney 的默认输出总是"精致"的，即使提示词很普通。

### 6.2 高质量艺术数据集

David Holz 多次强调 Midjourney 对训练数据的极度重视。推测其数据策略包括：

| 策略 | 描述 | 影响 |
|------|------|------|
| **专业艺术数据** | 大量高质量插画、概念艺术、摄影作品 | 默认美学质量高 |
| **严格清洗** | 去重、过滤低质量、标注错误修正 | 输出一致性好 |
| **风格平衡** | 多种艺术风格的均衡采样 | 风格多样性 |
| **文本-图像对齐** | 精心撰写的描述性标注 | 提示词遵循度高 |
| **社区反馈循环** | 用户生成的优质图像可能进入训练集 | 持续优化 |

### 6.3 后处理管线

Midjourney 的输出并非原始扩散模型生成，而是经过精心设计的后处理：

1. **自动 Upscaling**：默认对生成图像进行 2x 或 4x 超分辨率
2. **细节增强**：可能包括锐化、噪声抑制、纹理增强
3. **色彩校正**：统一的色彩空间处理，使输出更"讨喜"
4. **格式优化**：针对屏幕显示优化的压缩和渲染

这些后处理步骤是 Midjourney"即开即用"体验的关键组成部分。

### 7.2 差异化分析

**Midjourney vs. Stable Diffusion**：
- Midjourney 追求"开箱即用的美学上限"，SD 追求"无限的可控性和定制性"
- SD 通过 ControlNet、LoRA、IP-Adapter 等生态工具实现了远超 Midjourney 的可控性
- Midjourney 的默认输出质量通常优于 SD 基础模型，但 SD 的上限由用户技术能力决定
- SD 的开源生态（Civitai、ComfyUI）在角色一致性、动画、视频等领域已超越 Midjourney

**Midjourney vs. DALL-E 3**：
- DALL-E 3 的提示遵循度（特别是复杂描述）通常优于 Midjourney
- DALL-E 3 的文本渲染能力（通过集成 GPT-4 的提示优化）更强
- Midjourney 的美学质量和艺术风格多样性优于 DALL-E 3
- DALL-E 3 与 ChatGPT 的集成提供了更自然的交互体验

**Midjourney vs. FLUX**：
- FLUX（2024 年发布）是 Black Forest Labs（原 Stability AI 核心团队）开发的开源模型，在质量和开源性之间取得了出色平衡
- FLUX.1 [pro] 的质量已接近 Midjourney V6，且部分模型开源
- FLUX 的文本渲染能力较强，对 Midjourney 构成直接竞争
- Midjourney 的社区生态和品牌认知仍是优势

**Midjourney vs. Ideogram**：
- Ideogram 在文本渲染方面一度领先，是 Midjourney V6 发布前唯一能可靠生成文本的模型
- Midjourney V6 发布后，文本渲染差距缩小
- Ideogram 的免费 tier 吸引了大量用户，但美学质量不及 Midjourney

## 8. 技术特点深度分析

### 8.1 美学优先的设计哲学

Midjourney 的所有技术决策都服从于一个核心目标：**让生成的图像"好看"**。这体现在：

- **默认参数的美学偏向**：即使输入简单提示词，输出也经过精心调整的色彩、构图和风格
- **负面提示词的弱化**：相比 SD 社区对负面提示词的依赖，Midjourney 的默认模型已经"内置"了大量美学优化
- **后处理的统一美学**：所有输出经过一致的色调和质感处理，形成品牌辨识度

### 8.2 社区即数据

Midjourney 的 Discord 社区不仅是用户支持渠道，更是**数据生产基础设施**：

- **实时反馈**：用户的每一次投票、放大、变体选择都是偏好数据
- **提示词共享**：公开频道中的提示词-图像对构成了巨大的训练数据潜力
- **风格发现**：社区中流行的风格关键词（如"--style raw"、"--niji"）指导模型迭代方向

### 8.3 与开源模型的根本差异

| 维度 | Midjourney | 开源生态（SD/FLUX） |
|------|------------|---------------------|
| **优化目标** | 美学上限 | 通用性、可控性、多样性 |
| **技术透明性** | 完全黑盒 | 完全透明 |
| **用户能力要求** | 低（开箱即用） | 高（需技术知识） |
| **定制能力** | 有限（参数调节） | 无限（训练、微调、插件） |
| **迭代速度** | 由公司控制，季度级 | 社区驱动，天级 |
| **成本结构** | 订阅费 | 硬件/云服务成本 |

## 9. 挑战与未来方向

### 9.1 当前挑战

1. **视频生成竞争**：OpenAI Sora、Runway Gen-3、Luma Dream Machine 等在视频生成领域领先，Midjourney 尚未发布正式视频产品
2. **开源模型追赶**：FLUX、SD3、PixArt 等开源模型质量快速提升，缩小与 Midjourney 的差距
3. **可控性需求**：专业用户需要更精确的角色一致性、姿态控制、构图控制，Midjourney 的封闭系统限制了这方面的发展
4. **版权与伦理**：训练数据来源、艺术家风格模仿等争议持续存在
5. **推理成本**：高质量生成需要大量 GPU 资源，订阅定价面临压力

### 9.2 未来方向推测

| 方向 | 可能性 | 推测依据 |
|------|--------|----------|
| **视频生成** | 高 | David Holz 已确认正在开发，2025 年可能有测试 |
| **3D / 世界模型** | 中 | 行业趋势，但技术难度高 |
| **实时生成** | 中 | 一致性模型、蒸馏技术发展 |
| **更深度的参考系统** | 高 | Character/Style Reference 的延续 |
| **与创意工具集成** | 高 | 网页版、API 的扩展 |
| **保持闭源** | 极高 | 公司核心策略， unlikely 改变 |

### 9.3 架构演进展望

基于行业趋势和 Midjourney 的历史路径，未来架构可能：

1. **Diffusion Transformer (DiT)**：如 Stable Diffusion 3 和 FLUX 所示，Transformer-based 扩散模型在质量和效率上展现优势，Midjourney 可能逐步迁移
2. **流匹配（Flow Matching）**：替代传统扩散过程，提升训练效率和推理速度
3. **多模态统一**：将文本、图像、视频生成统一在单一框架下
4. **一致性模型**：实现单步或少数几步生成，大幅降低推理成本

## 结语

Midjourney 作为 AI 图像生成领域的标志性产品，其成功不仅源于技术实力，更源于独特的产品哲学：**将人类审美偏好深度嵌入技术系统**。在完全闭源的策略下，其架构细节始终笼罩在神秘之中，但输出质量的持续飞跃证明了团队的技术深度。

从基于 Stable Diffusion 的早期改进，到可能的自研扩散模型，再到向 Transformer 化和一致性系统的演进，Midjourney 的技术路线反映了整个生成式 AI 领域的发展脉络。未来，随着视频生成、实时交互和更深度的可控性成为竞争焦点，Midjourney 能否保持其美学护城河，将是观察这一领域演变的重要窗口。
