# 量化感知适配与原生低精度训练：模型从哪里开始量化？

本篇并读五类不同问题：[LLM-QAT](https://arxiv.org/abs/2305.17888v1) 用教师生成数据适配量化模型；[QATFactory](https://arxiv.org/abs/2609.39223v2) 把训练数值对齐到推理引擎并扩展到 QAD/QARL；[LC-QAT](https://arxiv.org/abs/2606.10531v3) 用结构化 VQ 攻克 2-bit 可微训练；[BitNet b1.58](https://arxiv.org/abs/2402.17764v1) 从头训练三值权重模型；[Quartet](https://arxiv.org/abs/2505.14669v4) 研究硬件支持的 MXFP4 训练。它们都在训练环节处理量化误差，但训练对象、表示、目标格式和部署路径不同，不能简单称为一种“QAT”。

## LLM-QAT：让现成教师教量化学生

LLM-QAT 针对低位宽量化后模型输出分布变化，使用量化感知训练让学生适应目标数值格式。论文提出从浮点教师自回归生成文本，再以教师输出分布监督量化学生，因此不必访问原始预训练语料。这里的 **data-free** 指不使用原始训练集，不是没有训练数据、教师推理成本或优化过程。其方法覆盖权重、激活，并可按设定量化 KV cache；原文方法与消融见 [§2–§3.3](https://arxiv.org/html/2305.17888v1#S2)。

这种设计降低了获取预训练语料的门槛，但生成文本能否覆盖原始分布仍是核心假设。QAT 可能让模型更适应目标位宽，却引入训练计算、教师采样策略和潜在域偏移；论文的模型与任务结果不能替代业务分布上的质量评估。

## QATFactory：训练数值与部署格式对齐

QATFactory 将目标格式的可表示值、块结构、尺度共享和舍入规则放进训练期量化层，矩阵乘仍以 BF16 执行，再用 STE 更新连续权重。这样可以模拟 NVFP4、MXFP4 或 Q4_K 训练，而不要求训练 GPU 原生支持对应低位宽运算；训练后可直接导出给目标推理引擎。论文把流程分成 QAD（浮点教师监督低精度学生）和 QARL（低精度 rollout 加奖励/验证器反馈），把目标格式贯穿训练、采样和导出。[§3.1–§3.5](https://arxiv.org/html/2609.39223v2#S3)

一个重要发现是，**训练期精度不应只按部署精度机械复制**。论文在其 Qwen3.5-9B 等实验中发现，NVFP4 下训练权重而保留高精度激活可持平或优于同时量化激活；MXFP4 的结果则不同，激活量化训练能帮助对齐部署误差。作者把这种差异与格式 scale 粒度和反向梯度扰动联系起来，并指出解释仍是实验条件下的判断。[§4.3](https://arxiv.org/html/2609.39223v2#S4)

论文报告在固定 token 预算下，Qwen3.5-9B 的较长序列训练在四组比较中三组提升、一组持平，平均准确率高 1.9 个百分点；这只是其数学/代码数据和 benchmark 设置，不能外推为长序列 QAT 的通用规律。[§4.5](https://arxiv.org/html/2609.39223v2#S4)

## LC-QAT：让 2-bit 向量码本能通过梯度优化

LC-QAT 的问题是：2-bit 标量权重表达能力不足，而 VQ 的离散码本索引又不容易反向传播。它将向量 codeword 参数化为 `c = A z + B`：`z` 是整数编码，`A`、`B` 是浮点映射。训练前先用 PTQ 得到强初始化，再训练 proxy weights 并通过可微梯度估计器穿过离散映射；因此训练 forward 不需反复做显式 nearest-neighbor 码本搜索。这个线性结构还能重写成整数矩阵乘加小型映射，复用整数 GEMM kernel。[§2.2–§3.4](https://arxiv.org/html/2606.10531v3#S2)

作者在 2-bit weight-only 条件下比较 Qwen3、Llama-3 等模型，并报告其方法相对若干 PTQ/VQ-QAT 基线的结果与数据效率。[§4–§5.3](https://arxiv.org/html/2606.10531v3#S4) 解读时需保留模型、训练 tokens、benchmark 和对照来源；其中部分基线数字来自先前工作，不应将全表视为同一轮完全控制实验。证据说明受限的可微码本是一个值得研究的 2-bit QAT 方案，不意味着 VQ-QAT 已普遍解决训练收敛或推理性能。

## BitNet b1.58：三值参数是模型训练设计

BitNet b1.58 的权重取值为 `{-1, 0, +1}`，将原先的线性层替换为 BitLinear，并从头训练；论文还采用 8-bit 激活。位宽“1.58”来自三种权重符号的理想信息量 `log₂(3)`，不是说文件、激活、scale、缓存和全部运行状态都严格以 1.58 bit 存储。训练目标也不同于把已训练 FP16 checkpoint 量化：BitNet 必须在优化过程中适应三值权重。[§2–§4](https://arxiv.org/html/2402.17764v1#S2)

作者在相同模型规模和训练 token 设定下比较 perplexity 与任务效果，并报告特定 CPU 推理实现的内存与延迟结果。这支持“原生低比特参数化值得作为模型架构与训练路线研究”，不能推出三值权重已普遍替代后训练量化，或所有硬件都能获得同等推理优势。

## Quartet：让量化训练格式、梯度与 GPU kernel 共设计

Quartet 研究在 Blackwell 支持的 MXFP4 条件下从头训练 Llama-family 模型。它的分析把前向量化误差与反向梯度估计偏差分开：前向更关注低误差重构，反向则更需要梯度方向和幅度能支持优化收敛。作者基于这一权衡选择舍入与误差修正，并实现适配 Blackwell 的 kernel。方法见 [§4.1–§4.4](https://arxiv.org/html/2505.14669v4#S4)，训练和速度评估见 [§5](https://arxiv.org/html/2505.14669v4#S5)。

论文报告的 accuracy-vs-runtime 结论限定于其模型规模、C4 数据预算、MXFP4 格式和 Blackwell kernel；比如性能章节给出 RTX 5090、batch 64、序列长 512 的特定 kernel 测量，不能挪作其他 GPU 或端到端服务延迟。2025 年的 [FP4 All the Way](https://arxiv.org/abs/2505.19115v2) 从不同格式、scale 粒度和舍入策略研究全量化训练，也说明“FP4 训练”内部仍有格式与算法差别。

## 研究关系与判断

阅读时先问量化发生在何时：

- **教师监督的已有模型适配**：LLM-QAT 回答“能否不读取私有预训练语料而用教师输出校正学生”；QATFactory 进一步问训练数值能否与目标推理引擎的实际格式一致。
- **2-bit 权重和 VQ 表示**：AQLM 用多码本搜索做 PTQ，LC-QAT 则将向量码本受限为可微线性映射，作为 QAT 的参数化。
- **从头训练特殊权重表示**：BitNet b1.58 回答“模型能否直接学会三值权重”。
- **训练计算本身降到 FP4**：Quartet / FP4 All the Way 处理前向、反向和优化误差，并依赖具体数值格式与硬件核。

这几条路线的训练成本、可复用模型能力和硬件前提不同。QAT 不等于从头训练；“原生低比特”也不等于现有模型压缩。进一步比较需要固定模型容量、训练数据/token 预算、训练算力、部署格式和评测协议。项目只精读这些代表路线，没有对全部量化训练工作做系统覆盖，也未复现实验。
