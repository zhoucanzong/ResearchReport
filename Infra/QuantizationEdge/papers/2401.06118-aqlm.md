# AQLM：用多个学得的码本压缩权重向量

**原文**：[Extreme Compression of Large Language Models via Additive Quantization](https://arxiv.org/abs/2401.06118v4)，arXiv v4（2024-09-11）。重点位置：§3.1–§3.4、§4.1–§4.4、附录 A、C、I。完整 HTML 原文：[arxiv.org/html/2401.06118v4](https://arxiv.org/html/2401.06118v4)。

## 为什么标量舍入在极低位宽时碰到瓶颈

GPTQ / AWQ 主要为单个权重或小组权重选择尺度与整数值。位宽继续下降时，每个元素可用的离散值变少，量化器难以保留权重组内的组合结构。AQLM 把问题转成向量编码：把一组权重写为来自多个码本的向量之和。多个码本共同组合，得到比一个标量等级更丰富的表达集合。

## 方法：离散代码与连续码本交替优化

给定校准输入，AQLM 先最小化浮点线性层与量化线性层输出之间的误差。它将权重行分组，用若干码本 (C_1,ldots,C_M) 的选中向量相加重建各组。码本是连续变量，索引代码是离散变量，因此不能只对完整权重做一次普通梯度下降。论文从残差 K-means 初始化，然后交替更新离散代码和码本；代码更新使用 beam search，码本更新使用梯度优化。最后可在 Transformer block 级别优化码本、尺度及少数未量化参数，使整个 block 的输出接近原模型。[§3.1–§3.4、Algorithm 1](https://arxiv.org/html/2401.06118v4#S3)

这比标量 PTQ 更有表示能力，但也多了三个工程问题：离散搜索成本、码本自身的存储开销，以及推理时从索引恢复表示并完成矩阵乘的 kernel。名义位宽必须计入码本与元数据，不能把每个权重的索引位数直接当成实际模型文件平均位数。

## 论文证据与边界

论文主要在 Llama 2 家族并补充 Mistral/Mixtral 实验，报告 2–3 bits/parameter 区间的压缩质量、若干 block-level 微调消融和 GPU/CPU 推理实现。实验设置包括校准语料、模型版本和特定 kernel；相关细节见 §4.1–§4.4、附录 C 与 I。这里的证据支持“学得的向量码本能在论文模型上以更低平均位宽保留较多模型质量”，不支持对所有模型、校准数据和硬件都优于 GPTQ/AWQ。

## 与旋转量化的关系

QuaRot / SpinQuant 改变坐标系，让标量量化器看到更容易处理的分布；AQLM 则增加向量组表示的码本自由度。两种路线可组合的可能性，不代表它们组合后一定更好：变换会改变码本要拟合的分布，搜索复杂度和内核布局也随之改变。比较时应分开问：质量提升来自哪个表示变化？它是否能由压缩格式和硬件 kernel 实际利用？

更多跨路线综合见[主报告 §3.5](../report.md#35-现代量化的几条机制路线)。
