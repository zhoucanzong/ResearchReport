# QuaRot：让同一个 Transformer 在旋转坐标中更容易量化

**原文**：[QuaRot: Outlier-Free 4-Bit Inference in Rotated LLMs](https://arxiv.org/abs/2404.00456v2)，arXiv v2（2024-10-29）。重点位置：§3.1–§3.4、§4、§5.1–§5.3、附录 A.3–A.5。完整 HTML 原文：[arxiv.org/html/2404.00456v2](https://arxiv.org/html/2404.00456v2)。

## 问题：为什么只改量化刻度仍会留下很难处理的离群值？

Transformer 的某些残差通道、FFN 激活和注意力缓存会持续出现幅值显著更大的元素。按统一范围量化时，少数极端值会占去大量整数刻度，普通值只能挤在较窄范围里。逐层搜索 scale 或补偿误差可以缓解，却没有改变这些值在张量中的集中分布。

QuaRot 利用 Transformer 中的计算不变性：在一组表示上乘正交矩阵，并把逆变换合并进相邻权重，浮点网络可以保持同一函数；但逐元素量化会对坐标系敏感。因此，旋转前后浮点输出相同，量化误差却可能不同。随机 Hadamard 矩阵的乘法可用快速 Walsh–Hadamard transform 实现，论文把它作为分散通道离群值的实用变换。[§3.1–§3.4](https://arxiv.org/html/2404.00456v2#S3)

## 方法：把变换嵌入模型各处，再量化

论文分两阶段处理。首先用全局 Hadamard 结构旋转残差流及 FFN 表示，并对 attention value 路径作可抵消的变换；随后处理 key/value 表示，让 KV cache 可以落到更低位宽。变换能吸收进线性权重的地方尽量离线合并；不能消掉的在线旋转由 Hadamard 运算实现。其关键不是把所有算子“做成 4-bit”，而是让权重、激活和注意力缓存经过更适合量化的坐标变换后，再分别采用相应量化器。[§4.1–§4.2](https://arxiv.org/html/2404.00456v2#S4)

这条设计路线与 AWQ 的通道缩放不同：AWQ 重分配少数通道的量化动态范围；QuaRot 则改变多个通道共同使用的基底，试图把离群值摊开。旋转不提供额外模型容量，也不保证每个局部张量都会变得更容易量化；它提供的是一种保持浮点函数的重参数化自由度。

## 论文实验说明什么

原文评估 Llama 2 系列的语言建模和 zero-shot 任务，性能测试使用 RTX 3090；激活采用 per-token 对称量化，KV cache 采用带分组的非对称量化，GPTQ 权重量化用 WikiText-2 校准样本。作者报告，在其模型和设置中，旋转后的 4-bit 权重、激活与 KV cache 可以将质量退化控制在有限范围内，并与当时的量化基线比较。[§5.1–§5.2](https://arxiv.org/html/2404.00456v2#S5)

这些结果是作者针对特定 Llama 版本、校准数据、量化方案和 GPU 报告的实验，不是对后来模型、通用 4-bit kernel 或长上下文服务的独立验证。论文另有 clipping、group-wise 和 KV cache 消融；它们支持“组合细节决定效果”，而不支持“旋转单独带来全部收益”。[§5.3、附录 A.3–A.5](https://arxiv.org/html/2404.00456v2#S5)

## 关键取舍与后续关系

- 随机旋转避免了为每个模型反向学习变换，但随机种子可能影响量化结果。SpinQuant 后续把这点变成研究问题：若候选旋转的效果波动较大，能否直接以量化目标学习旋转？
- 在线 Hadamard 变换和 4-bit attention cache 需要相应 kernel；可折叠变换减小运行时开销，却不能替代内核融合和硬件适配。
- 旋转可与 GPTQ 等权重量化器组合，因此“旋转量化”不是单一完整量化器。比较工作时要固定后续 weight quantizer、校准和评测协议。

QuaRot 最适合作为“函数不变变换如何改变量化误差”的机制案例。它不解决码本如何表达低于 3-bit 的权重，也不等同于从头训练低比特模型；这两条路线见 [AQLM](2401.06118-aqlm.md) 和[低精度训练综合](../topics/low-precision-training.md)。
