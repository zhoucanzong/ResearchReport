# When Is a Draft Accepted?：给贪心与树形局部接受条件建立 KL 证书

来源：Sharma, [*When Is a Draft Accepted? A Theory of Acceptance in Speculative Decoding*](https://arxiv.org/html/2606.30265v1)，固定版本 v1（2026-06-29）。重点阅读 §3–§6，尤其 §4.5–§4.9、§5、§6.2–§6.4。

## 它补的理论缺口不是“随机采样是否无损”

经典拒绝采样的目标是输出分布严格等于 target 分布：候选按 draft 分布抽样，接受概率依据 `p/q`，拒绝后从残差分布回补。实际推理还常见确定性贪心、margin 放宽、top-m 和 entropy 门控；这些规则问的是局部 token 是否与 target 的 argmax/阈值一致，不一定输出从 `p` 抽出的随机样本。

本文研究这一不同问题：给定某种接受规则，draft 分布 `q` 与 target 分布 `p` 至少要相差多远，候选才可能被拒绝？作者将拒绝集合写成 target 概率的 lower level set，再求使 `q` 的最高概率 token 落入拒绝集时所需的最小 `KL(p\|q)`。如果实际 KL 小于此阈值，就能**证书式保证**该接受规则不会拒绝当前候选。[§3、§4.1–§4.2](https://arxiv.org/html/2606.30265v1)

## 贪心证书：目标 margin 越大，草稿越难翻转 argmax

严格 greedy 接受只有在 draft 的 argmax 与 target 的唯一 argmax 相同才接受。论文推导所需的精确 KL 阈值只取决于 target top-1 与 top-2 概率形成的 margin；直觉是：若 target 明显偏好 top-1，draft 分布须跨过更大的 KL 距离才会把另一个 token 推成最高概率。[§4.5](https://arxiv.org/html/2606.30265v1)

论文还将框架扩展到 additive / multiplicative relaxed acceptance、top-m 和 entropy-based 判据。树形 greedy 的结果不是“验证树已严格保持随机分布”，而是比较 draft 的候选树是否覆盖 target top-1：在 target 与 draft KL 满足证书时，target greedy token 一定落入树所允许的 top-m 范围。[§4.6–§5](https://arxiv.org/html/2606.30265v1)

## 这和 HSD、RheoSampling 的“无损”不是同一种保证

| 问题 | 本文 | HSD / RheoSampling |
| :-- | :-- | :-- |
| 接受目标 | target 的确定性 greedy / relaxed local criterion | 概率采样下的严格分布保持与序列级接受 |
| 证据形式 | draft-target KL 阈值作为局部接受证书 | 候选路径和残差/概率质量构造的无偏分布证明 |
| tree 结论 | target greedy token 是否落在候选 top-m 范围 | 随机 target continuation 如何在树路径与退出分支间保持目标分布 |
| 不能推出 | stochastic speculative sampling 与 `p` 分布等价 | 所有 relaxed greedy 条件都有 KL certificate |

它也不同于 [Approximate Speculative Decoding](2608.03447-approximate-sd.md)：后者允许 greedy 轨迹偏离，并用 regret 门和预算限制近似风险；本文是在给定 `KL(p\|q)` 的条件下，证明某个局部候选一定通过或落入 top-m，而不是给整段输出的 regret 预算。

## 经验分析测的是证书在模型分布上的覆盖

作者在 Qwen3-1.7B / Qwen3-4B 的生成分布上计算多种规则对应的 KL certificate 分布，报告不同 relaxed threshold 与 tree branch factor 下，有多少解码位置可以获得更大的 certificate。该实验分析的是证书在这些模型/语料生成位置上有多宽，不是端到端速度实验，也不表示运行系统可以无代价地精确获取所有位置的 `KL(p\|q)`。[§6.1–§6.4、Table 2–4](https://arxiv.org/html/2606.30265v1)

**带走的区别**：当接受规则不再是经典随机拒绝采样时，仍可提出可证明的局部稳定性问题；但必须说清证书保证的是哪条规则、哪个 margin/KL 条件和哪一层粒度，不能把“draft 被接受”写成通用的分布等价。
