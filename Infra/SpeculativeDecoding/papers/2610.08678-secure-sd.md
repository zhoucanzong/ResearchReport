# Secure Speculative Decoding for Large Language Models

## 1. 研究问题

严格 speculative decoding 的接受规则保持 target 模型的输出分布。为换取更高接受率，一些有损 verifier 放松了这个约束。本文问：这类分布偏移是否会同样影响通用任务和安全行为？作者把比较对象设为同一输入下的“有损验证”与“标准无损验证”，将 target 行为作为参照，聚焦 jailbreak 与 prompt injection 风险。

威胁模型是黑盒调用：攻击者能提交请求、观察响应，知道 target 模型的大致家族，但不知道 draft 模型、放宽规则、阈值或随机性设置。研究的是 verifier 放宽造成的系统行为差异，不是攻击推理服务实现本身。[§3，PDF p.3]

## 2. 指标口径

论文把分数方向统一成越高越好，再定义：

`PRR = (有损 speculative 的分数 − draft 分数) / (target 分数 − draft 分数)`

PRR 衡量从 draft 向 target 的指标差距保留了多少。安全任务使用 attack failure rate（AFR），因为攻击失败代表拒答更有效；因此 PRR 不是攻击成功率的百分点。SPD 是标准 target 解码墙钟时间与 speculative 解码时间之比。论文另用 acceptance rate（AR）表示接受草稿 token 的比例。[§4.2，PDF pp.4–5]

## 3. 实验设计

安全与效用任务分别覆盖：

- **jailbreak**：Jailbreak-SD 共 200 例，来自 WildJailbreak、JailbreakBench、HarmBench 和 AdvBench。
- **prompt injection**：OpenPromptInjection 200 例；另在 AgentDojo 做长上下文注入评测。
- **效用**：HumanEval 164 道代码题、GSM8K 200 道数学题。

主表比较 LossySD、BiLD、SpecCascade、FSD、FLy 和 MARS，并扫描各方法自己的超参数以形成不同 AR。默认设置 `k=5`、batch 32、temperature 0（贪心）；机器为四张 RTX PRO 6000 Blackwell。论文另测温度 0.3、0.7、1.0。AFR 使用 GPT-4o-mini 作为 LLM judge，因此安全分数也依赖该判分器。[§4.2，Tables 1–3，PDF pp.3–5]

## 4. 发现：安全指标更早偏离 target

Table 1 对六种有损 verifier 的超参数扫描取平均。Qwen3-0.6B/8B 的安全 PRR 为 0.744，效用 PRR 为 0.905；Llama-1B/8B 分别为 0.719 和 0.866。安全任务并没有因此获得更大加速：Qwen 安全/效用平均 SPD 为 1.49× / 1.79×，Llama 为 1.69× / 1.85×。

随 AR 增加，安全 PRR 在部分设置下约 AR=0.3 就开始下降；HumanEval/GSM8K 常到约 0.7 才出现明显退化。这支持作者提出的安全—效用不对称：轻微的输出分布变化可能早早影响拒答或注入抵抗，而常规准确率仍接近 target。[§4.3，Figure 1；Table 1，PDF pp.3–5]

## 5. SecureSD：先收紧开头，再放宽后续

SecureSD 在每个生成位置把标准 verifier 与原有有损 verifier 混合。校正系数 `η=0` 对应标准无损验证，`η=1` 对应原放宽 verifier；中间值在两者间插值。默认 step schedule 在开头若干位置采用更严格的标准验证，随后恢复放宽规则。它不是把整段解码重新变成严格无损：校正窗口之外仍可能采用有损接受。

理论部分将任务分数偏移上界关联到每个位置的输出分布总变差与该位置对最终分数的敏感度。作者用这解释为什么相同规模的偏移若发生在开头，可能比发生在后续位置更影响拒答结果。[§5–§6，PDF pp.6–9]

Table 5 的 SecureSD 默认配置相对原有 verifier：Qwen3 的 Jailbreak-SD / OpenPromptInjection 平均 `ΔPRR=+0.270/+0.114`，对应 `ΔSPD=+0.026/−0.014`；Llama 的 `ΔPRR=+0.042/+0.099`，`ΔSPD=+0.019/−0.001`。这些是**归一化 PRR 的变化**，不是攻击成功率下降的百分点。AgentDojo 的 Qwen 配置中，六种方法平均 PRR 从 0.696 提到 0.808，SPD 从 1.898× 到 1.925×。[Tables 5、7，PDF pp.11–12]

校正长度也依赖模型族：Qwen 的安全收益在 `L=1` 已接近饱和；Llama 到 `L=4` 才收回大部分收益，而进一步扩大窗口会带来速度损失。因此作者的结果支持“按早期敏感位置分配校正预算”，不支持一个对所有模型通用的固定 L。[Table 6，PDF p.12]

## 6. 研究结论与边界

这篇工作补上了现有谱系偏重吞吐、接受率和通用效用的缺口：**对有损 speculative decoding，安全评测不能由常规 utility benchmark 代替**。严格无损方法仍按输出分布等价证明判断；安全退化结果针对放宽 verifier，不能泛化到所有 speculative decoding。

证据范围仍有限：只有 Qwen3、Llama 两个家族；攻击集是受控 benchmark，AFR 借助 GPT-4o-mini 判分；实验主要在给定温度、batch 和四卡 Blackwell 环境中完成。SecureSD 不是安全认证，也没有证明任意攻击者、任务或生产流量下都能恢复 target 的安全行为。作者在论文中提供代码与 benchmark 地址 `https://github.com/YichiCS/Secure-Speculative-Decoding`；本批未拉取仓库、固定其 commit 或运行代码。
