# 长 CoT 中的投机接受会随生成位置衰减吗？

来源：Meng, [*Speculative Acceptance Does Not Decay with Position: A Full-Length Diagnostic on Long Chain-of-Thought with Independent Drafts*](https://arxiv.org/html/2610.30644v1)，arXiv v1（2026-10-22）。重点读 §1、§3–§8，尤其是 §3.2–§3.4 对接受指标的区分、§4–§6 的长位置/高熵诊断，以及 §8 的限制。

## 先分开两种“位置”

长 CoT 中的投机解码常遇到两类位置效应，但它们不是一个问题：

- **draft block 内的位置**：同一轮提出的第 1、2、… 个候选。早位拒绝会使后缀失去提交机会，DFlash 的固定位置衰减、D-PACE 的动态位置权重都在这一尺度上分配训练信号。
- **整段生成中的位置**：从回答开头走到几千或上万个 token 后，草稿与 target 是否越来越难对齐。本文测量的是这条跨长序列的接受轨迹。

因此，本文不直接否定 D-PACE：一个固定 block 内的前缀结构仍然成立。它检验的是另一种常被假定的规律——**独立草稿与 target 生成越久，接受率是否必然持续下降**。[§1、§3](https://arxiv.org/html/2610.30644v1)

## 长序列诊断如何构造

作者用 DeepSeek-R1-Distill-Qwen-7B 作 target，比较两个未在 target 输出上训练的独立 draft：同系列的 DeepSeek-R1-Distill-Qwen-1.5B，以及跨系列的 Qwen2.5-1.5B-Instruct。评测覆盖 MATH-500 的 500 道题、greedy 和 Leviathan sampling；每道题最多生成 16,384 个新 token，四种组合合计约 178 万个验证轮次。采样配置采用 target 的温度与 top-p，记录每个位置的 draft / target 概率。[§3.1–§3.5](https://arxiv.org/html/2610.30644v1#S3)

论文区分两个不能混称的指标：

- `def2` 是 draft token 与 target argmax 相同的**可见排名一致率**；它在 greedy 与 sampling 都能算，但在采样下不是拒绝采样的期望接受概率。
- \(\alpha=\mathbb{E}_{x\sim q}[\min(1,p(x)/q(x))]=1-\mathrm{TV}(p,q)\) 是 sampling 下的**真实单 token 期望接受概率**，需要完整 target / draft 分布。它可在两分布 argmax 排序不同但质量仍重叠较多时保持较高。

这一区分解释了温度升高时为什么“argmax 一致率下降”不一定表示投机解码本身更容易拒绝：分布变平会让两个模型的 top-1 排名更容易互换，但只要它们仍覆盖相近概率质量，\(\alpha\) 可以几乎不变。[§3.2–§3.4、§6.1](https://arxiv.org/html/2610.30644v1)

## 论文报告的现象与解释

去除长输出中的重复自验证循环样本后，作者在支持充分的范围内没有观察到接受率随生成位置下降：greedy 只对 0–8K token 作强结论，sampling 对 0–12K 作强结论；更远位置可用样本很少，论文不外推。配对比较在同一问题内部进行，减少了短题与长题题型组成差异造成的混淆。整体上后半程接受率反而略高，作者将其中一部分归因于后半程数字、运算符等较容易被两模型共同预测的 token 占比上升。[§3.6、§4–§5、Appendix C](https://arxiv.org/html/2610.30644v1)

作者同时发现拒绝更集中于 “wait / however / check” 等反思触发 token，而不是简单集中在序列末尾；跨系列 draft 会放大这类位置上的不一致。温度扫描中，`def2` 降得明显，而 \(\alpha\) 变化很小，说明只用 greedy-match / argmax agreement 诊断 sampling 可能把**排名可见性**误读为**真实接受概率**变化。[§6](https://arxiv.org/html/2610.30644v1)

一项小型 LoRA 干预尝试把训练重点放到反思标记或高熵位置，但没有提高平均接受长度。作者把这个负结果限定为：在这套数据、适配器和训练设置中，单纯模仿 target 轨迹未能修复接受问题；它并没有证明高熵决策点不可改进，也没有证明其它接受感知目标无效。[§7](https://arxiv.org/html/2610.30644v1)

## 它与 D-PACE、长推理衰减工作的关系

| 研究 | 测量/优化的“位置” | 读者应如何连接 |
|---|---|---|
| [D-PACE](2605.18810-dpace.md) / [D-PAL](2610.28355-dpal.md) | **块内**草稿位置；为可能被接受的前缀安排训练权重 | 处理一轮内“前缀越长，后续位置的贡献怎样计算”，不要求跨整个 CoT 的接受率必须递减。 |
| [Acceptance-Aware Training](2609.24150-acceptance-aware-training.md) / [EDR](2610.10411-expected-decoding-rounds.md) | 固定窗口接受长度 / 跨轮状态访问 | 把训练目标更直接连到验收事件或全序列解码轮数；仍需分别检验具体 draft 和推理长度。 |
| [Test-Time Speculation](https://arxiv.org/abs/2605.09329)、[DSpark](https://arxiv.org/abs/2607.05147)、[SharpDraft](https://arxiv.org/abs/2610.05106) | 已训练 drafter 的**长输出/跨生成位置**表现及对应机制 | 训练–推理长度失配、块内依赖与长上下文计算都可能造成退化；不能把其结果简化成无条件的“位置定律”。 |
| 本文 | 未经 target 输出训练的独立 draft，在长 CoT 中的跨位置诊断 | 给出一个没有训练长度失配的基线，并把 sampling 的排名指标与分布接受指标分开。 |

本文与已训练 drafter 的长序列衰减报告不矛盾。作者将既有退化归因于短训练序列被外推到更长推理；如果该解释成立，**未经历这种训练长度失配的独立 draft 不衰减**正是可预期的对照。决定性后续实验仍是把 EAGLE / DFlash 等已训练 drafter 放到相同的全长、同题配对协议中，逐轮记录 \(p,q\)、target top-1 mass 和接受事件；当前论文没有完成这一闭环。[§2.2、§8](https://arxiv.org/html/2610.30644v1)

## 结论能覆盖到哪里

- 这是**诊断测量**，不是一种新 drafter、验证器或加速算法。
- 证据来自一个 target 家族、一种数学推理域、两个 independent draft 和单个 seed；长位置支持范围有限。不能据此宣布已训练 draft 在任意长 CoT 上都不会退化。
- 论文用完整分布测得 sampling 下 \(\alpha\)，但 greedy 轨迹报告的是 argmax 前缀匹配；两种模式的曲线不能不加区分地拼在一起。
- 负向 LoRA 结果只排除当前窄设定下的轨迹拟合增益，不能作“训练无法解决反思 token 接受问题”的普遍结论。

**带走的判断**：讨论“长推理位置效应”前，先确认比较的是块内位置还是整段生成位置，再确认用的是 argmax 一致率还是完整分布的接受概率。否则对长 CoT 的系统退化、D-PACE 的位置权重和采样接受行为会被混成同一个结论。
