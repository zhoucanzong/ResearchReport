# D-PAL：让接受权重看见完整 target 分布

来源：Wu et al., [*Beyond the Point Mass: Acceptance-Derived Weights and Distributional Losses for Speculative Decoding*](https://arxiv.org/html/2610.28355v1)，arXiv v1（2026-10-20）。重点阅读 §2–§4、特别是 §3.1–§3.3、§4.2–§4.4 与 Appendix A–B。

## 从 D-PACE 的“一个 target token”走到分布重叠

D-PACE 以训练样本里的 target token $y_i^\star$ 为单点监督，用 drafter 对该 token 的置信度 $q_i(y_i^\star)$ 近似每位置接受率，再由前缀乘积导出动态位置权重。这个代理对 greedy target 较直观；但在随机 target 下，拒绝采样接受率是 drafter 与 target **完整分布**的重叠，而不只是它们在一个记录 token 上的概率。[D-PACE 对读](2605.18810-dpace.md)

若位置 $i$ 的目标和草稿分布分别为 $p_i,q_i$，标准拒绝采样的单位置接受概率为

\[
\alpha_i=\sum_v\min(p_{i,v},q_{i,v})=1-\mathrm{TV}(p_i,q_i).
\]

D-PAL 将这个 overlap 代入 expected accepted length 的位置权重推导中。其权重为截至当前的平滑前缀 overlap 乘以后续位置的 continuation value；权重从当前 drafter 与 target 分布重算，再 stop-gradient 作为局部损失的系数。[§3.1](https://arxiv.org/html/2610.28355v1#S3)

这不是简单把 D-PACE 的 CE 换成 KL：D-PAL 改了两处。**权重信号**从单 token confidence 变为 full-distribution overlap；**本地拟合损失**则可选择 log acceptance、forward KL 或 Rényi-1/2 等分布损失。若 target 分布是单点，overlap 才退化为 $q(y^\star)$，D-PAL 的权重可还原 D-PACE；D-PAL 的作者正是将其定位为突破 D-PACE point-mass 近似，而非声称 D-PACE 完全没有接受长度目标。[§2.3、§3.1–§3.2](https://arxiv.org/html/2610.28355v1#S3)

## 为什么局部损失还要再选一次

理论上的 D-PAL[LA] 用每位置的负对数 overlap $-\log\alpha_i$；但论文指出 LA 在 $q_i=p_i$ 附近不可微且梯度不自然地保持非零，而 KL 和 Rényi 梯度在匹配处归零。作者发现直接最小化 TV 虽语义上等于优化 overlap，却有很小/不稳的初始化梯度，训练可能塌缩；CE+TV 也可能让 CE 与 TV 梯度冲突。[§3.2–§3.3、§4.2–§4.3](https://arxiv.org/html/2610.28355v1#S3)

D-PAL[KL] 直接拟合 full target 分布的 forward KL；D-PAL[Rényi] 使用 Bhattacharyya overlap 对应的 Rényi-1/2 divergence。论文证明该 divergence 对 total variation overlap 给出上下界，所以拟合它能控制接受重叠的两侧，而单独 KL 的一个方向界可能太松。换言之，**位置权重决定接受路径上哪些位置更值得训练，本地 loss 决定怎样让 $q_i$ 接近 $p_i$**，两者是可区分的设计轴。[§3.2、Lemma 1](https://arxiv.org/html/2610.28355v1#S3)

还有一个从理论到实测的重要边界：标准 $1-\mathrm{TV}(p,q)$ 是 draft token 按 $q$ 采样时的精确单 token 接受概率；论文使用的 SGLang DFlash 后端实际上在 $T=0$ 和 $T=1$ 都提议 draft argmax，并非从 $q$ 采样。作者另证明 overlap/TV 可以界定这种 argmax proposal 的接受表现：$T=0$ 下需结合 target 第一、第二大概率之间的 margin，$T=1$ 下用 target 对该 argmax token 的概率下界。故“按完整分布构造训练信号”不意味着原始 overlap 在所有部署解码规则下就是实测接受率。[§3.1、Proposition 1](https://arxiv.org/html/2610.28355v1#S3)

## 它与 AAT、D-PACE、EDR 的关系

- **D-PACE**：用 $q_i(y_i^\star)$ 作为点质量接受代理，再把它的动态前缀权重用于 CE；主要缺口是 sampling target 的其余概率质量没有进入代理。
- **AAT / WTV**：对固定窗口用实际的 per-position overlap $1-\mathrm{TV}(p_i,q_i)$ 构造窗口接受长度目标，特别覆盖随机采样。它已经显式考虑分布重叠和前缀乘积；D-PAL 不是“第一个把 TV 放进接受目标”的方法。D-PAL 另把目标分成 overlap-derived position weights 与可替换的局部分布损失，并比较 KL/Rényi 的优化性质。[AAT 对读](2609.24150-acceptance-aware-training.md)
- **EDR**：用跨 block/round 的 anchor occupancy 计算整段生成需要的验证轮数；它比 D-PAL/AAT 的固定 block 或 window 目标更全局，但目标量是 rounds，不是每步真实 kernel wall-clock。[EDR 对读](2610.10411-expected-decoding-rounds.md)

可把粒度读作：**记录 token 上的置信代理（D-PACE）→ 完整分布的窗口接受（AAT）→ 完整 overlap 权重和分布损失分工（D-PAL）→ 跨轮状态占用（EDR）**。这是目标建模方式的差别，不是四种方法已在统一设置下排好的性能名次。

## 实验支持什么？

论文在 DFlash drafter 上训练，主要 target 包含 Qwen3-4B，另测 Qwen3-8B、Llama-3.1-8B；主要六基准有 GSM8K、MATH-500、HumanEval、MBPP、MT-Bench 和 Alpaca。Qwen3-4B 主比较采用 100K target-generated 数据、三层 draft、block size 16；训练在 H200，speedup 在 L40S、batch 1 测量，另有并发 batch 与不同温度的敏感度实验。[§4.1](https://arxiv.org/html/2610.28355v1#S4)

在该设置下，作者报告 D-PAL[Rényi] 的六基准平均 MAL 从 D-PACE 的 4.50 提高到 4.56（$T=0$），从 4.20 提高到 4.28（$T=1$）；对应平均 speedup 从 3.11× 提到 3.14×、从 2.79× 提到 2.85×。这里采用 Table 1 与 §4.2 的数字；原文摘要将 $T=0$ 的数值写为 4.57，与表格和正文不一致。结果是作者报告的、特定数据和评测设置下的小幅增益，不能将单一任务最高值外推成普遍收益，也不能把接受长度目标当作 wall-clock 代价模型。[Table 1、§4.2](https://arxiv.org/html/2610.28355v1#S4)

## 失效边界

- D-PAL 训练需取得 target 分布 $p_i$，而不是只用 target 生成的记录 token；词表规模、温度处理和 target logits 的可用性会影响训练成本与适用条件。
- 论文的 overlap 权重来自固定 block 的 target 轨迹；它没有等同于 D-PACE 或 AAT 在任意动态 tree、在线变 block 或 cross-round state 下的目标。
- Rényi-1/2 对 overlap 的数学界有意义，但目标与 accepted length 的关系仍处于论文给定的 draft/target、数据和验证协议内；实际速度还受 drafter、verification kernel 和 batch 影响。
- 本专题没有复算论文均值或运行训练；性能结果均为作者在所述模型、数据、硬件与 benchmark 下报告。
