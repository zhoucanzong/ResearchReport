# Attention Drift：草稿链越长，内部注意力为何逐步离开 target 表征？

> Eldenk et al., [*Attention Drift: What Autoregressive Speculative Decoding Models Learn*](https://arxiv.org/abs/2605.09992v1), arXiv v1, 2026-05-11。重点阅读 §§2–5、Figures 4–16 与 Tables 1–3；它是草稿机制分析与修补研究，不是新的独立 drafter 家族。

## 观察：draft 起步像 target，递归后开始盯着自己

EAGLE-3 草稿器的输入不是普通 token embedding，而是 target 的多层隐藏态融合。第一步因此能接触 target 的表示；后续草稿步则递归消费自己生成的隐藏态。作者观察到：若 target 的注意力集中在序列开头某个 sink token，draft 最初也会复制这一模式；随着草稿链变深，注意力逐步从该 sink 转向最近生成的 draft token。作者把这称为 **attention drift**。[§3、Figures 4–8](https://arxiv.org/html/2605.09992v1#S3)

论文在多种 target 上观察到类似变化：Llama 3.1 的 sink 主要在首 token，Qwen 的在第二 token，GPT-oss 则没有强首 token sink；draft 会跟随对应 target 的起始注意力模式，而后在自生成阶段发生漂移。Qwen3.5 的 MTP head 也呈现从 sink 转向近期 draft token 的趋势。这个现象跨 EAGLE-3 和 MTP 提供了证据，但样本是论文测试的模型与 prompt，不足以证明所有多步 drafter 都存在同样行为。

## 机制诊断：隐藏态残差累积改变了 draft 的工作区间

作者先比较 target 的低/中/高层隐藏态、融合表示和 draft 每一步的隐藏态 RMS。EAGLE-3 的 pre-norm 残差通路在递归草稿步中逐渐放大隐藏态；draft 后续层收到的输入分布因此偏离它从 target hidden states 起步时的输入。作者观察到链深越大，草稿隐藏态幅值持续上升；这与 attention mass 更偏向新生成 token 同步出现。[§4.1、Table 1、Figure 9](https://arxiv.org/html/2605.09992v1#S4)

这是一种**表征在推理递归中的分布变化**，与普通蒸馏误差不同：即使第一步拟合很好，重复用自己的输出作为下一步输入也可能积累误差。长上下文和 chat-template 改动会加重脆弱性，因为提示部分的稳定锚点被改变后，draft 更依赖自生成链条。

## 两项修补：让每一步重新落回可控尺度

论文提出两项要重新训练 drafter 的架构改动：

1. **Post-norm drafter**：在草稿层的残差更新后做归一化，限制链深增长带来的状态幅值累积。
2. **逐 hidden-state RMSNorm**：在融合/注入 target 的低、中、高层隐藏态后分别归一化，避免不同层尺度不一致支配后续 draft 动力学。

这两项修补针对的是“递归状态往哪里漂”而非“draft 的单步 token loss 如何下降”。作者报告 post-norm 在四类 target（Llama 3.1 8B、Qwen3 8B、Qwen3.5 9B、GPT-oss 20B）上提高接受长度，最高约 **12%**；对模板扰动与长上下文任务的接受长度改善更大。另一个作者报告结果是训练期 TTT 深度由 8 降到 4 时仍可泛化到更长推理草稿链，减少训练成本。[§5、Figures 13–16、Appendices B–D](https://arxiv.org/html/2605.09992v1#S5)

**结果口径**：论文大多报告 acceptance length，而不是完整 serving wall-clock；不同 benchmark 中是否计入 bonus token 的口径也有说明。不能把“接受更多 token”直接当作同等比例的时延加速。post-norm 及逐态 RMSNorm 需要重新训练，也不能直接声称适用于所有已发布 checkpoint。

## 与其他草稿训练工作的分工

- **EAGLE-3 TTT** 模拟草稿链上的目标验证，让训练阶段看到类似推理的递归输入；Attention Drift 指出即便 TTT 存在，未归一化状态累积仍会带来深度依赖的偏移。
- **AdaSPEC** 改 token-level KD 的训练位置选择；Attention Drift 改每步的表示尺度和残差动力学。
- **VSD / Acceptance-Aware Training** 改目标函数，使路径或窗口接受性进入训练；它们不自动修复 hidden-state drift。
- **Component-Aware Self-Speculation** 改 drafter 来源，使用 hybrid target 的内部子图；Attention Drift 主要分析 EAGLE-3/MTP 类型递归 drafter，结论不应直接移到 SSM 子图。

这些方案分别改训练轨迹、优化目标、表征结构和 proposal 来源。它们可互补的结构判断不是已做过组合实验；本论文未验证与 VSD/AAT 等目标的联合收益。[草稿与训练横切专题](../topics/draft-side-and-training.md)

## 适用边界与开放问题

- 证据集中在 EAGLE-3 与目标模型自带的 MTP head，不能推广为所有 independent draft、小模型、检索式候选或扩散块草稿都存在 attention drift。
- “sink 被弱化”与“隐藏态幅值增长”是关联机制和干预证据；对每种 target 是否存在同一因果链，仍要看论文的逐模型干预与消融。
- 模板扰动、上下文长度和 draft depth 是相互作用因素；单一 acceptance length 不能替代端到端延迟、显存和并发评测。
- 开放问题：能否在不增加每步归一化开销的情况下校准链深；不同草稿训练目标是否会自然学出稳定的递归状态；attention-free / linear hybrid draft 是否有类似的状态漂移，只是表现为递归记忆偏移而非 attention mass 转移？
