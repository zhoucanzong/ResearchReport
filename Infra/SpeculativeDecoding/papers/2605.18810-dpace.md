# D-PACE：按连续接受机会动态分配 draft 训练权重

来源：Wu et al., [*D-PACE: Dynamic Position-Aware Cross-Entropy for Parallel Speculative Drafting*](https://arxiv.org/html/2605.18810v1)，arXiv v1（2026-05-12）。重点阅读 §2–§3、§4.1–§4.3、§5.4–§5.6 和 Appendix B–C。

## 问题：固定位置衰减没有看当前哪一段在卡接受长度

DFlash 等块式 drafter 一次预测一个 token block，但 target 只接受其中连续正确的前缀：若第 2 个位置被拒，后面即使预测正确，也不能直接提交。常见训练目标却给每个位置独立交叉熵，或用固定的指数衰减权重强调 block 开头；这种 schedule 不会随当前 drafter 的短板移动。

D-PACE 将位置重要性连到一个可微的接受长度代理。设每个位置的条件接受概率为 $a_i$，一段长度至少为 $k$ 的草稿要让前 $k$ 个候选都通过，故

\[
\mathbb{E}[X] = \sum_{k=1}^{B}\Pr(X\geq k)=\sum_{k=1}^{B}\prod_{i=1}^{k}a_i.
\]

这是“前缀通过概率之和”，不是各 token 接受率的平均。更早位置出错会让后续整段失去提交价值，所以它对多个未来前缀的贡献更大。[§3.1](https://arxiv.org/html/2605.18810v1#S3)

## D-PACE怎样近似这个目标

训练时真实 verifier 接受概率 $a_i$ 不可直接拿到。D-PACE 用 draft 对 target 记录 token $y_i^\star$ 的置信度 $q_i=q(y_i^\star)$ 作为代理，再从代理接受长度对每个位置求梯度，导出

\[
w_j=\sum_{k=j}^{B}\prod_{i=1}^{k}\tilde q_i,
\qquad \mathcal{L}_{\text{D-PACE}}=\sum_{j=1}^{B} w_j[-\log q(y_j^\star)].
\]

其中 $\tilde q_i=(1-\alpha)q_i+\alpha$ 只用于稳定权重，CE 项仍使用未平滑的 $q_i$；权重 stop-gradient 后充当动态 credit assignment：哪个位置当前较容易被接受、它对后续前缀还有多大 continuation value，都会影响训练信号。它是**动态的局部 CE 权重**，不是直接对完整 target 分布做 distillation。[§3.1–§3.3、Eqs. 4–9](https://arxiv.org/html/2605.18810v1#S3)

## 关键假设：点质量 target 与随机 target 分布不是一回事

D-PACE 的 $q(y_i^\star)$ 把训练样本里的一个 target token 当作本位置监督对象。对 greedy 解码，target 的实际选择是 argmax，置信度代理较自然；对温度采样，target 可能以不同概率产生多个 token，而 verifier 的拒绝采样接受概率取决于 draft 与**整个 target 分布**的重叠。单个记录 token 的 draft 概率不等于完整分布的接受概率。

因此 D-PACE 的位置权重有一个清晰边界：它改进的是“哪些 block 位置更值得拟合”的动态分配，但其接受代理仍是 target 样本上的 point-mass confidence。D-PAL 将这一问题直接扩展到 full-distribution overlap；它指出当目标分布退化为单点时，其 overlap 权重才还原为 D-PACE 的置信度权重。[D-PAL 对读](2610.28355-dpal.md)

## 论文报告结果怎样读

D-PACE 在其固定的 DFlash block drafter 结构上训练，主实验采用 Qwen3-4B 的 100K target-generated 数据；扩展比较包含 Llama-3.1-8B-Instruct、Qwen3-8B、不同 draft 深度、block 长度及 $T=0/T=1$。训练在 H200，wall-clock speedup 在 L40S 测量，基准包括 GSM8K、MATH-500、HumanEval、MBPP、MT-Bench 和 Alpaca；这些设置是作者报告的训练/推理条件，不是跨硬件或跨 drafter 的通用效果。[§4.1–§4.2、Tables 1–2](https://arxiv.org/html/2605.18810v1#S4)

原文报告 D-PACE 相比 DFlash 固定指数衰减，在若干目标、温度和任务上提高 mean accepted length 与 wall-clock speedup；作者也展示 position weights 会随训练阶段与不同位置的预测置信变化，而非始终使用同一 decay。这里支持的学习结论是“position weighting 可以对齐当前 block bottleneck”；它没有证明置信度等于实际 verifier 接受率，也没有覆盖树分支下的 cross-round 状态访问。[§5.2、§5.5](https://arxiv.org/html/2605.18810v1#S5)

## 与 AAT、D-PAL、EDR 的关系

| 目标 | 位置重要性信号 | 本地拟合信号 | 优化范围 |
| :-- | :-- | :-- | :-- |
| D-PACE | 由 $q(y_i^\star)$ 的前缀乘积推导 | 记录 target token 的 CE | 一个 block 的动态位置权重，点质量代理 |
| [AAT](2609.24150-acceptance-aware-training.md) | 以 greedy 的 EAL 或 sampling 的 WTV 形成窗口接受目标 | 对应规则下的 target argmax 或分布重叠 | 固定 draft window 的连续接受长度 |
| [D-PAL](2610.28355-dpal.md) | 用完整 overlap \(1-\mathrm{TV}(p_i,q_i)\) 推导位置权重 | LA、forward KL 或 Rényi 等分布损失 | 扩展 D-PACE 的 point-mass 假设，并直接拟合全分布 |
| [EDR](2610.10411-expected-decoding-rounds.md) | round-start 状态的 occupancy | round/rejection 成本与状态访问 | 跨整个生成序列的 expected verification rounds |

D-PACE 的主要增量在于位置权重不再是预设常数；它并不是最早关注窗口接受目标的工作，也不是最终 wall-clock 的全局成本模型。AAT 显式比较 greedy 和 stochastic window objectives；D-PAL 从 D-PACE 的点质量近似走到 full target–draft overlap，并允许选择不同局部 loss；EDR 再把 anchor/round 的跨轮访问加入目标。以上工作没有在完全一致的 target、数据、draft 结构、树预算和硬件条件下做统一损失排行榜。[AAT、D-PAL、EDR 对读](../topics/draft-side-and-training.md)

## 阅读边界

- 置信度 $q(y_i^\star)$ 是验收概率的代理；在随机目标分布下，只有完整 overlap 才直接对应 rejection-sampling 接受率。
- D-PACE 的推导针对单一路径、固定 block 的 parallel drafter；不能直接代替动态树或跨轮 occupancy 分析。
- accepted-length surrogate 不含每个 draft/verify step 的实际 kernel 成本；更长的接受前缀不自动等于端到端更快。
- 本精读按 arXiv v1 阅读，没有重新训练 drafter、复算指标或复现实验。
