# AdaSPEC：用参考模型挑选草稿蒸馏信号

> Yuezhou Hu et al., [*AdaSPEC: Selective Knowledge Distillation for Efficient Speculative Decoders*](https://arxiv.org/abs/2510.19779v1), arXiv v1, 2025-10-22；发表于 NeurIPS 2025。重点阅读 §§2–5、Tables 1–4 和 Figure 1。它优化训练时使用哪些 token 的 KD 信号，不改变推理期 draft–verify 算法。

## 为什么不是所有 token 都同样值得蒸馏？

经典 knowledge distillation（KD）让 draft 在所有位置拟合 target 的分布，通常最小化交叉熵或 KL。但一个容量很小的 drafter 未必能吸收 target 的全部预测细节。对投机解码而言，训练每个 token 的成本相同，推理时贡献却不均等：一个可学且能提高 target 接受率的 token，比一个 draft 很难复现、但对下一步接受没有多少帮助的 token 更值得分配有限的训练容量。

AdaSPEC 的问题是：**能否用一个中间能力的 reference model 给训练 token 打“相对可学”分数，再只把一部分 target 知识蒸馏给 draft？** 它并没有直接最大化推理时的接受长度，而是通过选择性 KD 调整训练信号。[§1–3](https://arxiv.org/html/2510.19779v1)

## Reference model 是选择器，不是 drafter 的替代品

方法分两步：先用 target 在任务数据上训练 reference model，作者采用 DistillSpec 式 KD；再比较 target、reference 和 draft 对同一上下文 token 的预测误差。设 \(P\) 是 target、\(R\) 是 reference、\(Q\) 是 drafter，则论文定义：

\[
\Delta_{\mathcal L}(w)=\mathrm{KL}(P(w\mid c)\Vert Q(w\mid c))
-\mathrm{KL}(P(w\mid c)\Vert R(w\mid c)).
\]

作者将这个**相对 loss gap**作为 learnability signal，并选择 \(\Delta_{\mathcal L}\) 排名靠前的 \(k\) 比例 token 来训练 draft；未选中 token 不进入该轮 distillation loss。[§3、Eqs. (6)–(10)、Figure 1](https://arxiv.org/html/2510.19779v1)

读公式时应保留“relative”这个词：它不是 target 的绝对不确定度，也不直接等于该 token 的 speculative acceptance probability。作者将它解释为当前 draft 相对 reference 的改善空间；实现上则按相对分数筛选。因而 reference 的训练质量和所选比例 \(k\) 都会影响被当作“可学”的位置。不能简写成“模型检测所有难 token 并删除”，也不能把它说成直接的接受率 loss。

## 训练流程与实验条件

论文使用两种 draft/target 尺寸组合：Pythia-31M → Pythia-1.4B，以及 CodeGen-350M → Phi-2。五类任务覆盖 GSM8K、Alpaca、MBPP、CNN/DailyMail 和 XSum；比较 DistillSpec，并报告 3-epoch 与按任务调优 epoch 的设置。Reference 与 drafter 从同一预训练模型初始化；reference 先用 target 对任务数据做 KD，再用于筛选 draft 训练 token。[§4.1–4.2](https://arxiv.org/html/2510.19779v1)

作者报告 AdaSPEC 在这些配置和任务上普遍提高接受率，最高提升 15%；提升随 draft/target 容量差增大而更明显。它支持“选择性对齐可能比无差别拟合所有 token 更适合小 draft”的机制判断。实验只覆盖两个模型配对与五类任务，不能说明所有 reference 架构、筛选比例或大型 target 都有相同收益。[§4–5、Tables 1–4](https://arxiv.org/html/2510.19779v1)

## 放在 draft-training 路线中的位置

AdaSPEC 改变的是**哪些训练位置进入 KD**；GRIFFIN 等工作关注训练/推理时 token 与隐藏态的对齐；Attention Drift 追问多步 draft 的内部状态会不会离开 target 表征分布；VSD、AAT 与 EDR 则更直接把 path acceptance、window accepted length 或全局 round count 纳入目标。它们修改的是不同环节，不能只用最终接受长度排序。综合比较见 [草稿与训练横切专题](../topics/draft-side-and-training.md)。

## 边界与开放问题

- Reference model 本身需要先训练，且它与 target/draft 的关系决定 token gap 的含义；reference 不是无成本的普适标签器。
- 论文称“learnable tokens”的操作定义是 target–draft loss 相对 reference loss 的差，不是经验证的真实接受率标签；它更像一种训练数据筛选代理。
- 小 draft / 两个 target-draft 配对限制了结论外推范围。论文的最高 15% 是其任务配置下的作者报告，不代表端到端 wall-clock 加速。
- 论文测试离线任务微调；reference 维护成本、数据域变化后的筛选稳定性，以及与动态树/parallel drafter 的组合仍待研究。
