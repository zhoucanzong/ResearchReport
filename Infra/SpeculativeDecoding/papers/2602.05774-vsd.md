# VSD：把草稿训练从单 token 拟合改成路径接受

> 本文按 arXiv [v6](https://arxiv.org/abs/2602.05774v6) 阅读，首次提交于 2026-02-05、最后修订于 2026-08-12。阅读重点：§3 的目标错位、§4.1–4.4 的变分目标和 EM 优化，以及 §5/Table 1–7 的实验条件与消融。指标均为作者报告，没有独立复现。

## 问题：训练时的 token 似然不是解码时的接受收益

草稿模型通常用 target 的输出轨迹训练：给定前缀，最小化下一 token 的交叉熵或 KL。这个目标让草稿接近 target 的逐 token 分布，但一次投机解码真正消费的是一条**候选路径**：一个 token 被拒绝后，后面的草稿 token 都作废。因而第 4 个草稿 token 的价值取决于前三个是否已被接受，训练时将每个 token 独立计权会忽略这种路径依赖。

VSD（Variational Speculative Decoding）提出的问题是：**能否直接让草稿把概率放到 target 更可能接受的整条路径上，同时避免把它推离 target 的目标分布？** 它改的是 draft training objective，不改推理时的拒绝采样规则；因此论文的“无损”指标准验证仍从 target 分布生成，不意味着草稿本身不会犯错。[§1、§3](https://arxiv.org/html/2602.05774v6)

## 路径接受概率：将多个位置的存活条件乘起来

给定上下文 \(x\)，草稿从 \(q_\psi(z\mid x)\) 产生长度为 \(\ell\) 的路径 \(z=(z_1,\ldots,z_\ell)\)。每个位置接受概率为：

\[
\alpha_i(x,z_{<i})=\min\!\left(1,\frac{p_\theta(z_i\mid x,z_{<i})}{q_\psi(z_i\mid x,z_{<i})}\right).
\]

整条路径都通过验证的概率为 \(\kappa(x,z)=\prod_{i=1}^{\ell}\alpha_i(x,z_{<i})\)。草稿的目标不应只让某个位置的 \(q\) 接近 \(p\)，而应提高从实际草稿路径分布抽到高 \(\kappa\) 路径的概率。[§4.1、Eq. (2)](https://arxiv.org/html/2602.05774v6#S4.SS1)

作者将路径视作潜变量，构造“被 target 接受”的潜在事件，并最大化其边缘概率 \(Z_\theta(x)\)。用 draft 分布作变分分布，可得下界：

\[
\mathcal{L}_{\mathrm{VSD}}(\psi;x)=
\underbrace{\mathbb{E}_{z\sim q_\psi}[\log\kappa(x,z)]}_{\text{偏好可被接受的路径}}
-\underbrace{D_{\mathrm{KL}}(q_\psi(z\mid x)\Vert p_\theta(z\mid x))}_{\text{约束其接近 target 路径分布}}.
\]

它把两种作用显式放在一起：第一项直接奖励通过验证的路径；第二项防止为了提高接受率而把 proposal 推向 target 不支持的轨迹。这里的 KL 不是又把训练退回逐 token distillation：比较对象是**路径分布**，效用项也是路径级的接受概率。[§4.1、Eq. (7)](https://arxiv.org/html/2602.05774v6#S4.SS1)

## EM：从不可直接求的接受后验中采样

接受后验由 target 路径概率和路径接受率共同决定，但对所有可能路径求和不可行。VSD 用 EM 近似优化：

1. **E-step**：从由 target oracle 过滤的后验提议中采样候选路径，并计算接受相关的 path utility；这是训练时查询 target 的步骤，不是推理时额外增加模型。
2. **M-step**：以路径权重训练 draft。Adaptive Rejection Weighting（ARW）让接受价值不同的路径对梯度贡献不同；Confidence-Aware Regularization（CAR）抑制模型对困难/高风险路径过度自信。

这样能把“序列哪些位置互相依赖”传回草稿训练，但成本也更高：训练依赖 rollout / target 评分和多条路径采样，论文的消融显示 proposal 数量 \(S\) 增加会改善结果；作者受计算预算限制，实验最高用到 \(S=40\)。因此它回答的是“如何在给定训练预算下更贴近接受目标”，不是零成本替换原有训练。[§4.2–4.3、§5.2、Appendix B](https://arxiv.org/html/2602.05774v6)

## 作者报告了什么

论文覆盖 LLM 和 MLLM。文本实验包含 LLaMA-3.1-Instruct-8B、LLaMA-3.3-Instruct-70B、Vicuna-1.3-13B 与 DeepSeek-R1-Distill-LLaMA-8B；MLLM 实验用 LLaVA-1.5 7B/13B。主要比较在 batch=1、\(T\in\{0,1\}\) 下报告 speedup ratio 与 mean acceptance length；LLM 任务为 MT-Bench、HumanEval、GSM8K，MLLM 使用 VQA、图表理解和幻觉类 benchmark。模型部署在 RTX PRO 6000（70B 配置用两张）或 L40S；草稿训练从已发布 checkpoint 开始，比较方法采用相同数据与 update steps。[§5、Table 1–3](https://arxiv.org/html/2602.05774v6#S5)

Table 1 中，VSD 加到 EAGLE-3 后，在不同 target、任务和温度下普遍提升作者报告的接受长度与速度比；最大的提升不是一条可泛化的固定倍数。Table 4 的消融显示增加 latent proposals、使用 ARW 与 CAR 均能改变结果；Table 5 的 batch 4/8 结果也仍有相对提升。它支持“路径级训练信号能补充 token 级匹配目标”，但不能据此断言所有 draft 架构、目标模型或服务负载都获得同样收益。

## 与相邻训练方法的区别

| 方法 | 优化对象 | VSD 与它的区别 |
|---|---|---|
| CE / KL distillation | 逐位置预测 target token / 分布 | VSD 以整条路径接受效用作为变分目标，并通过 KL 项限制偏离 target 路径分布 |
| AdaSPEC | 筛掉难拟合 token 后做选择性 KD | 重点是**哪些训练 token 参与对齐**；VSD 重点是**路径被接受的概率及位置间依赖**。见 [draft-side-and-training](../topics/draft-side-and-training.md) |
| Attention Drift | 修正草稿链深增长时的隐状态漂移 | 改输入表征/归一化，不直接改变 VSD 的路径目标 |
| AAT / EAL、WTV | 窗口内最大化预期接受长度，并区分 greedy 与 sampling | 与 VSD 都直接面对接受目标；AAT 的目标按一个 draft window 构造，VSD 用整条 latent path 的变分推导 |
| EDR | 最小化完整序列期望验证轮数 | EDR 显式处理轮次起点 occupancy；VSD 最大化路径接受有效性并约束路径分布，不等同于全局 round-count 最优 |

这些方法研究的训练目标不同，不能只拿各论文最高 speedup 做对比；更合理的问题是它们是否能在同一 drafter、数据、温度、block 长度和 target rollout 上互补或相互替代。

## 边界与阅读顺序

- VSD 的接受效用依赖可采样并可由 target 评估的路径；训练计算量与 proposal 数量是现实限制。论文承认最高只评到 40 条 latent proposals。
- 作者测量的 speedup 受硬件、batch、模型/草稿配置影响。主要实验是单请求设定，不能外推到高并发 serving。
- VSD 不提供一种新的 draft 架构，而是训练目标；如果瓶颈是 draft latency、KV 状态或 verifier kernel，这个目标本身不能解决它们。
- 按 §3 看单链验收概率，读 §4.1、Eq. (7) 理解 path-level ELBO，再看 §4.2–4.4 和 §5.2 判断 EM、方差控制和实验支持到哪里。
