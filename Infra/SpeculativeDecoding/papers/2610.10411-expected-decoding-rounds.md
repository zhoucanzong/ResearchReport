# EDR：把草稿目标从窗口接受长度推进到全序列解码轮次

> 原文：Zhao and Cai, [*Training Parallel Speculative Draft Models by Directly Minimizing Expected Decoding Rounds*](https://arxiv.org/abs/2610.10411v1), arXiv v1, 2026-10-07。本文按 v1 阅读，重点见 §§2–5、Tables 1–3 与 Appendices B–F。结果均为论文报告，不是本次运行或独立复现。

## 问题：并行 draft 的训练位置取决于之前的接受结果

自回归 draft 在任意位置都可以根据完整已生成前缀预测下一 token；并行/半自回归 draft 一次提出一个 block，block 内后续位置还依赖本轮开始位置和此前草稿。某位置最终成为哪一轮的第一个候选，取决于前一轮哪些 token 被 target 接受。于是草稿质量不仅影响**一个 block 内能接受多少 token**，也改变**之后的 round 从哪里重新开始**。

常见 block-local 目标（如 token 级 KL 或一个固定位置权重的 surrogate）主要在局部拟合 draft 与 target，不显式追踪这个跨轮反馈。EDR（Expected Decoding Rounds）问：**能否把整个序列上需要多少次 target verification 当作训练目标？**[§1–2](https://arxiv.org/html/2610.10411v1)

## 一个 round 如何变成马尔可夫奖励过程

论文固定一条由 target 采样的序列 \(x\)。状态 \((n,t)\) 表示已有前缀 \(x_{1:n}\) 已提交，而本轮正验证位置 \(t\)。若草稿在该位置被接受，仍留在当前 round，转到 \((n,t+1)\)；若拒绝，target 修正该 token，并从这个新前缀起一轮，转到 \((t,t+1)\)。draft block 已用尽时同样开启下一 round。每访问一个对角状态 \((t,t+1)\) 就开始了一轮，因此序列的轮数等于访问对角状态的次数。[§3.1、Eqs. (2)–(6)](https://arxiv.org/html/2610.10411v1#S3.SS1)

这一路径依赖可用状态的**occupancy** \(\omega^q_{n,t}\)：它是使用 drafter \(q\) 时，验证过程到达 \((n,t)\) 的概率。拒绝在状态 \((n,t)\) 的概率是该状态的局部 round-start 成本；把局部成本乘以状态访问概率，再沿整条 target 序列求和，就得到该序列期望解码轮数。再对 target 输出序列求期望，即为总体 EDR 目标。[§3.1–3.2、Proposition 1、Eqs. (6)–(12)](https://arxiv.org/html/2610.10411v1#S3)

**为什么这比一个固定位置权重更全局？** 某 draft 位置的拒绝不仅浪费当前 block 的后缀，也决定之后哪些前缀和 block-start 位置会被访问。EDR 将这种反馈写进 \(\omega^q_{n,t}\)；常见 block-local 目标把 round anchors 近似等权，容易忽略某些起点在实际解码中很少或很常出现。[§3.2、§4.2](https://arxiv.org/html/2610.10411v1)

## 精确目标如何变成可训练梯度

定义目标序列的局部拒绝成本 \(c^q_{n,t}\)，以及 draft 产生该状态的访问概率 \(\omega^q_{n,t}\)。EDR 以两者的 occupancy-weighted sum 表示 expected rounds。由于真实 target 输出不可枚举，训练从 target 模型生成的 rollouts 估计期望；论文进一步推导 temporal-difference 形式的梯度，使 draft 参数更新可利用状态价值函数与相邻状态差，而无需对所有生成路径作完整枚举。[§3.2–3.3](https://arxiv.org/html/2610.10411v1#S3.SS2)

论文还提出一个 **offline evaluator**：对同一批 target rollouts 计算两个 draft 的期望轮数，不用每次都实际运行完整 speculative decoding 流程。这使候选 drafter 可以在共享 target 样本上成对比较，减少独立采样引入的差异。它仍然要求有 target 轨迹、draft 条件概率及论文所需的 acceptance 统计；它不是不需要 target 的估计器。[§3.4–3.5、Appendix B](https://arxiv.org/html/2610.10411v1)

## 实验：改了训练目标，没有改 drafter 架构

作者将 EDR 用于两个 parallel / semi-AR drafter：Qwen3-4B 的 DSpark 与 Qwen3-8B 的 DFly，block size 均为 7。训练用 target 生成的 Open-PerfectBlend 轨迹，仅微调 draft 参数；对照为 end-to-end block-local objective（E2E），模型结构、数据、optimizer 与 update steps 匹配。target 和 draft 的采样温度、截断参数按模型设置固定；评测覆盖 9 个数学、代码和对话 benchmark，每种方法对同一组 target 轨迹作配对比较，运行使用 H100 或 H200。[§5.1、Table 1、Appendix D](https://arxiv.org/html/2610.10411v1#S5)

Table 2 报告 one-epoch 后的 **mean accepted length (MAL)**：EDR 在两类 drafter、9 项 benchmark 中总体上高于或持平 E2E。这个结果支持跨 round 的 anchor occupancy 对 parallel draft 训练有作用；它不是端到端服务延迟或 GPU kernel 的直接收益。文章在 §5 的主要结果使用 MAL 展示训练质量，另给出 expected-round count 的离线评估，因此不能把“轮次目标更精确”自动解释为“墙钟必然更快”。[§5.2、Table 2](https://arxiv.org/html/2610.10411v1#S5)

## 与 VSD、AAT 的目标粒度对比

| 方法 | 主要训练对象 | 它显式计入什么 | 尚未等同于什么 |
|---|---|---|---|
| [VSD](2602.05774-vsd.md) | latent draft path 的验证有效概率 | 一条候选路径整体通过概率与 target-path prior | 全输出序列里 round anchors 的访问分布 |
| [Acceptance-Aware Training](2609.24150-acceptance-aware-training.md) | 固定窗口内的 EAL/WTV | 前面通过后，后续位置才有资格被接受；按 greedy/sampling 选择信号 | 跨整个生成序列的 anchor occupancy |
| EDR | 整个 target 序列的 expected verification rounds | 哪些 round-start 状态会被实际访问、每处拒绝造成的新轮次成本 | 每轮真实 kernel/设备耗时与动态硬件代价 |

三者可以读成优化粒度逐渐扩展：**路径有效性 → 窗口接受长度 → 全局验证轮数**。这是一种目标定义上的比较，不代表三种损失可直接累加或已由同一实验做过控制比较。EDR 的作者也明确把 adaptive block size、occupancy/value 计算成本和 target 分布差异列为后续问题。[§6](https://arxiv.org/html/2610.10411v1#S6)

## 边界与开放问题

- EDR 在其固定 speculative block 机制下精确等于期望 round count；但 draft forward、target verify 与分支/窗口大小的 GPU 成本并不必然相等，所以 round count 不是完整 wall-clock 代价模型。
- 训练实验限于 Qwen3 target、DSpark/DFly 两种 drafter和 9 个任务；不能外推为所有 parallel draft architecture 都会受益。
- 当前框架假定固定 block size；高并发中较长 block 可能浪费验证计算，如何把自适应 block length 加进 MRP 是论文明确提出的后续方向。
- EDR 精确目标需要 occupancy/value 计算；相较局部损失，它如何扩展到更长序列、更大 batch 和更复杂 tree topology 仍需研究。
