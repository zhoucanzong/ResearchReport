# Argus：让长程研究运行跨任务保留经过审查的状态

原文：[Argus: A General-Purpose Agentic Reasoning Runtime for Long-Horizon Tasks](https://arxiv.org/html/2608.05144v2)，固定版本 v2。建议读 §3.1–3.3、§4.1–4.5、§5–6 与 §8。

## 问题：难点可能是目标尚未定义清楚

在软件、数学、芯片或材料研究中，Agent 开始工作时不一定能准确知道最终可验证的目标。一次性长对话容易丢掉失败路线、测量结果和目标修正理由；只扩展上下文长度也无法规定谁能修改目标、什么证据能让某个做法被后续任务复用。Argus 将长任务拆成一系列有终态的 mission，并把持续性放在**项目级运行状态**，而不是单一模型 transcript。

## 机制：职责分离、任务契约和持久状态更新

运行时有 Manager、Planner、Engineer、Reviewer 四种角色：Manager 管理项目目标和阶段，Planner 将当前状态切成有边界的任务，Engineer 修改工件或运行工具，Reviewer 在需要时检查真实工件和执行记录。每个 mission 有明确的完成、继续或阻塞结果；未完成时可以保持、回滚或转交，而不是由 Engineer 默默改写整个 campaign 目标。

报告把用户意图、当前操作目标、约束和验证标准分开表示。运行过程可以修订表达或澄清已知歧义；会改变具体目标的更新则要求相应权限确认。Model weights 保持固定，变化发生在持久化 memory、skills、verifiers、routing 和任务状态等运行环境中。候选状态不是因为被模型写出就自动复用，而要依据该状态所能获得的任务原生证据，由拥有该状态面的角色提交。

核心设计取舍是：用 mission 边界管理连续性和重启，用显式角色权限避免“做任务的人自己悄悄改变目标或认证完成”。Reviewer 可以检查产物、要求修订或判定阻塞；但允许某些低风险任务由 Engineer self-review，因此运行时并不声称每个结果都经过独立审查。

## 证据：任务结果与运行时自我演化是两类结论

论文报告七个 benchmark arena 的 task-native 结果，并分析一个 731-task SWE-Bench Pro 顺序轨迹中的 review routing、恢复和资源变化。纵向窗口 W19–22 相较启动窗口 W1–6，作者报告每任务 solve input tokens 少 21%、active time 少 15%。但任务顺序、repo 难度与执行延迟也在变化，作者明确说缺少匹配的 frozen-state replay；因此这是该运行序列中的观察，不能把降幅因果归于某一条 memory 或 skill 更新。

同一轨迹中 Reviewer 路由、官方 verifier 恢复和严格 review-loop rescue 显示“失败后有独立反馈再修订”可以被追踪。作者也明确区分 verifier pass、Reviewer 判断和任务最终正确性：自动检查只能证明其编码的性质，Reviewer 也可能判断错误。该系列结果是系统运行时的证据，不是同一基准下“Agent 比 Agent 更可靠”的统一评分。

## 失效边界与开放问题

- **状态持续不等于状态正确。** checkpoint、event tape 与 skill 会丢失、过时或传递错误；review 质量依赖审查证据和 verifier 边界。
- **Review routing 影响任务难度。** Reviewer 多用于更难或风险更高的工作；观察到的资源与恢复差异不能当作随机实验的因果效应。
- **目标修订的可验证性仍不足。** 作者指出，用户指导的 pivot 尚无公开前瞻评估；需要区分发现目标不充分与失败后的事后合理化。
- **跨域结果不能合成总分。** 七个 arena 使用不同模型、硬件和协议；论文按原始单位报告，并将 SWE-Bench 顺序轨迹和具体研究 campaign 作为不同证据。
- **被记录的外部状态依然有限。** durable project state 和审查 gate 支持跨 mission 连续性，但不能替代对真实外部副作用、不可逆操作和错误 specification 的独立核验。

与[CivBench 精读](2609.02459-civbench.md)合读：Argus 测一个具有持久项目状态、明确 mission 和 review 的运行时；CivBench 提供单个工具环境里主动监控与计划兑现的行为测量。前者不能直接证明 CivBench 指标会改善，后者也不证明跨 mission 自我演化有效。
