# TEPA：让长期记忆能够撤销过时证据

> Yan Zhou、Yue Ouyang、Kaiyang Zheng、Suncheng Xiang，*TEPA: Revoking Stale Memories for Conflict-Robust Language Agents*，arXiv:2608.07429v2（2026-08-10）。[固定版本完整 HTML 原文](https://arxiv.org/html/2608.07429v2) · [arXiv 页面](https://arxiv.org/abs/2608.07429)。本文依据 v2；论文自标为 preprint。

## 记忆的难题不止是“记住新值”

假设 Agent 记住“项目默认使用 CSV 工具”，后来环境改成只接受 JSON。追加式记忆会同时保留两条经验；只按相似度检索时，两条都和当前问题相关。简单的“最后写入覆盖”也可能失灵：Agent 在新环境第一次尝试错了，新值还未成功写入，旧规则便继续指导下一次调用。问题不是旧内容不相关，而是它已经失效，却仍处于可检索状态。

TEPA 将这种现象称为 **memory pollution**：被新证据取代的旧记忆仍参与普通检索，导致有记忆的 Agent 反而不如无记忆。它研究的是一类狭义但重要的更新：能识别同一冲突键下的值变化，并判断旧值是否应撤销。它没有试图解决任意自然语言记忆的全部纠错问题。

## 核心机制：把“有效性”作为记忆状态

TEPA 将一条经验表示为带键值和证据计数的 precedent：冲突键 `k`、断言值 `v`、支持/冲突计数、生命周期状态和创建时间。状态有三种：`Hypothesis`（候选）、`Active`（可被检索）和 `Revoked`（退出普通检索，但保留在归档中）。在该系统里，检索器只返回 Active 记忆；同键的新证据会增加旧值的支持或冲突计数。

这改变了更新的基本动作。追加式方法把新证据加到记忆集合；last-write-wins 直接保留最新值；TEPA 则在新值出现时检查旧值是否应从 active 集合撤销，并在证据充分后提升新候选。撤销按键局部生效，不清空其他领域的记忆；归档保留旧记录，便于审计，也允许未来证据让某个值重新进入有效状态。

默认 TEPA 用 Beta-Bernoulli 后验均值表示某条 precedent 当前仍有效的证据强度：

`q(p) = (s + α) / (s + f + α + β)`

其中 `s` 和 `f` 分别是支持和冲突次数，论文实验使用 `α=β=1`。旧 precedent 在累计至少 5 次观察后，若后验低于 0.3，或最近至少 3 次同键结果的成功率低于 0.34，就会撤销。新值则需要支持计数达到 3 后成为候选，并在后验达到 0.6 时晋升。这里的阈值是论文在其基准上设定的工程规则，不是已证明适用于真实开放记忆的通用常数。

TEPA-Full 另加试执行验证：候选值分别经支持、反事实和跨域污染检查，三次试验中至少 60% 为正且至少一个支持任务成功才晋升。两种操作解决不同问题：验证降低错误新值进入记忆的风险；撤销清除已经被新证据取代、但仍然很容易被检索到的旧值。对偏好更新实验，二者结合优于只加验证的 last-write-wins，说明“写入前筛选”不能替代“旧值失效管理”。

## 实验说明了什么，又没有说明什么

论文用三个自建更新流和一个外部基准测试。受控漂移中，Agent 先积累正确规则，再遇到隐藏规则反转；可执行漂移把任务落到真实文件 I/O 和代码执行，另有稳定 JSON 任务作为控制；偏好流测试用户长期偏好被新会话反馈纠正的情形。前三类各运行 50 个种子、每个种子 160 个任务；任务执行器确定性运行，因而主要比较记忆更新逻辑，而非模型采样波动。原文 §4 与 Appendix C、E 给出了这些条件。

在完整反转阶段，受控漂移的成功率是：TEPA 0.950，append-only 和 last-write-wins 均为 0.210，无记忆 0.309；真实文件执行中的结果分别为 0.950、0.203 和 0.298（Table 2，§5）。因此关键证据不是记忆系统普遍更强，而是**旧经验不撤销时，记忆会比不记忆更糟**；同键撤销能在这类反转后恢复。去掉撤销后成功率降至 0.211（Figure 4），支持撤销机制确实是主要因素。反转后的前几次尝试仍会出错，0.950 也反映规则收集到足够矛盾证据前的适应延迟（§5）。

外部 MemoryAgentBench 的 SH-6k 单跳冲突设置上，TEPA-Rev 与 last-write-wins 都达到 0.890，TEPA-NoRev 为 0.630（300 个问题、3 个查询顺序种子；Table 3）。这说明直接收到明确新事实时，按键覆盖已经足够；TEPA 的生命周期机制优势主要体现在新旧规则需从执行结果中逐渐识别的漂移场景。边界测试也很鲜明：在 MH-6k 多跳设置上只有 0.040，在 SH-262k 超长上下文上为 0（Table 5）。状态有效性不能代替关系链构造和长上下文选择。

## 与已有 Agent 记忆研究的关系

- [AgeMem 精读](2026-acl-long-981-agemem.md)已经让策略调用 `ADD/UPDATE/DELETE`，并联合管理长短期记忆；TEPA 的增量是把有效性显式保存为数据状态，进一步区分候选、可检索、已撤销，以及何种冲突证据触发撤销。AgeMem 的操作学习与 TEPA 的生命周期模型可以互补，不是互相替代。
- [Mem2ActBench 精读](2026-acl-long-370-mem2actbench.md)问记忆能否支撑有历史依赖的工具参数生成；TEPA 追问更新机制何时应让旧经验停止进入检索。前者衡量“找到并用对”，后者隔离“旧值是否仍有效”。工具调用正确率仍不能由 TEPA 的撤销结果推出。
- [JAM 精读](2609.34385-jam.md)保留原始历史，并在请求到来时多步查找、组织证据；它补充了证据来源可回查的路径。TEPA 面向记忆项状态，不提供 JAM 式的按需研究器。将“原始证据归档”与“有效记忆撤销”组合，是一种可研究的架构互补，而非本文实验证明的集成结果。
- [AgentRx 精读](2602.02475-agentrx.md)在执行轨迹中定位不可恢复的失败步骤；TEPA 把执行结果反馈到跨任务记忆的有效性状态。前者诊断轨迹，后者管理后续可复用的经验，不能把失败定位准确率等同于记忆纠错能力。
- [STALE](https://arxiv.org/html/2605.06527v1)补充了 TEPA 的边界：旧状态可能被隐含的新情况推翻，甚至跨属性传播，不存在可直接匹配的同键冲突。TEPA 作者也将开放域隐式冲突列为限制。它提供的是较窄情形下的可撤销机制证据，不是该问题的完整解法。

## 值得带走的研究判断

评估持久记忆时，不能只看召回率、事实准确率或答案分数；还应制造可控反转，比较有记忆和无记忆，并观察旧证据何时离开活动检索集。记忆项应同时表示内容与有效性，必要时还要保存冲突来源和撤销理由。TEPA 的档案提供了“可撤销但不抹去历史”的具体设计样例。

不过，论文实验把冲突键通过 schema 给定或解析出来。键提取噪声从 0 增至 20% 时，受控反转成功率从 0.950 降到 0.777（Appendix C/Table 6）；自然语言里的隐含矛盾、相关事实的级联失效、多用户并发更新、恶意错误反馈和撤销后的再晋升，还没有由这些实验解决。下一步重要问题不是简单扩大记忆，而是：当冲突关系不显式、证据可靠性不一致时，Agent 如何提出可审核的失效假设，并在误撤销后安全恢复？
