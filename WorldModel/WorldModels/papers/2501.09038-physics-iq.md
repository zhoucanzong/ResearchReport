# Physics-IQ: Do generative video models understand physical principles?（2025）

> **一手来源**：arXiv:2501.09038（v1 2025-01-14；本轮抓取最新 HTML 版正文）｜ **主等级**：`[精读原文]`
> **一句话定位**：用一个「只能靠真懂物理才能做对」的真实拍摄基准，证明**视觉真实感 ≠ 物理理解**——当前视频模型物理理解严重受限且与画质无关。它是本专题「不可比性 / 评测」一章的关键证据。

---

## 1. 方法细节（关键设计 / 公式 / 超参）

### 1.1 核心设计：真实拍摄 + 受控物理方差

- **396 条高质量视频** = **66 个物理场景 × 3 视角 × 2 次拍摄**；
- **拍摄规格**：30 FPS、3840×2160（16:9）、Sony Alpha a6400 + 16-50mm 镜头、**静态相机**（无相机运动）；
- **5 类物理**：固体力学、流体动力学、光学、热力学、磁学；
- **physical variance**：同一场景拍两次，量化真实物理过程的内在变异（混沌运动、摩擦微差、力轨迹变化）——这是**用真实方差作参照**的严谨设计。

### 1.2 评测协议

- 把 8 秒视频切成 **3 秒条件段 + 5 秒测试段**；
- **switch frame** 人工精选：既要给足物理事件信息，又要保证「预测后续必须懂物理」（如多米诺第一张刚倒、还没碰到第二张的时刻）；
- i2v 模型只给 switch frame（单帧）；多帧模型（VideoPoet/Lumiere）最多给 3 秒条件帧。

### 1.3 为什么不用 PSNR/SSIM/FVD/LPIPS

- 作者明确论证：PSNR/SSIM 只看像素级相似、不敏感于运动与交互的物理正确性；FVD 看整体分布但不惩罚物理上不可能的动作；LPIPS 看人类感知相似而非物理合理性。**这些指标都不足以判定「懂不懂物理」**。

## 4. 失效边界（明确）

1. **只覆盖 5 类物理、66 个场景**：远非物理全集。
2. **静态相机、无相机运动**：不含视角变化下的物理理解。
3. **模型覆盖不全**：Luma/Veo2 缺席（政策/可得性），结论不代表全部前沿模型。
4. **i2v 与多帧模型输入不对等**：单帧 vs 3 秒条件本身就不公平，横向比较需谨慎——这本身就是「不可比性」的一例。
5. **「物理理解」操作化受限**：把「懂物理」操作化为「预测 5 秒后续」只是一种代理，预测对 ≠ 理解机制。

### 7.2 「physical variance」的严谨性

同一场景拍两次，量化真实物理过程的内在变异（混沌、摩擦微差、力轨迹）。这给「模型预测与真实有多大差距」提供了一个**真实世界的下限参照**——模型预测的偏差如果小于两次真实拍摄的差异，才算「够准」。这是评测设计里少见的严谨做法。

### 7.3 为什么真实拍摄优于合成

许多物理基准用合成数据（Physion、CRAFT 等），引入 **real-vs-synthetic 分布偏移**——在合成上训练的模型可能因此失真。Physics-IQ 用真实拍摄视频克服这一点，加上三视角 + 双拍摄的受控方差，构成更严的评测。

### 7.4 失效边界的延伸讨论

- **物理覆盖不全**：只 5 类、66 场景；
- **静态相机**：不含视角变化；
- **模型不全**：Luma/Veo2 缺席；
- **操作化受限**：「预测 5 秒后续」只是「懂物理」的代理。

### 7.5 阅读路线建议

- 抓核心 → §2（数据集设计 + switch frame）+ §3（评测协议）；
- 看结论 → 摘要「视觉真实感 ≠ 物理理解」+ 逐模型结果；
- 看设计 → physical variance 与真实拍摄的动机段。

**一句话**：Physics-IQ 用一个「只能靠真懂物理才能做对」的真实拍摄基准，定量证明了当前视频模型「画质高 ≠ 懂物理」——这是评测「世界模型」绕不开的证据。

### 7.6 「视觉真实感 ≠ 物理理解」的机制级含义

这条结论对世界模型研究是一记警钟：一个视频模型可以生成**视觉上极逼真**的帧，却完全不懂背后的物理。这直接挑战「next-frame prediction 会逼模型懂物理」的乐观论证（作者 §1 引用并反驳了这套「预测即理解」的说法）。对世界模型而言，它意味着：**能渲染得好看 ≠ 能当可信的环境/模拟器**。

### 7.7 与「世界模型评测」谱系的关系

| 基准 | 测什么 | 数据 | 对世界模型的意义 |
| :-- | :-- | :-- | :-- |

Physics-IQ 是三者中唯一用**真实拍摄**且**专精物理**的——它给出了「物理理解」这条维度的最严下限。

### 7.11 在本专题中的定位

Physics-IQ 是本专题「评测/不可比性」一章的关键实证：它用「只能靠真懂物理才能做对」的真实拍摄基准，定量证明了「视觉真实感 ≠ 物理理解」。这为「评测缺失/碎片化」提供了最锋利的一刀——**画质指标再高，也不能推出物理理解**。它与 VBench-2.0（自动评判、含 Physics 维）与 WorldScore（controllability/quality/dynamics）三者口径互不重叠，是「评测碎片化」的直接证据。

### 7.12 评测协议的完整细节（§3）

- **切分**：8 秒视频 → 3 秒条件 + 5 秒测试；
- **switch frame**：人工精选——给足信息但保证「预测后续必须懂物理」（如多米诺第一张刚倒未碰第二张）；
- **输入适配**：i2v 模型只给 switch frame；多帧模型最多给 3 秒条件帧；逐模型匹配帧率（8–30 FPS）与分辨率（256×256 到 1280×768）；
- **对照**：模型预测 vs 真实拍摄的后续帧，用多个互补指标。

### 7.13 「指标批判」的延伸

作者逐一批判 PSNR/SSIM/FVD/LPIPS：PSNR/SSIM 只看像素相似、不敏感于运动/交互的物理正确性；FVD 看整体分布但不惩罚物理不可能动作；LPIPS 看人类感知相似而非物理合理性。这等于论证：**现有视频生成指标都不足以判定「懂不懂物理」**——这正是「评测碎片化/缺口」的机制级证据。

### 7.15 一页纸记忆点

- **396 视频** = 66 场景 × 3 视角 × 2 拍摄，真实拍摄、30 FPS、3840×2160；

### 7.16 「预测即理解」论证的反驳

作者在 §1 明确引用并反驳了「next-frame prediction 会逼模型懂物理」的乐观论证（类比 LLM 的 next-token prediction）。Physics-IQ 的结果说明：**至少在 2025 年初的模型上，这个论证不成立**——模型可以靠模式复现而非物理理解来生成逼真视频。这直接挑战了「视频生成模型自动成为世界模型」的假设。

### 7.17 与其它「物理基准」的区别

| 基准 | 数据 | 与 Physics-IQ 的区别 |
| :-- | :-- | :-- |
| Physion / Physion++ | 合成 | 物体碰撞/稳定性 |
| CRAFT / IntPhys | 合成 | 因果/直觉物理 |
| VideoPhy / PhyGenBench | 文本描述 | 物理常识（无真实视频） |
| **Physics-IQ** | **真实拍摄** | 真实视频 + 受控物理方差 |

**真实拍摄**是 Physics-IQ 的关键差异——合成数据会引入 real-vs-synthetic 分布偏移，混淆「模型懂不懂真实物理」的结论。
