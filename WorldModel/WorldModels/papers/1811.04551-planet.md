# PlaNet: Learning Latent Dynamics for Planning from Pixels（Hafner et al., 2019）

> **一手来源**：arXiv:1811.04551（v1 2018-11-12；本轮抓取最新 HTML 版正文）｜ **主等级**：`[精读原文]`
> **一句话定位**：提出 **RSSM**（确定 + 随机双分量循环状态空间模型）与 **latent overshooting**（多步变分目标），把「从像素学动力学」推进到能做连续控制；**用 CEM 在线规划（MPC）选动作，不用策略/价值网络**——它是 Dreamer 系的世界模型内核。

---

## 1. 方法细节（关键设计 / 公式 / 超参）

### 1.1 问题设定：POMDP

把环境建成部分可观测马尔可夫决策过程：隐状态 `s_t`、图像观测 `o_t`、连续动作 `a_t`、标量奖励 `r_t`，遵循随机动力学。模型学的是**斜体（近似）动力学** `p(s_t|s_{t-1},a_{t-1})` 对真实（正体）动力学的逼近。

### 1.2 RSSM：确定 + 随机两条路径

- **确定性路径**：`h_t = f(h_{t-1}, s_{t-1}, a_{t-1})`（GRU），承载可预测的部分；
- **随机路径**：`s_t ~ p(s_t | h_t)`（对角高斯），承载多峰 / 不可预测的未来；
- **为什么都要**：纯确定性（GRU）在部分可观测 / 多峰未来下过自信；纯随机（SSM）难训练、缺长期记忆。消融见 §3。

### 1.3 模型组件与目标函数

| 组件 | 公式 | 是否用于规划 |
| :-- | :-- | :-- |
| 转移模型 | `p(s_t \| s_{t-1}, a_{t-1})` | ✅ |
| 观测模型 | `p(o_t \| s_t)` | ❌（只提供训练信号） |
| 奖励模型 | `p(r_t \| s_t)` | ✅ |
| 编码器 | `q(s_t \| o_{≤t}, a_{<t})`（filtering） | 推断当前 belief |

- **观测模型不用于规划**——它只负责给表征一个丰富的训练信号；规划只在潜空间做。这点直接启发后来的「预测什么才算世界模型」之争（对比 MuZero）。
- **Latent overshooting**：把单步 ELBO 推广到多步预测分布的变分目标，缓解长程预测的误差累积。论文 §4 与附录 D 给出推导。

### 1.4 规划：CEM + MPC

- **没有任何策略 / 价值网络**。动作由**在线规划**产生：
  - 用 **CEM**（cross-entropy method）在潜空间搜最优动作序列：初始化时间相关的对角高斯 belief `a_{t:t+H} ~ N(μ_{t:t+H}, σ²_{t:t+H}·I)`，采样 `J` 条候选动作序列、在模型下评估、取前 `K` 条重新拟合，迭代 `I` 次后取 belief 均值；
  - **MPC**：每收到一个新观测就把 belief 重置为零均值单位方差**重新规划**，避免局部最优；
- **动作重复 `R` 次**以降低规划时域、给模型更清晰的信号；
- **迭代采集**：从 `S` 条随机种子 episode 起步，每 `C` 个更新步往数据集加一条新 episode，采集时往动作上加小高斯探索噪声。

### 1.5 动作条件化的形态

动作 `a_{t-1}` 进入 RSSM 的**确定性路径**（`f(h_{t-1}, s_{t-1}, a_{t-1})`）——动作在**潜变量转移层**注入，与 World Models 同族，但转移是确定 + 随机的复合。

### 1.6 与低维先例的区别

作者指出：此前潜变量模型规划只解「cartpole 平衡、2-link 机械臂、稠密奖励」这类简单任务（Watter 2015、Banijamali 2017）；PlaNet 把它推进到接触动力学、部分可观测、稀疏奖励的更难任务。

### 1.7 训练与规划的完整流程（Algorithm 1/2）

**模型学习（Algorithm 1）**：

1. 用 `S` 条随机种子 episode 初始化数据集 `D`；
2. 从 `D` 均匀采样长度为 `L` 的序列块 `{(o_t,a_t,r_t)}`（batch=`B`）；
3. 训练 RSSM（转移/观测/奖励 + 编码器），目标含 latent overshooting；
4. 每 `C` 个更新步：用当前模型规划、加小高斯探索噪声、收一条新 episode 进 `D`。

**规划（Algorithm 2，CEM）**：

1. 初始化时间相关对角高斯 belief `a_{t:t+H} ~ N(μ, σ²I)`（零均值单位方差）；
2. 采样 `J` 条候选动作序列，在 RSSM 下前滚评估预期回报；
3. 取回报最高的 `K` 条重新拟合 belief；迭代 `I` 次；
4. 取 belief 均值 `μ_t` 作当前动作；**收到新观测后 belief 重置**，重新规划（MPC）。

### 1.8 latent overshooting 的直觉

单步 ELBO 只保证「下一步预测准」，长程 rollout 会累积误差。Latent overshooting 把目标推广到**多步预测分布**——让模型对「未来多步」都负责，而不只是下一步。这是它能在稀疏奖励、长时程任务上规划的关键。

## 2. 实验设置与数字（带条件）

| 条件 | 值 |
| :-- | :-- |
| 环境 | DeepMind Control Suite（图像输入，连续控制；含接触动力学、部分可观测、稀疏奖励任务） |
| 规划器 | CEM（种群 `J`、精英 `K`、迭代 `I`）+ MPC（逐步重规划） |

| 对照 | model-free A3C / D4PG |
| **结果** | **最终性能显著超过 A3C，部分任务超过 D4PG**；能解出「以往学习型动力学 + 规划解不出」的任务 |

## 3. 消融与变量

| 变量 | 对照 | 结论 |
| :-- | :-- | :-- |
| 动力学形式 | **RSSM（确定+随机）** vs 纯 GRU（确定） vs 纯 SSM（随机） | RSSM 整体最强；纯确定模型在稀疏奖励任务上退化明显 |
| 目标函数 | 是否加 latent overshooting | 加多步目标后长程预测更稳（纯 RNN 无随机潜变量，不用 overshooting） |
| 规划器选择 | CEM | 选 CEM 因「给定真实动力学时能解全部任务」且鲁棒 |

## 4. 失效边界（明确）

1. **规划开销**：每个动作都要做一次 CEM 搜索 + 逐步重规划——比学好的策略网络慢一个量级（Dreamer 正是为解决此点而生）。
2. **模型不准则规划崩**：作者明说难点多步预测误差累积、多峰未来、训练分布外的过自信。
3. **观测模型是「训练信号」不是「能力」**：重构质量高 ≠ 规划好用——观测重建占用了大量容量在无关细节上（MuZero 抓住这一点做了激进简化）。
4. **任务规模有限**：DeepMind Control Suite 低维连续控制，未及 Atari 级视觉复杂度。
5. **POMDP 过滤的近似**：用 filtering（`q(s_t|o_{≤t},a_{<t})`）推断 belief，历史很长时近似误差累积。

## 5. 与其它系统的可判定对比

| 维度 | PlaNet (2019) | World Models (2018) | Dreamer (2019) |
| :-- | :-- | :-- | :-- |
| 动力学 | RSSM（确定+随机潜变量） | MDN-RNN（纯随机潜变量） | 同 PlaNet 的 RSSM |
| 动作注入 | 确定性路径 `f(h,s,a)` | `P(z_{t+1}\|a_t,z_t,h_t)` | 同 PlaNet |
| 行为从模型怎么来 | **CEM 在线规划**（无策略网） | CMA-ES 离线进化线性 C | **actor-critic 在想象里用解析梯度学** |
| 训练目标 | 观测重构 + 奖励 + latent overshooting | 仅潜变量转移（VAE 重构） | 同 PlaNet |
| 每步规划成本 | 高（每步 CEM 重规划） | 低（C 是查表级线性） | 低（学到的 actor 直接出动作） |
| 观测模型角色 | 训练信号，不用于规划 | 就是状态本身 | 同 PlaNet |

**可判定差异**：PlaNet 与 Dreamer **共享同一个世界模型**（RSSM），差别只在「行为怎么从模型里出来」——PlaNet 在线规划，Dreamer 在想象里学策略。这条是本专题「架构谱系」里**世界模型 vs 行为派生**两个轴分离的关键判例。

---

## 6. 对条目结论的影响

- **坐实 RSSM 作为潜空间动力学的标准件**：Dreamer / DreamerV3 / Dreamer 4 都继承它。
- **「观测模型只作训练信号、不用于规划」** 是本专题「动力学该预测什么」争论的第一个明确立场，与 MuZero「不重构观测」形成对照。
- **「规划开销大」是 Dreamer 把行为派生改成 actor-critic 的直接动机**，支撑谱系里 PlaNet → Dreamer 的演进逻辑。
- **latent overshooting 是「长程预测误差累积」的最早工程对策之一**，与 GameNGen 噪声增强、DreamerV3 free bits 同属「治漂移」工具箱。

## 7. 深挖补遗

### 7.1 数字一览（便于检索）

| 指标 | 值 | 条件 |
| :-- | :-- | :-- |
| 环境 | DeepMind Control Suite | 图像输入、连续控制 |
| 数据效率 | **少 200× 环境交互** | 平均，对照 model-free A3C/D4PG |
| 动力学 | RSSM（确定 GRU + 随机对角高斯） | 消融：RSSM > 纯 GRU > 纯 SSM |
| 规划器 | CEM + MPC（逐步重规划） | 候选 J、精英 K、迭代 I |
| 目标 | 观测重构 + 奖励 + latent overshooting | 观测不用于规划 |
| 评估 | 5 seed × 10 trajectory 中位数 + 5–95 分位 | 图 3 |

### 7.2 与 PILCO / 贝叶斯方法的关系

PILCO（Deisenroth & Rasmussen 2011）用贝叶斯动力学 + 不确定性估计做规划，是「model-based 且知道模型不确定」的先驱；PlaNet 的不同在于**在学到的潜空间里规划**（而非直接在状态/观测空间），并用 **latent overshooting** 处理长程误差——两者都承认「模型不准」，但应对手段不同（PILCO 用不确定性，PlaNet 用潜空间 + 多步目标）。

### 7.3 失效边界的延伸讨论

- **在线规划的延迟**：每个动作都要 CEM 搜索——这在「需要高频控制」的机器人上是硬伤，Dreamer 用学到的 actor 把它摊销；
- **观测模型的「容量浪费」**：重构观测会把容量耗在无关细节上（MuZero 据此做了激进简化：干脆不重构）；
- **稀疏奖励下的高方差**：图 3 中两个任务阴影大，说明稀疏奖励时规划信号弱、结果不稳。

### 7.4 阅读路线建议

- 抓核心 → §3 RSSM + §4 latent overshooting；
- 看规划 → §2 CEM/MPC + Algorithm 2；
- 看失效 → §6 discussion + 图 3 的高方差任务。

**一句话**：PlaNet 把「从像素学动力学」推进到能做连续控制，但「每步都在线规划」的开销直接催生了 Dreamer 的「想象里学策略」。

### 7.6 方法学意义：「观测模型只作训练信号」

PlaNet 最具前瞻性的设计抉择是：**观测模型 `p(o_t|s_t)` 提供训练信号但不用于规划**。规划只在潜空间做。这等于明确表态——**「学会重构观测」不是目的，只是让隐状态学到有用动力学的脚手架**。这一立场直接开启了后续的「世界模型该预测什么」之争：

- **PlaNet**：重构观测（但只作训练信号）；
- **MuZero**：完全不重构观测（只预测 reward/policy/value）；
- **GameNGen**：像素即状态（重构就是交付物）。

PlaNet 处在这条光谱的中间——它最早把「重构」与「规划可用」解耦。

### 7.7 与「世界模型该多大」的关系

PlaNet 的 RSSM 是「足够做规划的最小模型」——作者强调「learning a compact latent space to enable fast planning」。这与后来「世界模型越大越好」（DreamerV3 规模律、Cosmos 平台化）形成对照：**早期潜空间方法追求「够用的紧凑」，后期生成式方法追求「尽量逼真」**。这个张力贯穿整个谱系。

### 7.9 引用注意（何时不该引它）

- 不要说「PlaNet 学了一个能渲染的世界模型」——它的 rollout 在潜空间、不可读，**不能当可交互环境**；
- 不要说「PlaNet 用了策略网络」——它用 CEM 在线规划，**无策略/价值网络**；
- 不要把它的高数据效率（200×）直接平移到高维视觉域——它只在 DeepMind Control Suite 低维连续控制上验证。

### 7.10 在本专题中的定位

PlaNet 是「潜空间动力学 + 规划」这条线的奠基者，也是「世界模型 vs 行为派生」两个轴分离的第一个清晰判例（与 Dreamer 共享同一世界模型、仅行为派生不同）。它对「动力学该预测什么」给出的立场（观测重构只作训练信号）是后续 MuZero「不重构观测」与 GameNGen「像素即状态」两个端点之间的中间点。

### 7.11 训练细节的工程注记

- **动作重复 `R`**：重复每个动作 R 次以降低规划时域、给模型更清晰的信号——这是 RL 的常见技巧（Mnih 2015/2016）；
- **探索噪声**：采集新 episode 时往动作上加小高斯噪声；
- **迭代细化**：从 S 条随机种子 episode 起步，每 C 个更新步加一条新 episode——模型与数据**共同进化**，避免模型在「没去过的地方」过自信。
