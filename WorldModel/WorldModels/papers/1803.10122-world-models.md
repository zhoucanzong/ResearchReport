# World Models（Ha & Schmidhuber, 2018）

> **一手来源**：arXiv:1803.10122（v1 2018-03-27；本轮抓取最新 HTML 版正文）｜ **主等级**：`[精读原文]`（已抓取一手正文并定位到方法 / 实验 / 失效段落）
> **一句话定位**：用「VAE 压缩观测 → MDN-RNN 学动作条件下的潜变量动力学 → 极简线性控制器」的三分解，首次完整演示「在学到的梦境里训练策略再迁回真环境」；它是「潜空间动力学 + 想象训练」谱系的源头。
> **它新在哪**：把「VAE 压缩 + MDN-RNN 动力学 + 极小控制器」三分解组合成闭环，并**在学到的梦境里训练策略再迁回真环境**（不据本次选文断言历史上没有其他先例）。
> **证据强度**：CarRacing-v0 连续 100 次 rollout 均回报 **906 ± 21**（10,000 条随机 rollout 训练、867 参数线性控制器 + CMA-ES）；只在 CarRacing / DoomTakeCover 两个低维域验证；含 `z` vs `z+h` 的表征消融。
> **值不值得引用**：**谱系源头，值得引**；引用「梦境训练」结论时必须带「低维域 + 极小控制器」限定。

---

> **补充核验（2026-10-22）**：已回 [作者正式文章](https://worldmodels.github.io/) 的 Car Racing / VizDoom Experiment / Procedure 段区分两种训练路径：CarRacing 的控制器在真实环境训练，DoomTakeCover 的控制器在模型生成的环境训练后迁移。不能把 CarRacing 906±21 当成梦境训练迁移结果；Doom 的 Controller 参数表为 1,088，不能沿用 CarRacing 的 867。

## 1. 方法细节（关键设计 / 公式 / 超参）

### 1.1 三分解架构（V / M / C）

| 模块 | 职责 | 结构 | 是否看 reward |
| :-- | :-- | :-- | :-- |
| **V（Vision）** | 把每帧图像压成潜向量 `z_t` | 卷积 VAE（Kingma & Welling 2013） | 否（纯无监督重构） |
| **M（Memory）** | 学动作条件下的潜变量动力学 | MDN-RNN（LSTM + 混合密度输出头） | 否 |
| **C（Controller）** | 输出动作 | **单行线性** `a_t = W_c [z_t h_t] + b_c` | 是（唯一接触 reward 的模块） |

- **动力学公式**：`P(z_{t+1} | a_t, z_t, h_t)`，`a_t` 是动作、`h_t` 是 RNN 隐状态。M 输出**高斯混合分布**参数（MDN = Mixture Density Network，Bishop 1994）而非点估计，采样时用温度 `τ` 控制随机性。
- **为什么 M 出分布而非点**：作者明言——确定性动力学模型「若不完美就极易被 agent 钻空子」；MDN-RNN 把环境**近似为随机环境**，即使真环境是确定的，借此引入可控随机性。
- **刻意把 C 做小**：CarRacing 的线性控制器有 **867 个参数**，作者明说「把 agent 的复杂度尽量压进世界模型（V+M）」，用进化算法 **CMA-ES**（Hansen 2016）优化。C 小到「解空间只有几千参数」，正好落在 CMA-ES 的适用区间；单机多 CPU 核并行跑 rollout。

### 1.2 训练流程（三段，彼此解耦）

1. 用**随机策略**收集 **10,000 条 rollout** 作为数据集；
2. 训练 VAE（V）把每帧压成 `z`（最小化重构误差）；
3. 在 `z` 序列上训练 MDN-RNN（M）预测 `z_{t+1}`；
4. 用 CMA-ES 优化 C：CarRacing 使用真实环境回报；Doom 的 M 额外预测终止事件，包装成虚拟环境后在其中训练 C，再迁回真实环境。

> 关键点：V 和 M **完全不知道 reward**；只有 C 接触 reward。这是「世界模型与任务解耦」的最早实现之一。

### 1.3 动作条件化的形态

- 动作 `a_t` 作为 M 的输入参与状态转移（`P(z_{t+1}|a_t,z_t,h_t)`）——**潜变量级**的动作条件化，动作**只影响 M 的转移**，不影响 V 的压缩。
- 与「视频级动作条件化」（GameNGen 把动作注入扩散去噪）是两种机制，见「可判定对比」。

### 1.4 谱系渊源

作者明言本文**不是综述**，而是蒸馏 Schmidhuber 1990–2015 一系列「RNN 世界模型 + 控制器」论文的关键概念；记号沿用《On Learning to Think》（Schmidhuber 2015a）。这把它锚定在一条比 2018 更早的思想线上。

### 1.5 训练超参与实现（正文 / 附录 A）

| 项 | 值 / 说明 |
| :-- | :-- |
| V | 卷积 VAE，把每帧压成潜向量 `z` |
| M | LSTM + MDN 输出头（混合高斯） |
| C | CarRacing 867；Doom 的原文参数表为 1,088 |
| C 的优化器 | **CMA-ES**（Covariance-Matrix Adaptation Evolution Strategy，Hansen 2016），适合「几千参数级」解空间 |
| 并行 | 单机多 CPU 核并行跑多条 rollout 来评估 C |
| 数据 | **10,000 条随机 rollout** |
| 参数量级 | 作者把 V+M 放在 **10⁷ 参数**量级（对比典型 model-free RL 的 10³–10⁶、SOTA 深度模型的 10⁸–10⁹）——**刻意让「世界模型大、控制器小」** |

### 1.6 为什么要「大模型 + 小控制器」

作者的论证（正文 §1）：把 credit assignment 的压力压到一个**小搜索空间**（867 参数的线性 C）上，让 CMA-ES 这类免梯度方法也能解；同时**不牺牲**世界模型的容量与表达力。V 和 M 用反向传播在 GPU 上高效训练，C 则可以用进化这类非传统方法——这个「大头可微、小头可进化」的不对称设计是有意为之。

## 2. 实验设置与数字（带条件）

### 2.1 CarRacing-v0（连续控制）

| 条件 | 值 |
| :-- | :-- |
| 环境 | `CarRacing-v0`（俯视像素输入） |
| 求解标准 | 连续 100 次 rollout 平均回报 **≥ 900** |
| 训练数据 | **10,000 条随机 rollout** |
| 控制器 | 867 参数线性层，CMA-ES 在真实 CarRacing 环境中评估候选策略 |
| **结果** | **906 ± 21**（越过 900 线） |

**表征消融（§3.x）**：C 只看 `z_t`（不看 `h_t`）→ 驾驶「摇摆不稳」（wobbly，图 11）；同时看 `z_t` 与 `h_t` → 稳定（图 12）。说明 `h_t`（M 的隐状态）承载了**对下一步的预测**——这是本架构的关键增益来源，也是「世界模型提供『当下 + 预期』双重表征」的直接证据。

### 2.2 DoomTakeCover（梦境训练 + 迁移）

| 条件 | 值 |
| :-- | :-- |
| 环境 | `DoomTakeCover-v0`（VizDoom；躲开怪物火球；无显式 reward，以存活步数作适应度） |
| 求解标准 | 连续 100 次 rollout 平均存活 **> 750** 步（约 20 秒；每条 rollout 上限 2100 步 ≈ 60 秒） |
| 梦境训练温度 | `τ = 1.15` |
| 梦境内得分 | **959**（1024 条 rollout） |
| **迁回真环境得分** | **1092 ± 556**（100 条 rollout；远超 750 线） |
| 同期 OpenAI Gym 排行榜最佳 | 820 ± 58 |

**关键现象**：梦境里训出来的策略**迁回真环境反而更高分**（1092 vs 梦境内 959），作者将更高的真实环境均值解释为较高温度带来的稳健性；这不是 CarRacing 的对照实验，也不能由两个不同环境均值独立证明因果。

## 3. 消融与变量

| 变量 | 对照 | 结论 |
| :-- | :-- | :-- |
| 温度 `τ` | `τ=0.1`（近确定性）vs `τ=1.15` vs `τ=1.30` | `τ=0.1` 时 MDN-RNN **模式坍缩**、怪物不射火球，策略梦里满分 2100 但真环境**不如随机策略**；`τ=1.15` 得 1092±556；`τ=1.30` 分数更低但回报方差更小（更保守策略） |
| 表征给不给 `h_t` | 只看 `z` vs `z+h` | 只看 `z` → 不稳定驾驶 |
| 优化器 | CMA-ES（进化） | 因 C 仅 867 参数可行；作者也讨论了传统 RL + RNN 的替代 |

## 4. 失效边界（明确）

1. **世界模型可被控制器「钻空子」**（§4.5 Cheating the World Model）：M 是近似概率模型，会生成不符合真实规律的轨迹；控制器会利用这些漏洞找到「对抗性策略」，在梦里高分、真环境失效。**唯一缓解是调温度 `τ`**（用随机性掩盖模型缺陷），治标。
2. **VAE 与任务无关**：无监督重构不知道什么对任务有用——复现了 Doom 里无关的墙砖纹理，却漏掉 CarRacing 里与任务相关的路面瓦块。**与 M 联合训练可缓解，但会牺牲 VAE 的跨任务复用性**。
3. **无分层规划 / 抽象推理**：逐时间步仿真，没有像人一样忽略无关时空细节的能力（作者把它指向 Learning to Think / One Big Net 的方向）。
4. **环境简单**：只在 CarRacing / DoomTakeCover 两个低维环境验证；`z` 的容量有限。
5. **确定性动力学不可行**：作者以 PILCO（贝叶斯不确定性）、Nagabandi 2017（model-based 初始化 + model-free 微调）等作对照，说明「纯确定性模型易被钻空子」是已知难题，本文只是用 MDN 的随机性缓解。

## 5. 与其它系统的可判定对比

| 维度 | World Models (2018) | PlaNet (2019) | MuZero (2019) | GameNGen (2024) |
| :-- | :-- | :-- | :-- | :-- |
| 动力学落点 | 潜变量 `z`（MDN-RNN） | 潜变量 RSSM | **价值/策略/奖励**（不重构观测） | **像素**（扩散去噪下一帧） |
| 动作条件化 | `P(z_{t+1}\|a_t,z_t,h_t)` | `p(s_t\|s_{t-1},a_{t-1})` | `g(s_{t-1},a_t)→(r,p,v)` | 动作流注入扩散去噪 |
| 策略来源 | CMA-ES 线性控制器 | CEM 在线规划（MPC） | MCTS | （只仿真，不管控） |
| 是否重构观测 | 是（VAE 瓶颈） | 是（但观测不用于规划） | **否** | 是（像素即状态） |
| 是否端到端 | 否（V/M/C 三段） | 是（RSSM 联合） | 是（端到端） | 两阶段（RL 采集 → 扩散训练） |
| 防钻空子机制 | 温度 `τ`（唯一） | 随机分量 + overshooting | （不可被「渲染钻空子」，因不渲染） | 噪声增强 |

## 6. 对条目结论的影响

- **坐实「潜空间动力学 + 想象训练」谱系的起点**：Dreamer 系（PlaNet → Dreamer → DreamerV3 → Dreamer 4）的「在潜空间里 rollout、在想象里训练」范式由此而来。
- **「梦境可被钻空子 + 温度缓解」是「世界模型作训练环境」这条线最早的失效边界证据**，直接支撑 topics/world-model-as-env 的「对抗性利用」小节。
- **动作条件化发生在潜变量层**（而非像素层），是 topics/dynamics-and-action-conditioning 中「机制差异」的一个端点。
- **「V/M 不看 reward、只有 C 看 reward」**是「世界模型与任务解耦」的最早实现，支撑「世界模型可跨任务复用」的论点（也埋下 VAE 任务无关的失效）。

## 7. 深挖补遗：训练与推理的完整流程（附录 A 伪代码）

作者给出的完整 agent 流程（伪代码 `rollout(controller)`）：

1. 环境产生观测帧 → V 压成 `z_t`；
2. M 据 `(z_t, a_t)` 更新隐状态得到 `h_{t+1}`（`h_{t+1}` 编码了「下一步会怎样」）；
3. C 取 `[z_t, h_t]` 输出 `a_t = W_c[z_t h_t] + b_c` 作用于环境；
4. 重复直到 episode 结束，返回累计 reward。

**梦境训练**只是把上面第 1 步的「环境」换成「M 自己生成的 `z` 序列」——C 在梦里被 CMA-ES 演化，再迁回真环境评测。这个「把环境整个换成模型」的操作是全文最核心的概念演示。

### 7.1 相关工作定位（正文 §1 的讨论）

- 作者明确把自己放进 **Schmidhuber 1990–2015** 的 RNN 世界模型谱系，而非当作全新发明；
- 对照 **PILCO**（Deisenroth & Rasmussen 2011）：用贝叶斯不确定性估计缓解「模型被钻空子」，但作者指出它**只是部分解决**；
- 对照 **Nagabandi et al. 2017**：model-based 初始化 + model-free 真环境微调——作者指出这仍**依赖真环境微调**，而本文做到了「完全在梦里训练再迁移」。

### 7.2 失效边界的延伸讨论（§4.5 + §5）

- **模式坍缩的具体形态**：`τ=0.1` 时怪物不射火球——MDN-RNN 无法跳到「生成火球」那个高斯分量，说明**随机性不是装饰，而是防钻空子的必要机制**；
- **温度的两难**：`τ` 太低 → 模型太确定、易被钻空子；`τ` 太高 → 梦境太难、策略学不到东西。`τ` 是个**需要手调的超参**，没有自动准则；
- **VAE 复用的取舍**：与 M 联合训练能让 VAE 聚焦任务相关区域，但**牺牲跨任务复用**——这是「世界模型通用性」与「任务特化」的首次明确张力。

### 7.3 为何它是「谱系源头」

它把三件事第一次拼成一个可跑的系统：① 无监督学一个可渲染/可 rollout 的环境模型；② 在这个模型里（而非真环境里）训练策略；③ 迁回真环境。后续 PlaNet/Dreamer 把「可渲染」换成「潜空间」、把「进化控制器」换成「规划/actor-critic」，但「在模型里训练再迁移」这个骨架没变。

### 7.4 数字一览（便于检索）

| 指标 | 值 | 条件 |
| :-- | :-- | :-- |
| 控制器参数量 | CarRacing **867**；Doom **1,088** | 不跨实验共用一个数 |
| 训练数据 | **10,000 条**随机 rollout | CarRacing / Doom 相同 |
| CarRacing 求解线 | **900**（连续 100 次平均） | 作者结果 **906 ± 21** |
| DoomTakeCover 求解线 | **750** 步存活 | 梦境内 **959**（1024 rollout） |
| DoomTakeCover 迁移得分 | **1092 ± 556** | 100 rollout；Gym 榜最佳 820±58 |
| 梦境训练温度 | **τ = 1.15** | `τ=0.1` 模式坍缩、`τ=1.30` 更保守 |
| 单 rollout 上限 | 2100 步 ≈ 60 秒 | DoomTakeCover |
| V+M 参数量级 | **10⁷** | 对照 model-free 10³–10⁶、SOTA 10⁸–10⁹ |

### 7.5 一页纸记忆点

- 世界模型 = VAE（压观测）+ MDN-RNN（学动作条件潜变量动力学）；控制器刻意保持小规模，CarRacing 为 867 参数、Doom 原文表为 1,088。
- 「在梦境里训练再迁回真环境」首次跑通，且梦境更难反而更鲁棒（τ 调高）。
- 最大教训：**学到的环境模型会被策略钻空子**，唯一防线是把模型做成随机的（MDN）并调温度。
- 最大局限：VAE 任务无关、无分层规划、环境太简单。

### 7.6 与认知科学的呼应（正文开篇的论证）

作者用「棒球击球手在视觉信号到达大脑前就挥棒」作类比：人靠的是对球路的**内部预测模型**，在毫秒级本能反应。这个类比奠定了全文的主张——**智能体需要一个对环境的预测模型**，而「学一个可用来规划的内部模型」正是世界模型的认知动机。这不是修辞装饰，而是作者把「predictive model of the future」当作 agent 必备组件的论证起点。

### 7.7 对后续工作的直接启发

- **PlaNet**：把 VAE+MDN-RNN 换成 RSSM（确定+随机），把「进化控制器」换成「CEM 在线规划」；
- **Dreamer**：保留 RSSM，把行为派生换成「想象里 actor-critic + 解析梯度」；
- **DreamerV3**：保留骨架，加鲁棒损失工程（symlog/free bits/twohot/回报归一化）；
- **Dreamer 4**：加 shortcut forcing 实现单 GPU 实时交互，并做到纯离线数据训练。

这条「VAE+MDN-RNN → RSSM → 鲁棒 RSSM → 实时 RSSM」的演进线，正是本专题架构谱系的主干。

### 7.8 阅读路线建议

- 想抓核心概念 → 读 §1–§2（V/M/C 三分解 + 训练流程）；
- 想看数字 → 读 §3（CarRacing）与 §4（DoomTakeCover + 温度消融）；
- 想看失效与局限 → 读 §4.5（Cheating the World Model）与 §5（讨论）。

**一句话**：这篇把「世界模型」从概念变成了可跑的系统，也第一次暴露了「梦境会被钻空子」这个贯穿至今的核心失效模式。
