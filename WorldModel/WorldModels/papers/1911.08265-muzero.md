# MuZero: Mastering Atari, Go, Chess and Shogi by Planning with a Learned Model（Schrittwieser et al., 2019）

> **一手来源**：arXiv:1911.08265（v1 2019-11-19；本轮抓取最新 HTML 版正文）｜ **主等级**：`[精读原文]`
> **一句话定位**：把「学到的模型」**只**用来预测规划直接需要的三个量——**奖励、策略、价值**，**完全不重构观测**；隐状态「爱代表什么就代表什么」。这是对「世界模型 = 预测下一帧」的最大背离，也是「预测什么」轴上的极端点。

## 1. 方法细节（关键设计 / 公式 / 超参）

### 1.1 三个函数 + MCTS

| 函数 | 输入 → 输出 | 作用 |
| :-- | :-- | :-- |
| **表征 `h`** | 历史观测 `o_1..o_t` → 隐状态 `s^0` | 编码过去 |
| **动力学 `g`** | `(s^{k-1}, a^k)` → `(s^k, r^k)` | 递推假设动作产生的隐状态与即时奖励 |
| **预测 `f`** | `s^k` → `(p^k, v^k)` | 出策略与价值 |

- **训练损失**（对 `k=0..K` 步统一回归）：
  `L = Σ_k [ l^r(u_{t+k}, r^k_t) + l^v(z_{t+k}, v^k_t) + l^p(π_{t+k}, p^k_t) ] + c‖θ‖²`
  只惩罚奖励/价值/策略三类误差——**没有任何观测重构项**。
- **规划**：在学到的隐状态动力学上跑 **MCTS**，用 `f` 出的策略/价值引导搜索。

### 1.2 关键设计抉择

- **隐状态无语义约束**：作者明言——没有要求隐状态能重构观测、也没有要求它匹配环境的真实状态。「隐状态可以自由地用任何对预测当前与未来价值/策略有用的方式来表示状态」。
- **动作条件化**：`g(s^{k-1}, a^k)` —— 动作进入**隐状态动力学**（与 PlaNet 同族），但输出不是「下一观测」而是「奖励 + 供下一步规划的隐状态」。
- **相对 AlphaZero 的扩展**：MuZero 复用 AlphaZero 的搜索与「搜索作策略迭代」，但把「给定规则」换成「学到的模型」，并扩展到单智能体域与中间非零奖励。

### 1.3 超参（正文）

| 项 | 值 |
| :-- | :-- |
| 假设步数 | `K = 5` |
| 训练 | 100 万个 mini-batch（棋盘类 batch=2048；Atari batch=1024） |
| 搜索 | 棋盘类每步 **800 次模拟**；Atari 每步 **50 次模拟** |
| 表征网络 | 同 AlphaZero 的卷积 + 残差，但 **16 个残差块**（AlphaZero 用 20），256 hidden planes |

## 2. 实验设置与数字（带条件）

| 条件 | 值 |
| :-- | :-- |
| Atari | **57 个游戏**（Arcade Learning Environment），50 simulations / 每第 4 步搜索一次、动作重复 4 次 |
| 棋盘类 | Go / chess / shogi，**800 simulations / move** 对 AlphaZero 评 Elo |
| **结果（Atari）** | 均值与中位 human-normalized 均**新 SOTA**；**57 个里 42 个**超过上一代 model-free SOTA R2D2；对上一代 model-based SimPLe **全胜** |
| **结果（棋盘）** | 在 Go / chess / shogi 上追平被给了游戏规则的 AlphaZero（MuZero **不知规则**） |
| **Reanalyze 变体** | 200M frames/game，中位归一化得分 **731%**，对照 IMPALA 192% / Rainbow 231% / LASER 431% |

## 4. 失效边界（明确）

1. **完全不可生成**：隐状态不对应观测，**没法从模型里「看」出未来长什么样**——它不是一个能当环境来渲染/交互的世界模型，只是一个规划引擎。**这正好把它排除在本专题的 (a)(b)(c) 判据之外**：它没有学「环境的可渲染动力学」。
2. **依赖 MCTS**：行为强度绑在搜索预算上（800 vs 50 simulations 的差距即是性能差距），没有搜索就没有行为。
3. **只预测了三个量**：任何不在 reward/policy/value 里的环境信息都丢失了——要拿它做「数据合成 / 反事实回放」都不行。
4. **训练成本极高**（100 万 mini-batch × batch 2048），非复现友好。
5. **「learned model」≠「世界模型」**：它自称 learned model，但语义上更像「价值等价的隐动力学」，并无「可交互世界」的含义——这是术语歧义的典型。

## 5. 与其它系统的可判定对比

| 维度 | MuZero (2019) | PlaNet/Dreamer | GameNGen | Genie 3 |
| :-- | :-- | :-- | :-- | :-- |
| 隐状态是否重构观测 | **否** | 是（重构只作训练信号） | 是（像素即状态） | 是 |
| 动作条件化 | `g(s,a)→(r,p,v)` | RSSM `f(h,s,a)` | 动作注入扩散 | 动作逐帧 |
| 行为来源 | MCTS（在学得隐动力学上） | CEM / actor-critic | 不产行为 | 人 / agent 交互 |
| 能否当「环境」渲染 | **否** | 部分（潜空间 rollout 不可读） | **是** | **是** |
| 归属本专题判据 (a)(b)(c) | **(a)✓ (b)✗ (c)✓** → **不入**（产出非可交互环境） | 入（作训练环境） | 入 | 入 |

**可判定差异**：MuZero 是「预测什么」轴上**最不重构观测**的端点；它证明了「规划需要的只是 reward/policy/value」，但**也因此不能当作可交互环境**——这是本专题把 MuZero 判为「世界模型的近亲而非世界模型」的依据。

## 6. 对条目结论的影响

- **为「预测目标」维度提供极端对照**：PlaNet「观测重构只作训练信号」→ MuZero「完全不重构观测」→ GameNGen「像素即状态」，构成一条完整的光谱。
- **支撑边界判据 (b)**：MuZero 的模型是「给系统用的」，但产出的是规划量而非可回放环境——判为**不入**本专题、归 RL 决策侧，与本专题「环境/状态演化」的判据形成互证。
- **「世界模型」一词在 RL 语境的歧义**由它最典型：MuZero 自称 "learned model" 但并无「可交互世界」。

## 7. 深挖补遗

### 7.1 数字一览（便于检索）

| 指标 | 值 | 条件 |
| :-- | :-- | :-- |
| Atari 覆盖 | **57 个游戏** | 42 个超 R2D2；对 SimPLe 全胜 |
| Atari 搜索 | **50 simulations / 每 4 步一次** | 动作重复 4 次 |
| 棋盘搜索 | **800 simulations / move** | Go/chess/shogi 对 AlphaZero 评 Elo |
| 训练 | **100 万 mini-batch** | 棋盘 batch=2048、Atari batch=1024 |
| 假设步数 | **K = 5** | 预测未来 5 步的 reward/policy/value |
| Reanalyze 中位得分 | **731%** | 200M frames/game；对照 IMPALA 192 / Rainbow 231 / LASER 431 |
| 网络 | 16 残差块、256 hidden planes | AlphaZero 用 20 残差块 |

### 7.2 训练损失的完整形态

`L = Σ_{k=0}^{K} [ l^r(u_{t+k}, r^k_t) + l^v(z_{t+k}, v^k_t) + l^p(π_{t+k}, p^k_t) ] + c‖θ‖²`

三项分别对齐：观测到的真实奖励 `u`、搜索改进后的价值目标 `z`、搜索改进后的策略目标 `π`。**没有任何一项要求隐状态能重构观测**——这是与 PlaNet/Dreamer 最本质的分歧。

### 7.3 与 AlphaZero 的关系

MuZero = AlphaZero 的搜索/策略迭代 + **学到的模型**替代「给定规则」。它把 AlphaZero 从「需要完美模拟器（游戏规则）」推广到「动力学未知」的域（Atari、单智能体、中间非零奖励）。棋盘类追平 AlphaZero 是关键证据：**学出的模型足以支撑围棋级规划**。

### 7.4 失效边界的延伸讨论

- **不可渲染**：隐状态无语义，无法「播放」未来——它不是「可交互环境」，只是规划引擎；
- **搜索即行为**：800 vs 50 simulations 的差距就是性能差距——行为质量绑在搜索预算上，没有廉价推理路径；
- **只预测三量**：reward/policy/value 之外的环境信息全丢，不能用于数据合成或反事实回放。

### 7.5 阅读路线建议

- 抓核心 → §3 MuZero Algorithm（三函数 + 损失）；
- 看数字 → 图 2 + Table S1（57 Atari）+ Reanalyze 段；
- 看边界 → 注意它**不提供**任何「可交互世界」。

**一句话**：MuZero 证明「规划只需要 reward/policy/value」，但代价是它**不再是一个能渲染的世界模型**——这正是本专题把它判为「近亲而非世界模型」的原因。

### 7.6 「隐状态无语义约束」的哲学

MuZero 最激进的宣言是：隐状态**不需要**能重构观测、**不需要**匹配环境真实状态、**没有任何语义约束**——「隐状态可以自由地用任何对预测当前与未来价值/策略有用的方式来表示状态」。这把「模型」从「对世界的模拟」彻底变成「对规划有用的工具」。作者甚至说「智能体可以**在内部发明**那些能带来最准规划的规则或动力学」。

### 7.7 与「可交互环境」的断裂

- **PlaNet/Dreamer**：潜状态 rollout 虽不可读，但理论上能通过解码器重建成观测（部分可渲染）；
- **GameNGen/Genie 3**：像素级，直接可渲染可交互；
- **MuZero**：隐状态**没有任何重构回观测的路径**——它甚至不能告诉你「下一步长什么样」。

这条断裂是判据 (b)「系统可调用作环境」的关键：MuZero 的模型给系统用（MCTS 规划），但**产出的不是可回放的环境**。

### 7.8 训练成本与复现性

100 万 mini-batch（棋盘 batch=2048、Atari batch=1024）+ 每步 50–800 次 MCTS 模拟——训练与推理都极重。这让 MuZero 成为「最强但最难复现」的一档：它不是「下载权重就能交互」的世界模型，而是一套需要完整 RL 基础设施的系统。

### 7.10 引用注意（何时不该引它）

- 不要把 MuZero 说成「世界模型」并暗示它能渲染/交互——它**完全不可生成**，隐状态无语义、无重构回观测的路径；
- 不要说「MuZero 学了环境动力学模型」而不加限定——它学的是「价值等价的隐动力学」，与「可渲染环境动力学」是两回事；
- 不要把它的 MCTS 搜索预算（800/50 simulations）当成模型本身的能力——行为强度绑在搜索上。

### 7.11 争议点：它到底算不算「世界模型」

这是本专题的一个真争议。按本专题判据 (a) action-conditioned ✓（`g(s,a)`）、(c) 动力学从数据学得 ✓，但 **(b) 系统可调用作环境 ✗**（产出是规划量，不是可回放环境）——因此**判为不入**本专题。但 RL 文献普遍把 MuZero 的 learned model 称为 world model。本专题的立场是：**术语上以「可交互环境」为准**，MuZero 这类「规划用隐动力学」归入决策/RL 侧，与世界模型形成对照而非同类。

### 7.12 Reanalyze 的机制

Reanalyze 变体用**最新网络参数重跑 MCTS**，为旧轨迹提供新目标——这显著提升了小数据档的样本效率（200M frames/game 下中位 731%）。它本质上是「用改进后的模型重新标注历史经验」，是「世界模型/搜索改进训练目标」的一个范例。

### 7.13 训练/推理成本细节

- **训练**：100 万 mini-batch（棋盘 batch=2048、Atari batch=1024）；
- **推理**：棋盘每步 800 次 MCTS 模拟、Atari 每 4 步搜一次（50 simulations）；
- **网络**：表征/动力学同 AlphaZero 架构但 16 残差块（AlphaZero 用 20）、256 hidden planes。

这些数字说明 MuZero 是「算力换性能」的极端——它**不适合**「下载权重就交互」的用法。

| 符号 | 含义 |
