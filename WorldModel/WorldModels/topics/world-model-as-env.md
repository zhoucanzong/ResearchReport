# 横切专题：世界模型作训练 / 评测环境

> **定位**：把「把学到的世界模型当成训练环境或评测环境」这条线单独抽出来——它贯穿 World Models（梦境训练）、Dreamer 系（想象训练）、UniSim（通用模拟器零样本真机）、Dreamer 4（纯离线训练）。
> **证据口径**：本页结论凡出自 `../papers/` 十篇分册的标 `[精读原文]`；凡引用**未精读**的近期工作（如 Dreamer 4、WorldScore）一律标 `[摘要级]`，其证据强度与前一类不同。

---

## 0. 本章结论

1. **「在模型里训练再迁移」是贯穿 2018 至今的主线**：World Models（梦境训练 + 进化控制器）→ PlaNet（模型内规划，无策略网络）→ Dreamer（想象训练 + actor-critic）→ DreamerV3（固定超参跨 150+ 任务）→ Dreamer 4（纯离线，`[摘要级]`）。`[精读原文]`
2. **这条线的核心失效模式只有两个**：① 模型被策略钻空子（对抗性利用）；② 模型误差直接变成策略误差（误差传播）。`[精读原文]`
3. **「零样本真机」的最强实证是 UniSim**，但它是**域内零样本**（仿真数据来自真机域）——引用须带这个限定。`[精读原文]`
4. **「世界模型作评测环境」目前几乎不存在**：评测仍靠真实环境或独立 benchmark——学到的模型当评测环境是明确空白。`[精读原文]`
5. **环境的质量不是"像不像"，而是"能不能支撑策略学出可迁移行为"**：World Models 里梦境训练反而迁移得更稳；DreamerV3 里模型变大**同时**提高分数与降低所需交互——这两条是"模型即环境"的价值证据。`[精读原文]`

## 1. 五种「用模型替代/补充环境」的形态

| 形态 | 代表 | 机制 | 部署 | 失效主因 |
| :-- | :-- | :-- | :-- | :-- |
| 梦境训练 | World Models (2018) | 在 M 生成的梦境里用 CMA-ES 演化线性 C | 迁回真环境 | 梦境被钻空子（τ 缓解） |
| 模型内规划 | PlaNet (2018) | CEM + MPC 在潜空间逐步重规划，**不学策略** | 真环境 | 规划开销 + 模型不准 |
| 想象训练 | Dreamer / DreamerV3 | 在 RSSM 潜空间 rollout 里学 actor-critic（解析梯度） | 真环境 | 想象误差 → 策略误差 |
| 通用模拟器 | UniSim (2023) | 多源数据编排成「动作进-视频出」模拟器 | **零样本真机**（域内） | 数据集信息鸿沟 |
| 纯离线想象 | Dreamer 4（`[摘要级]`） | 纯离线数据在想象里训练 | Minecraft 取钻石 | 离线数据分布 |

证据：各篇分册（[world-models](../papers/1803.10122-world-models.md)、[planet](../papers/1811.04551-planet.md)、[dreamer](../papers/1912.01603-dreamer.md)、[dreamerv3](../papers/2301.04104-dreamerv3.md)、[unisim](../papers/2310.06114-unisim.md)）。

## 2. 逐系统的「环境 → 策略」证据表（全部带条件）

| 系统 | 环境 / 域 | 训练在哪 | 关键数字（带条件） | 部署条件 |
| :-- | :-- | :-- | :-- | :-- |
| World Models | CarRacing-v0（俯视像素） | V+M 内在**梦境**里训 C（10,000 条随机 rollout，867 参数线性层 + CMA-ES） | 连续 100 次 rollout 均回报 **906 ± 21**（求解线 ≥900） | 迁回真环境；温度 τ 抑制钻空子 |
| PlaNet | DeepMind Control Suite（图像） | **不训练策略**，每步在模型里 CEM 搜索 + MPC 重规划 | 平均比 model-free（A3C/D4PG）**少约 200×** 环境交互 | 真环境在线规划（每步一次搜索，慢一个量级） |
| Dreamer | DMC 20 任务（图像） | 潜空间 rollout 内 actor-critic | **5×10⁶ 步平均 823** > D4PG 在 **10⁸ 步**的 786；**20 任务 16 胜 4 平** | 真环境；每 10⁶ 步约 3 小时（PlaNet 11、D4PG 24） |
| DreamerV3 | **150+ 任务**（locomotion/manipulation、Atari、ProcGen、DMLab、Minecraft 等） | 同上，**固定一套超参** | 固定超参下超过各自调参的专家算法；**首个从零在 Minecraft 拿钻石** | 真环境；规模律：模型变大 → 分数更高**且**交互更少 |
| UniSim | 长时程视觉-语言策略 + 低层 RL | 纯仿真数据（多源编排） | 真机 **Language Table 零样本**；Habitat/HM3D 低数据域**仅 700 样本**；连续 **8 次指令**交互保持被操作物体状态 | 真机部署；**域内**零样本；域标识符提升域内质量但伤泛化 |

**读法**：这张表把"世界模型当环境"的价值拆成三个可核对的量——**省交互**（约 200×）、**省时间**（3h vs 24h per 10⁶ 步）、**提鲁棒**（梦境训练迁移后更稳）。

## 3. 两个核心失效模式（机制级）

### 3.1 对抗性利用（exploiting the world model）

- **World Models §4.5**：MDN-RNN 是近似概率模型，会生成不符合真实规律的轨迹；控制器会利用这些漏洞找到对抗性策略（**梦里高分、真环境失效**）。作者给出的缓解只有**把模型做成随机的并调温度 τ**——治标。`[精读原文]`
- **机制**：策略在模型里训练，会**过拟合到模型的缺陷**；模型越好、缺陷越隐蔽，策略越可能贴着缺陷生长。

### 3.2 误差传播（model error → policy error）

- **Dreamer**：策略完全在世界模型内训练，模型差则梯度差、策略差；作者把"更高视觉复杂度环境"列为 future work。`[精读原文]`
- **DreamerV3**：用鲁棒损失工程（symlog、free bits、KL 平衡、回报归一化）让误差**跨域可控**，但**不消除**——本质仍是"想象里训练"。`[精读原文]`
- **PlaNet**：多步预测误差累积、多峰未来、训练分布外的过自信——正文级表述的"模型不准则规划崩"。`[精读原文]`
- **与对抗性利用的区别**：前者是「策略主动钻空子」，后者是「模型被动不准」；两者共同前提是**世界模型必须足够好**。

**推论（判据）**：判断一个"世界模型当环境"的工作是否可信，先问两句——**它怎么防钻空子？它怎么界定误差传播的边界？** 只报"在模型里训练成功"而不交代这两点的，证据强度都要打折。

## 4. 「零样本真机」的证据强度分级

| 系统 | 部署形式 | 证据强度 | 限定条件 |
| :-- | :-- | :-- | :-- |
| World Models | 梦境训练 → 迁回真环境 | 中 | 低维域（CarRacing / DoomTakeCover），`z` 容量有限 |
| PlaNet / Dreamer | 模型内规划/训练 → 真环境 | 中 | 以 DMC 低维连续控制为主，未及 Atari 级视觉复杂度 |
| DreamerV3 | 想象训练 → 真环境 | 中高 | 跨 150+ 任务且固定超参，但**仍是同一批域内**；"Minecraft 取钻石"≠通用性证据 |
| **UniSim** | 纯仿真 → **零样本真机** | 中高 | **域内**（仿真数据来自该真机域 Language Table）；跨域时域标识符不可用 |
| Dreamer 4（`[摘要级]`） | 纯离线数据 → Minecraft | 未定（本轮未精读） | 上报为"无环境交互"，需回原文核对口径 |

**引用红线**：UniSim 的"零样本真机"是**域内**的——真机验证域的仿真数据正来自该域。**它不是跨域零样本的证据**；写"零样本迁移"时必须带这个限定，否则属于**升格证据**。

## 5. 「作评测环境」是空白（可核对的缺口）

- 目前评测仍靠**真实环境**（Atari / DMC / Language Table）或**独立 benchmark**（[VBench-2.0](../papers/2503.21755-vbench-2.md) / [Physics-IQ](../papers/2501.09038-physics-iq.md) / WorldScore `[摘要级]`）；
- **「用一个学到的世界模型当评测环境」**（在模型里评测策略，而非在真环境）**几乎没有工作**——这是明确的空白；
- **为什么空白**：模型不够准时，在里面评测的分数**不可信**；这与 §3 的两个失效模式是同一个原因，详见 [incomparability-checklist.md](incomparability-checklist.md) §5。

## 7. 失效条件（本专题自身的边界）

1. 本页把"作环境"限定为**用学到的模型产生训练/评测信号**；**模型内规划**（PlaNet / MuZero）严格说是"用模型替代环境查询"，列入本页只为机制对照，**判据归属**见 [dynamics-and-action-conditioning.md](dynamics-and-action-conditioning.md) §7。
2. UniSim 的真机结论**只有一个域**（Language Table），其余域只有仿真；**不得外推**。
3. **Dreamer 4** 本轮**未精读**，其"纯离线 + 单 GPU 实时"的说法标 `[摘要级]`，不作为本页结论证据。
4. 本页所有数字**都带条件**（环境/步数/硬件）；脱离条件引用即为不可比——这正是 [incomparability-checklist.md](incomparability-checklist.md) 处理的问题。

## 8. 训练信号是怎么构造的（机制细节）

"在模型里训练"听起来简单，实际每种形态都要先回答一个工程问题：**在模型内怎么得到训练信号？**

| 形态 | 信号来源 | 关键设计 | 代价 |
| :-- | :-- | :-- | :-- |
| 梦境训练（World Models） | **真环境的回报**在梦里被"想象"出来（C 在 M 生成的轨迹上评估） | C 只有 867 参数、用 CMA-ES 演化——**可搜索空间极小**，是对噪声的天然防护 | 只能训极小控制器；不适用高维策略 |
| 模型内规划（PlaNet） | 无训练信号（不训练策略），每步用 **CEM 的评估值**选动作 | 规划器把模型当"打分器"用 | 每步一次搜索，慢一个量级 |
| 想象训练（Dreamer / DreamerV3） | **在好的轨迹上给高奖励**，用**价值模型估计想象时域之外的回报** | 解析梯度穿过想象动力学（要求动力学可微且较准） | 想象时域固定 → 短视风险；模型误差直接进梯度 |
| 通用模拟器（UniSim） | 视频帧 + 动作标注（多源编排） | 零样本策略训练；逆动力学把视频还原为机器人动作 | 信息鸿沟；域标识符伤泛化 |
| 纯离线想象（Dreamer 4，`[摘要级]`） | 离线数据 + 想象 rollout | 本轮未精读 | — |

**读法**：这张表回答"**为什么同一个世界模型可以有完全不同的训练协议**"——因为训练信号的来源不同：真回报（World Models）、模型打分（PlaNet）、价值估计（Dreamer 系）、视频动作对（UniSim）。

## 9. 迁移/部署矩阵（在线 vs 离线、域内 vs 跨域）

| 维度 | 取值 | 代表 | 证据强度 |
| :-- | :-- | :-- | :-- |
| **交互需求** | 在线交互（边采边训） | World Models / PlaNet / Dreamer / DreamerV3 | 中（域内） |
| | 纯离线（无环境交互） | Dreamer 4（`[摘要级]`） | 未定（本轮未精读） |
| **部署方式** | 模型内训练 → 真环境执行 | Dreamer 系 | 中 |
| | 纯仿真训练 → **真机零样本** | UniSim | 中高（**域内**） |
| **域关系** | 域内 | 上述全部 | — |
| | 跨域 | **未见有力证据** | — |

**结论**：这条线上**"跨域零样本"是空的**——现有最强证据（UniSim）是域内。引用时要严格区分。
