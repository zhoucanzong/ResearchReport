## 七问

### 1. 解决什么问题？

把动作条件视频生成器当作 VLA 的虚拟 RL 环境，面临两种相连的错误：动作跟随不精确时，轻微偏差仍可能被生成成成功；同时，若奖励由错误视频另行估计，RL 信号也不可靠。策略更新后又会产生新的动作与失败模式，固定世界模型可能逐渐与策略脱节。论文分别用近成功数据、联合奖励—视频预测和数据回灌循环处理这些问题（v2 §1、§3、Fig. 1–3）。

### 2. 核心方法是什么？

**SANS**（Success and Near-Success Dataset）将成功轨迹与仅因末端执行器定位略有偏差而失败的近成功轨迹配对纳入训练，使视频模型学习细粒度动作—结果边界。ManiSkill 的失败还用物体位姿扰动构造；LIBERO 和真机部分加入策略 rollout 的自然失败（§3.1）。

视频世界模拟器以 Cosmos-Predict 2 为底座，把 6-DoF 末端执行器位姿和夹爪开合状态作为动作条件。DiT 生成未来视频 latent 后，MLP 奖励头从去噪 latent 预测逐步标量 reward；训练损失是 flow-matching 视频损失加权后的 reward 回归损失。这样 reward 信号和视频生成共享 latent 与训练过程（§3.2，Fig. 3）。

下游用 OpenVLA-OFT 为基础策略，在世界模型里闭环生成多步观察和 reward，并按阈值将 reward 转为 GRPO 的二元成功信号。每次策略更新后，将新策略的成功和近成功 rollout 加入 SANS，再微调模型用于下一轮策略优化。这是“在学习模拟器内训练”，不是每个策略更新都由真机试错（§3.3，Algorithm/pipeline Fig. 3）。

### 3. 数据与规模是什么？

- ManiSkill 预训练 SANS 包含 **23 项任务、约 35,000 个视频—动作对**；LIBERO 和真机下游数据较少，每任务大约 50 条成功与 50 条失败轨迹（§3.1）。
- 目标任务阶段，世界模型使用约 **80–100 条**成功及近成功轨迹微调，其中约 50 条成功轨迹用于 OpenVLA-OFT 初始任务微调；更一般的 §3.3 描述为每任务通常少于 50 成功加 50 近成功样本（§4.3、§3.3）。这些数据是任务适配条件，因此不是零样本训练。
- 仿真评估覆盖 LIBERO-Object、LIBERO-Goal、LIBERO-Spatial；LIBERO 每个汇总条件用 500 次 rollout。真机任务是随机位置下的“将杯子放到绿盘”和“把方块推入簸箕”，Table 3 的物理评估每任务 **30 次 rollout**（§4.1、§4.3、Table 3、Appendix A.3）。
- 策略与模拟器交互用 24 动作 chunk，GRPO group size 为 8；模型一次批量生成 24 帧约需单张 H100 6 秒，单任务完整 RL 通常约 25–35 小时（Appendix A.2、A.4）。

### 4. 主要结果是什么（带条件）？

- LIBERO Table 3 是仿真结果：OpenVLA-OFT SFT base 到模型内 RL 后，Object 两任务为 73.9→97.9%、73.9→91.9%；Goal 为 91.9→100%、86.1→96.2%；Spatial 为 83.9→93.9%、87.9→94.0%。这些数基于各 LIBERO suite 的 500 次 rollout，不能当真机成功率（§4.3、Table 3）。
- 同一表中的真机 30 次物理评估：Place Cup 从 13.3% 到 36.7%（增加 23.4 个百分点），Push Cube 从 26.7% 到 40.0%（增加 13.3 个百分点）。这是两项小样本任务，不足以说明广泛机器人部署收益（Table 3）。
- 迭代实验另报告：SFT base 在 Place Cup / Push Cube 为 13.3% / 26.7%，两轮协同优化后为 50.0% / 53.3%（§4.3、Fig. 1b）。30 次物理试验对应约 15/30 与 16/30 成功，点估计对少量试验较敏感。摘要中的 36.7% 和 26.6% 是相对 SFT 的双任务提升表述；逐任务最终值见 Fig. 1b 与 Table 3，需区分基础 RL 与额外迭代轮次。
- Table 2 衡量模拟器的结果对齐，不是策略成功率。50 个样本/任务的结果中，Place Cup / Push Cube 的 reward alignment 为 94% / 78%，visual alignment 为 90% / 84%（§4.2、Table 2）。这说明预测虽可用于训练，仍存在任务间差异和标签错误。
- Figure 4 的“Real-World”训练曲线是在**世界模拟器中**评估，不是物理试验；只有 Table 3 及迭代结果中明确的最终真机评估才是物理 rollout（§4.3、Fig. 4、Table 3）。

### 5. 消融说明什么？

Table 4 的消融显示，去掉近成功数据会显著损害 visual alignment；去掉奖励头也会降低视觉结果对齐。以 LIBERO-Object 的两列为例，完整模型为 92% / 90%，无近成功数据为 60% / 66%，无奖励头为 68% / 70%；真机列也呈相同方向（Table 4、§4.4）。这是模型对齐指标的消融，不是对应幅度的实机策略成功率提升。

奖励头还与基于同一生成视频作判断的 Qwen3-VL-8B-Instruct 比较：Table 4 的 reward alignment 在 LIBERO-Object 两列为 88% / 90%，Qwen 判断器为 84% / 58%；真机列完整模型 94%，Qwen 为 84%（Table 4）。消融支持共享 latent 的联合训练改善奖励/视频的一致性，但不能单独证明所有任务上均优于外部评估器。

迭代的必要性也有定性证据：第一轮策略会利用模型空间误差，出现 reward hacking（例如移动到方块前方）；把该策略 rollout 加入 SANS 后，模拟器学习更细空间边界，后续策略姿态改善（§4.5、Fig. 5）。这揭示协同循环同时承担发现模拟器盲点的作用。

### 6. 什么条件下失效或结论受限？

- 自回归视频模型超过约 300 帧后出现质量漂移；作者没有评估需更长生成的 LIBERO-100，且 LIBERO-Long 常需 300–400 帧。长任务是明确失效边界（§5、Appendix B.1 Table 5）。
- 近成功动作本来就容易被视觉模型误判；reward head 和 visual alignment 在 Table 2 仍有错误，且 Place Cup / Push Cube 的 reward alignment 分别为 94% 与 78%（§4.2、Table 2）。错误的模拟奖励会诱发模型内策略去追逐模拟器漏洞。
- 真机只有抓放杯子与推方块两个任务，每项 30 次物理试验；作者的 50.0% 和 53.3% 迭代结果适合作为小规模可行性证据，不应外推为广泛现实成功率。
- 下游需要任务专属的几十条成功/近成功轨迹适配模型和策略；“少量数据”不是“没有目标任务数据”。也不能把在学习模拟器里跑出的训练曲线计作物理成功（§3.3、§4.3、Fig. 4）。

### 7. 与同类系统如何判定差异？

相较 VLAW，World-VLA-Loop 把 near-success 作为显式训练对象，并令生成器 latent 同时负责未来视频和逐步 reward，使用 GRPO 在模拟器内优化策略。VLAW 则用外部视觉语言 reward model 给想象轨迹打标签，策略以 flow-matching 监督微调，并把真实成功 rollout 加入更新；其物理实验覆盖五类接触任务。两者都使用策略真实 rollout 校准世界模型并迭代，但奖励来源、策略更新规则和任务评估分母不同，不宜只按摘要中的成功率增幅排序（VLAW v2 §4–5；World-VLA-Loop v2 §3–4）。
