# π*0.6 / RECAP：从真实部署经验中学习的 VLA

> **来源版本**：[arXiv:2511.14759v2](https://arxiv.org/html/2511.14759v2)，2025-11-19（首页版本行与版本记录见[来源清单](../sources/MANIFEST.md)）
> **主等级**：`[精读原文]`。本文按 arXiv HTML 全文核读，关键数值锚到章节与图；本地 PDF 下载未完整结束，因此不把 HTML 未呈现的图中误差棒细节补写为数字。
> **适用问题**：部署中的 VLA 如何跨 episode 学会更快、更可靠地完成真实、长时程任务？

## 亮点与差异

- **一句话亮点**：RECAP 把大规模 VLA 的真实部署数据、成功/失败回报和遥操作纠正放进 advantage-conditioned 的离线策略学习循环，展示真实双臂任务跨回合改善。
- **新在哪**：不是单回合重试动作，而是训练 value function 评估进展，再以 advantage indicator 条件化连续动作策略；失败纠正、自动 rollouts 与示范可混合，迭代时从预训练 checkpoint 重新微调以抑制漂移。
- **证据强度**：真实双 6-DoF 手臂，50 Hz 关节位置控制、三路相机；洗衣、意式咖啡与纸箱装配任务，每项历时 5–15 分钟。多任务真实结果和迭代曲线由 Fig. 7–10 支撑；轨迹数量只在部分实验明确报告。
- **值不值得引用**：值得作为“跨回合、真机 VLA 策略学习”代表。它不能支撑单次 episode 内按视觉反馈即时修复，也不是所有 VLA 真机 RL 的统一基准。

## 七问

### 1. 解决什么问题？

高容量 VLA 往往能从示范执行复杂任务，但部署中的独立试错、稀疏终局奖励、人工纠正和异构历史数据不容易安全稳定地转成策略改进。RECAP 针对的是**真实任务回合之间的策略更新**：机器人运行、收集成功与失败轨迹，按需接受专家接管，然后在新数据上更新 value 和 policy（RECAP v2 §I、§IV–V）。

### 2. 核心方法是什么？

预训练阶段先训练分布式 value function，把回报分成 201 个 bins；成功轨迹用剩余步数作负回报，失败 episode 在终点给较大负值（§4、§5-C，Eq. 1、5）。估计的 advantage 经 task-specific threshold 转为二值 improvement indicator，作为 π*0.6 的条件输入。部署后先用任务示范 SFT，再收集 autonomous rollouts 与 expert teleoperator interventions；修正片段强制标为 improvement，其余数据也可按 episode 纳入。每轮重新微调 value/policy，默认从预训练 checkpoint 开始而非接着上一轮权重训练（§5-D）。

这是一种 advantage-conditioned policy extraction，不要求对每一批新真机数据直接跑 PPO。论文在 t-shirt/shorts 控制比较中报告 AWR、PPO 使用相同 Recap 数据；PPO 为稳定离线训练使用小 trust-region `η=0.01`，仍未达到 Recap 的吞吐；AWR可取得一定成功率但动作较慢（§6-C.3，Fig. 11）。

### 3. 数据与规模是什么？

- 预训练混合网页视觉语言数据、子任务预测和多机器人动作数据；value 模型使用 670M VLM 主干。
- 真机增量平台为静态双臂，每臂 6 DoF、平行夹爪；关节位置 50 Hz，观测含关节/夹爪位置及基座、左右腕部三台相机（Fig. 5）。
- 评测覆盖短袖/短裤和多品种衣物折叠、浓缩咖啡制作、真实工厂纸箱装配；单任务时限各异（常见 200s、500s、600s），不能当作同一回合长度比较（§6-A）。
- 具体迭代数据量：T-shirt/shorts 洗衣两轮改进每轮在 4 个 robot stations 收集 300 条 autonomous trajectories；纸箱装配每轮 600 autonomous trials + 360 intervention trials（§6-C.2）。针对定向失败移除的 T-shirt 实验两轮各 600 条（§6-C.4）。这些量不应推广成所有任务的固定预算。
- 补充材料的 **Dataset composition** 另列出本批实验采集量：T-shirt/shorts 300 episodes（用于汇报评测）；多品种洗衣 450 evaluation episodes + 287 correction episodes；咖啡单轮 414 autonomous + 429 correction episodes；定向失败移除约 1,000 autonomous + (280 + 378) correction episodes、分布在 3 台机器人。纸箱装配每轮 600 demonstrations + 360 correction episodes，覆盖 3 台机器人。主文把纸箱的 600 称为 autonomous trials，补充材料称 demonstrations；此处保留两处原文用语，不把采集 episode 数误称为共同独立测试集的 n。

### 4. 主要结果是什么（带条件）？

- **成功吞吐量**定义为每小时成功完成任务数，兼顾成功率和速度；成功标签来自人工多项质量评估的汇总（§6-C）。
- 对比 offline-RL+SFT 起始策略，真实多品种洗衣与 espresso 的最终策略吞吐均超过 2×，失败率约减半；所有任务中除 diverse laundry 外最终成功率达到 90% 以上（Fig. 7–8，§6-C.1）。这是论文报告的跨任务类别结果，原文没有在正文文本中列出每个 bar 的具体数值，故不在本册反推读图数字。
- 两轮改进中，t-shirt/shorts 洗衣吞吐总体提升 50%；箱体装配在第二轮后吞吐为 2×，但仍有末段堆放失败，约 90% 的折箱/贴标子任务成功率受 600s 时限约束（Fig. 9–10，§6-C.2）。
- 严格领口朝上失败模式实验在特定对抗初始摆放下，两轮（每轮 600 trajectories）后成功率 97%（Fig. 12，§6-C.4）。主文称该设置没有 intervention data 或 additional demonstrations；但补充材料 **Dataset composition** 又称此 ablation 使用了 policy correction data，并给出约 1,000 autonomous + (280 + 378) correction episodes。因此“无需干预数据”的结论与补充材料口径冲突，暂不将其作为确定事实。此结果是单项失败模式实验，不能当作综合任务成功率。

### 5. 消融说明什么？

- Fig. 7–8 对比 supervised π0.6、offline-RL 预训练 π*0.6、offline-RL + task SFT，以及含真机数据的最终 RECAP 策略，支持“仅有离线预训练/SFT 不足以复现完整真机经验收益”。
- Fig. 11 在固定同一批数据下比较 advantage-conditioned extraction 与 AWR/PPO；RECAP 在 t-shirt/shorts 上吞吐最好。基线拿到由 RECAP 收集的同一数据，作者指出这对基线略有利。
- 失败移除实验隔离特定不良行为，说明策略学习可以修正指定失败模式；但其固定、对抗初始状态比自然分布更受控。

### 6. 什么条件下失效或结论受限？

- 干预可修补大错、帮助探索，但作者指出它有打断性且质量不稳定，难以持续优化速度等细节（§5-D）。
- 纸箱长任务需要更多数据；末段堆放仍会失败，且超时是主要失效机制之一（§6-C.1–2）。
- 主结果只覆盖一套双臂平台和若干任务，未给跨系统共基准；吞吐量、成功率与每任务终止时限绑定。
- 文中“约两倍”是同一系统中加入 on-robot data 与 offline-RL+SFT 的对照，不能与其他论文的成功率或吞吐横比。

### 7. 与同类系统如何判定差异？

π*0.6/RECAP 的更新对象是**跨 episode 的神经策略参数**，学习信号来自离线估计的 advantage、终局成功/失败和可选人工纠正；它需要采集后训练。VLCP 改写的是当前 episode 的 Python 控制函数，模型本身冻结；VersualRL 跨 episode 修改 Behavior Tree，属于任务层规划；LingBot-VA 则每个动作 chunk 接收新的真实观察并滚动预测/执行，论文并未把此过程称作在线策略 RL。四者的成功率口径不可混并。
