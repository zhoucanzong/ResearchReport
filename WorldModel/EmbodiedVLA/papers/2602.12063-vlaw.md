# VLAW：让真实策略轨迹校准世界模型，再用想象数据改进 VLA

> **来源版本**：[arXiv:2602.12063v2 HTML](https://arxiv.org/html/2602.12063v2)，2026-02-15。题名：*VLAW: Iterative Co-Improvement of Vision-Language-Action Policy and World Model*。
> **证据等级**：`[精读原文]`；本分册回读固定版本 HTML 的方法、实验与附录，不声称独立复现。
> **适用问题**：在昂贵的真实机器人交互预算下，能否用少量策略实机轨迹校准动作条件视频世界模型，再由模型生成额外训练轨迹，提升多任务 VLA？

## 七问

### 1. 解决什么问题？

真实机器人策略优化需要反复重置、看护和收集轨迹。纯示范训练又很少包含策略会犯的错，导致视频世界模型会把偏差动作也预测成成功，尤其难建模接触、碰撞和可变形物体。VLAW 的问题设定是：以有限真实 rollout 覆盖当前策略遇到的状态—动作分布，提升世界模型的物理与失败预测，再用它扩展训练数据（v2 §1、§2.2、§4.1）。

### 2. 核心方法是什么？

起点是 DROID 预训练的 Ctrl-World 动作条件扩散世界模型、`π0.5` VLA，以及 Qwen3-VL-4B-Instruct 视觉语言奖励模型。每轮先让当前策略在真实机器人上执行，并给每条轨迹标成成功或失败；世界模型用这些在线轨迹微调，同时保留 DROID 数据共同训练，避免只记住狭窄的下游 rollout。奖励模型也用在线数据调准（§3、§4.1、Algorithm 1）。

随后，当前策略从真实轨迹的初始帧出发，在更新后的模型中与其闭环交互，生成**想象轨迹**。外部奖励模型判断哪些想象轨迹成功，达到阈值的轨迹被留下。策略以 flow-matching 损失微调，样本来自两类：筛选后的**想象成功轨迹**和筛选后的**真实成功轨迹**（Eq. 4、Algorithm 1）。所以 imagined rollout 提供扩量数据，而非物理执行；真实成功也明确进入策略更新。作者将这个加权监督更新解释为带参考策略正则的 RL 近似（§4.3），但实现仍是监督目标。

### 3. 数据与规模是什么？

- 平台是 DROID 配置的 Franka Panda 与 Robotiq 夹爪，输入包括两路第三人称相机和腕部相机；五类任务为堆叠、开书、擦白板、舀取、画圆（§5.1、Fig. 4）。
- `π0.5` 每类先用 **25 条专家示范**微调作为 base policy。之后总计两轮；**每轮每类 50 次真实 rollout**，世界模型训练 50K steps，再为每类生成 **500 条合成轨迹**。每轮策略更新 2K steps、batch size 256（§5.1）。
- Qwen3-VL-4B-Instruct 奖励模型输入 16 帧抽样视频，训练 200 steps、batch size 128；以 `p(yes)>0.8` 判成功。附录 C 的 40 条人工标注检查中，该阈值把误报从 8 降至 2，同时真成功的判出数由 15 降至 10，体现保守阈值的取舍（Appendix C, Table 3）。
- 世界模型 replay 评测用 256 段、每段 5 秒的视频片段；交互事件混淆矩阵用 50 段含物理交互的视频。它们与策略任务成功率分母不同（§5.2、Table 1）。

### 4. 主要结果是什么（带条件）？

- 附录 Table 2 给出每项任务 50 次评估：base policy 平均成功率 46.0%；两轮 VLAW（Ours-2）在堆叠、擦除、开书、舀取、画圆分别为 92%、86%、86%、92%、78%，平均 86.8%。同期两轮 Filtered BC 平均 75.2%，DSRL 平均 50.0%（Appendix B, Table 2）。这些是作者报告的实机成功率，不是想象环境的成功率。
- 摘要称相对 base policy 的绝对成功率提高 **39.2 个百分点**；但 Appendix B Table 2 的均值 `86.8%-46.0%` 算得 **40.8 个百分点**。v2 正文没有解释这处差异，因此引用时应保留表格可复算值并注明摘要与表格口径不一致，不把两数混成一个结论（Abstract；Appendix B, Table 2）。
- 摘要报告合成 rollout 训练带来 **11.6 个百分点**提升。主文称 VLAW 两轮结果整体优于 Filtered BC 与 DSRL（§5.3、Fig. 7）；Appendix B 的均值也显示 Ours-2 比 Filtered BC-2 高 11.6 个百分点。该对照说明世界模型生成数据在同等真实 rollout 预算外提供了额外收益，不表示训练过程不需实机数据。
- 世界模型 replay 表中，“Ctrl-World + Expert Rollout”到“+ Online Rollout”后，腕部视角 PSNR 从 19.87 到 21.77、LPIPS 从 0.189 降至 0.136；50 个交互片段的假阳性从 11 降至 1，假阴性由 2 增至 4（§5.2、Table 1）。这反映在线失败数据削弱“错误动作仍预测成功”的偏差，同时不能将 replay 指标当成策略成功率。

### 5. 消融说明什么？

Table 1 对照原始 Ctrl-World、只加专家轨迹、再加策略在线轨迹；其中只有策略 rollout 同时带来成功和失败样本，模型的画面距离指标整体更好，假阳性明显减少。作者据此认为失败覆盖是物理接地的关键（§5.2、Table 1、Fig. 6）。

Fig. 9 在最难的画圆任务上将合成数据从 500 条减到 250 条，或去掉策略更新中的 50 条真实 rollout，二者都会使表现变差。该实验支持合成数据量和真实成功数据都重要；它没有证明这些数量在其他任务、模型或预算下的最优性（§5.3、Fig. 9）。

### 6. 什么条件下失效或结论受限？

- 作者把当前策略更新与世界模型精度的验证范围限定在五类任务（§6）；它不是跨本体、开放任务或零样本能力的证据。
- 想象轨迹依赖世界模型对当前策略分布的准确性，也依赖外部 Qwen 奖励筛选。阈值提高减少假阳性，却会漏掉真实成功；Appendix C 的 40 条样本已显示这种权衡，奖励模型误判仍可能污染监督（Appendix C, Table 3）。
- 真实数据量虽远少于合成轨迹，却不可省略：每轮每任务 50 次实机采集，并且成功真实轨迹进入策略更新。应称“以模型想象扩充有限在线数据”，不应称为纯离线或全仿真训练（Algorithm 1；§5.1；Fig. 9）。
- 论文的成功率是作者任务判据下、每任务 50 次 rollout 的估计；DSRL 评估只有 10 次，方差与评估预算并不完全相同（Appendix B, Table 2 下方说明）。

### 7. 与同类系统如何判定差异？

可按更新对象和数据来源判别：VLAW 以**策略真实 rollout 校准视频世界模型**，在模型中采集额外想象轨迹，再用二者的成功数据做监督式 flow-matching 更新；策略每轮仍需真实采样。World-VLA-Loop 则用 SANS 近成功样本和**视频—奖励联合预测头**建立策略 RL 模拟器，并由更新策略 rollout 继续更新模拟器；其奖励来自生成器内部。两者都让世界模型与策略迭代，但奖励学习、策略优化形式和实验分母不能混写（World-VLA-Loop v2 §3–4；VLAW v2 §4–5）。
