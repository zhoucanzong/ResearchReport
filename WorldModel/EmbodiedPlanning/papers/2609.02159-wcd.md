# World-Coherent Decoding：让执行后的真实误差指导下一次候选筛选

> **一手来源**：[arXiv:2609.02159v1](https://arxiv.org/html/2609.02159v1)，2026-09-02。论文为预印本。
> **适用问题**：如果因果 world-action model 一次会采样出好坏不同的未来与动作，如何在没有任务奖励模型、成功检测器或外部 verifier 时，估计并选出更可靠的候选？

## 亮点与差异

- **一句话亮点**：WCD（World-Coherent Decoding）把世界模型预测当作可被现实证伪的“未来—动作假设”：先用模型生成时的内部信号排序，执行后再用预测与实际观测的差异学习后续可靠性。
- **新在哪**：规划器不更新主干 WAM，也不要求外部奖励或 verifier。它将“视觉未来看起来是否符合模型的生成动态”“动作去噪路径是否稳定”与“前几次预测是否被现实证伪”合在候选选择里。
- **证据强度**：主要量化结果来自 RoboTwin 2.0；在随机化监督受限的 Hard 设置下，报告总体和 Horizon-3 增益。真实 Franka 视觉 shift 实验是定性压力测试，不支持统计显著的真机增益主张。
- **限制**：视觉 surprisal 冷启动计算昂贵；测试仍要并行采多个候选。latent 预测误差在已测轨迹中和任务失败相关，但该代理量不是通用任务价值或安全指标。

## 研究问题：把“随机采样”变成可判断的搜索

WAM 会根据视觉历史和语言指令，生成未来画面并解码为动作 chunk。即使条件相同，不同随机未来可能出现物体不存在、物体姿态不可能或夹爪漂移等问题；低质量未来对应的动作也可能错误。此时，单纯增加采样数只会增加候选，未必增加成功机会。论文先用同一前缀重放并采多个未来，观察到它们在事后与真实未来的误差有可选择的差异（§1，Figure 1）。

WCD 采取分时两步：动作执行前只能依赖生成过程内部信息挑选；执行后才得到真实 observation，可用它审计过去预测并训练下一轮排序器。它没有声称执行后能追回已发生的物理动作，而是把延迟反馈用到下一次决策。

## 候选排序与延迟自校准

对当前相同观测前缀，冻结 WAM 采样 `N` 个未来—动作候选。视觉分支用 flow surprisal 估计候选未来在模型学习到的视觉动态下有多低概率；直觉上，生成流的概率密度变化可以给出未来的自惊讶程度。动作分支计算 path effort，即去噪过程中动作轨迹的归一化变化量，作为动作生成稳定性的相对代理。两项分数分别按同一决策的候选标准化并融合，选择总分更低的一项执行（§3.2，Eq. 2–6）。

执行动作后，模型把已选未来 latent 与随后实际得到的 latent observation 比较，逐帧 MSE 的平均值即 backward error。误差既能临时降低视觉分数的权重，也能与该候选生成时可见的特征配对，训练轻量 predictor 去预估未来候选会有多大预测误差。早期没有在线样本时用 flow surprisal；样本积累达到阈值后改用 predictor，以免每个候选都重新计算昂贵 divergence（§3.3–3.4）。主干世界动作模型始终冻结，预测器与 replay buffer 可跨同任务 episode 保留。

这条校准链有一个重要前提：新决策需要与历史经验相关，且 latent mismatch 要足以反映候选的预测可靠性。如果像素/latent 差异对任务无关，或接触状态的关键变量不可见，误差 predictor 可能学到“画面差多少”而非“动作是否可行”。

## 结果如何解释

- 在 RoboTwin 2.0 50 任务基准上，作者用标准预训练模型和随机化较少的训练设置评测。限定随机化训练下的 Hard 平均成功率由基础 LingBot-VA 的 **55.80%** 到 WCD 的 **60.90%**；Horizon-3 从 **30.00%** 到 **46.43%**，绝对增加 **16.43 个百分点**。模型主干没有更新，结果支持在此分布变化设置中候选排序可降低多步错误累积（§4.1–4.2，Table 2）。
- 在数据充分、较接近饱和的标准设置里，Hard overall 从 **91.55%** 到 **92.28%**，增益较小；这提示额外候选计算更有价值的条件是底层策略仍有失败空间、且生成候选质量不均（§4.2，Table 1）。
- 在限定随机化 Hard 设置的消融中，Random-N 平均为 **53.5%**，完整 WCD 为 **60.9%**。单独使用 surprisal、action effort 或 online predictor 均低于完整组合，显示“多采样”与“能排序”必须分开；完整法相对 Random-N 高 7.40 个百分点（§4.3，Table 3）。
- 在线早期 mismatch 四分位中，失败率从最低误差组 **4.9%** 升到最高误差组 **21.2%**。这是预测误差与失败的关联证据，不代表误差造成失败，也不证明其外部校准能力（§4.2，Figure 5）。
- 真实 Franka hammering 任务测试只提供定性视觉 shift 案例（彩色灯光、相机模糊、杂乱布局）；论文描述彩灯案例中 WCD 找到可执行轨迹，而基线失败。它不是多任务、重复试验下的成功率对照（§4.1–4.2，Figure 4）。

## 失效边界和计算代价

论文指出 WCD 依靠并行生成额外候选；冷启动阶段还要保存视频去噪轨迹、回放速度场、估计散度。在线 predictor 训练后可减少打分成本，但没有消除 WAM 生成的成本。作者将高频控制所需的快速 WAM 推理和部署优化列为未来工作（§5）。

WCD 只审计已选并执行的候选，因此它不断为“已执行样本”获得标签；未执行候选的真实误差仍未知，候选排序存在选择偏差。论文使用同一任务的线上经验预测该任务上的 mismatch，不证明在新任务、不同机器人或新的摄像头下零样本可靠性已经校准。

此外，backward error 比较的是预测与观察 latent。运动/光照变化可能造成误差但不妨碍任务，反之画面看似一致也可能漏掉力、滑移、夹持或碰撞边界。故其“verifier-free”是指不用外部任务评估器，不代表提供了安全验证。

## 与 τ₀-WM 的机制差异

τ₀-WM 与 WCD 都在测试时生成动作候选、先做 re-denoising consistency 检查，并在低质量状态增加推理。但它们对低置信动作的补救不同：τ₀-WM 调用 ACVS 对候选 rollout 预测稠密任务进展，再用选中的未来修订动作；WCD 用执行后真实观测产生自监督 mismatch，在线学习未来可靠性代理。前者把任务进展明确放进 simulator 接口，后者把预测可信度作为无需任务奖励的排序信号。两者都需检验排序信号是否能覆盖真实任务成功，并将额外推理成本纳入比较。
