# 具身预测规划：执行前怎样筛选想象中的动作？

> **范围**：研究机器人在真实执行前，如何用 action-conditioned 视频/潜变量预测比较候选动作、筛掉不可靠 rollout，再执行或修订动作。重点是部署期的候选选择与可靠性校准。
>
> **与相邻入口的边界**：经典模型内规划、Dreamer 式想象训练和世界模型作为训练/评测环境见 [WorldModels](../WorldModels/report.md)；合成数据、world-model RL 与 sim-to-real 见 [EmbodiedVLA 的迁移专题](../EmbodiedVLA/topics/world-model-to-vla-transfer.md)；chunk 反馈、失败恢复和跨 episode 学习见 [闭环控制专题](../EmbodiedVLA/topics/closed-loop-control.md)。本页聚焦一个尚未精读的接口：在当前真实观测后生成多个未来—动作假设，以预测模型自身或实际反馈来选择下一段动作。

## 为什么单独看这条线

世界模型常被用来在模型里训练策略，或生成可交互环境；机器人部署规划则问另一个问题：**当前有多个可执行动作时，能否先预测其后果，再把更可靠的一项交给真实机器人？** 这使世界模型成为每次决策时的“候选审查器”，而不是离线训练数据或替代评测环境。

现有两个入口已涵盖 PlaNet 的 CEM/MPC 和 Dreamer 的模型内学习，也讨论 LingBot-VA 在动作 chunk 间并行预测、由新观测重新接地；VLA 迁移专题还把在线候选规划器列为独立角色。但 Cosmos Policy、τ₀-WM 和后续 WAM 规划工作此前只登记为候选，没有精读其筛选、回退和闭环证据。因而本页只补部署期机制，不重复梳理世界模型谱系或机器人闭环全景。

## 两种筛选思路

先用一个简单例子理解：机器人要把笔放进盒子，策略一次生成四种动作块。规划器不立即执行第一种，而是估计每个动作会导致什么未来，并决定继续使用哪个候选、是否调用更昂贵的模型，或依据执行后的真实观测修正未来的可靠性判断。

| 问题 | τ₀-WM | World-Coherent Decoding (WCD) |
|---|---|---|
| 候选是什么 | VAM 生成的连续动作 chunk | 冻结 WAM 在同一观测历史下生成的未来—动作 chunk |
| 便宜的第一道筛选 | Re-denoising Consistency Score (RCS)：重新加噪并检查候选是否仍符合模型动作分布 | 视觉 flow surprisal + 动作去噪路径 effort：估计未来在视频模型下的 plausibility 与动作生成稳定性 |
| 何时用世界模型 rollout | RCS 判定候选不可靠时，调用 action-conditioned video simulator (ACVS)，预测场景和任务进展；再把高分未来交给 VAM 重新生成动作 | 每次执行后，把想象未来与实际 latent observation 比较；误差作为自监督标签，训练轻量预测器给未来候选打可靠性分 |
| 核心取舍 | 任务进展信号更直接，但依赖训练好的进展/奖励预测器，低置信时额外运行 rollout 和二次策略查询 | 不需要任务 reward、成功检测器或外部 verifier，也不更新 WAM 主干；可靠性分数是预测一致性，不等同任务成功概率 |

二者构成一条可检验的设计轴：**先用模型内一致性做低成本过滤，再用任务进展或真实执行误差来校准。** τ₀-WM 选择性调用明确的 simulator/reward 接口；WCD 则把执行后的世界差异转成下一步的可靠性标签。二者都说明“多采样”本身不等于更好，候选必须有有效排序信号。

## 论文证据能支持什么

- **τ₀-WM** 将视频动作模型 (VAM) 与 action-conditioned 视频模拟器 (ACVS) 放在同一预测框架中。实机测试时先从 VAM 取候选，以 RCS 排序；若候选质量低，则让 ACVS 预测各动作的多视角未来和稠密进展分，再按选中的未来二次查询 VAM 生成修正动作。论文的 test-time computation 对照在两个真实操作任务上各重复 20 次、仅允许一次完成且不允许重试：无该机制的平均成功率 0.43，RCS 为 0.50，RCS+LAR 为 0.60。该组结果支持机制增益，但只覆盖 Tissue→Box 与 Pen→Box 两项任务，不能外推为一般机器人成功率。[τ₀-WM v2 §VI–VII、Algorithm 1–2、Table II](papers/2606.01027-tau0-wm.md)
- **WCD** 从因果 WAM 的随机 rollout 出发：同一历史下的想象未来可靠性会有明显差异。执行一段候选后，系统用未来 latent 与实际观测计算 backward error；一个在线预测器学习从生成时特征预估该误差，供后续候选选择。RoboTwin 2.0 的 limited-randomization Hard 设置中，成功率从 55.80% 到 60.90%，Horizon-3 从 30.00% 到 46.43%；标准、接近饱和设置中总体 Hard 结果只从 91.55% 到 92.28%。真实 Franka 测试覆盖彩色光、模糊相机和杂乱布局，但论文把它报告为定性压力测试，不能当作有统计功效的真机成功率提升。[WCD v1 §3–4、Tables 1–3、Figure 4–6](papers/2609.02159-wcd.md)

## 读者应特别区分的量

1. **候选一致性 ≠ 任务价值**。RCS 或 WCD 的生成轨迹分数说明候选相对符合某种模型分布；只有 ACVS 的进展信号直接尝试预测任务状态，但也可能错估模型之外的现实约束。
2. **预测误差 ≠ 执行失败**。WCD 把 latent imagination–reality mismatch 用作自监督可靠性信号；它在其任务集合中与失败相关，不自动证明该误差在新对象、光照或控制器上也能校准真实成功率。
3. **更长规划需要真实回馈**。二者都仍按动作 chunk 闭环执行；模型 rollout 不能替代每段动作后的实际观测。真实状态变化、接触力或触觉可能改变后续决策，视频预测不一定观察得到。
4. **test-time compute 有成本**。采样更多动作需额外模型前向；τ₀-WM 在低 RCS 时增加 simulator 和二次 VAM 查询，WCD 冷启动时还需对生成轨迹计算 flow divergence。把 success 增益与延迟、失败回退、安全约束一起报告，才足以判断系统是否适合部署。

## 建议阅读顺序

1. 先读 [τ₀-WM](papers/2606.01027-tau0-wm.md)：看“策略提案 → 一致性筛选 → 视频模拟评估 → 未来条件化修订”完整链路及其实机对照。
2. 再读 [WCD](papers/2609.02159-wcd.md)：看不使用任务奖励的候选排序如何通过实际观测逐步校准，以及为什么该增益集中在未饱和、视觉变化更难的设置。
3. 回到 [world-model-to-vla-transfer](../EmbodiedVLA/topics/world-model-to-vla-transfer.md)，将候选规划与训练数据生成、模型内 RL 分开；再读 [closed-loop-control](../EmbodiedVLA/topics/closed-loop-control.md)，比较它与动作 chunk 重规划、失败恢复和 rollout 接地的反馈位置。

## 仍需解决的问题

- 预测分数是否能跨任务、物体、相机与机器人本体校准，还是只在训练分布内有效？
- 多候选搜索带来的成功提升能否在匹配的延迟和计算预算下保持？高频、接触丰富的任务是否承担得起额外规划时间？
- latent 视频误差和任务进展预测如何处理“画面相似但接触/受力不同”的状态？触觉、力矩和控制器约束应进入何种预测接口？
- 若所有候选都不可靠，系统应安全停止、请求人工介入，还是尝试新的观测/动作？现有两篇论文的候选选择结果还不等于安全保证。
