# Context Forcing：让长上下文监督跟上自回归学生

来源：[Context Forcing: Consistent Autoregressive Video Generation with Long Context](https://arxiv.org/html/2602.06028v1)，固定阅读版本 v1。重点位置：§1、§3.1–3.4、§4.1–4.4 与 Table 3。

## 问题：学生在长历史上滚动，教师却只会看短片段

流式视频模型通常逐段生成：当前段依赖此前所有片段的历史。若学生已能滚动生成较长视频，却仍由只接受短窗口的教师监督，教师就无法判断学生当前历史下的长程延续是否合理。学生虽然“看到了”更长上下文，但训练信号没有告诉它该如何利用这段历史。Context Forcing 将此称为 student–teacher mismatch，并把长视频漂移分解为两种失败：窗口太短会遗忘远处主体/事件；扩大窗口又会把学生已生成的误差带进后续条件，逐步偏离真实视频分布。[§1](https://arxiv.org/html/2602.06028v1)

## 两阶段分布匹配：先学局部，再在自身历史上学延续

第一阶段用约 1–5 秒短窗口做局部分布匹配，建立稳定的局部视频生成能力。第二阶段将学生生成的上下文作为条件，让有长上下文能力的 teacher 监督后续延续；目标是匹配 `student continuation | student history` 与 teacher continuation，而不是只在真实前缀上训练学生。这样直接训练模型面对推理时自己产生的历史，减少 exposure bias。[§3.1–3.2](https://arxiv.org/html/2602.06028v1)

这个目标依赖两个假设：第一阶段让学生前缀仍接近真实视频分布；teacher 在这类前缀上能提供可靠的长程延续。作者进一步用 Error-Recycling Fine-Tuning 在 teacher 的历史上下文中注入来自模型残差的扰动，使 teacher 在学生出现轻微漂移后仍能给出监督。若学生偏离到 teacher 不熟悉的区域，这种蒸馏并不能自动保证纠错。[§3.2、§3.4](https://arxiv.org/html/2602.06028v1)

## Slow–Fast KV memory：保留近因，也保留显著历史

直接缓存所有 token 会随视频长度增长。作者把 KV cache 拆为三部分：Attention Sink 保留开头 token 以稳定注意力；Fast Memory 是滚动 FIFO，保存邻近片段；Slow Memory 保存被判为高信息量的历史 token。新 key 与前一个 key 的相似度低于阈值时才晋升到 slow memory，逐步将固定缓存扩展成覆盖更长历史的上下文；位置索引也限制在固定范围，避免时间位置无限外推。[§3.3](https://arxiv.org/html/2602.06028v1)

这里的核心假设是“局部特征变化大，往往对应值得长期保存的视觉事件”。它提供可解释的缓存策略，但 key 相似度只是信息价值代理：缓慢变化但重要的状态可能显得冗余；场景切换等高差异 token 也未必都要长期保留。slow memory 的选取、容量和位置编码仍是方法本身的重要取舍。

## 论文结果说明什么

作者以 Wan2.1-T2V-1.3B 为 teacher 和 student 基础。teacher 用筛选后的长视频训练；student 先以短视频做局部分布匹配，再以 10–30 秒 rollout 做上下文蒸馏。论文在 5 秒 VBench 与 60 秒生成设置下报告结果，slow/fast cache 共 21 个 latent frames，并报告超过 20 秒的有效上下文。这里的“有效上下文”是该模型、缓存和评测协议中的结果，不等于任意场景的长程叙事一致性，也没有证明分钟级视频已经稳定。[§4.1–4.4、Table 3](https://arxiv.org/html/2602.06028v1)

消融显示上下文蒸馏、slow memory 采样与 bounded positional encoding 分别影响长视频的主体/背景稳定。这些结果支持“长程生成需要训练目标与缓存策略协同”，但不能将增益归因于单独扩大 KV cache。

## 与相邻路线的关系和边界

Context Forcing 把问题放在**学生训练和教师监督**上；Wan 的因果分块缓存与滑窗则主要将**运行时计算和跨块延续**做成可处理路径。两者都管理历史，但前者还要求 teacher 能看到足够长的上下文并提供条件化监督。

论文局限是 teacher 需要具备长上下文、teacher-student 架构与训练数据要相匹配，训练还增加了 context distillation 成本；慢记忆筛选也可能误删有意义但视觉相似的历史。长上下文是持续一致性的必要工具之一，不等于显式场景状态、剧情规划或物理模拟。
