# GenEval：把文生图对齐拆成可检查的对象条件

来源：[GenEval: An Object-Focused Framework for Evaluating Text-to-Image Alignment](https://arxiv.org/html/2310.11513v1)，固定版本 v1。重点阅读 §3、§4、§6 与附录 C；本文只研究其评测设计，不把它当作通用图像质量总分。

## 问题：整体相似度为什么看不出属性绑错

FID 衡量生成图像分布与参考图分布的差异，不直接检查提示是否兑现；CLIPScore 把图像和完整文本映射为整体向量，可能在对象、数量、位置和颜色出错时仍给出相近分数。GenEval 的问题更窄也更可解释：给定一条结构化提示，逐项确认图里有没有对象、数量是否匹配、相对位置是否正确、颜色是否属于正确对象。

## 方法：先检测，再按任务属性核验

它把提示拆成对象类型、属性和对象关系。六项任务从单对象、双对象开始，再加入计数、颜色、位置和颜色绑定。检测器提供对象框与分割掩码；检测结果用于验证对象存在、个数和框中心的相对位置，颜色任务再裁剪对象并用分类器判断颜色。一个生成结果于是可以返回哪些对象条件通过、哪些失败，而不是只得到一个不可解释的整体相似度。

这个模块化设计解释了它为何能诊断属性错绑：模型可能生成了红车和蓝椅子，但把提示要求的颜色互换；全局图文向量无法直接指出错误对象，逐对象核验则能分解这项失败。作者的提示由固定模板和 MS-COCO 类别构成：位置词只覆盖上/下/左/右，计数重点为 2–4 个对象。它适合受控组合任务，不代表开放域提示的所有空间与语义关系。

## 人类一致性：支持到什么范围

作者对 1,200 张图收集 6,000 条细粒度标注。在其评测样本中，GenEval 对“图像是否符合提示”的整体判断与标注者有 83% 一致率，标注者彼此的一致率为 88%；复杂计数、位置和属性绑定任务上，它比阈值化 CLIPScore 有更高的一致性。以上均为论文报告结果，限于论文的三个被测来源（Stable Diffusion v2.1、IF-XL 与 LAION-5B 图像检索）、模板任务和人工标注协议。[§4、Appendix D](https://arxiv.org/html/2310.11513v1)

这个证据支持“对象级检测管线能在这些任务上提供有用的自动诊断”，不证明它是所有提示上的通用裁判。83% 也不是一个可直接迁移到新类别、新模型和真实创作任务的准确率保证。

GenEval 的模型分析还提醒读者不要把“规模增加”当成一条统一能力曲线：作者在 IF 同架构的尺寸对照里看到计数和属性绑定随尺寸改善，但相对位置任务没有同步提升；Stable Diffusion v1 后续 checkpoint 的更多预训练也没有带来一致的 GenEval 提升。SD v2 在该评测上的变化同时伴随文本编码器和数据变化，因此论文不能把增益单独归因于某一项。[§5.2](https://arxiv.org/html/2310.11513v1#S5.SS2)

## 失效边界：评测器自己的视觉能力就是上限

GenEval 使用的检测器以 MS-COCO 类别和粒度为基础，因此可以核验“图里有几个人”，却不能核验“每个人有几根手指”。颜色分类同样依赖检测框和裁剪；物体遮挡、罕见类别、颜色语义边界与不在检测词表中的实体都会影响结果。位置判定依据对象框中心和预先设定的相对关系，不能覆盖任意复杂布局、遮挡关系、动作或物理因果。

所以自动分数应与可见中间证据一起读：检测到了哪些对象、框在哪里、颜色模型如何判定。要评估开放文本、审美或复杂场景理解，仍需其它指标和人工检查；不能把对象级分数当作 prompt-following 的完整定义。

## 与 T2I-CompBench++ 的关系

GenEval 的设计优势是对象级检查路径清晰；[T2I-CompBench++](2307.06350-t2i-compbench-plus.md) 将问题扩展到颜色/形状/纹理绑定、2D/3D 空间与非空间关系、数量及复杂组合，并为不同任务组合不同评估器。两篇论文的任务集合、提示构造、指标和生成版本不同，分数不可拼成同一排行榜。它们共同说明：prompt adherence 需要被拆成多种可检验要求，评测器自身的词表、视觉能力和评分协议也要纳入结论。
