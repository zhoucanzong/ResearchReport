# 精读：文本优先的 Omni 推理后训练

## 固定原文

Ziyang Cheng, Yuhao Wang, Hongcheng Liu, Qimin Wu, Jingru Fan, Chen Qian, Yanfeng Wang, and Yu Wang, “Text-Centric Post-Training for Omni-Modal Reasoning,” arXiv [`2610.02819v1`](https://arxiv.org/abs/2610.02819v1), submitted 2026-10-02. 固定版本许可为 arXiv non-exclusive distribution license；这是预印本，未见同行评审版本。PDF 与 HTML 均来自 arXiv v1。

## 四个亮点

1. **核心发现**：作者在九个 Omni-LLM 上观察到，多跳音视频问题可能在对应单跳感知问题答对时仍然失败；诊断与梯度投影实验提示感知和推理目标的局部优化方向部分解耦（§3、Fig. 2；来源与固定版本见 [MANIFEST](../sources/MANIFEST.md)）。
2. **训练安排**：先用文本数据做主要推理优化，再用较少原生音视频数据修复感知；同一 Qwen2.5-Omni-7B 的最佳文本 SFT→GRPO 路线，将九项推理宏平均从 39.80 提至 49.39，几何均值相对提升 25.83%（Table 2；版本和 PDF 身份见 [MANIFEST](../sources/MANIFEST.md)）。
3. **成本与代价**：相较完整音视频 SFT→GRPO，文本路线报告少用 56.6% GPU-hours、少处理 61.3% 训练输入 token；七项感知宏平均同时从 77.37 降到 76.41（Tables 2、5）。减少数据的音视频 GRPO 使用约 90% 更少输入 token，将感知宏平均提至 78.50，并保留 93.5% 的文本路线推理几何均值增益（Table 6）。
4. **适用边界**：跨数据、规模和模型家族的趋势包括 Qwen2.5-Omni-3B、Qwen3-Omni-30B-A3B、Gemma-4；但最完整的分阶段对照仅在 Qwen2.5-Omni-7B 上。作者报告的有限基准结果不确立后续 Qwen Omni 型号的训练配方、普遍收益或内部训练事实（版本与读取范围见 [MANIFEST](../sources/MANIFEST.md)）。

## 七问精读

### 1. 研究问题是什么？

论文问：Omni 模型的音视频多跳推理是否能主要通过文本推理训练改善，从而降低原生音视频训练量，同时保留感知能力？作者的起点是单跳感知题答对、跨模态或跨时间组合题答错的现象（§1、§3.1；原文身份见 [MANIFEST](../sources/MANIFEST.md)）。

### 2. 方法是什么？

提出“文本优先、音视频修复”的两阶段后训练。第一阶段以文本 SFT 与 GRPO 优化推理；第二阶段用减少数据的原生音视频 GRPO 重新校准感知。诊断部分比较 perception/reasoning 梯度方向，训练部分则在相同基座和对应评测上比较数据路线及顺序（§3、§4、§5.5）。

### 3. 评测和训练范围是什么？

推理集合含九项基准，包括 Daily-Omni、Omni-Cloze、OmniVideo、SocialOmni 三个子项、Video-Holmes、Video-MME-v2、WorldSense；感知集合含 AVHBench、MUSIC-AVQA、AVQA 和 NExT-QA 子项（§4.2、Tables 2、5、6）。报告覆盖 Qwen2.5-Omni-7B 和 3B、Qwen3-Omni-30B-A3B 与 Gemma-4 小型模型，但各项对照不完全相同（Table 3）。

### 4. 主要结果是什么？

在 Qwen2.5-Omni-7B 上，文本 SFT→GRPO 的推理宏平均为 49.39，对比基座 39.80 和完整音视频路线 47.37；GPU-hours 为 284.17，对比音视频路线 654.52（Table 2）。文本训练后的感知宏平均是 76.41，低于基座 77.37；追加减少数据音视频 GRPO 后，推理宏平均为 48.48、感知宏平均为 78.50（Tables 5、6）。这些都是论文所报实验数据。

### 5. 证据支持何种解释？

文本合成数据也能带来推理增益，且在部分其它尺寸或家族中复现方向，支持“跨模态推理的一部分可由通用文本推理训练改善”。感知下降及其被音视频阶段修复，说明两类目标可以分阶段权衡。梯度投影只是局部优化方向诊断，不能证明推理与感知是完全独立的能力模块（§3.2、§5.3–5.5；原文锚点见 [MANIFEST](../sources/MANIFEST.md)）。

### 6. 结论在哪些情况下会变弱？

最强数字集中在 Qwen2.5-Omni-7B、九项推理和七项感知基准；基准平均分不能替代真实用户任务。不同模型的路线覆盖和初始化不同，跨家族结果不能视作统一复现。GPU-hours 与输入 token 是作者定义的训练预算，不能直接推为任意硬件或生产部署成本。还没有独立复现（§4–§6）。

### 7. 相对既有 Omni 推理路线的新意是什么？

它把后训练数据来源与被优化能力明确拆开：不要求推理数据本身包含音视频，而以缩减后的原生音视频训练承担感知修复。读者可用它理解“文本推理迁移”与“原生多模态监督”在同一模型里的互补关系；它不替代 Omni 架构论文，也没有公开足以推断 Qwen 产品内部训练流程的证据（论文读取边界与来源见 [MANIFEST](../sources/MANIFEST.md)）。
