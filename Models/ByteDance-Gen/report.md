## 1. 概述

字节跳动（ByteDance）作为全球领先的互联网科技公司，在 AIGC（AI Generated Content，人工智能生成内容）领域的布局呈现出"底层模型 + 中层平台 + 上层应用"的三层架构体系。与 OpenAI、Google 等以底层大模型为核心的策略不同，字节跳动依托其强大的 C 端产品矩阵（抖音、TikTok、剪映/CapCut、即梦AI），形成了独特的"模型驱动产品、产品反哺模型"的闭环生态。

本报告聚焦于字节跳动生成模型系列中的核心组成部分：

- **Seedance**：Seedance 1.0 技术报告披露 DiT（Diffusion Transformer）架构；后续版本须按各自一手材料判断，不能继承 1.0 的未披露实现
- **即梦AI（Dreamina）**：面向 C 端用户的 AI 创作平台，集成 Seedance 视频生成能力，主打中文场景与本土审美
- **剪映/CapCut**：全球领先的视频编辑工具，深度集成 AI 生成能力，形成"编辑 + 生成"一体化工作流
- **豆包/Seed**：底层大语言模型与多模态模型体系，为上层应用提供基础能力支撑

模型、创作产品与服务渠道是不同层面。官方模型页同时列出 Playground 与 API 入口；集成先后顺序、平台间数据流和商业策略需要产品发布记录支持，不由同一公司归属自动推出。

## 3. 字节跳动 AIGC 布局全景

### 3.1 三层架构体系

字节跳动的 AIGC 布局可以清晰地划分为三个层次：

```
┌─────────────────────────────────────────────────────────────┐
│                    应用层（C 端产品）                          │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐  │
│  │   即梦AI     │  │ 剪映/CapCut │  │   抖音/TikTok       │  │
│  │  AI创作平台  │  │ AI视频编辑  │  │  AI内容生态         │  │
│  └─────────────┘  └─────────────┘  └─────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│                    能力层（生成模型）                          │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐  │
│  │  Seedance   │  │  豆包-视觉   │  │   豆包-语音/音乐     │  │
│  │  视频生成   │  │  图像理解    │  │   音频生成          │  │
│  └─────────────┘  └─────────────┘  └─────────────────────┘  │
├─────────────────────────────────────────────────────────────┤

│  │         LLM → MLLM → 多模态统一模型 → Agent 框架        ││

```

### 3.2 即梦AI（Dreamina）：C 端 AI 创作平台

即梦AI 是字节跳动面向 C 端用户推出的 AI 创作平台，定位为"每个人的 AI 创意助手"。其核心特点包括：

- **中文场景优先**：针对中文提示词进行深度优化，理解中文文化语境、成语、网络用语
- **本土审美**：训练数据包含大量中文互联网内容，生成风格更符合中国用户审美偏好
- **低门槛创作**：提供丰富的模板和预设，降低普通用户使用 AI 创作的门槛
- **社区生态**：支持作品分享、风格收藏、创作灵感推荐，形成创作者社区

即梦AI 的产品演进路径清晰：从 2024 年的 AI 绘画工具，发展为 2025 年的 AI 视频创作平台，再到 2026 年的多模态 AI 创作工作流。

### 3.3 剪映/CapCut：集成 AI 生成能力

剪映（国内版）和 CapCut（国际版）是字节跳动旗下的视频编辑工具，全球月活用户超过数亿。其 AI 集成策略：

- **编辑 + 生成一体化**：用户在编辑视频时可直接调用 Seedance 生成素材，无需切换应用
- **智能剪辑辅助**：AI 自动识别视频高光时刻、生成字幕、推荐 BGM
- **模板化生成**：提供大量 AI 生成模板，用户只需替换素材即可快速产出
- **跨平台协同**：手机端、PC 端、Web 端数据互通，创作无缝衔接

剪映的 AI 集成体现了字节跳动"工具即入口"的产品哲学——不单独做一个 AI 视频生成工具，而是将生成能力嵌入用户已有的工作流中。

### 3.4 Seedance：专业视频生成模型

Seedance 是字节跳动自研的专业级视频生成大模型，是即梦AI 视频能力的核心技术底座。其定位与特点：

- **专业级质量**：面向高质量视频内容生成，而非简单的短视频特效
- **DiT 架构**：采用 Diffusion Transformer 架构，区别于早期的 U-Net 扩散模型
- **质量与速度平衡**：针对消费级 GPU 和云端推理进行优化，兼顾生成质量与推理效率
- **多平台部署**：支持即梦AI（C 端）、剪映（工具端）、火山引擎（B 端 API）多形态输出

### 3.5 豆包/Seed：底层大模型能力支撑

豆包（Doubao）是字节跳动的大语言模型品牌，Seed 是其内部研发代号。在 AIGC 体系中，豆包提供：

- **文本理解**：解析用户提示词（Prompt），提取生成意图、风格要求、场景描述
- **多模态理解**：理解图像内容，支持图生视频时的视觉特征提取
- **Agent 能力**：在即梦AI 中支持多步骤创作工作流，如"生成角色 → 保持角色一致性 → 生成多场景视频"
- **中文优化**：针对中文语料进行预训练，在中文理解和生成上具有优势

## 4. Seedance 1.0：原文已经公开的设计

### 4.1 表示、注意力与条件

论文 §2.1–2.2、图 2 描述视频 VAE 与 diffusion Transformer。主干采用**解耦的空间层和时间层**：空间层进行逐帧的视觉/文本联合注意力，时间层仅处理视觉 token，并配合窗口划分在时间方向获得全局感受野。MMDiT 空间层对两种模态保留分别的调制、QKV 与 MLP 权重，并对 Q/K 做归一化。[Seedance 1.0, §2.2]

这与“所有时空 token 一次完整联合注意力”不是同一个结构。原稿通用架构图中的 T5/CLIP、12–24 层、16–32 潜通道及空间/时间分支伪代码不能替代正式实现，已撤回；文本编码器在原文中描述为微调的 decoder-only LLM，但具体型号不能从提示扩写模型的名字倒推。

### 4.2 多镜头与统一任务

Multishot MM-RoPE 在视觉 token 的三维位置之外，为文本引入位置表示，支持交错的视觉和文本序列，各镜头按时间组织并有自身 caption。统一任务形式把噪声输入、干净或补零帧沿通道拼接，用二值 mask 指示条件帧，混合文本到图像、文本到视频和图像到视频任务。[§2.2]

因此，多镜头一致性不是凭“身份 embedding + 对比学习损失”就能解释的功能。原稿的角色编码、运动预测模块与具体损失尚无对应原文，不保留为 Seedance 的实际组件。

### 4.3 高分辨率不是单个大主干直接输出

原文 §2.3 采用**级联**：Base 先生成 480p 视频，再由 diffusion refiner 提升到 720p / 1080p；Refiner 从 Base 初始化，将上采样的低分辨率视频作为条件。质量、显存和时间比较要覆盖整个级联，不能仅凭最终输出分辨率推断“原生 2K”或主干参数翻倍。

### 4.4 提示词扩写与训练边界

§2.4 的 prompt engineering 模型基于 Qwen2.5-14B，先 SFT，再用偏好对与 LoRA 做 DPO，使用户提示接近训练 caption 格式。它是提示转换环节，与 diffusion 主干的文本编码器是不同角色。扩写也可能幻觉，所以论文才用偏好训练约束语义偏移。

这项机制支持“输入处理有助于提示遵循”的解释；它不能单独证明即梦在成语、古诗词或所有中文文化场景上优于竞品，相关优势需专门中文对照集。

### 4.5 Seedance 2.0：从视频生成扩展到统一多模态参考、编辑与音视频输出

ByteDance Seed 的 [Seedance 2.0 技术报告](https://arxiv.org/abs/2604.14148)（arXiv v1，2026-04-15）将其称为统一多模态音视频联合生成模型：输入可组合文本、图像、视频和音频，任务覆盖参考生成、编辑、延展与多镜头叙事，并输出同步音视频。报告给出的公开接口范围是 4–15 秒、480p/720p；这些规格描述系统可见能力，不揭示 token 化、主干结构、专家分配或具体音频融合位置。报告只以“统一、高效、大规模架构”和“稀疏架构”作概括，没有提供可以验证的完整网络图或训练配方，因此不把“稀疏架构”扩写成 MoE 或其他具体实现。

**训练与评测变化**：论文 §2.2 将 SeedVideoBench 2.0 扩展到多模态任务跟随、参考一致性、编辑保真、视频延展、叙事质量和多语言音频；将可自动评估的运动稳定性与盲评美学分开。§2.2.2 另报告截至 2026-04-08 的 Arena 视频榜：Seedance 2.0 720p 的 T2V / I2V Elo 分别为 1450±15 / 1449±11。该结果是有日期的外部偏好榜快照，不能视作当前榜单或架构消融。

作者自建 SeedVideoBench 2.0 的 T2V 表 1（§2.3.1）按 1–5 分评价六个维度，Seedance 2.0 的运动质量为 3.75、提示遵循 3.43、音质 3.63、音画同步 3.75、音频提示遵循 3.56，均高于表中 Seedance 1.5、Kling 3.0、Sora 2 Pro 和 Veo 3.1 的对应结果。表 2 中运动质量“可用率”（评分≥3）为 97.55%。这是开发者报告的模型对比；论文未提供足以独立复建整套比较的完整提示清单、评审人数和原始投票，因此这些数字不能当成独立复现或无条件的跨模型胜率。§2.3.2 表 3 还保留了任务级差异：Seedance 2.0 在 30 个运动类别中 29 项排名第一，群体协同运动与 Kling 3.0 并列；表 11–12 也显示脚本控制与组合指令仍有模型间差距。

**适用边界**：论文明确承认多主体一致性、文字还原、复杂编辑、边缘情形运动合理性、音频噪声和多说话人唇形同步仍待改进。因而该代的可学习进展是“更广的混合模态任务接口 + 更细分的对齐评测”，不是已公开的内部架构突破；发布页宣传性物理真实表述不作为实验结论。

## 5. 即梦AI 产品演进

### 5.1 演进阶段

#### 第一阶段：AI 绘画工具（2024）

- **技术基础**：基于开源 Stable Diffusion 模型，进行中文场景微调
- **核心功能**：文生图、图生图、风格迁移、局部重绘
- **产品特点**：
  - 丰富的中文风格模板（国风、二次元、写实等）
  - 针对中文提示词优化，理解中文文化元素
  - 社区化运营，支持作品分享和风格收藏
- **用户群体**：设计师、插画师、自媒体创作者、普通 C 端用户

#### 第二阶段：AI 视频创作平台（2025）

- **技术基础**：集成 Seedance 1.0 视频生成模型
- **核心功能**：
  - 文生视频：输入文字描述生成视频片段
  - 图生视频：上传图片，生成动态视频
  - 视频风格化：将现有视频转换为特定风格
  - 智能分镜：根据脚本自动生成分镜画面
- **产品特点**：
  - 与 Seedance 深度集成，生成质量显著提升
  - 推出"视频模板"功能，降低视频创作门槛
  - 支持视频编辑基础功能（裁剪、拼接、加字幕）
- **用户群体扩展**：短视频创作者、电商卖家、教育工作者

#### 第三阶段：多模态 AI 创作工作流（2026）

- **技术基础**：Seedance 2.0 + 豆包多模态大模型 + Agent 框架
- **核心功能**：
  - **AI 短剧**：支持角色设计 → 分镜生成 → 场景生成 → 视频合成 的完整工作流
  - **AI 广告**：面向电商、本地生活的 AI 广告生成模板
  - **多模态创作**：文本、图像、视频、音频统一创作环境
  - **角色一致性**：跨场景保持角色外观一致
  - **批量生成**：基于统一设定批量生成系列内容
- **产品特点**：
  - 从"单点工具"进化为"创作工作流"
  - 深度整合豆包 Agent 能力，支持复杂多步骤任务
  - 与剪映打通，支持一键导出到专业编辑环境

## 6. 推理优化：分别标注环节和端到端条件

论文 §5.1 的加速路径包括 TSCD 分段一致性蒸馏、进一步的 score distillation，以及多步对抗训练改善激进加速后的视觉伪影；同时固定编码器、缩窄靠近像素端的 VAE 解码通道。蒸馏减少函数求值次数，VAE 优化减少解码成本，两者作用于不同瓶颈。

| 作者报告的结果 | 作用范围 | 不应推广的结论 |
|---|---|---|
| TSCD 约 4 倍加速 | §5.1 DiT 模型阶段 | 不是所有分辨率的 API 延迟承诺 |
| 薄 VAE 解码器约 2 倍 | §5.1 VAE 解码阶段 | 不能直接算成整个流水线 2 倍 |
| 核融合提升 15% 吞吐 | §5.2 kernel 优化 | 不能与各项局部倍数直接相乘 |
| 5 秒、1080p 视频约 41.4 秒，NVIDIA L20 | 摘要与 §1 的作者系统结果；含整套加速 | 本次没有独立跑分，也不等于某用户请求的排队+网络+服务延迟 |

上述来源均为 [Seedance 1.0 v2](https://arxiv.org/abs/2506.09113v2)。原稿“量化 1.5–2 倍、蒸馏 2–5 倍、全球 CDN 边缘推理”等没有匹配实验或部署证据，已移除。论文中异步卸载、并行与量化是具体工程方案，不能由通用技术名称推导任意显卡的运行条件。

## 7. 对比实验与失效边界

### 7.1 固定任务的评价设计

### 7.2 结论需要同时保留反例

论文图 10–13 与正文认为 Seedance 在提示遵循和多镜头上有优势，也写到 Kling 的运动质量和视觉保真表现较强。开发者评价及选例不能独立证明全场景领先，更不能推出“中文优秀/海外模型一般”或“可灵三分钟因此更适合叙事”的跨服务结论。

本轮移除缺少型号、同一提示集和原始评审数据支撑的 2K / 最长时长比较表与主观雷达评分。Seedance 2.0 的作者基准可作为有明确版本和条件的开发者证据，但不替代独立评测。后续补证应优先保留各任务失败类别，记录提示是否被扩写、生成长度、输出尺寸和评审方式，再比较质量与成本；不会为闭源模型补造参数和消融。

## 9. 挑战与未来方向

### 9.1 当前挑战

| 挑战 | 描述 | 影响程度 |
|------|------|----------|
| **长视频生成** | 当前最长约 10 秒，难以满足短剧、叙事需求 | 高 |
| **物理一致性** | 复杂物理交互（如流体、弹性碰撞）仍不完美 | 中 |
| **推理成本** | 2K 视频生成计算成本高昂，限制规模化 | 高 |
| **版权风险** | 训练数据版权争议，生成内容版权归属不明 | 中 |
| **内容安全** | 生成内容审核，防止深度伪造（Deepfake）滥用 | 高 |
| **与可灵竞争** | 快手可灵在时长和生态上紧追不舍 | 高 |

### 9.2 未来方向推测

| 方向 | 描述 | 时间预期 |
|------|------|----------|
| **Seedance 3.0** | 支持 4K 分辨率、更长时长（30 秒+）、更精细物理模拟 | 2026 下半年 - 2027 |
| **实时视频生成** | 低延迟生成，支持直播场景实时特效 | 2027-2028 |
| **世界模型（World Model）** | 从视频生成进化为可交互的 3D 世界模拟 | 2028+ |
| **多模态 Agent** | 文本 → 脚本 → 分镜 → 视频 → 配音 → 发布 全自动工作流 | 2026-2027 |
| **端侧部署** | 轻量化模型支持手机端本地生成 | 2027+ |
| **全球化** | CapCut 深度集成，服务全球创作者 | 持续推进 |

### 9.3 战略建议（分析性观点）

1. **时长优先**：在可灵已支持 3 分钟时长的背景下，Seedance 应优先突破长视频生成技术，否则在短剧等场景将处于劣势
2. **开放生态**：适度开放模型能力（如通过火山引擎提供更多自定义选项），吸引开发者和专业创作者
3. **垂直深耕**：在电商广告、教育、游戏等垂直场景建立深度解决方案，形成差异化
4. **成本持续优化**：视频生成的规模化应用取决于成本下降速度，需持续投入工程优化
