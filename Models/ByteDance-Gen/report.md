# ByteDance Seed 生成模型：从双语图像生成到多模态视听创作

> 本报告围绕一条研究问题展开：当图像生成从“画得像”走向复杂提示、文字排版、分辨率扩展和可控编辑，训练数据、文本条件与后训练如何共同变化？当目标转为视频，时间维度、多镜头、源图保真与推理成本又迫使架构作出什么取舍？
>
> 阅读主线是 Seedream 2.0 → 3.0 → 4.0 的图像路线，以及 Seedance 1.0 → 2.0 的视频路线。两条线共享 DiT、VLM 和后训练等技术背景，但公开材料没有证明它们共用同一生成器或权重。Seedance 1.5 Pro 是公开产品代际；目前可引用的公开材料不足以逐项说明其独立架构，因此不把它作为已知机制的中间环节。
>
> 论文报告的数据仅用来说明特定评测支持了什么。除非特别注明，本报告没有重算指标或复现实验。闭源服务的产品入口也不等于内部模型结构。

## 阅读地图：生成模型在解决哪些不同问题

图像和视频生成常被合并成“提示词变好、画质变高”的版本故事，但研究问题实际分成几层：

| 问题 | 直接困难 | 本报告中的代表机制 |
|---|---|---|
| 文字与文化语义如何进入图像？ | 通用图文编码器可能弱化中文词义、专有知识、字形和版式 | Seedream 2.0 的双语 LLM 文本编码器、Glyph-Aligned ByT5、专门的文本图像数据 |
| 如何让模型听懂复杂关系并适配不同画幅？ | 物体数量、位置、属性绑定、长尾概念和分辨率变化会同时增加学习难度 | Seedream 3.0 的缺陷感知数据、双轴采样、混合分辨率、跨模态 RoPE 与 REPA |
| 图像生成和编辑是否必须是两套系统？ | 编辑要执行修改，同时保留原图身份与结构；多张参考还要推断哪些属性应该迁移 | Seedream 4.0 将生成、单图编辑、多图参考与多图输出联合后训练 |
| 视频如何把空间质量、运动和提示遵循放进同一个生成器？ | 时空 token 数远高于图像，压缩会影响细节；逐帧质量无法替代运动和时间关系 | Seedance 1.0 的时空 VAE、空间/时间解耦 DiT、统一 T2V/I2V 与多镜头编码 |
| 多模态参考和音视频编辑如何统一？ | 输入可能是文字、图像、视频、音频的组合，还要保持主体和声音的对应 | Seedance 2.0 的任务与评测覆盖扩大；其具体网络和训练配方尚未公开 |

这种路线说明，模型“能力”并非单由参数规模决定：数据决定模型能看见哪些构图与知识，表示方式决定文本、图像、视频如何交互，后训练决定系统偏向哪些输出，推理技术则决定所选质量能否以可用的成本生成。理解报告时应把这些层分开。

## 一、图像生成路线：从双语语义与字形，到生成—编辑统一

### 1.1 Seedream 2.0：把中文理解和文字渲染作为核心问题

Seedream 2.0 的报告从现有文生图系统的三个短板出发：提示遵循和结构正确性不足、文字渲染不稳定、中文文化细节理解不足。它的设计重点不是提出一种全新扩散目标，而是让数据、条件编码和后训练共同服务于这些失效类型。[Seedream 2.0, §§1–4]

**图文骨干仍是 DiT，关键变化在条件信息。** 图像先由 VAE 压缩为 latent，再切成图像 token；图像与文本 token 进入受 MMDiT 启发的 Transformer。图像和文本共享注意力交互，但因模态差异使用独立 MLP 与自适应归一化。这个结构本身不是 Seedream 独有的新范式，研究上的重点是怎样把足够丰富、语言能力更强的条件送进 DiT。[§3.1]

文本编码使用团队训练的 decoder-only 双语 LLM。报告认为，直接从中文和英文原始数据学习能改善文化语义和专业词汇的表达。对图像中出现的文字，系统再增加 Glyph-Aligned ByT5：LLM 保留句子和版面意图，字节级文本编码器提供更细的字符信息，两组表示对齐后共同作为 DiT 条件。论文指出，单靠 ByT5 虽能提供字形细节，却可能在长文本中重复字符或打乱布局，因为它缺少整体语义理解；因此字符级编码要与 LLM 语义编码互补，而不是取代后者。[§3.2–3.3]

报告还采用 Scaled RoPE，使模型能向未训练过的图像分辨率推广。这与字符编码解决的是不同问题：前者改变位置外推，后者丰富文本条件。二者都以较局部的机制处理“内容正确”和“布局适配”之间的误差来源。[§3.1–3.3]

**数据管线与文本编码是同一设计的一部分。** 论文描述了双语通用 caption、审美 caption、文本 caption 与超现实内容 caption；用于文字渲染的数据通过 OCR 定位文字区域、裁切水印、筛选低质量文本框，再重新描述并构造图文对。这里的研究含义是，模型不能仅从普通自然图像学会稳定的拼写与排版：目标能力需要相应的样本覆盖和监督表示。[§2.4–2.5]

**后训练将多目标偏好显式化。** Seedream 2.0 使用继续训练、SFT 与 RLHF。其奖励不是一个笼统的“审美分”：报告分别训练图文匹配、审美和文字渲染奖励模型，并在提示涉及文字时选择性使用文字奖励；随后用多个 reward 信号优化扩散模型。这个设置回应了目标间冲突：提升审美可能牺牲文字准确度，而严格贴合字形也可能令画面僵硬。多维反馈试图同时顾及它们，但论文报告的综合偏好不能证明所有维度都已被同时解决。[§4.1–4.3]

Seedream 2.0 还展示了文生图模型向指令编辑适配的早期路径。SeedEdit 将扩散模型本身作为图像编码器，让输入图像的表示与生成空间保持一致，再通过成对编辑数据和迭代优化学习“按要求改、其余尽量不动”。这与只把 CLIP/DINO 特征当作外部参考的路线不同：复用生成表示可能有助于输入特征与输出生成对齐，但一致性仍要在身份保持、构图和指令服从上实测。[§5]

同一报告还把提示扩写（Prompt Engineering, PE）作为独立的条件准备阶段。作者的观察是：用户提示通常比训练 caption 短，直接输入会让模型缺少训练中常见的风格、构图和细节条件；PE LLM 因而把短提示改写成更适合模型的描述，再以扩散模型生成结果作为反馈做偏好优化。论文报告，在其内部评估中 PE 使审美指标提升 30%、图文对齐提升 5%。这些数字是提示扩写模块对 Seedream 2.0 的作者报告，不是生成器单体的增益，也不能排除扩写改变用户意图的风险。[§4.4]

**原文结果能说明什么。** Seedream 2.0 报告的人评将中文与英文任务分开，并分别评估提示跟随、结构、审美等维度；自动评价主要覆盖英文，因为所用工具对英文支持更成熟。这个设计本身提示读者：一个模型的“双语能力”不能只凭英文自动分数代表。论文的比较和 ELO 是作者组织的评估证据，不是开放权重下的独立复现，也不覆盖所有真实排版和文化语境。[§7]

### 1.2 Seedream 3.0：把问题从条件表达扩展到数据分布、分辨率和采样稳定性

Seedream 3.0 沿用 Seedream 2.0 的 MMDiT 主干和双语生成目标，但把改进集中在整条训练—推理管线：复杂提示和物体关系、细小文字、高分辨率，以及训练样本分布中的缺陷。[Seedream 3.0 v3, §§1–2]

**缺陷感知训练改变了数据过滤的取舍。** Seedream 2.0 会排除包含水印、叠字、字幕或马赛克等问题的图片，这使一部分长尾图像无法用于预训练。Seedream 3.0 训练缺陷检测器定位图中的缺陷区域：当缺陷占比低于设定阈值，保留该样本，但在 latent 扩散损失中用空间 mask 排除缺陷区域的梯度。作者报告有效训练数据增加 21.7%。这不是“噪声图片也可以不加筛选地训练”，而是把全图二元取舍改成局部利用；其效果依赖缺陷检测和 mask 定位是否准确。[§2.1]

双轴协同采样同时看视觉形态和语义分布。视觉侧通过层次聚类平衡不同图像形态，文本侧用词频信息处理长尾描述，并用跨模态检索为特定概念补样、校准分布和扩展相邻图文对。它试图避免只按“常见自然图像”做 top-down 重采样而丢掉专业图表、公式和低频概念。相应代价是需要稳定的分类、检索和数据标注环节；系统性偏差可能随采样策略进入整个训练集。[§2.1]

**分辨率训练与表示对齐针对不同的误差。** 模型先在多画幅、平均约 256² 的图像上训练，再用从 512² 到 2048² 的高分辨率数据微调，并把目标尺寸作为条件；跨模态 RoPE 让文本 token 也使用与图像位置兼容的二维位置编码。它们分别处理分辨率覆盖和文本—图像位置关系。训练目标采用 flow matching，并增加 REPA 表示对齐损失：DiT 中间特征与预训练 DINOv2-L 特征做余弦距离约束，作者称它可以加速大规模文生图训练收敛。REPA 不能被解读成“图像理解问题已经解决”；论文的论据是训练收敛和若干评测能力改善，而非对所有视觉关系作了证明。[§2.2]

时间步也按分辨率调整。更高分辨率样本的 timestep 分布向低信噪比移动，使训练噪声与推理时目标尺寸相匹配。Seedream 3.0 因能直接覆盖 512²–2048² 的训练和生成，取消了 Seedream 2.0 单独的 Refiner 阶段。这个变化让高分辨率从“主干生成后再超分”转成主干原生能力，但也把更高分辨率训练的算力需求放回基础模型训练本身。[§2.2–2.3]

**奖励模型从 CLIP 分数转向 VLM 判别。** Seedream 2.0 使用多种 CLIP 奖励；Seedream 3.0 把评估说明作为 query，并以 VLM 对“是/否”判断的归一化概率构造 reward，报告实验了 1B 到超过 20B 的 reward model。作者报告模型规模增长与奖励建模表现改善相关。阅读时应把它视为作者对奖励模型 scaling 的训练观察，而非所有 VLM judge 都天然可靠的结论；它仍受提示、标注维度与模型偏好的影响。[§2.3.3]

加速方面，论文提出一致噪声期望和重要性时间步采样，让不同样本沿自身轨迹生成，目标是稳定减少去噪函数调用。论文摘要报告相对 Seedream 2.0 的 4–8 倍加速并尽量保持质量；正文的具体耗时条件是 1K 图像、未使用 Prompt Engineering 模型时报告 3 秒。数字用于说明该报告的设置，不应推广成所有分辨率、硬件和服务接口的延迟。[§2.4]

**评测与结论边界。** Seedream 3.0 报告使用 377 条提示的 Bench-377，覆盖电影、艺术、娱乐、审美设计和实用设计；文字能力另用 180 条中文与 180 条英文提示，覆盖 logo、海报、显示屏、印刷和手写等类别。作者还使用 EvalMuse、HPSv2、MPS 与内部评估器比较图文对齐和审美。多种指标同时改善支持“训练管线在该评测范围内更均衡”的判断；其中包含内部模型和作者构造的提示集，因此不能将排名解读为对任意提示的普遍优势。[§3]

### 1.3 Seedream 4.0：从单一生成任务转向生成、编辑和多图推理的统一系统

Seedream 4.0 将研究问题从“怎样让文生图更好”进一步转为“能否用同一模型处理生成、单图修改、多图参考和多图输出”。它的技术报告 v3（同时整理 Seedream 4.5 的追加内容）仍以 DiT 为生成骨干，但改变了图像 token 成本和多任务后训练方式。[Seedream 4.0/4.5 v3, §§1–2、4]

**高压缩 VAE 是高分辨率路线的系统级前提。** 报告称新的 VAE 显著减少 latent 图像 token 数量，让 DiT 能在 1K–4K 原生分辨率训练和推理；相对于 Seedream 3.0，报告称推理加速超过 10 倍，并给出在不使用 LLM/VLM Prompt Engineering 时生成 2K 图像的秒级结果。这里的机制链是“VAE 压缩减少序列长度 → DiT 计算下降 → 更高原生分辨率在可承受成本内训练”，而不是只靠采样步数压缩。报告同时包含 CUDA kernel、算子融合、并行调度等工程优化，所以端到端速度不能全部归因于 VAE 或单一模型结构。[§1–2.1、2.3]

**统一任务改变了“保真”和“服从”之间的训练关系。** Seedream 4.0 用一个经过微调的 VLM 处理文本和图像参考，再将描述/条件送给 DiT；生成与编辑任务通过 CT、SFT、RLHF 多阶段联合训练。报告指出 CT 主要改善编辑指令遵循，SFT 进一步改善编辑前后的一致性。其训练样本包含参考图、目标图和编辑指令，并用不同详略程度的 caption 增加表达变化。论文进一步以因果扩散框架把 T2I 和编辑任务组合起来。核心取舍是：同一系统能共享生成先验，但编辑必须同时优化“按指令改”和“未指定部分保留”，而不同任务之间的梯度并不会自然一致。[§2.2]

Seedream 4.0 的多图编辑不只是拼贴。模型需要从多张输入中选出应保留的对象、风格或属性，再把它们组合到目标画面。作者用图文指令符合度、一致性和结构评价这类任务，并报告随参考图增多时，竞争系统更容易出现结构退化，而 Seedream 4.0 在其测试中可以处理十张以上图像。这个结果支持多参考上下文是明确训练目标；它不证明任何数量的任意输入都能可靠融合。[§3.1.3、3.3]

这里有一个重要的比较维度：编辑模型常在“执行修改”和“保留原图”之间偏向一端。Seedream 4.0 报告用三项衡量单图与多图编辑：指令执行、输入一致性、结构完整性。它报告 GPT-Image-1 在指令响应上较强但一致性较弱，Gemini 2.5 更偏向保留但有些变换任务的执行不足，Seedream 4.0 力求三者均衡。这个结论来自作者构造的成对比较和 GSB 评价，能说明报告所测试任务中的取舍，不应脱离数据集泛化为所有编辑指令的模型排序。[§3.1.2–3.1.3]

另一个变化是把“文生图”扩展为带上下文推理的生成：读懂参考图中的隐含关系，再推断应生成的后续画面。报告列举视觉谜题、漫画续画、物理/空间关系等案例。案例说明系统开始面向多模态输入推理，仍不足以证明具备通用视觉推理能力。论文的 DreamEval 包含 128 个子任务、1,600 条提示，并分难度检查指令遵循；作者指出困难等级上的单图编辑表现下降，提示这种统一路线仍受复杂编辑约束。[§3.2]

DreamEval 的作用不只是给一个总分。它将提示按基础生成、较复杂的组合能力和更高阶理解分层，并把每项拆成细粒度视觉问答评分。论文称自动评价总体趋势与人评一致，但也报告 Seedream 4.0 在困难层、尤其单图编辑上下降；此外，模型平均分和 best-of-4 结果并不完全相同。这意味着采样次数也会影响用户观察到的能力，不能把多次生成中挑选出的最佳样例直接视作单次可靠性。[§3.2]

Seedream 4.5 在报告中主要作为进一步扩展模型规模和数据的版本出现；公开文本没有提供足以把它写成新架构阶段的机制细节。故本报告把 4.5 视为统一路线的后续扩展，不虚构具体模块变化。[§4]

### 1.4 图像路线的跨代变化

| 代际 | 首要瓶颈 | 主要机制变化 | 新能力与代价 |
|---|---|---|---|
| Seedream 2.0 | 双语语义、文字渲染、偏好质量 | 双语 LLM + Glyph-Aligned ByT5；专门文字数据；多维 CLIP reward | 让字词语义和字形细节同时条件化；系统多了专项数据和奖励支路 |
| Seedream 3.0 | 复杂关系、长尾概念、原生高分辨率和采样稳定性 | 缺陷 mask 训练、双轴采样、mixed-resolution、跨模态 RoPE、REPA、VLM reward | 把数据分布和分辨率纳入训练目标；高分辨率不再依赖单独 Refiner |
| Seedream 4.0 | 生成与编辑分离，多图上下文难以利用 | 高压缩 VAE + 高效 DiT；VLM 条件；T2I/编辑联合后训练 | 单一生成系统覆盖多任务，但“改变多少、保留多少”成为主要冲突 |
| Seedream 4.5 | 继续扩大统一系统 | v3 报告只说明规模与数据继续扩展 | 可确认是后续扩展，不能据此推导具体新机制 |

这个路线不是单调的“模型越大越强”：2.0 强化输入文本与字形的表示；3.0 把数据分布和原生分辨率当作主要瓶颈；4.0 再把生成改造成多任务条件系统。编辑中的保真冲突是由任务目标本身产生的，不能只靠更强的提示编码器解决。

## 二、视频生成路线：从统一 T2V/I2V 到混合音视频参考

### 2.1 Seedance 1.0：压缩、时空解耦与统一条件任务

Seedance 1.0 把目标定义成在提示遵循、运动合理性和视觉质量之间同时取舍，并在单一系统里支持文生视频（T2V）、图生视频（I2V）和多镜头生成。其报告比 Seedream 公开了更完整的视频模型构造，适合学习“视频为什么不能简单沿用图像 DiT”。[Seedance 1.0 v2, §§1–5]

**视频 VAE 的压缩决定后续 DiT 的工作量。** 视频像素体积随帧数、宽度和高度相乘增长。Seedance 1.0 使用时间因果 VAE 联合压缩时空维度，并采用 4 倍时间、16 倍高宽下采样，latent 通道数 48；因果设计也允许图像在时间维长度为零时走同一表示路径。VAE 使用重建、KL、感知和对抗损失，作者明确将重建质量视作生成清晰度上界之一。压缩降低 Transformer token 成本，但会把纹理、局部结构和运动信息的保真压力转移到 VAE。[§2.1]

**空间和时间注意力分开计算。** 每帧内空间层负责视觉和文本交互；时间层处理跨帧视觉关系，并用窗口划分提高时间方向感受野。空间层采用类似 MMDiT 的多模态注意力，文本与视觉 token 分别有调制、QKV 和 MLP 参数；时间层只处理视觉 token。这样避免每个时空 token 都参加一次完整联合注意力，计算更可控，但模型仍须通过层间交替把“这一帧是什么”与“帧间怎样变化”组合起来。[§2.2]

多镜头处理通过 MM-RoPE 扩展位置表示：视觉 token 使用三维时空位置，文本 token 加入位置编码，文本与视觉片段可交错排列，每个镜头配有自己的描述。T2V 和 I2V 则通过统一条件任务训练：输入端将噪声 latent 与干净条件帧/补零帧按通道组合，并用掩码区分条件信息。统一任务让同一个生成器学习“从文字造场景”和“从给定画面延续动作”，但不意味着两个任务的数据分布或质量天然平衡。[§2.2]

高分辨率生成使用级联 Refiner：Base 先生成 480p，Refiner 将结果提升至 720p/1080p，并以低清结果作为条件。这个设计把高分辨率纹理恢复从基础时空主干中拆出来，便于独立训练和后训练；风险是如果 Base 已经丢失动作或主体细节，超分模型只能重建外观，不能可靠恢复不存在的运动信息。[§2.3]

**视频 caption 既描述发生了什么，也描述画面本身。** Seedance 1.0 将 caption 拆分为动态特征（动作、主体/场景变化、镜头运动）与静态特征（外观、风格、场景）。T2V 可以用丰富 caption 学习主体和事件；I2V 的首帧已经提供静态外观，因此训练还使用只描述运动的 caption，减少条件重复。推理时的提示扩写模型以 Qwen2.5-14B 初始化，经过 SFT 学习把用户指令改写为训练 caption 格式，再用 DPO 偏好数据减少改写时的语义幻觉。扩写器和视频 DiT 是两个环节：前者规范化用户意图，后者学习从条件生成视频；扩写变得更丰富，并不等于用户原意一定保留。[§2.4、§3.2]

### 2.2 训练课程与后训练：先学习分布，再补条件能力

预训练从低分辨率图像开始，逐渐加入视频、提高分辨率和帧率；报告的阶段包括 256px 图像/视频联合、640px 视频，以及 24fps 训练。视频阶段仍保留少量 T2I 任务，而 I2V 占比为 20%。之后继续训练阶段提高 I2V 占比至 40%，并精选运动丰富、审美较高的视频。这个课程针对视频任务的稀有度：先学广泛的视觉分布，再增加条件生成的相对权重。[§4.1–4.2]

SFT 使用人工核验 caption 的高质量样本，按风格、运动和场景切分训练；报告还描述分别训练专门模型后再合并，以覆盖多个风格和运动类型。此处的设计取舍是增加高质量定向监督，同时通过早停和合并减少对 prompt controllability 的损害。没有相同数据和训练预算下的逐阶段对照，最终结果不能完全归因于模型合并。[§4.3]

视频专用 RLHF 将人类偏好拆为文本视频对齐、运动、视觉质量等多维 reward，迭代训练扩散模型与 reward model。高分辨率 Refiner 也接受 RLHF：低分辨率 latent 作为条件，由奖励模型评价高分辨率结果。作者报告显示人类偏好学习被直接用于加速后的低 NFE Refiner，目标是兼顾速度、运动和细节，而不是先做慢模型再另行量化。[§4.4]

三个 reward 不是简单重复打分：基础 reward model 检查图文对齐与结构稳定；运动 reward model关注视频伪影、运动幅度和鲜明度；审美 reward model以视频关键帧为输入，沿用图像审美评价的思路。作者还说明，他们对 DPO、PPO、GRPO 等反馈方法做了比较，并选取直接最大化多 reward 组合的优化方式；之后交替更新生成器和奖励模型。这个设计把人类偏好拆成更可诊断的反馈，但 reward 之间仍需权衡，且论文给出的“更有效”只适用于其实现、数据和比较设置。[§4.4]

推理加速包括模型层和服务层。模型层用轨迹分段一致性蒸馏、score distillation 和带偏好监督的多步蒸馏，减少函数评估次数；系统层则优化并行、异步卸载和批处理等资源使用。论文摘要报告约 10 倍加速；它还报告在 NVIDIA L20 上生成 5 秒 1080p 视频耗时 41.4 秒。这是特定硬件、请求与服务栈下的论文报告结果，不能把系统计时当成纯算法加速，也不能直接推广到其他分辨率或供应商 API。[§5]

### 2.3 Seedance 1.0 的评测：将整体偏好拆成可诊断维度

Seedance 1.0 的 SeedVideoBench 包含 300 个 T2V 提示和 300 个 I2V 提示，与电影导演合作制定人评标准。标签覆盖主体属性与位置、动作类别与时间顺序、相机运动、镜头切换、风格、光照等。因此它比单一“画质分”更适合讨论视频生成的结构性问题：主体是否出现、动作是否正确、镜头如何变化、风格是否连贯。[§7.2]

它的四类评分还分别定义了问题：运动质量覆盖结构异常、物理合理性、稳定性和动作连贯；提示跟随覆盖动作响应、主体属性、风格、辅助实体、时间顺序、镜头和环境；审美质量看纹理、材质与视觉表现；I2V 另测源图的身份、风格、材质、内容、色彩和光照保留。这个拆分使“生成得好”有了更具体的含义：T2V 的任务执行和 I2V 的源图保持不能共用一个模糊的质量标签。[§7.2.2]

论文还使用 Artificial Analysis Arena 的公开偏好结果，并报告 Seedance 1.0 在当时的 T2V/I2V 榜单表现。论文明确说明 Kling 2.1 的榜单分数因公开数据缺失而沿用了 Kling 2.0；其论文快照不能作为所有模型同日同版本的严格比较。作者人评报告了 I2V 中 Seedance 与 Kling 的强项差异：Kling 在运动质量方面表现突出，Seedance 在复杂镜头转换和细粒度指令跟随方面更好。这个结论的价值是指出能力维度可能互相错位，不是宣布某模型全局胜出。[§7.1–7.2]

多镜头演示展示了正反打、插入镜头、动作切等叙事形式，说明模型学到一定的镜头条件序列；但案例图不足以证明任意长视频的叙事连贯。论文基准只有固定提示和短片段，长时程角色记忆、复杂物理交互与编辑精确度仍是不同问题。[§7.3]

## 三、Seedance 2.0：任务接口变宽，模型内部仍待披露

Seedance 2.0 的论文 v1 将其描述为原生多模态音视频生成系统，输入包含文本、图像、视频、音频，覆盖参考生成、视频编辑、延展、多镜头叙事和同步音视频输出。相比 1.0 的主要可证变化是输入模态与任务范围扩展，而不是可以从论文中逐层复刻的网络结构。[Seedance 2.0 v1, §§1–2]

论文把评测从单纯的 T2V/I2V 扩展到多模态任务跟随、参考一致性、编辑保真、视频延展、叙事质量和多语言音频；并分别报告自动运动稳定性和盲评美学。SeedVideoBench 2.0 的这种任务拆分有助于看出“一条整体分数”掩盖的能力差异。作者也报告第三方 Arena 的带日期榜单快照，以及自建基准中多个任务的分数；这些是开发者报告结果。可引用时应同时注明任务/版本/表格位置，不能改写成独立验证或当前排名。[§2.2–2.3，表1–3、11–12]

以论文表 1 的 T2V 对照为例，作者按 1–5 分报告运动质量 3.75、提示遵循 3.43、音质 3.63、音画同步 3.75、音频提示遵循 3.56；表 2 的运动质量可用率（评分不低于 3）为 97.55%。这些指标分别对应运动、文本条件和音频一致性，不宜合并成“整体真实度”。同一报告表 3 显示类别成绩并非完全一致，表 11–12 的脚本控制与组合指令也保留了模型差距。作者还报告截至 2026-04-08 的 720p Arena T2V/I2V Elo 快照为 1450±15 / 1449±11；它有明确日期、分辨率和榜单语境，不是长期稳定的模型属性。[§2.2.2–2.3.2，表1–3、11–12]

报告明确列出仍待改进的边界，包括多主体身份一致性、文字还原、复杂编辑、极端运动合理性、音频噪声和多说话人唇形同步。由于公开论文没有足以重建生成主干的网络图与完整训练配方，不能根据“统一”或“稀疏”措辞推断其使用何种 MoE、tokenizer、音频融合层或采样器。产品界面能证明用户能提交哪些输入、能获得什么输出；它不能作为模型内部结构证据。

Seedance 1.5 Pro 出现在两代之间，但没有被本报告读到的独立架构论文覆盖。若后续需要补充，应新增其专属一手材料后再比较音频联合生成、提示控制和角色一致性机制；不能按产品发布时间在 1.0 与 2.0 之间臆造技术演进。

## 四、图像与视频路线如何相互参照

这两条路线可以比较训练和表示的共同问题，但不可据此断言共用底层系统。

| 维度 | 图像：Seedream 2–4 | 视频：Seedance 1–2 | 可以得到的综合判断 |
|---|---|---|---|
| 条件语义 | 双语 LLM、字符级 ByT5、VLM 提示处理 | LLM 文本编码、视频 caption、提示扩写；2.0 扩展到图像/音频/视频参考 | 条件模型把自然语言整理成可学习目标，但预处理也可能引入语义偏移 |
| 时空表示 | DiT/MMDiT 处理图像 token；高分辨率依赖 VAE 压缩 | 时间因果 VAE + 空间/时间解耦 DiT，另用多镜头位置编码 | 图像长宽扩展主要增加空间 token，视频还增加时间交互和运动连续性 |
| 数据问题 | 文字、长尾概念、复杂布局、缺陷图像 | 动静态 caption、镜头、运动、帧率、源图条件 | 训练数据的描述粒度与目标能力绑定；增加数据量不等于增加结构性监督 |
| 后训练 | 多目标审美/文字 reward；生成与编辑联合训练 | 对齐、运动、画质等视频 reward，Refiner 单独接受反馈训练 | 人类偏好可以缓和多个目标冲突，却不能替代显式评估各目标 |
| 编辑/一致性 | SeedEdit 到生成—编辑统一，主要冲突是修改与保留 | I2V、多镜头和多模态参考，主要冲突是动作变化与主体/场景连续 | 一致性是不同任务定义的条件，不是单一通用分数 |
| 证据透明度 | 2.0–4.0 连续技术报告披露较多机制 | 1.0 披露较完整；2.0 披露任务范围和评测多于生成结构 | 论文公开程度不同，报告不能把产品可见功能当成机制连续性 |

共通的发展方向是：提示扩写和 VLM 条件让输入更丰富，任务联合训练减少模型切换，奖励模型将偏好编码进生成过程。共同风险也随之出现：上游理解/改写错误会被下游生成放大；联合任务使评测更复杂；“表现更好”的总分可能掩盖在文字、保真、运动或困难样本上的退步。

## 五、结论、失效边界与开放问题

### 5.1 现有材料支持的研究结论

1. **中文文字能力来自数据和表示协同，不是单纯换一个文本编码器。** Seedream 2.0 把双语语义编码、字符级 ByT5 与 OCR 筛选的专项数据组合起来；3.0 又用复杂提示、细小文字和空间关系数据扩展目标。证据支持的是这套组合在作者评测中的改善，不是“模型已经正确排版任意中文”。
2. **原生高分辨率是数据、latent token 成本和训练目标共同决定的。** 3.0 从多分辨率训练取消单独 Refiner；4.0 再压缩 VAE token 数以降低高分辨率计算。报告中的速度和质量均是论文设置下的数据，不能脱离分辨率、PE、硬件及服务栈解释。
3. **编辑统一化后，评价重点从“像不像”转为“改对什么、保留什么”。** Seedream 4.0 以任务联合训练处理文本指令、单图和多图参考，但作者也显示困难等级编辑会掉点。不能只看生成质量或单一人类偏好排名。
4. **视频需要同时显式处理空间、时间与镜头层级。** Seedance 1.0 将注意力按空间和时间分工，用多镜头位置表示、统一条件任务、训练课程和视频专用后训练相互配合；其中任何一个模块都不能单独解释全部视频能力。
5. **2.0 的公开增量首先是任务和输入范围。** Seedance 2.0 报告覆盖更多视听输入与编辑评测，但实现披露不足。研究者应把“任务接口扩大”与“模型架构创新”分开陈述。

### 5.2 原文边界与未解决问题

- **指标无法替代跨任务诊断。** ELO 或综合偏好对快速比较有用，但会把构图、提示遵循、细节、运动和保真压成一个排序。Seedream 和 Seedance 的自建 benchmark 更细，但样本设计、评审流程和厂商参与都要纳入解释。
- **奖励模型是否引入偏好偏差？** 多维 RM/VLM judge 可扩展反馈规模，但 reward 本身由模型、提示和标注方式决定。复杂中文、少数风格、编辑保真和非典型运动需要独立诊断。
- **复杂指令中的实体绑定仍是瓶颈。** 图像中的多个对象属性和空间关系、视频里的多个主体与动作先后关系，需要超越整体图文相似度的评价。
- **编辑与生成联合训练的干扰如何控制？** 对编辑来说，语义变化越大，保真通常越难；多图参考还需分辨哪些对象、颜色、风格和关系应该迁移。需要更公开的按任务拆分消融。
- **视频时长扩展与长程一致性。** Seedance 1.0 的公开评价关注短视频和镜头序列。长时程身份记忆、跨镜头因果关系、动作可执行性与声音持续一致不能由短片段榜单推出。
- **架构可复核性不均。** Seedream 2–4 与 Seedance 1.0 给出了较多训练细节；Seedance 2.0 对主干与训练配方披露不足。后续应按具体技术报告更新，不能把前代结构外推到闭源服务。

### 5.3 推荐阅读顺序

1. 先读 Seedream 2.0 §3 和 §4：看双语 LLM、ByT5 和多维 RLHF 如何围绕“语义与字形”协作。
2. 再读 Seedream 3.0 §2：看数据采样、mixed-resolution、RoPE、REPA 和加速如何共同解决复杂关系和高分辨率。
3. 接着读 Seedream 4.0 §1–2 与 §3.1–3.2：理解高压缩 VAE、VLM 条件、联合编辑训练，以及编辑任务的困难分层。
4. 读 Seedance 1.0 §2–5：从 VAE、时空 DiT、多镜头编码一路跟到课程训练、RLHF 和蒸馏。
5. 最后读 Seedance 2.0 §2.2–2.3：把任务接口与评测分类同 1.0 比较，同时留意其架构证据边界。
