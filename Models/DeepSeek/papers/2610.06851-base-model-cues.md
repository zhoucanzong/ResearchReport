# 精读：基座模型从训练数据线索中调用推理

## 固定原文

Sophie L. Wang, Amil Dravid, Rulin Shao, Kevin Farhat, Sewon Min, and Alexei A. Efros, “Base Models Can Reason By Taking a Cue From Training Data,” arXiv [`2610.06851v1`](https://arxiv.org/abs/2610.06851v1), submitted 2026-10-05. 固定版本许可 CC BY 4.0；这是预印本。PDF 与 HTML 均来自 arXiv v1。

## 四个亮点

1. **研究问题**：短回复开头是否可作为从基座模型训练分布中学到的行为线索，触发推理，而不先更新权重？（§1、§2）
2. **基准结果**：作者报告 Olmo-3-7B 的 `.\n\n Okay` 将 MATH-500 pass@1 从 42% 提至 78%（RL 对照 75%）；Qwen3-14B 的 `Alright ,` 从 72% 提至 87%，与其 GRPO 对照相当（§2.2、Fig. 2）。
3. **机制干预**：在可控的 Olmo 与 SmolLM3 中训练数据替换可改变 cue 与后续行为的关联；例如将中训练数据的 “Okay” 改为 “Chicken” 后，作者观察到新 cue 的数学表现随之提高（§3.1、Figs. 5–6）。
4. **对 R1/DeepSeek 的边界**：论文研究 R1-Zero 风格的直接基座 RL，但实测模型是 Olmo 与 Qwen，反事实数据实验是 Olmo 与 SmolLM3。它提供比较假说，不解释 DeepSeek-R1 的内部训练机制；作者也指出模型依赖性、多阶段后训练和数据混合会限制外推（§6）。

## 七问精读

### 1. 论文要区分什么？

模型“能否生成推理”与“在给定提示下是否容易进入推理”不是同一问题。作者考察固定一两个回复起始 token 能否改变基座模型的推理行为与准确率，以及 RL 是否提高这些有效开头出现的概率（§1–§2.3）。

### 2. 如何挑选 cue？

作者对候选开头做 beam search，以候选开头下不同采样响应间的一致性等无参考答案指标排序，再在数学和代码基准上评估选出的 cue；具体提示模板、采样和搜索见 §2.1、Appendix B。识别出的 cue 是模型和提示相关的 token 序列，不是通用自然语言指令。

### 3. 如何比较基座与 RL？

主要对照是 Olmo-3-7B 和 Qwen3-14B，各自使用无 cue、选中 cue 和从基座直接 RL 的模型；作者在 MATH-500、GSM8K、AMC 23、AIME 2024、HumanEval 等任务报告 pass@1（§2.1–2.2、Fig. 2；版本和缓存身份见[来源清单](../sources/MANIFEST.md)）。不同模型的 RL 配方和提示不完全相同，跨模型分数不应直接排名。

### 4. 主要结果是什么？

MATH-500 上，Olmo cue 42%→78%，RL 对照为 75%；Qwen cue 72%→87%，达到其 RL 对照水平。固定 cue 对 GSM8K、AMC 23、AIME 2024 多数也有改善；HumanEval 上 Olmo 有提升，Qwen 的基座表现本已较高（§2.2）。这是作者在指定采样、提示和基准上的实验，不是“基座等同于 RL”的一般结论。

### 5. 数据编辑说明了什么？

作者使用 Olmo 已公开的 10B-token 中训练配方，构造相同 checkpoint、数据顺序和随机种子的 10B-token counterfactual runs；将 “okay” 替换成 “chicken” 后，`Chicken` cue 在 MATH-500 上从 2.4% 到 37.2%，并在 GSM8K 上从 2.2% 到 60.6%。反向把问答文档的 “Question:” 标签改为 “Okay,” 又改变 cue 之后的行为（§3.1、Figs. 5–6）。这些干预显示训练关联能产生因果影响，但仅在作者可控训练设置中成立。

### 6. 适用范围和限制是什么？

作者聚焦直接对基座做 RL 的 R1-Zero 式场景；复杂的多阶段后训练可能新增 cue 无法解释的能力。cue 效果依赖模型：在所测试开头中，Llama-3.1-8B 没有找到有效 cue。数据编辑实验使用 Olmo 与 SmolLM3，其训练混合包含合成推理轨迹，因此效果可能受此数据分布影响（§6）。论文没有测试 DeepSeek 权重或复现 DeepSeek 的训练过程。

### 7. 对 DeepSeek 推理讨论的价值是什么？

它为“RL 激活已有行为”和“训练改变模型行为分布”提供了一组独立、可干预的例子，可作为阅读 R1-Zero 时的比较视角。由于没有 DeepSeek 实验，报告只把它作为外部方法论文，不将 cue 机制或数据编辑结果归因给 DeepSeek。
