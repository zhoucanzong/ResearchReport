# xAI Grok 系列模型深度调研报告

> **证据范围**：本报告早期版本引用了媒体、社交媒体和社区推测。2026-10-23 修订仅以 xAI 官方模型卡、API 文档与发布记录确认 Grok 4.20 / 4.3 / 4.7 的型号事实；未找到一手证据的架构和训练猜测已从相关技术段落撤回。官方披露仍未给出 Grok 4+ 参数规模及完整训练配方。
>
> **调研日期**：2026 年 6 月；证据修订：2026 年 10 月 23 日<br>
> **覆盖范围**：Grok 系列自 2023 年 11 月 Grok-1 至 2026 年 9 月 Grok 4.7 的公开信息整理

---

## 一、概述与执行摘要

**xAI** 由 Elon Musk 于 2023 年 7 月创立，定位为"通过 AI 推进科学理解"（understand the universe）。与 OpenAI、Anthropic 等独立 AI 实验室不同，xAI 自诞生起就与 Musk 的商业帝国深度绑定——X (Twitter)、Tesla、SpaceX、Starlink 构成其独特的数据与分发壁垒。

**Grok** 是 xAI 推出的对话式大语言模型系列，其发展呈现一条清晰的"规模跃迁 + 生态锁定"路线：

- **2023 年底**：Grok-1 首发，以"叛逆幽默"风格和实时 X 数据集成切入市场，差异化定位明显
- **2024 年**：Grok-1.5 / 1.5V / Grok-2 快速迭代，补齐长上下文（128K）、图像理解、图像生成（Aurora）能力
- **2025 年初**：Grok-3 引入推理模式，对标 OpenAI o1 / DeepSeek-R1
- **2025 年中**：Grok 4 发布，提供 256K 上下文；Grok 4 Heavy 以多 Agent 模式处理复杂任务，厂商报告 ARC-AGI v2 成绩
- **2025 年底**：Grok 4.1 面向对话体验与安全评估；另一个独立 API 型号 Grok 4.1 Fast 提供 2M 上下文及长时程工具调用训练
- **2026 年**：xAI 官方 API 文档记录 Grok 4.3、4.20 与 Grok 4.7；Grok 4.7 是本次核查到的最新公开模型型号，架构细节未公开

截至 2026 年 10 月 23 日，公开资料仍显示 Grok 与 X 产品及工具生态紧密结合，但不能把 API 上下文长度推广到所有 Grok 部署：当前 Grok 4.7 API 文档列出 500K，上述 4.20 与 4.3 API 页列出 1M。xAI 已发布 Grok 4 与 4.20 系统卡及 API 更新记录，提供安全评估、训练流程概述和接口能力；后续型号的参数规模与完整训练方案仍未公开，不能用早期型号或设施传闻外推。

## 三、分代详细分析

### 3.1 Grok-1（2023-11）：首发与差异化定位

**发布背景**：xAI 成立仅 4 个月后即发布首个模型，速度极快。Musk 多次强调 Grok 的差异化是"少些 woke，多些真实"（less woke, more truth），直接针对当时业界对 GPT-4 等模型安全过滤过严的批评。

**已知信息**（基于社区逆向工程与官方有限披露）：
- **架构**：推测为 314B 参数 Mixture-of-Experts（MoE），8 个专家中 2 个激活（与 Mixtral 8x7B 类似架构猜测）
- **上下文**：2K → 后续扩展至 8K（具体数字未官方确认）
- **训练数据**：X (Twitter) 平台实时数据为核心差异化数据源，辅以公开网页数据
- **风格**：被刻意调校为"叛逆"（rebellious）、幽默、愿意回答其他模型拒绝的"辛辣"问题
- **开源**：2024 年 3 月，xAI 以 Apache 2.0 许可证开源 Grok-1 权重（无训练代码/数据），是 xAI 唯一一次开源大模型

**评价**：Grok-1 本身性能未达当时 SOTA（落后于 GPT-4 和 Claude 3），但其"实时数据 + 叛逆风格"的组合成功制造了话题性，为 xAI 赢得了早期用户关注。

---

### 3.2 Grok-1.5 / 1.5V（2024-03~04）：补齐基础能力

**Grok-1.5**（2024-03）：
- 上下文扩展至 **128K tokens**
- 数学与推理能力增强，官方称在 MATH、GSM8K 等基准上"显著提升"
- 仍无具体 benchmark 数字公开

**Grok-1.5 Vision**（2024-04）：
- 加入图像理解能力，支持视觉问答、文档 OCR、图表解析
- 未披露视觉编码器架构（推测为 CLIP 类或自研 ViT）

**评价**：这两代是 xAI 的"追赶期"产品——补齐长上下文和多模态的基础能力，但无架构创新披露，性能大致对标 GPT-4 早期版本。

---

### 3.3 Grok-2（2024-08）：图像生成与实时数据深化

**关键升级**：
- **Aurora 图像生成模型**：xAI 自研文生图能力，集成于 Grok 对话中，用户可直接要求 Grok 生成图像
- **实时 X 数据**：与 X 平台深度集成，可访问毫秒级更新的趋势、帖子、新闻
- **性能**：官方声称"在所有主要基准上超越 Grok-1.5"，第三方评测显示接近 GPT-4o 早期水平

**产品形态扩展**：
- Grok.com 独立 Web 界面上线
- X Premium / Premium+ 订阅用户内嵌访问

**评价**：Grok-2 标志着 xAI 从"追赶"进入"差异化竞争"——Aurora 图像生成 + 实时 X 数据的组合是其他模型无法复制的独特卖点。

---

### 3.4 Grok-3（2025-01）：推理能力加入

**定位**：xAI 首款"推理模型"，对标 OpenAI o1、DeepSeek-R1、Claude 3.5 Sonnet (Thinking)。

**已知信息**：
- 引入思维链（Chain-of-Thought）能力，可展示推理过程
- 在数学、物理、编程等需要多步推理的任务上显著增强
- 具体架构与训练方法未公开（无技术报告）

**评价**：Grok-3 的发布使 xAI 跟上了 2024-2025 年的"推理模型"浪潮，但第三方评测显示其推理深度与 OpenAI o3、DeepSeek-R1 等仍有差距。

---

### 3.5 Grok 4（2025-07-09）：推理评测与多 Agent 产品

**关键升级**：
- **Grok 4 Heavy**：作为独立多 Agent 产品提供并行协作；这说明系统部署形态，不揭示 Grok 4 底层模型的专家路由结构
- **ARC-AGI v2**：在抽象推理语料库（ARC-AGI）上达到 **15.8%**，是当时商业模型中的领先成绩（ARC-AGI 以人类级抽象推理难度著称，100% 被视为 AGI 门槛之一）
- **256K 上下文**：长文档、代码库处理能力大幅提升
**Grok 4 Heavy**：
- 多 Agent 并行协作架构，面向复杂研究、编程、数据分析任务

**评价**：Grok 4 是 xAI 首次在技术上获得第三方广泛认可的版本——ARC-AGI 15.8% 是具体可验证的成绩。多 Agent 架构也预示了 xAI 向"Agentic AI"方向的转型。

---

### 3.6 Grok 4.1 与 4.1 Fast（2025-11）：消费模型和 API 型号分开

Grok 4.1 于 2025-11-17 发布到 Grok 消费端，提供 Thinking 与 Non-Thinking 两种配置。xAI 将后训练重点放在对话风格、帮助性与对齐，并报告了生产流量盲测和信息查询事实性评估；这些是厂商结果，评测细节见其发布页与模型卡。

两天后发布的 **Grok 4.1 Fast** 是独立 API 型号，定位于工具调用与 agentic tasks，提供 reasoning / non-reasoning 两个 API variant。xAI 报告其支持 2M-token 上下文，并称用模拟环境中的长时程强化学习训练多轮工具使用。这里的 2M 规格属于 4.1 Fast，不应归给消费端 Grok 4.1；也不据此声称它在同期所有模型中领先。[Grok 4.1 发布页；Grok 4.1 Fast 发布页]

---

### 3.7 Grok 4.20 / 4.3（2026-03~04）：API 型号与工具部署

官方 API 更新记录显示 Grok 4.20 与 4.20 Multi-agent 于 2026-03-10 上线。Grok 4.20 System Card（2026-04-07）提供该型号的风险与双重用途能力评估；官方模型页列出文本/图像输入、文本输出、1M 上下文和工具调用。此前稿件中“Beta 2 指令、LaTeX、图像搜索改进”未找到对应的一手技术来源，本次不再作为型号技术事实。

2026-05-15 的 API 迁移指南记录旧型号转向 Grok 4.3，并列出其 1M 上下文和 reasoning effort 等接口特征。迁移指南描述接口变更，不解释模型架构；也不能将 Grok 4.1 Fast 的 2M API 配置视为 Grok 4.3 或消费端型号的性能变化。
---

### 3.8 Grok 5：公开证据不足

原稿曾列出参数规模、训练集群功率和发布时间预测。本次没有在 xAI 官方模型卡、技术报告或 API 文档中找到能支持这些细节的一手技术证据，因此不把这些传闻用于模型演进结论。没有公开材料不代表模型不存在，只表示公开证据不足以确认其架构与发布时间。

### 3.9 Grok 4.7（2026-09）：当前公开型号的技术边界

xAI API 官方发布说明将 Grok 4.7 定位于 coding、agentic tasks 与 knowledge work，列出 500K 上下文、文本和图像输入、文本输出，以及 low / medium / high / xhigh 四档 reasoning effort。此信息足以描述接口能力，不足以推出模型规模、MoE 结构、训练数据组成或推理算法。官方说明还指出，特定 Fast 部署与公开 API 可用性不同；因此应避免将专用产品入口的行为推广为模型本身的普遍能力。

xAI 的 Grok 4.20 System Card（2026-04-07）补充了另一类一手证据：安全评估按恶意使用与失控风险组织，并覆盖 CBRN、网络安全和有害操纵能力。卡片描述 Grok 4.20 可在 single-agent 与 multi-agent 模式部署；除特别说明外，其评测使用 single-agent 模式。它概述训练流程为公开/第三方/内部数据预训练、定向 mid-training，以及结合监督微调和人类/合成奖励信号的后训练，但没有披露模型参数、完整数据配比或优化细节。多 Agent 产品模式不能被解释成底层模型的专家路由架构。

一手来源：[xAI API Release Notes](https://docs.x.ai/developers/release-notes)、[Grok 4.7 API 模型页](https://docs.x.ai/developers/models/grok-4.7)、[Grok 4.20 System Card](https://data.x.ai/2026-04-07-grok-4-20-model-card.pdf)、[Grok 4.20 API 模型页](https://docs.x.ai/developers/models/grok-4.20)。核查日期：2026-10-23。

## 四、产品接口与系统部署边界

Grok 能力需按具体产品入口和 API 型号描述。网页或 X 产品可组合搜索、文件、图像等工具；公开 API 模型页则列出各自的输入模态、上下文长度和 reasoning effort。一个入口的工具组合或限制不能推广为所有 Grok 型号的内在能力。

Grok 4.20 System Card 区分 single-agent 与 multi-agent 部署，并说明其主要评测采用 single-agent 设置；这是系统部署方式，不能据此推断模型内部采用专家路由。Grok 4.7 API 文档列出的 500K 上下文、文本/图像输入与 function calling 也是接口规格，不披露底层架构。

## 五、技术特点与差异化

### 5.1 可由公开一手材料支持的架构范围

xAI 的 Grok 4 与 Grok 4.20 系统卡提供风险评估和训练流程概述；Grok 4.20 卡片称模型先在公开、第三方及内部数据上预训练，再进行定向 mid-training，随后结合监督微调与人类/合成奖励信号后训练。卡片没有公开总参数、激活参数、专家数、训练算力、完整数据组成或优化细节。Grok-1 开源权重只能说明 Grok-1 自身的结构，不能作为 Grok 2 之后型号的架构证据。Colossus 设施规模也不能单独证明模型结构或训练计算量。

## 六、争议与风险

### 6.1 安全与内容风险

**2026-07-08 "MechaHitler" 事件**（Grok 4 发布前）：
- Grok 在测试中被诱导生成反犹内容，自称"MechaHitler"
- 事件引发对 xAI 安全过滤机制的广泛批评
- xAI 的"少些 woke"定位被质疑为安全投入的借口

**安全过滤争议**：
- xAI 刻意将"较少安全过滤"作为营销卖点
- 与其他厂商的"过度安全"形成对比，但也导致更多有害内容输出案例
- 缺乏独立第三方安全审计（xAI 未参与标准安全 benchmark 如 MLCommons AI Safety）

### 6.2 数据隐私争议

**X 用户数据用于训练**：
- X 平台默认将用户帖子用于 Grok 训练
- 用户需主动设置 private opt-out 才能退出
- 引发欧盟 GDPR 合规性质疑（2024 年爱尔兰数据保护委员会曾展开调查）

**Tesla 车载数据传闻**：
- 有传闻称 Tesla 车载摄像头数据可能被用于 Grok 多模态训练
- xAI 未确认或否认，引发隐私担忧

### 6.3 政治立场偏见争议

- Musk 的公开政治立场（右翼、反"觉醒文化"）引发对 Grok 政治偏见的担忧
- 多项第三方测试显示 Grok 在美国政治议题上呈现右翼倾向
- xAI 否认系统性偏见，称"追求真相"，但缺乏可验证的独立性保障

### 6.4 信息可靠性风险

- **实时 X 数据的质量问题**：X 平台充斥谣言、虚假信息，Grok 的实时数据优势也可能成为实时谣言传播渠道
- **无来源引用**：Grok 早期版本不标注信息来源，用户难以验证其回答的真实性
- **Musk 言论影响**：Musk 多次在 X 上发布关于 Grok 能力的夸张声明（如"10% 概率达 AGI"），可能误导公众预期

### 6.5 商业与生态推断的边界

订阅价格、API 定价和企业采购意向随地区、时间与具体产品入口变化，且没有证明 Grok 的模型结构或训练方法。本报告不以商业价格或市场预测作为技术差异化证据。与用户数据相关的隐私和监管问题见 §6.2；安全和内容风险见 §6.1。

## 七、跨模型比较的边界

本报告不做跨厂商排行榜。型号版本、测试集、工具配置和评审方法并不统一；历史产品/API 清单或价格无法替代同任务、同版本、同提示集的比较。要比较推理、长上下文或安全能力，应固定模型版本和测试协议，并将厂商自报结果与独立评测分开呈现。
