# Natural-Language-Guided Generator-Agnostic Shortlisting for Protein Binder Design

> **固定来源**：arXiv:2608.20755v2，2026-09-05；license: CC BY 4.0。原文：[arXiv HTML v2](https://arxiv.org/html/2608.20755v2)。v1 首次提交于 2026-08-21；本分册引用 v2。
> **证据等级**：`[精读原文]`（§3–8、Tables 1–6、Appendix A–B）。未执行研究所用 GPT 模型、候选预测器或排序代码。

## 亮点与差异

- **① 一句话亮点**：把“从大量已生成 binder 中挑出少数送实验”单独定义为 post-generation shortlisting，并比较固定指标、监督学习和 LLM 生成的多特征排序策略。
- **② 新在哪**：LLM 不设计序列、不预测结构，而是根据预计算的 17 个结构置信度/界面代理分数，产出可解释的特征选择与加权规则。
- **③ 证据强度**：回顾性汇总 10 个留出靶点、2,269 条候选、251 个已验证 binder；有 target-disjoint split 和模型知识截止审计，但任务规模仍是十个靶点，数据来源与 assay 异质。
- **④ 值不值得引用**：值得用于说明筛选规则会影响实验预算命中率，并且多指标组合可补充单分数；不支持“LLM 能设计出 binder”或普遍提升湿实验成功率。

## 1. 解决什么问题

现代设计流程可以产生成千上万条候选，但每个靶点能进行湿实验验证的候选数量有限。论文将候选池固定，要求方法只根据预计算分数选择 top-K，使问题变成“有限实验预算如何分配”（§1、§3）。

## 2. 核心方法

每个候选有 17 个代理特征：AF2-Multimer 的 ipTM/pTM/pLDDT/interface PAE，Boltz-2 的 ipTM/pTM/pLDDT/ipSAE/pDockQ2，Protenix/PXDesign 的 pair/binder 置信度，以及 Rosetta interface ΔG、buried SASA 和 shape complementarity（§4、Table 2）。论文比较单指标、Logistic Regression、XGBoost、通用 LLM 策略和 target-conditioned LLM 策略。

LLM 生成的是确定性排序策略 `(F,w,g)`：选一组特征、给整数权重、再由固定 executor 在目标候选池内归一化、排序并取 top-K（§3.2）。target-conditioned 方法可读取该目标候选池未标注的分数分布，但不读取留出标签（§5.2）。

## 3. 数据与规模

development split 为 BoltzGen 的 11 个靶点。10-target held-out split 汇集 BindCraft 复测、pMHC minibinders、Nipah、RBX1、TREM2、EGFR 等 2,269 个候选，其中 251 个实验确认 binder；3-target subset 为 Nipah、RBX1、TREM2（Table 1）。来源工作流和实验条件不同，论文按靶点合并并对相同候选序列去重；无实验测量的候选不当作负例（Appendix A）。

## 4. 主要结果与条件

在 10 个 held-out 靶点上，五个迭代 GPT-4o 全局策略的平均 Recall@10 为 0.589，Protenix binder ipTM 单指标为 0.571；target-conditioned iterative GPT-4o 的 NDCG@10 为 0.523（Table 3、§6）。目标条件化 iterative GPT-5.4 在三个靶点子集上 Recall@10 为 0.519、NDCG@10 为 0.583，固定 Protenix binder ipTM 分别为 0.504、0.506（Table 3）。

Recall@10 是 top-10 中找到多少已验证 binder 的比例，目标分母为 `min(10, 已验证 binder 数量)`；Hit@10 是是否至少命中一条（§5.2）。这些数值不等价于预测亲和力，也不能将 0.018 的绝对 Recall 差异解释为所有实验流程中的成功率提升。

## 5. 失效边界与审计

- **小的目标数**：10 个靶点是主要 held-out 样本，3 个靶点的 GPT-5.4 子集更适合作为探索性结果。不同目标的命中比例差异较大，汇总均值不能掩盖低命中目标。
- **代理分数来源**：结构预测置信度、界面几何和 Rosetta descriptor 来自模型/能量函数，并非直接的结合测量；若 upstream 预测存在偏差，组合打分可能放大该偏差。
- **数据来源差异**：候选来自不同生成器、竞争赛和公开复测，assay 与标签过程并不完全同质。作者处理序列重复、无标签候选和目标级划分；这些处理提升可审计性，但不能保证未来实验分布相同。
- **时间泄漏**：论文按 GPT-4o-2024-11-20 的 2023-10-01 知识 cutoff 和 GPT-5.4 的 2025-08-31 cutoff 审核数据发布日期（Appendix B）。这支持其时间审计口径，不等于对所有序列同源、训练语料或 target knowledge 泄漏作形式化证明。

## 6. 研究含义

这篇工作把瓶颈从“能否生成更多候选”转成“如何把真实 assay 证据反馈到下一轮候选筛选”。结果显示 Protenix binder ipTM 这类单分数仍是强基线，LLM 策略的提升温和；更重要的研究方向是扩大独立靶点、预注册排序策略并做前瞻实验，而非只增加代理特征。
