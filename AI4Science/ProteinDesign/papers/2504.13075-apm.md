# An All-Atom Generative Model for Designing Protein Complexes（APM）

> **固定来源**：arXiv:2504.13075v3，2025-09-08；license: CC BY-NC-ND 4.0。原文：[arXiv HTML v3](https://arxiv.org/html/2504.13075v3)。本分册按该版本精读；未运行作者代码或模型。
> **证据等级**：`[精读原文]`（§3–5、Table 5–6、Appendix D/F）。具体证据范围和限制见 [MANIFEST](../sources/MANIFEST.md)。

## 亮点与差异

- **① 一句话亮点**：把多链蛋白复合物的序列、主链坐标与侧链 torsion angles 放进一个全原子生成体系，支持复合物生成、folding、inverse folding 和设计相关任务。
- **② 新在哪**：相对只生成 residue-level 主链的多链路线，APM 增加侧链构象模块与 refinement；表示是“氨基酸类型 + 主链 SE(3) frames + 侧链 torsions”，不是每一步直接扩散所有 Cartesian atom 坐标（§3.1–3.2）。
- **③ 证据强度**：论文给出公开数据集基准、抗体 CDR-H3 与 peptide 设计的计算比较；多链训练用 11,620 个样本。没有报告新设计 binder 的湿实验验证。
- **④ 值不值得引用**：值得用于说明多链复合物需要显式建模界面与侧链，也值得作为“高分计算指标不等于生物学验证”的案例；不能据此声称获得了经过实验验证的治疗性 binder。

## 1. 解决什么问题

常见单链蛋白模型可以折叠或补序列，但 binder 设计关注多链相互作用：给定目标或复合物条件，提出能够形成合理界面的序列与结构。APM 试图统一多链建模、全原子侧链细节和序列—结构共同生成（§1、§3）。

## 2. 核心方法

APM 包含三个模块（§3.2，Figure 2）：

1. **Seq&BB**：flow matching 联合生成氨基酸序列与主链刚体帧。
2. **Sidechain**：预测侧链 torsion angles，将主链扩为原子级构象。
3. **Refine**：对生成结构作细化。

训练分两阶段：先分别训练 Seq&BB 与 Sidechain，再组合三个模块做交替训练（§3.3，Figure 3）。这种拆分让模型可以逐步加入侧链信息，但侧链完备和合理结合仍是模型预测，不是结合实验。

## 3. 数据与规模

- 单链数据来自 PDB、Swiss-Prot 与 AlphaFold DB。论文保留 18,684 个 PDB 样本、140,769 个 Swiss-Prot 样本和 28,041 个 AFDB 样本，共 187,494 个单链样本（§4.1）。
- 多链数据来自 PDB Biological Assemblies；排除了 PDB ID 出现在 SAbDab 的样本、含短于 30 aa 肽链的样本、长度超过 2,048 或缺少 cluster ID 的样本，最终为 11,620 个多链样本（§4.1）。超过 384 个残基时围绕链间界面裁剪（§4.1）。
- 抗体 CDR-H3 设计在 RAbD benchmark 上评测；训练集用 SAbDab 并按 CDR-H3 40% 序列相似度聚类，RAbD 中保留 55 个测试复合物（Appendix D.4）。

## 4. 主要结果与条件

在 RAbD CDR-H3 比较中，APM-SFT 的 AAR 为 41.20%、RMSD 为 2.08 Å；zero-shot 的 AAR 为 28.35%、RMSD 为 5.81 Å（Table 6）。作者还报告 pyRosetta 的能量与结合能指标。数字支持“不同训练方式在天然相似度与计算能量指标之间存在权衡”，不支持直接换算为体外亲和力。

在 peptide 设计中，论文用 PepBench 训练/验证、LNR 测试，并以 Boltz-1 折叠生成序列，按 pLDDT、ipTM、DockQ 和 Rosetta binding energy 评估（§4.4.2）。这些是计算评估链的一部分，且不同指标回答的问题不同。

## 5. 失效边界与反例

作者指出 zero-shot 设计虽然在计算 binding energy 上有较好结果，但抗体序列和结构不一定像天然抗体；示例包括 CDR-H3 转而接触抗体轻链，以及结合部位与参考抗体不同（Appendix D.4，Figure 9）。SFT 后这些模式有所改变，但仍是基准内计算观察。

论文讨论明确承认实际效果仍需湿实验验证（§5）。模型能输出几何上合理、预测界面分数较高的结构，不能单独确认表达、溶解性、靶点特异性或实验结合。

## 6. 与相邻工作的区别

APM 的核心是联合多链/all-atom 建模与生成。PepEDiff 把 peptide 序列生成搬到蛋白嵌入空间；2026 年的 shortlisting 工作则不生成候选，而是对已有候选池排序。它们处在流水线不同阶段，分数不应相互排名。
