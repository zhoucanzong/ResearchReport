## Collection and verification notes

- Used PaperFetcher search and batch metadata/citation retrieval for arXiv `2412.07978`, `2510.06546`, and `2309.00544`, then read fixed-version primary sources. Note: `2309.00544` is *Modular, Multi-Robot Integration of Laboratories: An Autonomous Solid-State Workflow for Powder X-Ray Diffraction*; it is not the A-Lab novelty critique despite its mention in secondary coverage, and is excluded from the evidence base here.
- Official full-text sources were read online where available. A direct request to the RSC HTML endpoint returned HTTP 403 in this environment; RAISE details are limited to the official publisher's indexed article text and article/landing page. Its supplementary package is linked but was not downloaded or inspected.
- Checked `/Users/zhoucanzong/Documents/paper-cache` for filename matches to the arXiv IDs used in this report; none were found. No full paper was added to the repository. The Nature version of record and correction, RSC publisher article, and arXiv fixed HTML were used as primary evidence.
- No code repository was cloned, reviewed or executed; no laboratory protocol was run or independently reproduced. Linked code is not counted as implementation evidence.
- Source diversity is limited: several recent examples center on materials research and overlapping Toronto/Berkeley acceleration-lab collaborations. The selection prioritizes mechanism diversity (BO, thermodynamics/active learning, state-machine LLM agents, agentic hypothesis generation) over survey-like coverage.

## Claim discipline

- Distinguish automation of execution from autonomy in experiment selection and feedback.
- Label results as simulation, retrospective evaluation, prospective physical operation, or independent repeatability evidence. A repeated trial within one setup is not cross-lab reproducibility.
- Use current corrected A-Lab results. “New to the platform” is not synonymous with “new to science.”
- For GPSS, keep the reported denominator and workflow boundary intact; do not call a partly manual characterization sequence fully end-to-end autonomous.
- Report a campaign's best metric with the target definition, sample window and the paper's own limitations. Never generalize a single task/campaign to domain-wide autonomous discovery.
