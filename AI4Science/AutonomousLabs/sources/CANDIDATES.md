# AutonomousLabs 文献筛选记录

核查日期：2026-10-23。本文为机制导向的定向选读，不是系统性检索；未主张覆盖了完整候选池。

## 纳入的六项研究

| 工作 | 纳入理由 | 在报告中的作用 |
| :-- | :-- | :-- |
| A mobile robotic chemist (2020) | 真实设备执行 Bayesian optimization，报告连续物理实验的规模和闭环反馈 | 说明定量目标下的机器人化选点 |
| A-Lab (2023; 2026 更正) | 机理约束主动学习用于无机合成，且作者更正影响“新材料”主张 | 说明实验失败反馈和 novelty 证据边界 |
| k-agents (2025) | 将实验状态机、工具代理和物理量子处理器操作连接起来 | 说明 LLM 代理编排多步骤实验的机制 |
| AILA / AFMBench (2025) | 包含真实 AFM 操作基准、重复任务和错误分析 | 提供仪器代理的任务级评测证据 |
| RAISE (2026) | 多目标 BO 驱动液体配方、接触角测量和下一轮实验 | 补充应用目标优化及模拟对照的解释边界 |
| A-Lab GPSS (2026 预印本) | 将异常归因和跨样本归纳用于前瞻性实验选择 | 展示 LLM 假设提案与单次 campaign 的边界 |

## 排除与范围边界

- 只纳入能够区分决策、物理执行、测量反馈或真实仪器评测机制的代表作；同一类别的近似工作未逐篇收录，不据此推断数量或总体效果。
- arXiv `2309.00544` 曾在二手讨论中被误指为 A-Lab 新颖性争议来源。核对官方题名后确认它是 *Modular, Multi-Robot Integration of Laboratories: An Autonomous Solid-State Workflow for Powder X-Ray Diffraction*，与该争议无关，故不作为 A-Lab novelty 证据。
- 生物筛选、自动化细胞实验及其他实验室方向未在本条目覆盖；后续可另立专题，避免把不同科学任务混为同一“自主程度”排行。
