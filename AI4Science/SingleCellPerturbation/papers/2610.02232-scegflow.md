# scEGFlow：在群体状态输运后用能量函数适配条件

**固定原文**：arXiv `2610.02232v1`，2026-09-27，arXiv perpetual non-exclusive license to distribute。精读入口：[官方 HTML](https://arxiv.org/html/2610.02232v1)。

## 亮点与差异

1. **一句话亮点**：把未配对 control/perturb populations 用 optimal transport 连成软伪轨迹，以 conditional flow matching 学状态输运，再以条件能量梯度修正 OOD 预测。
2. **新在哪**：不是把一个固定模型直接映射到每种条件，而是将 flow backbone 和 endpoint guidance 解耦，尝试对新药物/剂量/context 作低成本推理期调整。
3. **证据强度**：4i、SciPlex3、ComboSciPlex、LINCS L1000 四类既有实验数据，覆盖形态/蛋白与转录组读数；论文为 2026 年 arXiv v1，无独立复现或本研究新实验。
4. **值不值得引用**：值得作为 single-cell distribution transport + energy-guidance 的近期方法案例；不能用其模拟轨迹声称已观测细胞命运或因果机制。

## 1. 解决什么问题？

预测 perturbation response 不只是预测条件均值，还希望还原处理组细胞间的分布、异质性与低维结构。由于测序是破坏性采样，control 和 treated cells 独立观察；flow learning 需要某种对应监督。scEGFlow 用 OT 构造软对应，并让模型在 control state、perturbation vector、cellular context 条件下生成 perturbed-state distribution（Introduction、Methods §§4.1–4.3）。

## 2. 核心方法

1. 用 optimal transport 在独立采样的 control/treated cells 间构建 soft correspondences / pseudo-pairs（Methods §4.2）。这一步给学习提供几何结构，但配对本身是计算估计，并非追踪同一细胞得到的实测 lineage。
2. 用 conditional flow matching 学连续 velocity field，将 control states 运输到 treated distribution；条件含扰动、剂量与 context（Fig. 1、Methods §4.3）。
3. 对每个条件建立 energy model，并在 Euler inference step 中加 `−λ∇E` 修正，使生成 state 更符合被查询条件；独立条件可以组合为加权能量（Methods §4.4、Eq. 10–14）。Flow backbone 与 energy model 分开训练，因此条件修正可推理时进行。

关键超参因数据集不同：4i 训练 100,000 iterations、learning rate `1e-6`；SciPlex3 与 ComboSciPlex 50,000 iterations、`1e-7`；L1000 30,000 iterations、`1e-7`，energy model 300 iterations、`1e-4`，推理时 energy refinement 10 步、guidance `λ=0.05`（Methods §4.7）。不能把一个 benchmark 的收益推广为与其它 benchmark 相同的最优设置。

## 3. 数据与规模

- **4i**：77,743 cells、27 种药物处理、48 个属性（22 个形态 + 26 个蛋白强度）；来自两株共培养的 patient-derived melanoma cell lines（Methods §4.5）。
- **SciPlex3**：原始 649,340 个 cells、188 种小分子、4 个剂量、3 个癌细胞系；本文计算使用 290,888 cells 与 2,000 HVGs。
- **ComboSciPlex**：A549 的 63,378 cells、32 条件，含单药和组合药物。
- **LINCS L1000**：本文聚焦 Level 3 的 24,104 profiles、978 landmark genes、21 cell lines、79 compounds；Level 5 consensus signature 仅用于响应方向对照（Methods §4.5）。

## 4. 主要结果（带条件）

SciPlex3 的未见药物剂量 split 中，scEGFlow 的 Energy distance / Sinkhorn / MMD² 分别为 0.2438 / 0.1391 / 0.0039；对比 CellFlow 为 0.5218 / 0.3692 / 0.0065。未见 cellular context split 的 Energy distance 为 3.8726（CellFlow 22.3046），但 Sinkhorn 指标 scEGFlow 2.0344，而 Biolord 26.7688，条件比较必须逐指标读 Table 2。作者在这里报告高 Pearson 但同时指出 population-distribution 统计更能区分预测差异（§2.3、Table 2）。

在 111 个 LINCS held-out drug-dose contexts 上，以 top 10% 最强 Level 5 genes（98 genes）计算 up/down direction agreement。加入 energy guidance 后，平均一致率从 72.0% 至 81.0%，98/111 个 contexts 提升（§2.5、Fig. 5）。这支持与外部 consensus signatures 的方向一致性，不等于前瞻性干预命中率。

## 5. 消融说明什么？

文章比较有无 energy guidance、不同 guidance strength，并做 condition-wise OOD 分析（§2.3、Supplement S4.1–S4.2）。在 LINCS 方向一致率上，energy guidance 将均值由 72.0% 提至 81.0%，且 111 个评估 context 中有 98 个提升（§2.5、Fig. 5）。这些支持条件能量修正在特定 split 与指标下改善方向一致性；不是对真实 wet-lab outcome 的增益。作者指出方法需反复调用 velocity 与 energy 梯度，计算成本高；线性插值轨迹可能简化真实非线性变化；OT pseudo-pairs 依赖 feature-space distance，未必是真实 cell trajectory；组合多个 energy 还假定条件相互独立（Discussion §3）。这些边界说明它不是已验证的因果势能面。

## 6. 失效与外推边界

- OT pseudo-pairs 是依赖表示、代价函数与正则化的算法对应，可能把真实 lineage 不存在的假设写进训练轨迹。
- 评测主要是小分子处理或特定数据集，作者把 knockout 与 cytokine 扩展列为未来工作（Discussion）。因此不能泛化到任意遗传敲除或组织空间变化。
- few-shot 结果需要目标条件观测细胞；这是 adaptation，不是 zero-shot。3 个 4i target cells 的结果不能解释成只依赖 3 个细胞就能证明总体机制。
- L1000 Level 5 signatures 与 Level 3 training profiles 来自同一资源不同处理层级；它提供外部参考口径，但不是独立实验室复现。
- 本文没有做真实的细胞追踪、因果中介实验或新药物前瞻性 screen；生成多样细胞也不代表这些状态真是目标处理下观察到的结果。

## 7. 与同类系统的可判定差异

- 相对 P2P：scEGFlow 关注细胞状态分布与连续运输、条件能量重定向；P2P 关注随机 cell-set views 的期望效应一致和 condition memory。
- 相对 mean baseline：论文通过分布距离、MMD²、Sinkhorn 与能量距离比较预测群体，不仅看表达均值相关。
- 相对 perturbation-causality：模型以已收集干预数据训练并预测响应，未识别中介路径或验证反事实单细胞轨迹。
