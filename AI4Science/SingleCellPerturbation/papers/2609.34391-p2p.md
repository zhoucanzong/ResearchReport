# P2P：用跨视图监督估计未配对细胞群体的扰动效应

**固定原文**：arXiv `2609.34391v1`，2026-09-28，CC BY 4.0。精读入口：[官方 HTML](https://arxiv.org/html/2609.34391v1)。

## 亮点与差异

1. **一句话亮点**：把同一 condition 下两次随机 cell-set 抽样的共通部分当成群体 response 监督，显式区分 condition effect 与抽样 variation。
2. **新在哪**：多数方法以单细胞映射或处理组表达回归为目标；P2P 在 set 层面做 cross-view consistency，并让经验均值差通过 gate 与神经残差组合。
3. **证据强度**：Adamson、Norman、Replogle K562/RPE1 四个公开处理数据；五 seed 汇总；未见前瞻性验证。其 target condition training-role memory 与转导式 gene vocabulary 限制了“未见 perturbation”解释。
4. **值不值得引用**：值得作为近期 population-effect modeling 案例；若论证 zero-shot perturbation 或因果模型，则不能用这篇单独支撑。

## 1. 解决什么问题？

Perturb-seq 提供的是独立采样的 control 和 perturbed cell collections，不存在天然的一对一细胞前后配对。把任意 control 与 perturbed cell 配成一对，会制造没有实验依据的 counterfactual，并让群体差异和采样波动纠缠。P2P 把预测目标定义为条件层面的均值与相对于 control 的差异效应，而不是某个真实 cell 的命运映射（§1、§3.1，Eq. 1–3）。

## 2. 核心方法

每个 condition 各抽两个随机 view。若样本足够，views 不重叠；小样本则有放回独立抽样。模型用共享的 cell encoder 汇总 attention-weighted mean、普通 mean 与 hidden-state variance，保持对输入 cell 顺序不变（§3.1、§3.2.1，Eq. 2–6）。条件 encoder 表示扰动 token、context、dose，并对组合扰动加 pair-interaction block（§3.2.2，Eq. 7–8）。

输出 effect 由经验条件差 `m` 和神经残差加权：`δ_hat = g m + (1-g) Δ_neural`，gate 初始约为 0.75 的 memory 分支权重。模型还预测每个 gene 的 log variance。目标函数加权组合 Gaussian NLL、effect-weighted Smooth L1、effect correlation、moment matching 与跨视图一致性；论文给出系数分别为 0.35、1.50、0.15、0.08、0.05（§3.2.3–3.2.5，Eq. 11–14）。

关键 insight 是 loss 作用在 effect 与 population statistics 上，而不是只用全转录组表达拟合；这避免多数未变化基因完全支配目标。但它仍是论文作者提出的统计学习解释，不意味着 output variance 已经校准为真实生物个体差异。

## 3. 数据与规模

四个 processed AnnData 分别包括 Adamson 68,603 cells / 5,060 genes，Norman 91,205 / 5,045，Replogle K562 162,751 / 5,000，Replogle RPE1 162,733 / 5,000。过滤每 condition 至少 80 cells 后，task 数为 57、128、611、463。角色分配约 50% train、20% validation、10% support、20% test，结果汇总五个 seed（§4.1、Fig. 3）。

作者用 Welch test 和 Benjamini–Hochberg 校正定义 DEG：FDR ≤ 0.05 且绝对 effect ≥ 0.1。基线输出是在固定 benchmark protocol 下提供的结果；论文描述比较 GenePert、LinearPert、SLIM、Scouter、scPILOT（§4.2）。

## 4. 主要结果（带条件）

Table 1 中 K562 的 Effect Pearson：P2P 0.7018 ± 0.0003；Scouter 0.6432 ± 0.0025。DEG F1：P2P 0.1784 ± 0.0001；Scouter 0.0671 ± 0.0060。作者报告 P2P 在四个 benchmark 上获得最低 RMSE，并在主表 effect Pearson、DEG F1、DEG AP 等指标领先（§4.3、Table 1）。表达 Pearson 不总是 P2P 最佳，Adamson、Norman 上 GenePert 更高；这是作者对为什么要看 effect-level 指标的一个例子。

“五个 seed”并不等于五次独立生物实验。是同一 processed dataset 与 protocol 下的随机训练/评估重复。报告的是回顾性数据表现，不是前瞻性 screen hit rate。

## 5. 消融说明什么？

RPE1 消融（§4.4，Table 2）中，移除 dual-view loss 后 RMSE 从 0.0910 升到 0.0987、Effect Pearson 从 0.6609 降至 0.6412；移除 empirical memory 后 RMSE 为 0.1049、DEG AP 从 0.3120 降至 0.2088；移除 pair-interaction block 后 RMSE 为 0.1123。移除 heteroscedastic head 时 Effect Pearson 略升至 0.6681，但 DEG AP 降到 0.2319，提示单一 point metric 会掩盖其它目标的损失。消融支持这些组件在该 RPE1 protocol 上各有作用，不能证明跨实验室、未观测靶点或全新细胞类型泛化能力。

## 6. 失效与外推边界

最重要的阅读边界来自评测角色和经验 memory：直接 readout 为目标 condition 提供 control test cells，同时 memory 使用该 target condition 的 training-role cells；这不是完全未见 target 的 zero-shot test（Appendix B）。gene vocabulary 由当前 processed file 构造，作者明确称此 benchmark 对 token identity 是 transductive。memory-assisted transfer 也使用 target condition 的训练角色细胞（§4.6、Appendix B）。

小条件会出现有放回 view 抽样；两个 view 可以重叠。作者指出它们仍是同一个有限数据集合的采样，不是独立实验 replicates（§3.1、Appendix C）。因此模型在 cell-level splits 上的 low standard deviation 不应误读成跨实验重复的方差。

## 7. 与同类系统的可判定差异

- 相对 scEGFlow：P2P 把随机 cell-set cross-view 的统计一致性当监督，并预测条件均值/方差；scEGFlow 以 OT 软伪配对建立细胞状态路径，训练 flow，再进行能量条件修正。
- 相对 Systema：P2P 是响应预测模型；Systema 关注评估 reference 是否让共同系统偏移冒充 perturbation-specific response。
- 相对 foundation models：P2P 在本文中没有以大规模无监督 cell corpus 预训练为贡献点，突出模型规模之外的目标设计与监督单位。
