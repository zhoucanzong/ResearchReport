## Search and evidence handling

- Deep-reading workflow used the local `researcher` skill in `deep` mode and `paper-fetcher` `fetch`; metadata and version anchors are recorded per paper. The dossier openings use the repository's four-line “亮点与差异” convention and the bodies substantively address the seven review questions.
- PaperFetcher search query: `generative materials discovery inverse design experimental validation closed-loop autonomous laboratory`; arXiv returned MatterGen-related background, MASTER, SyMDis, ElementBERT and older experiment-design papers. These broad results were not promoted as report evidence without targeted primary-source inspection.
- PaperFetcher `fetch` was run for `2312.03687` and `2603.22748`. It was also run for `2309.00544`, which resolves to a different autonomous solid-state workflow and was excluded; A-Lab was read directly at its official Nature DOI instead.
- The report links every material-specific claim to the relevant primary work and narrows author-reported claims to the method/measurement used. No repository code was cloned, executed or independently audited. The MatterGen commit is a provenance pointer only; no source code was reviewed.
- No full article text, downloaded PDF or extracted passage has been copied into this repository. Local-cache lookup found no matching PDF artifacts for the cited identifiers.
