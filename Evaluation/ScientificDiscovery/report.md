# AI for Science：从回顾性基准到闭环实验，怎样判断“发现”

**范围与阅读路线**：本专题讨论 AI 系统提出科学假说、选择实验并解释结果时，证据能支持多强的“发现”主张。先读回顾性数据任务与方程发现基准，理解离线评测测到什么；再看 Coscientist 与 AutoSciLab，区分实验自动化、代理模型优化和真实实验反馈；最后读 Closed-loop Transfer（CLT），观察优化、独立预测检验和机制干预如何连成证据链。本文不是通用 AI4Science 目录，而是围绕“评测证据如何从离线能力走向实验检验”组织代表工作。通用基准效度、污染、评分器和 agent 外推另见[评测科学总论](../EvaluationScience/report.md)。

关于科学 Agent 的动态基准生成与慢速/不可逆实验评测，另见[科学 Agent 的评测证据](topics/scientific-agent-evidence.md)：前者研究怎样让任务跟上能力，后者把实验时间、资源占用和反馈时机纳入评测；两者都不能单独支持真实科学发现主张。

## 为什么“得到好结果”还不等于科学发现

闭环优化首先解决决策问题：在有限预算、既有数据和可行性约束下，下一轮实验应该测什么？它的效用可以是更快找到高性能候选、提高成功实验比例，或降低达到目标所需的资源。这些是有价值的工程成果，但不自动说明模型识别了真实机制。优化器可以利用代理模型偏差，也可以沿着数据中的偶然相关性找到高分候选。

“发现”是更强的知识主张。关键检验不是模型能否把已知数据拟合得很好，而是它能否在尚未参与拟合的条件下给出可区分竞争解释的预测，并通过新实验或干预接受检验。证据强度因此大致递进：历史数据重放检验分析与假说生成；前瞻性实验检验系统是否能提出并执行有用的实验；在新样本上验证预测检验外推；改变关键变量的干预则进一步判断某个机制解释是否具有可检验的因果内容。这几类研究回答不同问题，不能压成一个“科学发现分数”。

## 回顾性基准：测数据分析与假说形成，不测实验闭环

[DiscoveryBench](https://arxiv.org/html/2407.01725)（§4、§5.2、§B） 从已发表研究中的数据分析工作流构造任务，给系统数据集、元数据和发现目标，要求其形成包含背景、变量和关系的假说。论文报告的基准包含六个科学领域的 264 个真实任务，并另有 903 个合成任务；在其所测推理框架中，最佳系统得分为 25%（论文 §5.2）。这些是该基准任务构造与作者报告的基线结果，不是“科学发现成功率”。它能测试模型是否能从多表格、多步骤的数据分析走向有结构的发现陈述。任务来源于既有论文工作流，评测更接近“能否重走或完成数据驱动分析”，而不是在尚未观测的自然现象中做前瞻性发现。它也不能证明模型生成的假说已被新实验验证。

[LLM-SRBench](https://arxiv.org/html/2504.10415)（§2.1–2.3、§3.2） 把问题缩到科学方程恢复：一类任务把已知物理关系改写成不常见的数学形式，另一类从合成数据中提出方程，以降低只靠记忆经典公式过关的可能。它让读者区分“拟合观测”与“找回简洁、结构正确的关系”，并揭示符号搜索、表达式空间和噪声条件会怎样改变难度。该基准覆盖四个科学领域、239 个问题（111 个 LSR-Transform、128 个 LSR-Synth）；作者在 §3.2 报告的最佳模型分别达到 31.5% 与 28.1% 符号准确率。这说明方程发现仍困难，但分数只描述该基准的表达式变换/合成任务，不能作为现实科学发现率。即使在合成数据中准确恢复方程，也只说明算法在给定变量、噪声和方程族下完成了恢复；变量是否完备、实验测量是否可靠以及方程能否外推，仍需领域实验验证。

这类基准的优势是任务可重复、错误可定位，适合比较分析、检索、符号推理等组件。其边界则由任务构造决定：如果问题、变量和目标都从历史文献中给定，模型不必承担现实研究中最难的部分——确定什么值得问、哪些变量遗漏、实验如何设计，以及什么结果足以排除竞争解释。回顾性分数不是实验因果证据。

## 自动化实验：把计划变成可执行动作

[Coscientist](https://pmc.ncbi.nlm.nih.gov/articles/PMC10733136/)（Nature 正文） 展示了以大语言模型协调化学合成任务的系统：它把文献与网页搜索、实验规划、云实验室接口、液体处理设备的低层控制和已有实验数据上的优化串接起来。论文演示了已知反应的合成规划与执行，也展示了 Suzuki–Miyaura 和 Sonogashira 偶联反应的自动化实验。它的重要评测贡献是把“语言模型会不会写实验方案”推进到“系统能否把方案转成设备可执行的操作并处理结果”。

但自动执行和发现新机制是不同主张。Coscientist 的化学工作流依赖可访问的设备接口、试剂与预置实验空间；论文所示优化利用已有数据并在有限迭代预算内进行，设备板件搬运等环节仍有人参与。它支持的是特定实验室配置下的模块化自动化与优化，不应外推为跨实验室的完全自主科研能力，也不等同于因果机制已被验证。

## 代理模型闭环：优化效率与真实实验反馈要分开

[AutoSciLab 精读](papers/2412.12347-autoscilab.md)把候选生成、主动学习选点、潜变量约束和可解释关系拟合接进一个流程。其纳米光子学主结果中，候选搜索主要查询基于约 8,000 个网格样本训练的神经网络代理模型；报告中的 1,000 次搜索预算主要是代理查询，而非 1,000 次真实制备和测量。论文还展示了带噪真实实验反馈，但覆盖范围较小。方向自编码器使用研究者指定的物理量组织潜变量，方程学习也受候选函数库和数据质量约束。

因此，AutoSciLab 的主结果能说明系统在该代理搜索问题上如何提高候选探索效率，并展示如何把潜空间与物理先验、方程拟合结合；它不能单独证明同规模真实实验会获得相同提升，也不能仅凭拟合关系断言发现了因果机制。代理模型适合快速筛选，但只要实验分布离开训练网格、代理误差与搜索方向相关，闭环就可能“优化代理”而非优化真实系统。评估时要明确候选产生、代理查询、真实实验反馈分别占多少预算。

## 前瞻性预测与干预：把候选改进变成机制检验

[Closed-loop Transfer 精读](papers/2024-nature-closed-loop-transfer.md)将“找到更好的材料”和“解释为何更好”拆成阶段。研究在 2,200 个 donor–bridge–acceptor 分子设计空间中进行五轮闭环搜索，合成并表征 30 个新分子；随后从模型排序中选取 top 7 与 bottom 7 做验证。论文报告两组的平均 `T80 × spectral overlap` 分别为 165 与 97（Mann–Whitney `P = 0.026`，每组 `n = 7`；见论文 Figs. 1、4–5、Extended Data Table 1）。这提供了对排序预测的前瞻性检查，但 top/bottom 是按模型选择的极端样本，适合检验模型是否能区分高低候选，不是随机抽样估计整个化学空间的成功率。

更强的机制证据来自后续实验：作者依据物理描述符提出高能三重态密度与光稳定性有关，再改变溶剂并加入三重态淬灭剂，以考察溶剂介导 Dexter 能量转移这一解释所预测的方向是否出现。候选选择、独立样本检验和机制干预因此承担不同角色。它们共同支持该解释在所研究分子骨架和实验条件下具有预测力；不能据此断言同一机制适用于所有材料、溶剂和光化学过程。

这类设计也提示“验证实验”的两种用途。预先划出的独立样本有助于估计模型在目标总体上的预测能力；按假说专门选择的极端点或干预条件更适合区分机制。后者科学信息量可能很高，却不应被误读为无偏总体性能估计。论文需要说明样本为什么这样选、哪些数据参与了假说形成，以及干预前各竞争解释分别预测什么。

## 跨论文比较：证据阶梯不是单一排行榜

| 证据类型 | 代表工作 | 实际测量的能力 | 不能单独支持的主张 |
| :-- | :-- | :-- | :-- |
| 回顾性数据分析 | DiscoveryBench | 从历史研究数据和元信息完成多步分析并形成结构化假说 | 新假说已被真实实验确认 |
| 方程恢复 | LLM-SRBench | 在已设定变量、方程空间和噪声条件下恢复关系 | 变量完整、关系因果或跨域成立 |
| 自动化实验执行 | Coscientist | 在指定化学设备和工具接口中规划并执行部分工作流 | 完全自主研究或普遍实验室迁移 |
| 代理模型闭环 | AutoSciLab | 在代理模型上搜索候选，并以有限真实实验反馈做补充展示 | 大规模真实实验收益或已验证因果机制 |
| 新样本预测与干预 | Closed-loop Transfer | 在特定材料系统中检查排序预测并测试机制方向 | 任意材料与条件下普遍有效 |

这些层次不是严格单向流程：可解释方程可能从回顾性数据产生，也可能嵌入真实实验闭环；机器人化实验室能提高执行规模，却仍需独立实验设计与统计解释。读者应先问每篇论文要证明的是分析能力、优化效用、执行能力、预测效度还是机制知识，再判断其证据和主张是否匹配。

## 阅读一篇“AI 发现”论文时的检查问题

- **目标是什么？** 是找到高性能候选、缩短实验轮数、恢复已知方程、提出新假说，还是支持机制解释？
- **实验预算怎样拆分？** 历史数据、模拟器/代理查询、真实实验和人工干预分别占多少？“迭代次数”是否真的对应实验次数？
- **预测是否前瞻？** 假说或排序是否在新实验前固定？测试样本是否参与了候选筛选或参数调优？
- **验证点如何选择？** 随机留出适合总体预测评估；极端候选与针对性干预适合区分机制，但二者统计含义不同。
- **有哪些替代解释？** 仪器漂移、未观测变量、数据选择、代理偏差或实验操作限制，是否能解释同一结果？
- **能外推到哪里？** 新样本、新仪器、新实验室或新材料体系是否被测过？没有测试的外推范围应保持为开放问题。

## 开放问题

- 如何让自适应选样后的预测评估仍保持独立性，避免把多轮择优产生的高分误当成普通测试结果？
- 如何在有限预算下同时奖励目标优化与区分竞争假说，避免只追逐“当前最优值”？
- 代理模型的误差如何进入选点策略，并在真实反馈中被及时发现和修正？
- 哪种跨实验室、跨仪器和跨条件验证足以表明知识迁移，而不是原设置附近的局部有效？
- 阴性结果、失败实验和测量不确定性如何进入长期数据记录，使后续研究能区别“无效应”和“测不出来”？
