# AI 研究机构与团队入口

用于发现研究论文、技术报告和研究进展的官方入口清单。它是定期巡检的起点，不是论文证据本身；形成专题判断时仍应阅读原论文、官方技术报告或固定版本源码。页面可能同时发布论文、研究文章、产品公告和招聘信息，需按实际内容区分。

最后检查：2026-10-25。清单优先收录可直接浏览研究成果或论文的官方页面；不追求机构穷举。

## 定期更新方式

按季度巡检，或在启动相关专题时提前巡检：

1. 查看各入口自上次检查以来的新论文、技术报告和研究项目，跳过纯产品宣传、招聘和重复转载。
2. 记录候选工作的标题、官方页面、发布时间和所属研究方向；只有它提出独立研究问题或能推进现有专题理解时才纳入阅读队列。
3. 对入选工作回到论文原文、官方技术报告和代码仓库，按 `docs/team.md` 的阅读与证据规范开展精读；网站摘要只用于发现，不代替原文证据。
4. 更新本清单时检查链接是否仍有效、栏目是否迁移，并调整“最后检查”日期。无需为每次巡检建立逐页浏览日志。
