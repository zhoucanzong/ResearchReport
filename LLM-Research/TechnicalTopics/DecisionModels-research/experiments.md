## 2. EX-1 校准迁移（Calibration transfer）

### 假设

**H1**：一个在后校准集 A 上拟合的温度（或分群温度）**不能**迁移到条件 B（不同域 / 不同语言 / 不同服务精度 / 不同模型版本），其 ECE 会在 B 上退化到接近未校准水平。

**H1′（竞争假设，必须同时测）**：退化幅度**小于**"完全不做后校准"的代价——即"用一个通用温度也比不校准好"。

### 变式（8 个，逐个独立跑）

| 变式 | 迁移方向 | 固定量 |
|---|---|---|
| V1 | 域 A → 域 B（同语言、同版本、同精度） | 模型/版本/精度/语言/题型配比固定 |
| V2 | 服务精度 4-bit → bf16（同域） | 其余固定 |
| V3 | 语言 英语 → 低资源脚本（含高棉语类） | 其余固定 |
| V4 | 版本 v1 → v2（官方别名变更前后） | 其余固定 |
| V5 | 题型 choice → score → noul（跨原语迁移） | 其余固定 |
| V6 | 选项数 3 → 10 → 50 → 77（跨基数迁移） | 其余固定 |
| V7 | 标注量 N 阶梯（见"最小样本"）→ ECE 迁移曲线 | 其余固定 |
| V8 | 聚合温度 vs 分群温度（分群维度：题型 × 选项数档） | 其余固定 |

### 指标

- **主指标**：ECE（**分箱方案固定并写进报告**，建议同时报 10 箱与 15 箱），Brier，可靠性曲线分箱表。
- **副指标**：argmax 准确率（用于证明后校准**不该**改变它；若改变则实现有误）。
- **报告项**：`ΔECE = ECE(B|温度A) − ECE(B|温度B自拟合)`；以及 `ECE(B|无校准)` 作下界参照。

### 最小样本（含推导）

| 项 | 数值 | 依据 |
|---|---|---|
| 每个**判读胞元**（语言 × 题型 × 选项数档） | **≥ 300 条带标签样本** | 15 箱 ECE 的分箱定义要求最小关注箱有足够样本；300 条 ≈ 每箱 20 条的均匀情形。**研究推断**，反驳条件：若只判读 3 个信任区间（高/中/低），可降至 ≥100 条 |
| 温度拟合集与判读集 | **必须分离**（各占一半） | 有独立实现明确采用"half/half"；在同集上拟合+评估会高估效果（二手·模型卡） |
| 覆盖要求 | 每个**声明的选项**至少出现若干次（含罕见选项） | 选项集内无样本的选项，其概率无法被校准，也无法被判读 |
| 低资源脚本 | **单独一组**，不与其他语言合并 | 高棉语式的塌陷在混合池里不会显现（二手·模型卡） |

### 结果判读标准

| 观察 | 判读 |
|---|---|
| `ECE(B|温度A) ≈ ECE(B|无校准)` 且显著高于 `ECE(B|温度B自拟合)` | **H1 成立**（不可迁移）；H1′ 被推翻 |
| `ECE(B|温度A) < ECE(B|无校准)` 但 > 自拟合 | **H1′ 成立**：通用温度仍有残余价值，但**不可**替代域内重拟合 |
| 各胞元迁移损失差异 > 2 倍（如低资源脚本损失远大于英语） | **必须分群重校准**，禁止单一全局温度（与 Laya 的（题型 × 选项数）分群做法一致） |
| argmax 准确率在施加温度后发生变化 | **实现有误**（温度缩放是单调变换，不该改 argmax）——先修实现再报结果 |

## 3. EX-2 选项名 vs 定义冲突（Option-name vs definition conflict）

### 假设

**H2**：当选项的**名称**语义与**定义**相冲突时，模型跟随**名称**而非定义，且表现为**反转（inversion）而非混淆**，且该效应**随名称熟悉度放大**。

**H2′**：名称的**极性**（而非名称的"内容"）才是驱动因素——把名称换成**中性标识符**不改变结果，换成**反极性名称**才改变。

### 变式

| 变式 | 操作 | 目的 |
|---|---|---|
| V1 | 原名 + 正确定义（基线） | 基线 |
| V2 | **互换定义**：A 的定义挂到 B 的名称下（名称不变） | 若结果不变 → 名称主导 |
| V3 | **换中性标识符**：`A` / `B` / `C`（定义不变） | H2′ 的关键对照 |
| V4 | **随机字符串名**：如 5 字符随机串（定义不变） | 复现来源所述"随机字符串"条件 |
| V5 | **换反极性名**：与定义语义相反的常见词 | 定位"极性"机制 |
| V6 | **熟悉度梯度**：高频词名 → 低频词名 | 检验"熟悉度放大" |
| V7 | **二元 vs 多元**：2 选项 → 3+ 选项 | 检验"二元以上名称几乎承载全部信息" |

### 指标

- **混淆矩阵**（重点看**反转**方向的比例，而非总准确率）。
- **名称主导率** = 在 V2（定义互换）下跟随名称的样本比例。
- **极性敏感度** = `准确率(V5) − 准确率(V3)`。
- 一致性检验：同一状态上多次运行的 argmax 稳定率。

### 最小样本

| 项 | 数值 | 依据 |
|---|---|---|
| 每变式样本数 | **≥ 200 条**（每条含 ≥2 选项） | 要区分"反转率"与"混淆率"，需按方向分解；200 条使 10% 级效应具有可判读的 Wilson 区间。**研究推断** |
| 熟悉度梯度 | 每个熟悉度档 **≥ 100 条** | 需要档内估计 |
| 重复运行 | 每变式 **≥ 3 次**（顺序随机化种子不同） | 选项顺序效应与随机性需分离（P4） |

### 结果判读标准

| 观察 | 判读 |
|---|---|
| V2 ≈ V1（结果不变），且 V3 显著改善 | **H2 成立**：名称主导定义 |
| V3 ≈ V2（中性标识符无改善）而 V5 显著恶化 | **H2′ 成立**：只有"极性"在起作用，不是名称"内容" |
| V6 呈现单调"熟悉度 → 更大反转" | 与来源所述一致 |
| 无以上任何方向性差异 | **H2 / H2′ 在本模型上不成立**（必须如实报告为阴性结果，并给出置信区间） |

> **与既有证据的关系**：来源论文报告"名称主导 rubric、表现为反转而非混淆、逐谓词成立、极性被熟悉度放大、二元以上名称几乎承载全部信息，且换成随机字符串不改变结果"（精读原文·预印本，[2609.26758](https://arxiv.org/abs/2609.26758)）。**本协议的目的是在本模型/本域上复现或证伪，而不是复述该论文。**

## 4. EX-3 选择性预测：阈值与成本-精度前沿（Selective prediction）

### 假设

**H3**：存在一条由**置信度阈值**参数化的成本-精度前沿：随阈值提高，覆盖率下降、**段内准确率上升**，且**总成本**（模型调用 + 上抛强模型 + 人工复核）存在最小值。

**H3′**：最优阈值**不是**全局常数，而由风险分级决定（只读操作 vs 破坏性操作的门槛不同）。

### 变式

| 变式 | 操作 |
|---|---|
| V1 | 单阈值扫描（0.30 → 0.99，步长 0.02） |
| V2 | 三段门控（高自动 / 中复核 / 低转人工），**阈值由风险分级** |
| V3 | 低置信**路由回 LLM** vs **路由回人工**（两条升级路径的对比） |
| V4 | 用**不同门控信号**：`confidence`(p_max) vs 归一化熵 vs margin vs `act_probability` |
| V5 | 加入**成本模型**：模型调用单价、上抛模型单价、人工单条成本（三者给出敏感性区间） |
| V6 | **子群分层**前沿（语言 / 题型 / 选项数档各一条前沿） |

### 指标

- **risk–coverage 曲线**（每段覆盖率 / 段内准确率）。
- **成本-精度前沿**：横轴总成本（每千条），纵轴端到端业务准确率（**含升级后的最终结果**）。
- **门控 AURC**（risk–coverage 曲线下面积）或 AUROC（"门控信号把正确答案排在错误答案前"的能力）。
- **误判成本加权准确率**：按业务权重给错误类型赋不同代价（**关键**：这一步才把"概率"接到"业务正确率"）。

### 最小样本

| 项 | 数值 | 依据 |
|---|---|---|
| 总样本 | **≥ 2,000 条带标签** | 覆盖率-准确率曲线要按段估计；高阈值段流量小，需总量支撑。有公开基准用 **2,000 决策 / 400 例** 的规模（二手·模型卡），可作可比量级参照 |
| 每个高风险子群 | **≥ 300 条** | 子群前沿必须单独估计；与 EX-1 同量级 |
| 阈值扫描的分辨率 | 覆盖率每档 **≥ 50 条**才报点估计 | 低于此须报 Wilson 区间或合并相邻档 |
| 门控信号对比（V4） | 同一批样本上**同条件**对比 | 信号对比必须共享样本，否则不可比。有实现用 **396 条**做门控 AUROC（二手·模型卡）——**该量级只能给出粗方向，不能定阈值** |

### 可对齐的量级锚点（带条件列，**不是本实验的结果**）

| 锚点 | 覆盖率 / 准确率 | 条件（对照模型 / 缓存 / 工作负载 / 任务） | 等级 |
|---|---|---|---|
| ≥0.80 自动执行 | **62% 流量 / 93% 准确率** | `jev-lite` 1,898 条留出（31 个未见任务 + 78 个未见 state + SST-2 全留出）；单模型、无缓存、单问 | 二手·模型卡 |
| 0.50–0.80 人工确认 | 36% 流量 / 60% 准确率 | 同上 | 二手·模型卡 |
| <0.50 转人工 | 2% 流量 / 32% 准确率 | 同上 | 二手·模型卡 |
| 低置信路由回 LLM | 成本降至"全用 LLM"的 **1/4–1/2**，效果持平或更好 | CSS 18 任务 / 7,977 项，zero-shot；决策模型 + 单任务最优 LLM 两臂 | 精读原文·预印本（[2609.24574](https://arxiv.org/abs/2609.24574)） |
| 门控信号可用性 | `confidence` AUROC **0.77** vs `act_probability` AUROC **0.30**（后者读作 1.0，方向与正确性相反） | Laya，396 条带标签决策，同一批样本 | 二手·模型卡 |

> **纪律提醒**：上表四行来自**两个不同系统、三组不同任务**，**不可拼成一条前沿曲线**；它们只提供"量级"参照。真正的前沿必须由本协议在你自己的域上测出。

### 结果判读标准

| 观察 | 判读 |
|---|---|
| 段内准确率**不随阈值单调上升** | 该门控信号**不可用于选择性预测**（H3 被推翻） |
| 某信号 AUC < 0.5（如 Laya 自陈 `act_probability` AUROC 0.30） | **明确排除该字段**；不得因其名字含 "probability" 而使用 |
| 全局单阈值的最优成本显著高于风险分级阈值 | **H3′ 成立** |
| 子群最优阈值与全局最优阈值差异 > 0.1 | **必须分群设阈值**；全局阈值会给某些子群带来不可接受的错误率 |
| 成本最小点出现在**极低覆盖率**（如 < 20%） | 该任务不适合"决策模型 + 升级"架构，应直接使用强模型（此为**架构级**否证） |

## 5. EX-4 多问题干扰（Multi-question interference）

### 假设

**H4**：同一 state 上并行求解多个问题时，各问题的答案**相互影响**——增加问题会改变**已有问题**的答案（不满足"条件独立"）。

**H4′**：即便答案不改变，**增加问题会改变概率/置信度**（校准漂移）。

### 变式

| 变式 | 操作 | 目的 |
|---|---|---|
| V1 | 各问题**单独调用**（每问一次前向） | 独立基线 |
| V2 | 全部问题**一次调用**（fan-out） | 干扰组 |
| V3 | **渐进加入**：1 → 2 → 5 → 10 → 20 问，记录已有问题的答案变化 | 剂量-反应 |
| V4 | **顺序反转**：调整问题在请求中的排列 | 位置效应 |
| V5 | **注入异质问题**：混入一个语义上无关/对抗的问题 | 干扰强度上限 |
| V6 | **state 长度 × 问题数** 交叉格 | 分离"上下文被摊薄"与"问题互相干扰" |
| V7 | state 重复计入的 **token 成本**测量（官方定义的两层上下文上限） | 成本侧对照 |

### 指标

- **答案翻转率** = `V2 的 argmax ≠ V1 的 argmax` 的比例。
- **概率漂移** = 逐问题 `|p(V2) − p(V1)|` 的分布（均值/中位/p95）。
- **校准漂移** = `ECE(V2) − ECE(V1)`（同批样本）。
- **成本口径**（必报四要素）：对照模型 / 缓存假设 / 工作负载（问题数与 state 长度）/ 任务。

### 最小样本

| 项 | 数值 | 依据 |
|---|---|---|
| state 数 | **≥ 150 个不同 state** | 干扰需要足够多样的状态载体；按"每个 state 问 10 个问题"计，共约 1,500 决策 |
| 每个剂量点（问题数档） | **≥ 300 决策 × 3 次运行** | 翻转率是小概率事件，需多次运行分离随机性 |
| 翻转事件的报告门槛 | 若期望翻转率 ~10%，300 次的 Wilson 区间约 ±3.4pp | 低于该分辨率的差异不可解读为"有干扰" |

### 结果判读标准

| 观察 | 判读 |
|---|---|
| V2 与 V1 的**逐问题答案完全一致**且概率漂移 < 1pp | **H4/H4′ 均不成立**（支持"条件独立"的契约描述） |
| 有翻转但**仅出现在问题数 ≥ 10** | 存在**容量型**干扰（上下文被摊薄），不是语义干扰 → 应限制单请求问题数 |
| V4（顺序反转）造成显著差异 | 存在**位置偏置** → 必须随机化顺序（P4） |
| V5（异质问题）造成显著退化 | **对抗性问题会污染同批其它问题** → fan-out 需做输入隔离 |
| V6 显示 state 越长干扰越大 | 与官方"state 被每题重复计入"的上下文口径一致 → 按 token 成本设上限 |

> **契约侧参照**：官方文档称同一请求中每个问题"看到同一个 state、被独立评估"，并推荐把**所有**可能用的问题放进**一次**调用（speculative fan-out）（精读原文·官方文档）。**本协议的职责正是检验这一契约在概率层面是否真的成立**——因为同契约的第三方实现把"各决策条件独立"作为其并行性的前提（二手·模型卡）。

## 6. EX-5 长时程误差累积（Long-horizon error accumulation）

### 假设

**H5**：把决策模型放进多步循环（每一步做一次有界判断，结果进入下一步），**单步准确率不变**的前提下，端到端成功率随**步数**指数衰减（`≈ a^n`），且**校准不随步数恶化**时仍会衰减。

**H5′**：级联（高置信执行 / 低置信上抛）的收益随步数**衰减更快**，因为每一步的阈值触发条件是独立的。

### 变式

| 变式 | 操作 | 目的 |
|---|---|---|
| V1 | 纯决策模型链：n = 1, 2, 4, 8, 16 步 | 基线累积曲线 |
| V2 | 纯强模型链（同任务、同预算） | 对照臂 |
| V3 | 级联链（阈值门控 + 上抛） | 检验 H5′ |
| V4 | 每步**独立核对**（外部确定性校验介入） | 检验缓解手段 |
| V5 | **错误类型注入**：让错误发生在"不可逆承诺"步 vs "可延迟"步 | 与来源所述"错误在不可逆承诺与延迟之间迁移"对齐 |
| V6 | **缓存开/关** | 边缘编排研究显示缓存会消掉大部分时延优势；长链上缓存的影响更大 |
| V7 | 每步**概率记录**：逐积累以观察置信度是否随步数漂移 | 检验"校准是否随步数恶化" |

### 指标

- **端到端成功率 vs 步数**（主曲线）。
- **拟合的每步准确率 a 与实际单步准确率之差**（若 `端到端 < a^n`，说明存在**非独立**的误差累积）。
- **最早不可恢复步**（first unrecoverable step）的分布。
- **累积成本**（每步调用单价 × 步数 + 上抛成本），四要素齐报。
- **按错误类型加权的损失**（而不是只报成功率）。

### 最小样本

| 项 | 数值 | 依据 |
|---|---|---|
| 每条轨迹长度 | **≥ 16 步**（并含 32 步档） | 要观测指数衰减的曲率，至少需覆盖 4–5 个倍增点 |
| 轨迹数 | **每臂 ≥ 200 条轨迹**（随机初始状态） | 端到端成功率在 0.5 附近时，200 条的 Wilson 区间约 ±7pp。**研究推断**：若目标是分辨 `a^n` 与观测值的偏离，需 ≥300 条 |
| 步骤级标签 | 每步都要有**可判定的正确答案** | 否则无法区分"步错"与"评价错" |
| 随机种子 | **≥ 3 个**，报告种子间离散度 | 长链实验对随机性极敏感 |

### 结果判读标准

| 观察 | 判读 |
|---|---|
| 观测端到端成功率 ≈ `a^16`（含区间） | **H5 成立**：误差累积就是独立衰减的叠加，无需额外机制解释 |
| 观测**明显低于** `a^16` | 存在**非独立**误差累积（错误相互放大）→ 必须查状态污染路径 |
| 级联臂在短链有优势、在长链无优势或更差 | **H5′ 成立**：级联的价值随步数衰减 |
| V4 显著抬升长链成功率 | **缓解手段有效**，且应把它写成架构要求而非可选优化 |
| 每步置信度随步数系统性升高（漂移） | **校准在长链上失效** → 阈值门控在长链不可用（这是比"成功率下降"更严重的发现） |

> **背景证据（不是结论）**：REFLEX 风格的受控干预报告"相对只用强模型成本降 3.7×、成功率差异统计上未分辨"，同时报告"更大的动作集与'结构上近似合法'的备选会降低**授权边界**处的准确率"，且错误在"不可逆承诺"与"延迟"之间按备选类型迁移（精读原文·预印本，[2609.26532](https://arxiv.org/abs/2609.26532)）。该工作给了本协议 V5 的直接动机，但**其结论只在自身的 τ 风格任务与动作集条件下成立**，不可外推。
