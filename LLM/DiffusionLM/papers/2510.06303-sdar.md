# SDAR: A Synergistic Diffusion-AutoRegression Paradigm for Scalable Sequence Generation

**固定原文**：arXiv [`2510.06303v3`](https://arxiv.org/html/2510.06303v3), 2025-10-18；technical report；license: CC BY 4.0（arXiv 页面）。作者：Shuang Cheng et al. [版本记录与元数据](https://arxiv.org/abs/2510.06303)。PDF 由 `paper-fetcher download 2510.06303` 缓存于仓库外 `.paper-cache/LLM-DiffusionLM/2510.06303.pdf`，并从 PDF 提取全文阅读；核对 §§2–8、Appendices A–B、Figs. 1–8、Tables 1–7。没有运行作者代码或模型，没有独立复现。

## 四个亮点

1. **机制是 AR checkpoint 转换**：SDAR 从现成 AR 模型继续训练，换成 blockwise diffusion 目标和 block-causal attention；每个 block 内以 masked diffusion 联合去噪，block 间仍因果推进。其主要主张是节省从头训练 diffusion 的成本（§3.1；Fig. 1；原文 PDF：`.paper-cache/LLM-DiffusionLM/2510.06303.pdf`）。
2. **不同于固定块长的纯 block diffusion**：推理时每个 block 从全 mask 开始，依置信度逐步提交 token；静态解码每步固定提交数，动态解码按 confidence threshold 接受并设置最低进展量。可复用已完成块的 KV cache，生成结束条件可落在块中间（§3.2、Appendix A.2；Fig. 2）。
3. **成本来自额外适配数据，也有额外每 token 计算**：规模实验在 Qwen3 基座上用 50B token CPT 转换，再用 4B token SFT；论文基础设施说明每样本要处理 clean/noisy 两个版本，虽然原始 GPU token throughput 接近 AR，折算有效训练速度约为 AR 的一半（§5.1.1、Appendix A.1）。
4. **质量与速度必须连同设置读**：30B-A3B chat 在 18 项任务中有的高于、有的低于对应 AR-chat；8B、H200、LMDeploy 实测在小 batch 的动态 decoding 获益最大，优势随 batch 增大而收窄。结果不支持无条件宣称 AR 质量或吞吐 parity（§5；Table 2、Figs. 5–8）。

## 七问精读

### 1. 它要解决什么问题？

作者认为，纯 masked diffusion 的训练比 next-token prediction 计算利用率低，且全双向推理缺少标准 KV cache；从头训练块扩散又有明显训练开销。SDAR 想复用 AR 预训练获得的语言能力，只做较短的范式转换，使模型在 block 内并行生成、block 间保持因果结构（§1、§4）。

### 2. 转换训练和推理具体怎么做？

将序列分成固定宽度的块，目标概率分解为 `∏ₖ p(bₖ|b<ₖ)`。继续训练时随机 mask token；预训练可 mask 全序列，SFT 阶段保留 prompt、只 mask response。注意力变为 block-causal：前置块 clean，当前噪声块能看见自身和前置块；目标从 AR 的 NTP/NLL 改为条件 block diffusion NELBO。作者明确说转换时没有 logits shift 或 attention-mask annealing（§3.1、Eq. 6–7、Fig. 1）。

推理依次处理 blocks。当前块以全 mask 开始，重复模型前向预测 token；按静态低置信重遮策略固定步数提交，或按动态阈值 `τ` 一次提交所有超过阈值的 token，并在数量不足时强制至少提交若干高置信 token。前面完成的 blocks 可缓存 KV；当前块不存入 cache，完成后再进入上下文（§3.2、Fig. 2）。这仍有块间串行依赖；块内并行取决于 threshold、block size 和模型 confidence。

### 3. 训练配方与计算预算是什么？

受控 2B 比较从头在相同 1T-token 语料训练 AR 与 MDLM，架构、tokenizer、optimizer、context length 4,096 相同；随后各走 100B-token annealing，其中转换成 block diffusion 的模型块长 16，再以 4B-token 指令数据 SFT（§4.1）。规模测试使用 Qwen3 1.7B、4B、8B、30B-A3B 基座，50B-token CPT 加 4B-token SFT，context 4,096；主要聊天基准将 block length 与步数设为 4（§5.1.1）。科学模型另有 1T-token科学 AR CPT、50B-token SDAR conversion 和 0.5B-token 长 CoT SFT（§6.1）。这些是不同实验配方，不应混成单一成本数字（原文 PDF：`.paper-cache/LLM-DiffusionLM/2510.06303.pdf`）。

### 4. 结果支持到什么程度？

- **受控 2B**：`AR-BD-2B-Chat` 与 AR-2B-Chat 各任务表现混合：SDAR 在 MMLU/GPQA 更高（50.9/28.2 vs 48.7/26.3），在 MATH/HumanEval 更低（26.8/40.0 vs 29.9/42.1）。表 1 支持“部分能力保留且可块内并行”，不支持逐项质量持平。MDLM-BD 同样不稳定，多个分数高于未转换 MDLM，仍有明显任务差异（§4.2；Table 1；原文 PDF：`.paper-cache/LLM-DiffusionLM/2510.06303.pdf`）。
- **30B-A3B**：同一 CPT/SFT 配方下，SDAR-Chat 对 AR-Chat 的优势任务与劣势任务并存。例：MMLU 82.8 vs 82.2，GPQA 36.7 vs 37.3，GSM8K 91.4 vs 92.7，MMLU-Pro 61.5 vs 63.8，HumanEval 87.2 vs 84.8；不能只引用胜出的任务（§5.1；Table 2）。
- **速度**：算法性 TPF 衡量每次 forward 平均接受 token 数，不等于端到端延迟。实际部署实验使用 SDAR-8B-Chat、单张 H200、LMDeploy、Math-500，batch 4–512，动态 threshold 0.9；最大吞吐分别报告 block 4/8/16/32/64 为 6,600/5,510/4,236/2,520/1,509 tokens/s。相对 AR 的加速受 batch、block size 和特定引擎影响，小 batch 更有利（§5.2.4；Figs. 7–8）。
- **阈值代价**：降低 threshold 可增大并行提交，但错误 block 会抬高后续不确定性，TPF 与阈值、任务之间可能非单调；因此不能把理论 block size 直接当固定速度收益（§5.2.3；Figs. 5–6）。

### 5. 哪些实验隔离了范式影响？

§4 用相同基座训练数据和后训练数据比较 AR 与转换结果，是论文中相对更可解释的实验；但对照的 decode protocol 按架构不同，且转换 objective 与 NTP 不是单变量改动。30B chat 系列在对应 Qwen3 checkpoint 上采用相同 CPT/SFT 配方，较适合看任务级差异。科学模型的 SDAR/AR 对照也镜像了后续 50B data 和 SFT，但继承了上游 1T 科学预训练，不能视为从零训练成本比较（§4.1、§5.1.1、§6.1；Tables 1–5）。

### 6. 主要限制和部署边界？

SDAR 不是免成本转换：50B-token CPT 是主要案例，不是极短或零成本适配；实际每样本 clean/noisy 双输入，作者报有效速度约减半（Appendix A.1；原文 PDF：`.paper-cache/LLM-DiffusionLM/2510.06303.pdf`）。论文称模型可从不同 AR 架构转换，但公开的主实测集中在列出的 Qwen3 和自训 2B 模型。工业吞吐测试为单 GPU 和特定 LMDeploy 实现，不能迁移到其他 batch、硬件、引擎或负载。不同 decoding 会改变速度与准确率；大 block 更并行也更依赖阈值。论文未提供误差条或多 seed 区间；外部基线有些取自技术报告。没有独立复现或代码审计。

### 7. 它与 BD3-LM、CARD 有何区别？

SDAR 的关键贡献是**先有 AR，再以短 CPT 转成 blockwise diffusion**；它沿用固定 block 内 masked diffusion，按 confidence 逐步写入。BD3-LM 重点在 block 扩散的训练目标、计算向量化和低方差 noise schedule，并非以 AR 转换成本为中心。CARD 则保留 token 级严格 causal mask，在受限前缀上加噪并以局部 context reweighting 稠密训练；它不是按 block 做双向 self-attention。三者机制和成本口径不同，不能把其中一篇的速度或质量结果转借给另两篇（原文 PDF：`.paper-cache/LLM-DiffusionLM/2510.06303.pdf`）。
