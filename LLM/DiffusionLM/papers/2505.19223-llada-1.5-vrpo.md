# LLaDA 1.5: Variance-Reduced Preference Optimization for Large Language Diffusion Models

**固定原文**：arXiv `2505.19223v2` · 2025-10-12（最新版，2026-10-23 核验）· [官方 HTML](https://arxiv.org/html/2505.19223v2) · [arXiv 版本记录](https://arxiv.org/abs/2505.19223) · license：CC BY 4.0。2026 ACL Anthology 收录：[ACL 2026 paper page](https://aclanthology.org/2026.acl-long.524/)。作者：Fengqi Zhu、Rongzhen Wang、Shen Nie、Xiaolu Zhang、Chunwei Wu、Jun Hu、Jun Zhou、Jianfei Chen、Yankai Lin、Ji-Rong Wen、Chongxuan Li。原文缓存于仓库外 `.paper-cache/LLM-DiffusionLM/2505.19223.pdf`；已精读 §§2–4、Appendix B–D，核表 1–3。未下载或运行作者代码，未独立复现。

## 亮点与差异

1. **一句话亮点**：针对 masked diffusion 模型做 DPO 时无法直接求精确 log-likelihood、ELBO 蒙特卡洛估计方差高的问题，提出 VRPO；在 350K 内部偏好对、单 epoch 的 LLaDA-8B alignment 上报告多项基准高于 SFT-only 和朴素 DPO。
2. **新在哪**：将 log-likelihood 换成 ELBO 后，分析随机偏好分数经 `log σ` 非线性变换产生的误差；用更多样本预算、固定总预算时“多抽 timestep、每个 timestep 抽一个 mask”，以及 policy/reference 共用 Monte Carlo 样本的 antithetic sampling 降低方差。后两种是在合理预算下提升估计质量，不是新 diffusion 训练目标。
3. **证据强度**：有估计器/梯度方差分析与模块消融，也报告单模型 350K preference pairs 的多任务 benchmark；偏好数据为内部数据，8B 训练无超参搜索，缺少外部偏好集复验。性能差异来自作者报告，非独立复现。
4. **值不值得引用**：可引用为 MDM 上将 DPO 的 likelihood estimation 改造成可控 ELBO Monte Carlo 的方法及其实验；不能说已经证明适用于任意 MDM、公开偏好数据或任何 RL alignment 方案。

## 七问精读

### 1. 解决什么问题？

标准 DPO 的偏好损失使用 policy/reference 对 chosen 与 rejected response 的 log-likelihood ratio。masked diffusion model (MDM) 的响应 likelihood 需对扩散 timestep 和带噪样本取期望，实际要用双重 Monte Carlo 估计 ELBO；样本数有限时估计方差大，而 DPO 的 `log σ` 非线性会让随机分数带来额外偏差和方差，影响梯度。本文给出误差的理论联系，再针对这个估计器结构降方差，并将方法用于 LLaDA 8B Instruct（§1、§2.2、§3.1–3.2）。

### 2. 核心方法是什么？

**ELBO 替代与方差来源。** 对完整响应 `y`，论文写成

`Bπ(y|x)=E_{t∼U[0,1]} E_{yₜ∼q(yₜ|t,y,x)} [ℓπ(yₜ,t,y|x)] ≤ log π(y|x)`。

使用 `nₜ` 个 timestep、每个 timestep `nᵧₜ` 个随机 mask 样本，总预算 `n=nₜ×nᵧₜ`；把 policy 与 reference 的 chosen/rejected ELBO 代入 DPO，再用有限抽样分数更新。有限样本 ELBO 均值本身可无偏估计其期望，但把有噪声的分数放入非线性 `log σ` 后，偏好损失和梯度仍会出现偏差及方差（§2.2、Eq. 4–6；§3.1、Eq. 7–9）。

**VRPO 三个组成。**

1. **增加预算**：增大 `n` 可降 Monte Carlo variance，但增加计算。
2. **最优预算分配**：在固定 `n` 下令 `nₜ=n`、`nᵧₜ=1`，即每个 timestep 取一个噪声样本，而非少数 timestep 上各取多个 mask；作者分析显示这能降低 ELBO 估计方差。
3. **Antithetic sampling**：计算 policy 与 reference 相关 ELBO 时共用 timestep 与 mask 样本，利用差分中的相关性降低偏好分数方差。

作者的理论界说明，偏好分数估计方差会控制变换后 DPO loss 的 bias/variance，并进一步关联梯度估计误差（§3.2、Theorem 1、Propositions 1–2；Fig. 3；Appendix B.2–B.4）。这里的“optimal”专指文中对 ELBO estimator 的预算分配分析，不是声称对任意运行约束/所有模型都有全局最优训练策略。

**训练配方。** 基座 LLaDA 8B Instruct（32 层，hidden size 4096、32 heads、vocab 126,464，总参 8.02B）。使用约 350K 内部偏好对训练一 epoch，batch 64，AdamW `weight_decay=0.01, β₁=0.9, β₂=0.95`；15 warmup steps 升至 `5e−7`，后 cosine decay；DPO `β=0.2`，另加权重 `0.05` 的 MDM SFT loss 稳定训练。Reference 初始化为 LLaDA Instruct。默认 VRPO 总样本预算 `n=8`（`nₜ=8,nᵧₜ=1`），含 antithetic sampling；训练耗约 405 H100 GPU hours。资源受限，未做超参搜索（§4；Appendix D.1–D.3、Table 3；固定版原文：`.paper-cache/LLM-DiffusionLM/2505.19223.pdf`）。

### 3. 数据与规模？

- **偏好数据**：约 350K pairs，由作者内部大规模收集；筛掉低质量数据、相似度去重、用 reward model 排序挑选，并用先进 LLM 输出替换部分 chosen response。主题比例约为创意写作 35%、知识 QA 18%、NLP 任务 16%、数学 14%、推荐 7%、代码 5%、推理 3%，余量为安全及其他任务（§4；Appendix D.3；固定版原文：`.paper-cache/LLM-DiffusionLM/2505.19223.pdf`）。
- **模型**：LLaDA Instruct 与以它初始化的 LLaDA 1.5 8B；baseline 还包括使用 `nₜ=1,nᵧₜ=1` 且无 antithetic sampling 的 naive DPO（§4.1；Appendix D.2）。
- **评价集**：数学/科学 GSM8K、Math、GPQA；代码 HumanEval、MBPP；alignment IFEval、Arena-Hard、AlignBench、MTBench，共 9 项（§4）。对 MDM 采用 diffusion、diffusion semi-autoregressive、low-confidence remasking 等采样；遵循其评测习惯按任务采用最优 sampling strategy，细节放在 Appendix D.4。论文不是对每个模型强制唯一相同采样算法的纯模型参数对照。
- **重复性补充**：Appendix D 的部分置信区间与估计方差分析采用三次 VRPO runs；主表列的是模型 benchmark 主结果。seed-run 数不能理解为三套独立从头预训练模型（Appendix D.5）。

### 4. 主要结果是什么？

Table 1 在 `LLaDA 8B Instruct (SFT)`、`LLaDA DPO (SFT+naive DPO)`、`LLaDA 1.5 8B (SFT+VRPO)` 三者间报告：

| 任务（论文所用评测口径） | SFT-only | naive DPO | VRPO / LLaDA 1.5 | VRPO 对 SFT-only 差值 |
| :-- | --: | --: | --: | --: |
| GSM8K | 78.6 | 80.7 | 83.3 | +4.7 |
| Math | 42.2 | 41.6 | 42.6 | +0.4 |
| GPQA | 33.3 | 34.3 | 36.9 | +3.6 |
| HumanEval | 49.4 | 48.2 | 52.4 | +3.0 |
| MBPP | 41.0 | 41.4 | 42.8 | +1.8 |
| IFEval | 62.2 | 62.0 | 66.2 | +4.0 |
| Arena-Hard | 10.0 | 11.9 | 14.3 | +4.3 |
| AlignBench | 5.4 | 5.8 | 5.9 | +0.5 |
| MTBench | 7.2 | 7.1 | 7.3 | +0.1 |

Table 1 的关键结果是 VRPO 在这九项上均高于作者列出的 SFT-only 分数、并超过 naive DPO；但提高幅度差异明显，MTBench 仅 `+0.1`，不能统一表述成显著通用提升。abstract 的 + 值均为绝对分数点差（§4.1、Table 1；abstract；固定版原文：`.paper-cache/LLM-DiffusionLM/2505.19223.pdf`）。

在预算消融中，作者报告 `n=1→8` 时 score estimator variance 从 `44.0→1.0`，GSM8K 从 `80.1→83.3`；固定预算的 allocation 与 antithetic 对照一般降低估计方差，但作者也指出估计方差显著降低不总是转成下游指标的大幅提升，因为最终成绩还受 generalization 影响（§4.2、Table 2）。

### 5. 消融或对比说明了什么？

- **样本预算**：Table 2 中从 `n=1` 提升至 8 同时大幅降低估计方差并提高若干 benchmark；这支持更多 Monte Carlo 样本对有限估计的帮助，也有计算成本。
- **预算分配**：在总样本数一致的设置中，`nₜ=n, nᵧₜ=1` 相比每个时间点多 mask 样本一般产生更低方差和更好的成绩，符合作者的方差推导；不同配置在 downstream 分数上并非每项单调改善（§4.2、Table 2）。
- **Antithetic sampling**：共用样本显著减少 score/loss variance；benchmark 增益不稳定。作者举例认为其可能使模型更专注优化过程而影响 generalization，明确将此写为解释假设，而非实验证明的机理（§4.2、Table 2）。
- **数据消融与算法消融的区别**：这些对照主要改变估计器采样与计算预算，没有控制偏好数据质量、采样策略选择或多个随机训练种子的所有变异。因此其支持的是“这些估计器技巧在这个模型/数据上的效用”，不是独立归因所有 benchmark 增益都由某一个 VRPO 组件导致。

### 6. 什么条件下失效或结论变弱？

- **数据不公开**：偏好对为内部收集，且经历 reward-model 排序、LLM 替换 chosen response 等处理；缺少可让外部对数据偏差、过滤和模型污染进行完全独立审计的信息（§4；Appendix D.3）。
- **训练成本与搜索**：`n=8` 相比不做 Monte Carlo 估计约增加 8 倍相关计算；全流程约 405 H100 GPU hours。总量低于预训练成本 0.5% 是作者对其 LLaDA 系统的估计，不能泛化成任意 MDM/DPO 部署的成本比例。训练受资源限制，未做超参搜索（§4；Appendix D.3）。
- **特定 DPO/ELBO 设置**：理论与实现围绕用 ELBO 替代 diffusion likelihood 的 preference score；离散时间步数、mask 抽样、reference coupling 与 `β=0.2` 等均会影响估计。对 PPO/GRPO 的推广在 §3.3 给出理论动机，本文主实证没有覆盖这些算法，不能称已在它们上验证。
- **方差不等于最终质量**：Table 2 中 antithetic 关闭时 Arena-Hard 反而更高（15.6 对 14.3 base），尽管估计器方差巨大。单一 benchmark 有噪声，方差改善是优化信号稳定性指标，不保证每个任务必然收益（§4.2、Table 2）。
- **采样策略可能不等价**：作者按 benchmark 采用该任务下表现较好的 MDM sampler；Sampling 与 EOS 处理变化意味着主表反映“模型+评测期策略”的表现，不能单独归因于训练权重（§4、Appendix D.4）。
- **评估的不确定性**：内部偏好训练集不可审计；Arena-Hard/MTBench 等含 judge 评分的评估有评审方差；附录的少量重复结果不能代替对不同偏好语料、开源外部人类偏好标注集的复验（Appendix D.5）。本轮未运行作者评估代码。

### 7. 与同类系统的可判定差异？

| 维度 | VRPO for MDM | AR DPO / naive MDM-DPO |
| :-- | :-- | :-- |
| 被优化的 likelihood signal | MDM exact response likelihood 难算，用 mask diffusion ELBO 的 Monte Carlo 估计 | AR 自回归逐 token likelihood 可直接累加；naive MDM-DPO 通常有限次 ELBO 抽样后直接替代 |
| 降方差操作 | timestep 扩采样、每 timestep 一个 mask 的分配、policy/reference 共用样本 | AR 通常不需要为响应似然作 diffusion timestep/mask 双重积分 |
| 本文测得 | 单个 8B LLaDA 基座、内部 350K pairs，较 SFT-only 与其 naive DPO baseline 多任务分数更高 | 不是与所有 AR preference-training pipeline 的等预算、等数据、等采样器受控比较 |

区别不是 VRPO 创建了另一种人类偏好目标；它针对 MDM 特有的 ELBO 估计噪声，为 DPO-style preference optimization 改善有限样本估计。对原始 AR DPO，逐 token log probability 可以直接算，VRPO 的双重蒙特卡洛结构及共享 mask 样本设计并非必要（§2.1–2.2、§3）。
