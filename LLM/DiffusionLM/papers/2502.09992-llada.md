## 亮点与差异

1. **一句话亮点**：以逐 token 随机遮盖和双向 Transformer 去噪，把 masked discrete diffusion 从 GPT-2 量级推到 8B 参数、2.3T 训练 token，并报告与同量级自建 AR 基线接近的多任务表现。
2. **新在哪**：不是固定遮盖率的 BERT 式补词；训练时对 `t∼U(0,1]` 随机采样整句遮盖率，使用只在被遮 token 上计算、含 `1/t` 权重的交叉熵作为负对数似然上界，并用同一掩码目标做预训练和 SFT。
3. **证据强度**：提供 1.5B 与 8B MDM、同数据自建 AR 的缩放对照及 8B 基准；8B 训练只运行一次、没有超参搜索，且大规模 8B AR 受资源限制而未作完全同配置对照。结果是作者报告，非独立复现。
4. **值不值得引用**：适合说明 masked discrete diffusion 已在数十亿参数、万亿 token 规模上实证；不能据此声称它普遍优于 AR、推理更快或具有可靠的任意位置编辑能力（§2.2、§3.1–3.2；固定版原文：`/Users/zhoucanzong/Documents/paper-cache/LLM-DiffusionLM/2502.09992.pdf`）。

## 七问精读

### 1. 解决什么问题？

论文研究语言模型是否必须按左到右分解联合分布。AR 模型以 `p(x)=∏ᵢp(xᵢ|x₍<ᵢ₎)` 训练与生成；LLaDA 试图保留离散 token，同时以全序列的随机遮盖建模，让每个被遮位置利用两侧上下文预测。目标是检验这一非 AR 生成范式能否扩展到通用 LLM 规模，并在预训练、in-context learning (ICL)、指令微调后保留有竞争力的能力（§1；§2.1–2.3）。

### 2. 核心方法是什么？

**前向过程与学习目标。** 给干净序列 `x₀`，对每个 token 独立以概率 `t` 替换为 `[MASK]`，其中 `t∼U(0,1]`；`t=1` 时整句被遮盖。无 causal mask 的 Transformer `pθ(·|xₜ)` 同时预测所有 mask 位置，但交叉熵只计入被遮 token，并乘 `1/t`：

`L(θ)=−E[t,x₀,xₜ] [ (1/t) Σᵢ 1[xₜⁱ=MASK] log pθ(x₀ⁱ|xₜ) ]`。

论文给出的理论结果是 `−E_data log pθ(x₀) ≤ L(θ)`，因此此目标是模型负对数似然的上界。随机连续遮盖率和这个权重共同区别于固定遮盖率 MLM；若去掉 `1/t`，就不再是文中主张的同一个似然界目标（§2.1，Eq. 3–4；Appendix A.1，Eq. 7–13）。

**逆向采样。** 从指定回答长度的全 `[MASK]` 序列开始，prompt 保持可见；每个反向步将当前部分结果与 prompt 一起输入模型，同时预测所有仍被遮的位置。对预测 token 进行采样/选择后，再按转移概率把一部分预测重新遮盖，使剩余 mask 比例与下一噪声时刻 `s<t` 对齐；迭代至无 mask。论文的低置信度策略把下一步置信度最低的预测位置优先重新遮盖；随机 remasking 是过程定义的基线。纯 diffusion 是主默认，另可在无需重训下采用 AR 或 block/semi-AR 采样。实际基准普遍选低置信度 remasking；对 Instruct 若使用纯 diffusion 做部分任务，还将 EOS 置信度置零以缓解过短输出（§2.4；Appendix A.2–A.3、Algorithm 4–5、B.4、Table 9）。

**预训练与 SFT 配方。** 8B 模型用 2.3T tokens、4096 固定上下文长度、0.13M H800 GPU 小时；1% 训练样本随机取 1–4096 长度。AdamW weight decay 0.1、global batch 1280，WSD 学习率：前 2,000 步升至 `4e−4`，处理 1.2T token 后降到 `1e−4`，保持 0.8T，再对末 0.3T 从 `1e−4` 线性降至 `1e−5`。训练一次，无调参。8B SFT 使用 4.5M prompt-response 对、3 epochs、batch 256、AdamW weight decay 0.1；学习率先升至 `2.5e−5`，末 10% 降至 `2.5e−6`，也仅运行一次、无调参。两阶段均直接优化 masked-token 目标；SFT 仅遮 response，prompt 不遮（§2.2–2.3；Appendix B.1–B.2；固定版原文：`/Users/zhoucanzong/Documents/paper-cache/LLM-DiffusionLM/2502.09992.pdf`）。

### 3. 数据与规模？

- 预训练数据：公开来源的网页、书籍、学术论文、社媒、百科、数学和代码；清洗包括 PDF 文本提取、去重、有害内容过滤及 BERT 质量标注。数据约 11% 中文、61% 英文、28% 代码。预训练量 2.3T tokens；论文称不同来源与领域的混合比例由缩小规模 AR 模型指导（§2.2；Appendix B.1）。
- SFT：1M 人工标注样本加 3.5M 合成样本，覆盖代码、数学、指令、多轮对话及结构化理解。多轮对话拆为多个单轮 prefix-response 对，随机选一对训练；短样本在 batch 内以 EOS 补齐，补齐 EOS 也进入目标，推理后去掉 EOS 之后内容（§2.3；Appendix B.1）。
- 缩放实验：训练 1.5B 参数相同架构 ARM/MDM，另训练 8B MDM；因资源约束，较大规模 AR 用既有 7B 模型，且与 8B MDM 的架构和训练条件并非完全一致（Appendix B.2、Table 5）。

### 4. 主要结果是什么？

- **缩放**：在 6 个下游任务上比较同数据训练、横跨约 `10²⁰–10²³` FLOPs 的 LLaDA 与自建 AR。作者报告整体趋势具有竞争力，MMLU、GSM8K 的尺度趋势更强；没有拟合定量缩放曲线（§3.1、Fig. 3）。这不能读成所有点上胜过 AR。
- **Base**：LLaDA 8B Base（2.3T token）的 MMLU 5-shot 65.9、GSM8K 4-shot 70.3、HumanEval 0-shot 35.4；对照 LLaMA3 8B 在相同实现协议下分别为 65.4、48.7、34.8。对多个其他公开模型，训练数据、token 数和评测设置不同；不得把该表当完全受控的跨模型排名（§3.2、Table 1）。
- **SFT Instruct**：GSM8K 4-shot 69.4、HumanEval 0-shot 49.4、MMLU-Pro 0-shot 37.0；表 2 明示 LLaDA 只做 SFT，对比的其他指令模型还做了 RL alignment，故不能将该表用作同等后训练条件的胜负结论（§3.2、Table 2）。
- **采样消融**：LLaDA 8B Base 上，纯 diffusion 在 BBH/GSM8K/Math/HumanEval/MBPP 为 49.7/70.3/31.4/35.4/40.0，优于论文所测的 AR、block diffusion 和半自回归变体的整体表现。Instruct 的纯 diffusion 与 semi-AR 各任务优劣不同，例如纯 diffusion 的 GSM8K 69.4、HumanEval 49.4，semi-AR 分别 77.5、46.3，说明采样策略与任务相关（Appendix B.4、Tables 7–8）。
- **remasking 对照**：固定长度和 256 步的 Base 采样里，低置信度 remasking 相对随机 remasking 的 GSM8K 为 70.0 vs. 21.3、HumanEval 32.9 vs. 11.6；该对照是在特定 8B Base、generation length=256、sampling steps=256 下，不应外推为任意模型或步数上的固定增益（Appendix B.4、Table 9）。

### 5. 消融或对比说明了什么？

1. **双向目标相对 AR**：1.5B 同架构与同数据对照、以及更大 FLOPs 范围的任务分数表明 masked objective 可扩展，至少论文训练设置下并未出现“非 AR 必然无法扩展”的证据。规模增大后 AR/MDM 条件逐渐不等价，尤其 8B MDM 对比 7B AR，故此处证据支持可行性，不是严格架构因果归因（§3.1；Appendix B.2）。
2. **随机 vs 低置信重遮盖**：低置信重遮盖显著改善作者报告的几项采样任务成绩；不过实验只在所列 Base/长度/步数上进行。它是采样启发式，不改变训练目标（Appendix B.4、Table 9）。
3. **生成方式**：纯 diffusion 在 Base 多数所列任务整体较强；Instruct 结果依任务变化。固定 EOS 处理、输出长度和采样 block size 会影响结果，故“扩散采样一定最佳”不成立（Appendix B.4、Tables 7–10）。
4. **CFG**：在 6 项 Base 任务上每个任务从 `{0.5,1,1.5,2}` 搜索尺度并报最优，6 项均小幅或持平改善；主文与 AR 公平比较的结果没有使用 CFG（Appendix B.3、Table 6）。

### 6. 什么条件下失效或结论变弱？

- **训练证据规模**：8B 预训练和 SFT 各仅运行一次，无超参搜索。未报告跨随机种子方差，不能判断训练稳定性或最佳配方（§2.2–2.3）。
- **公平对照**：1.5B 是更接近受控的比较；8B MDM 对照 7B AR，且多个外部模型数据 token 数、数据质量、RL 后训练、shot 数有差异。Table 1/2 仅其中明确标 `*` 的重测才适合直接对照，仍应查看 Appendix B.6 的具体实现口径（§3.1–3.2、Tables 1–2）。
- **采样与计算**：纯 diffusion 要在一段固定长度上重复全序列前向计算；论文没有证明其整体推理吞吐或端到端延迟优于 KV-cache AR。每个采样步的并行预测也不意味着总生成成本更低。作者报告的 0.13M H800 GPU 小时是预训练计算量，不是推理速度比较（§2.4、§2.2）。
- **固定回答长度/EOS**：采样开始时需设定全 mask 回答长度；EOS 后丢弃。SFT 的 EOS padding 对纯 diffusion Instruct 造成过多 EOS、短回答问题，特定代码/数学任务以 EOS 置信度置零缓解；这表明长度控制和训练 padding 会影响结果（Appendix B.1、B.4）。
- **定性能力证据**：反转诗歌与多轮对话包括案例分析；“逆转诗歌超过 GPT-4o”是特定任务结果，不足以证明一般反转能力或广泛推理优势（§3.3–3.4、Table 4 与 Appendix B.9–B.10）。
- **复现边界**：论文链接了代码，但本 dossier 未运行代码或核重训。语料混合比例由作者描述，完整私有数据组成/全套运行细节不足以让独立读者从公开信息逐字复刻全部 2.3T 训练。

### 7. 与同类系统的可判定差异？

| 比较点 | LLaDA masked diffusion | 自回归语言模型 |
| :-- | :-- | :-- |
| 训练条件分解 | 随机 mask 比例下，双向上下文预测被遮 token；loss 只作用于 mask，含 `1/t` | 对每个 token 预测左侧 prefix 后继 token |
| 生成起点/更新 | 全 mask 回答；反复预测可并行更新、再重遮部分预测 | 从已有 prefix 逐 token 向右延长 |
| 可直接判断的优势 | 训练目标提供多种条件方向；可做全段迭代填充 | 生成顺序简单，标准 KV cache 可复用 |
| 本文证据限制 | 全序列多轮去噪的速度/质量取决于采样步数、长度和重遮策略；实测与 AR 训练控制不完全对等 | 8B 对照受参数量、训练配方和后训练差异影响 |

与固定比例的 BERT 式 MLM 相比，LLaDA 的连续随机 mask 比例及似然界目标让它成为明确的生成分布训练方法，而不是仅做固定噪声水平的填空器（§2.1）。与更早离散扩散工作的差异主要在规模与 LLM 训练配方的系统展示；论文将算法根基建立在 Sahoo et al. / Ou et al. 的 masked diffusion 理论上，而非声称首创离散扩散（§4、Related Work；固定版原文：`/Users/zhoucanzong/Documents/paper-cache/LLM-DiffusionLM/2502.09992.pdf`）。
