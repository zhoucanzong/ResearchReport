## 四个亮点

1. **token 级严格因果 diffusion**：CARD 采用 causal attention，每个位置从带噪的前缀 `x^t_<n` 预测原 token `x_n`；不像 BD3-LM / SDAR 那样在块内允许非因果上下文。作者用 shifted causal formulation 在单次前向中对所有 token 计算监督（§3.1；Fig. 1）。
2. **噪声只偏向动态尾部**：Soft Tail Masking 将给定噪声数量放入序列尾部的动态窗口，前缀保留可用上下文，窗口内仍可有干净邻词，避免 strict-tail 让目标局部上下文全断（§3.2；Algorithm 1、Fig. 3）。
3. **逐 token context-aware reweighting**：权重依据历史噪声数量、距离和连续密度构造局部模糊度，再按 `1/(β+S_local)` 降低不可靠上下文的训练贡献。消融中去掉 weighting，八项准确率平均值从 53.21 降到 51.66；随机噪声位置平均 51.62（§3.3、§5.3；Table 4；原文 PDF：`/Users/zhoucanzong/Documents/paper-cache/LLM-DiffusionLM/2601.22031.pdf`）。
4. **动态并行，但速度由质量预算决定**：推理向 prefix 尾部附加 mask block，超过 confidence threshold 的位置提交并缓存；阈值或最大步数可以让生成较快，但激进设置会重复/循环。论文的 1.7× 配置 Gen-PPL 12.65 对比 AR 11.19；4.01× 配置升到 18.38，不能据此说与 AR 生成质量 parity（§3.4、§5.4、Appendix D；Table 5、Table 8）。

## 七问精读

### 1. CARD 要解决什么问题？

作者认为 MDLM 的双向注意力不支持标准 KV cache，block diffusion 需要复杂掩码与 clean/noisy 序列复制、引入额外成本且把并行粒度固定在训练块长。CARD 的目标是在严格因果 Transformer 中定义 token 级 diffusion：训练仍可一次前向、每 token 有损失；推理端沿因果前缀缓存，并根据置信度自适应接收多个未来 token（§1、§2、Fig. 1–2）。

### 2. 噪声和目标函数具体是什么？

给定长度 `L` 的序列和连续时间 `t∈[0,1]`，对输入 token 做 absorbing-state mask corruption。目标位置 `n` 预测原始 `x_n`，可见上下文是其严格因果前缀 `x^t_<n`；损失累加各位置 `w(n,x^t_<n) log pθ(x_n|x^t_<n)`。因果约束限制未来 token 流向，因此 CARD 的“扩散”是对历史前缀状态加噪的训练目标，不是全序列双向 masked denoising（§2.3、§3.1；Eq. 5）。

CARD 的主要难点是因果早期位置上下文短：随机 mask 可能让某个位置完全没有可恢复信号。Soft Tail Masking 对每个 `t` 计算需 mask 数 `N≈Lt`，取动态尾窗 `W≈Nλ`，再只在尾窗中抽取 N 个位置 mask；于是历史开头保持 clean，尾部保留可用 local anchors（§3.2、Algorithm 1、Fig. 3）。Context-aware reweighting 把历史 mask 成本按距离衰减，并对相邻连续 mask 加更高惩罚；`w=1/(β+S_local)`，论文常设 `p=0.5, β=1`（§3.3、Eq. 6–8；原文 PDF：`/Users/zhoucanzong/Documents/paper-cache/LLM-DiffusionLM/2601.22031.pdf`）。

### 3. 推理如何并行并保持可变长度？

给当前 clean prefix 追加候选长度 `K` 的全 mask block；重复前向去噪，置信度超过阈值 `τ` 的 token 被定稿，剩余位置继续 mask。若设有最大步数 `Tmax` 而到上限仍有 mask，则余下位置强制解码；完成的块追加到 KV cache，再继续扩展（§3.4、Eq. 9、Fig. 2）。候选 block 宽度与接受数量可分开理解：`K` 控制候选窗口，某一步提交多少由 confidence 和剩余步数决定；“自适应”不代表无需试阈值或无质量代价。

### 4. 训练数据、模型与结果是什么？

主实验模型为约 1B 参数，在 FineWeb 300B token 子集上训练；以 ARM、MDLM、BD3LM 为对照。LM Harness 八项任务使用论文列出的 few-shot 设置（ARC-Challenge/Easy 25-shot、CSQA 7-shot、HellaSwag 3-shot、MMLU-redux 5-shot、PIQA/SciQ 0-shot、WinoGrande 5-shot）。Table 1 平均准确率 CARD 53.23、ARM 56.39、MDLM 47.55、BD3LM 47.45：它优于扩散基线但低于 AR，不能概括成 AR 质量 parity（§4.2；Table 1）。

跨域 PPL 表中 CARD 在八个数据集中的六个优于 ARM，并在总体报告均值 34.40 vs 38.68；但 CARD 仍在 arXiv 20.34 vs AR 18.15、PubMed 13.20 vs 11.93 上落后。论文的 PPL 结论因此是数据集相关；不宜从均值推导所有域上的优势（§4.2、Table 2）。另一组 110M、LM1B、33B token 实验报告 CARD PPL 21.54、ARM 21.12、MDLM 37.48、BD3LM 35.06（§5.1；Table 3）。

### 5. 速度与生成质量的证据怎样读？

Table 5 使用 batch size 128；作者报告 AR 为 3,771 tok/s、Gen-PPL 11.19。CARD block=16、steps=16 为 6,441 tok/s（1.71×）、Gen-PPL 12.65；block=16、steps=8 为 10,702 tok/s（2.84×）、PPL 13.81；block=32、steps=8 为 15,064 tok/s（4.01×）、PPL 18.38。该曲线显示吞吐提升伴随样本质量损失，且其 Gen-PPL 是四个不同模型（Qwen3-8B、SmolLM3-3B、Gemma-3-27B、GPT2-Large）的平均评分，不等于任务准确率或 AR 直接验证（§5.4；Table 5）。

训练时间的表述为归一化 ARM/CARD=1.0×、MDLM=1.5×、BD3LM=3×；论文把 BD3-LM 的 clean/noisy 输入复制和复杂 mask 视为主要开销来源（§4.1、Fig. 1；原文 PDF：`/Users/zhoucanzong/Documents/paper-cache/LLM-DiffusionLM/2601.22031.pdf`）。它没有把这一相对 latency 数字解释为可跨硬件、框架复用的 FLOPs 或美元成本。CARD 的“100% token utilization”是目标函数覆盖所有位置的描述，不意味着比 AR 多一倍独立训练数据或已经证明更高质量。

### 6. 消融、局限和失效模式？

Table 4 去除 random-position noise、strict tail、或 context-aware weighting 均降低平均准确率；主 CARD 的结果在该表为 53.21（与 Table 1 的 53.23 有轻微表内差异）。Appendix D 的例子显示 1.7× 下文本尚连贯，4× 设置会重复句式甚至落入循环。Table 5 的 4× Gen-PPL 恶化也佐证了质量边界（§5.3–5.4；Tables 4–5、8；原文 PDF：`/Users/zhoucanzong/Documents/paper-cache/LLM-DiffusionLM/2601.22031.pdf`）。

模型仅约 1B、特定 FineWeb 语料；没有大规模参数扩展或独立复现。主下游平均准确率仍低于 ARM。作者关于 CARD 对重复训练更耐久的结论来自 1B 模型对 1B-token FineWeb-Edu 子集重复 40 epoch；CARD 约第 11 epoch 超越 ARM，之后 MDLM 可先后超过 ARM 和 CARD，不能读成始终占优（§5.2；Fig. 4）。公开结果未提供足以推演商业部署质量/延迟的多模型、多硬件范围。

### 7. CARD 与 Block Diffusion / SDAR 的可判定差异？

CARD 的建模约束是**token 级单向 attention，扩散噪声仅改变因果历史，再以尾部窗口和局部权重避开无信息状态**。BD3-LM 和 SDAR 是块间因果、块内 masked diffusion；前者强调 diffusion 块分布与方差优化，后者强调 AR checkpoint 继续训练转换。CARD 不做块内双向 attention，也不是 AR-to-diffusion 迁移配方。其并行性来自尾部候选区的 confidence acceptance；不能借用其他两篇在块大小或模型规模上的表现（原文 PDF：`/Users/zhoucanzong/Documents/paper-cache/LLM-DiffusionLM/2601.22031.pdf`）。
