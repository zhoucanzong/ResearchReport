# 候选筛选 — 训练数据

筛选日期：2026-10-23。**本专题精读 3 篇；未以论文数量追求数据流程的穷尽覆盖。** 取舍标准是能否提供受控的过滤/去重对照、机制反例或明确的评测边界。

| 候选 | 决定 | 理由 |
|---|---|---|
| The FineWeb Datasets, arXiv:2406.17557v2 | 精读 | 同一模型和 token budget 下比较抽取、过滤、不同去重粒度；包含跨快照全局去重不总是有益的反例。 |
| DataComp-LM, arXiv:2406.11794v4 | 精读 | 固定模型/训练资源比较正例来源和筛选阈值，并暴露人类标签、训练效用、benchmark selection 的差异。 |
| Deduplicating Training Data Makes Language Models Better, arXiv:2107.06499v2 | 精读 | 对比文档级近重复与子串去重，直接测量生成记忆，并明确限制下游能力解释。 |
| The Pile / C4 / RefinedWeb dataset descriptions | 仅交叉定位 | 数据集文档能说明来源和组成，但不能单独识别过滤因果效应；本批由三篇原文中的固定对照提供主要证据。 |
| 大规模高质量过滤器 leaderboard | 排除 | 跨模型、训练数据、预算和评测版本不齐，无法回答“同预算的数据干预有何因果作用”。 |

本专题没有搜索或主张覆盖所有数据处理论文，也没有重新评估所有模型报告中的厂商数据描述；未来可沿多语言数据、代码语料和多模态重复数据另设窄问题。
