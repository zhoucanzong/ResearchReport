# The Curse of Recursion：递归训练何时会丢失分布尾部？

来源：Shumailov et al., [*The Curse of Recursion: Training on Generated Data Makes Models Forget*](https://arxiv.org/html/2305.17493v3)，固定阅读版本 v3（2024-04-14），后发表于 Nature。重点阅读 §3–§5，尤其 §4.2–§4.3、§5.1–§5.2。

## 研究问题：下一代模型不断学习上一代输出，会发生什么？

若模型生成的数据被抓取并进入下一轮训练，训练分布就不再独立于模型自身。论文将 model collapse 定义为模型逐代偏离真实数据分布：低概率模式或罕见尾部先减少，随后模型输出可能更集中并积累偏差。这不是常规 continual learning 中“新任务导致旧任务遗忘”的同义词，而是**训练数据分布本身由模型递归改变**的问题。[§1–§3](https://arxiv.org/html/2305.17493v3)

## 从理论示例到生成模型：误差如何逐代传递

论文用离散分布和一维 Gaussian 建立直觉：有限样本生成只能近似当前模型分布；下一轮再拟合这些样本，会把采样误差带入新模型。当尾部事件本来就少时，它们更容易在采样阶段消失；新模型随后无法生成这些事件，下一代的覆盖范围便进一步收窄。更复杂的 GMM/VAE 还叠加模型函数近似误差，论文在从头训练的设定中观察到模式混合与分布退化。[§4、§5.1](https://arxiv.org/html/2305.17493v3)

这条机制说明**数据是怎样产生、是否保留原始分布支持**很重要；它没有推出任何形式的合成数据都会造成崩塌。若合成任务只改写原始样本，或真实数据仍覆盖被合成分布遗漏的尾部，递归生成模型的假设并不完全适用。

## LLM 部分的关键限定：从头训练与微调不是同一结果

作者指出，直接从头训练语言模型很昂贵，因此其 LLM 部分主要测试从预训练模型开始、在新数据上连续微调的情境。论文观察到重复短语等生成问题，也用 repeating penalty 排除“只是重复文本导致退化”这一单一解释；但作者对该现实微调设定的结论是**只检测到早期 collapse 信号**，而非已经证明现代大模型做任何合成数据微调都会灾难性崩塌。[§5.2](https://arxiv.org/html/2305.17493v3)

所以它最强的贡献是把递归数据分布和尾部损失机制明确提出，并在分布模型、VAE 与语言模型设置中展示可观察现象。阅读时要保留不同实验之间的差别：小型生成分布从头训练提供更清楚的机制；LLM 微调则更像实际后训练流程，但退化程度和长期结果没有被同一实验完整证明。

## 与后续真实/合成数据混合研究的关系

后续的大规模单轮预训练研究发现，模型崩塌的观察会随合成数据类型和混合比例变化：[Demystifying Synthetic Data](feedback-pretraining-mixtures.md) 中，改写网页文本与纯生成教科书文本并不表现相同。这不推翻递归生成的尾部风险，而是指出“模型输出进入训练集”还不够描述条件；生成方式、真实数据保留、数据预算和训练轮数都影响结论。

## 带走的边界

- “递归使用模型生成数据”与“单轮使用一次合成数据”是不同实验条件，不能用同一个 collapse 结论概括。
- 论文里的分布和生成模型实验不直接代表所有当前 LLM、数据来源与筛选策略。
- 真实人类数据的保留可保护尾部覆盖，但比例与作用仍需具体语料、任务和训练预算验证。
- 本文的理论/仿真和有限 LLM 微调实验不是对开放互联网未来数据生态的长期预测。

重点定位： [arXiv v3 §3–§5](https://arxiv.org/html/2305.17493v3)，LLM 微调设置尤其是 §5.2；理论直觉见 §4.1–§4.3。
