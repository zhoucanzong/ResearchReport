# Self-Instruct：让模型从少量种子任务逐步扩展指令池

来源：Wang et al., [*Self-Instruct: Aligning Language Model with Self Generated Instructions*](https://arxiv.org/html/2212.10560v1)，arXiv v1（2022-12-20）。重点阅读 §3.1–§3.3、§4.2–§4.3、§5.3–§5.4、§6.3。

## 它生成的是“新任务”，不只是给现有问题换说法

Self-Instruct 从人工写的种子任务池开始。生成模型读入若干任务示例后提出新 instruction；接着先判断该任务更像分类还是非分类，再按任务类型生成输入—输出实例，最后将筛过的指令回收到任务池中，进入下一轮迭代。这使闭环为**种子任务 → 新任务定义 → 任务实例 → 过滤 → 扩充任务池**，而非只为一批固定 prompt 合成回答。[§3.1–§3.2](https://arxiv.org/html/2212.10560v1)

它的两个实例生成顺序解决了不同数据偏差：非分类任务使用 input-first，先造输入再完成任务；分类任务可以 output-first，先枚举标签再生成对应输入，避免模型只生成占多数标签的例子。这个设计说明生成顺序本身会改变合成集的类别平衡，合成数据质量不能只由最终 instruction 文本的可读性判断。[§3.2，Instance Generation](https://arxiv.org/html/2212.10560v1)

## 过滤环节定义了它能覆盖什么

新 instruction 只有在与任务池中已有指令的 ROUGE-L 重叠低于 0.7 时才保留；特定视觉输入关键词也会被排除，因为当时的文本模型无法执行这些任务。实例过滤会去掉完全相同的样例，以及“相同输入、不同输出”的冲突样例。[§3.2，Filtering and Postprocessing](https://arxiv.org/html/2212.10560v1)

这些规则降低了重复和显式冲突，但同时形成表示边界：词面差异大不等于任务语义新颖；关键词过滤会把多模态任务排除；相同输入不同输出有时可能是随机生成差异，也可能是任务本身允许多答案。过滤器决定了训练池的形状，不只是清理尾部噪声。

## 结果支持“可行的自举”，而非自动消除教师偏差

论文用 GPT-3 自生成 instruction/instance，再微调同一 GPT-3；作者在 Super-NaturalInstructions 上报告其模型比未微调 GPT-3 绝对提升 33.1%，并在新任务的人类评测中优于若干公开指令微调模型。这里验证的是该种子、生成器、过滤流程、GPT-3 训练配方和作者评测集的组合。[Abstract、§5.3–§5.4](https://arxiv.org/html/2212.10560v1)

生成器与被微调模型同源，意味着数据多样性仍从种子和生成模型已有能力出发。作者也把长尾任务覆盖、对大模型的依赖与偏差放大列为限制；“几乎不需标注”不等于完全没有人类设计、过滤决策或质量成本。[§6.3](https://arxiv.org/html/2212.10560v1)

**带走的区别**：Self-Instruct 的关键贡献是任务池闭环和实例生成顺序；单看合成样本数量，无法判断新增数据是否覆盖了新能力、是否只是重述了教师已有分布。
