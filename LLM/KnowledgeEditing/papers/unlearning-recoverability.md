# Recoverability：表面拒答与信息真正不可恢复之间的差别

来源：[On the Recoverability of Private Information Unlearning in Large Language Models](https://arxiv.org/html/2608.29943v1)，固定版本 v1。重点阅读 §1、§3–§5.1 与 §6；数据构造和模型设置见 §4、§5 与 Appendix D。

## 它问的是“低概率信息是否仍在”

许多微调式遗忘方法通过提高 forget-set token 的 loss，让标准解码不再输出目标信息。但标准贪心解码只选择最高概率 token；目标答案若被推到低概率区域，模型可能拒答或输出乱码，表面上看似忘记，内部 logits 仍可能保留关于目标答案的排序结构。本文把问题改写为：已声称遗忘的私有信息，能否由知道算法和模型的白盒审计者重新找出？[§1、§3](https://arxiv.org/html/2608.29943v1)

作者构造 Fake Private Information（FPI）合成数据，包含虚构人物的出生年份、血型、邮编和社会保险号码等结构化字段，再对 DeepSeek-7B 和 Qwen3-8B 做 LoRA 微调以建立“确实记住过”的模型；之后执行若干 forget-set 微调方法。字段有明确格式，使审计者可按数字、字母、类别或编辑距离检查答案，而不是只用文本相似度判断。[§4.1–§4.2、§5](https://arxiv.org/html/2608.29943v1)

## RIG 怎样从低概率区域恢复答案

Restricted Inverse Greedy（RIG）利用审计者对属性格式的先验，逐步从符合格式的候选 token 中选**最低概率**者，尝试重构被梯度上升类方法压低的目标答案。对于偏好优化（PO），论文另用 Restricted Greedy（RG），在与属性相关的词表中选最高概率 token，因为该类方法可将正确回答压为拒答，而不是依靠增加原目标 loss 来藏置信度。[§3、§4.2](https://arxiv.org/html/2608.29943v1)

在该论文的 FPI 设置中，常规生成下某些方法看起来有很高“遗忘质量”；RIG 可从部分方法生成被声称已忘的目标字段。作者报告一个 postcode 例子中，GA+KL 模型在标准问答下看起来像忘记了邮编，但 RIG 可恢复接近 97% 的目标邮编；这只支持其合成数据、模型和白盒属性限制条件下的可恢复性，不等于所有遗忘算法或真实私人数据都能以相同比例恢复。[§5.1、Figure 1/Table 2](https://arxiv.org/html/2608.29943v1)

## 它与 TOFU / MUSE 的关系

- **TOFU** 控制知识来源和 retain 关系，重点是 forget quality 与 utility；Recoverability 则专门研究某类结构化私有字段在参数中的残留是否能被白盒解码找回。
- **MUSE** 把 privacy leakage 纳入六项评测，主要用 membership-inference 观察模型是否显露某数据进入训练；Recoverability 则直接尝试提取目标值。成员身份泄漏与字段恢复是相关但不同的攻击目标。
- **单点模型编辑**改变特定事实或行为，Recoverability 的遗忘设定则问某类数据影响是否移除；一次标准输出变了，不能替代对模型内部残留或多种解码器的审计。

## 证据边界

这是一种白盒审计：审计者知道 unlearning 算法、模型 logits 和待遗忘属性格式。FPI 是虚构数据，用来避免真实个人信息泄露；因此结果展示了“表面压低概率不等于消除可恢复信号”的风险机制，但不是对真实数据删除的法律或隐私保证。RIG/RG 也依赖候选格式、解码预算和攻击知识；攻击更强弱会改变恢复结果。作者使用的模型和遗忘方法是有限集合，不能外推为每种遗忘算法均可恢复。

**带走的区别**：遗忘评测至少要问两件事：普通用户按正常接口查询时是否还会输出目标内容？知道系统目标的审计者能否借助 logits、受限候选或其它解码策略恢复它？前者测行为抑制，后者更接近信息残留审计；二者都不能单独替代重训参照与 retain utility 检查。
