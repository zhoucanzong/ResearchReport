# NL4Opt：从实体识别到优化逻辑表示

**原文**：[NL4Opt Competition, PMLR 220, pp.189–203](https://proceedings.mlr.press/v220/ramamonjison23a/ramamonjison23a.pdf)，NeurIPS 2022 competition track。阅读 Abstract、§2、§2.1–2.3、§3。

## 它把“自动建模”拆成什么

NL4Opt 把自然语言 LP 问题分为实体识别与 formulation generation：先标注变量、参数、目标方向、约束方向和界，再由这些实体生成可转换为求解器格式的逻辑表示。其基准共有 1,101 条 LP word problems，覆盖六个领域，数据拆为 713/99/289 个 train/dev/test 实例。[Abstract、§3]

生成子任务给模型提供第一步的 gold entity annotations，所以它隔离测试逻辑表示生成，不等于从开放业务描述直接生成完整模型。实体 micro-F1 与 declaration-level mapping accuracy 也回答不同问题，不能合成“端到端建模准确率”。[§2.1、Eq. 2]

NL4Opt 是理解研究起点的锚点：它将自然语言建模定义为 semantic parsing，同时明确指出自然语言组合性、低资源标注和实体—公式对齐都是难点。后续系统若把实体抽取、数学结构与 solver code 一起自动生成，评测任务和错误分母也必须相应扩展。
