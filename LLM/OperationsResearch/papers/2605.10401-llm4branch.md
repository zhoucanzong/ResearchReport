# LLM4Branch：按完整求解成本优化分支策略

**原文**：[LLM4Branch, arXiv 2605.10401v1](https://arxiv.org/html/2605.10401v1)，预印本。阅读 §§4–5、Tables 1–2、Appendix A、C、E。

## 从模仿专家改为优化 solver 指标

Branch-and-bound 每解一个 LP relaxation，就要在分数整数变量中选择一个变量分支。该选择影响搜索树大小和求解时间。很多学习型 branching policy 通过模仿 strong branching 的专家决策训练，但标签准确率并不必然降低整个求解器的成本。

LLM4Branch 把策略写成参数化、可执行的程序：LLM 生成 program skeleton，零阶优化方法再调其参数；目标直接使用完整 solver cost，而不是仅模仿专家标签。评估后的性能保存在数据库中，用于提示下一轮策略生成。[§4、Appendix A]

## 作者报告的条件

论文在 set covering、combinatorial auction、capacitated facility location、maximum independent set，以及 Item Placement、neural-network verification 上实验。标准任务按 Easy/Medium/Hard 划分，Easy 用于训练，Medium/Hard 用于观察泛化；使用 SCIP 8.0.0，每个实例最多一小时。指标为 solving time、branch-and-bound nodes 和 wins。[§5.1–5.2、Tables 1–2]

作者报告该策略在 CPU-based methods 中表现强，并与 GPU 方法作参考比较；GPU 方法不计入 wins 分母。Item Placement 在时限内难以求至最优，故改报 primal-dual gap。准确表述是“在所测六类基准、SCIP 版本和一小组训练实例下具竞争力”，不能改写为“超越所有通用求解器”。[Table 2]

这个例子体现 solver feedback 的设计价值：策略最终按完整树搜索成本评分，可能与强分支专家的局部决策不一致，甚至只有约四分之一的决策与专家相同，但在相应测试集上仍有更好的 end-to-end 指标。[Appendix A、Table 3]
