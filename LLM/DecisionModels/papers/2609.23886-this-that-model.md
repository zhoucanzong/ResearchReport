## 1 方法

**产物**：`this-that-model-1.0`，一个 **1.88B 参数的类型化决策模型**，自述"**答案直接从指定位置的隐藏状态读出**，并被限制在调用者声明的选项集内，因此不生成任何文本"。

**readout 机制（本文的实现要点）**：

> `one forward pass produces the hidden state at each answer position, and the distribution is a softmax over the option labels and nothing else.`

- **零采样**（`Nothing is sampled`）；**支撑集 = 声明选项集**：`a malformed answer is not unlikely, it is unrepresentable`。
- **标签设计**：**每个选项恰好占一个 token**。`n_k ≤ 10` 时用熟悉的 `(A) … (J)` 渲染；**超过则用 255 个大写字符串表**，tokenizer 将其映射到**单个 id**，从而"无论调用者声明多少选项都保持单次 gather"。
- **训练目标**：对**严格 proper scoring rule** 训练（§3.3），故"模型除如实报告其信念外无改进损失之途"——这是**阈值可路由**的前提。
- **N 问共享一次前向**：因答案不回写 prompt，各决策在给定输入下**条件独立**；N 问的成本是**一次**过 state（`one pass over |S| + Σ|q_k| + N`），而非 N 次。

**明确不主张**：`It is not a claim to be more accurate than a frontier model`——作者自陈在"较难的一半测试集"上不如 frontier 模型。

**开源与许可**（论文正文）：`the same interface under the MIT licence; it contributes the environment simulator and the recorded hosted-service cohort`——项目以 **MIT** 发布，并包含环境模拟器与真实托管服务队列记录。上游致谢：环境模拟器与 68 题队列来自 **NanoJev**（[模型卡](https://huggingface.co/flock-io/this-that-model-1.0)）。

## 4 失效边界

1. **不是"比 frontier 更准"**：作者**明说不是**（`It is not a claim to be more accurate than a frontier model`），且在自建 suite 的**较难一半**上确实不如。
2. **基准是自建的**：主要能力证据来自**本组构建并发布**的 benchmark（`a benchmark we built and released for this`），**非第三方独立评测**。
3. **30.9 ms 的条件是"一张笔记本 GPU"**：型号、batch、上下文长度、是否含预处理均**未在句中给出**；与模型卡主张的 31 ms 是**不同材料的两个数**。
4. **0.750 vs 0.746 的口径特殊**：这是"真实答案是**计算出的概率**"的**唯一一族**测量，且上限 0.746 被作者表述为"任何预测器都无法超过"——**不能**读作通用准确率。
5. **成本 `$10.636/千问` 是 API 对照价**，不是该模型自身的边际成本（作者称自身边际成本为"电费量级"，**未给数字**）。
6. **"百万分之一美分"是标题修辞**：正文**未**给出可复算到该量级的成本推导。
7. **模型卡自陈的分布外例子存在张力**：模型卡称某离训练分布的问题返回 `no (71%)` 为 `unconfident`，但 71% 按常规阈值并不低（详见 [open-implementations.md §1.5](../open-implementations.md)）。
