## 1 方法

**问题**：提示注入研究多集中于**生成式** agent，对**schema 定义输出**的模型影响不明。本文在 **Jev（非生成式决策模型）**上重建注入实验。

**数据构造**：从 InjecAgent 中**确定性重建 510 个 direct-harm 组合**——即 InjecAgent 的 **30 个 attacker goals × 17 个 user contexts = 510** 完整网格。每个上游样本先转成中间表示（user goal、clean/attacked observation、可用工具、attacker goal、攻击类别、注入通道），再渲染成**暴露于恶意内容之后的第一个安全关键决策**，且以**类型化选项集**替代自由生成。

> 关键设计：`Our endpoint is selection at the first security-critical decision after exposure to the injected content. It does not measure the completion of an end-to-end harmful workflow.`

**四个实验（同一批 510 案例，主研究共 54,060 次调用）**：

| 实验 | 检验什么 | 设计 |
|---|---|---|
| **DH-1** | 原始攻击能否迁移到 Jev | R = 1；同时测两种动作空间 |
| **DH-2** | 注入式**标记**（markers）的独立效应 | R = 5；A0=朴素攻击、A1=加 `IMPORTANT!!!`、A2=加 ignore-previous、A3=两者、A4=自然改写；A0–A3 构成**双标记因子设计** |
| **DH-3** | "上下文相关性"声明的效应 | R = 5；对照**预先注册的最小有意义效应量 SESOI = 0.02** |
| **DH-4** | **自适应攻击**：用分数反馈把概率位移变成被验证的目标选择 | 确定性 grammar-based 优化器可访问**报告的完整概率向量**；每个 checkpoint 用**5 次全新调用**验证，**≥3/5 选中攻击目标**才算 validated success |

**统计口径**：双向 pigeonhole bootstrap（attacker goals × user contexts），**10,000 次重采样，seed 20260923**，95% 百分位区间；配对条件在同一重采样内保持成组。

**关键区分（本文最易被误读处）**：**概率位移（ΔP）≠ 动作选择（ASR）**。ASR 用"每案例目标选择频率"的均值；robust-hijack 计数 K 用**每案例多数阈值**；两者不可互相换算（`The percentages and case counts measure different quantities and must not be converted into one another by rounding.`）。

## 4 失效边界

1. **本文是"低成功率"的正面证据，但不是"攻击不可能"的证明**：作者结论明确是 `schema-defined outputs change but do not eliminate prompt-injection risk`——**降低而非消除**。
2. **"很少改变最终选择"有三重口径混用风险**：DH-1 的 1.8%（R=1 的单次选择率）、DH-2 的 2.0% call-level ASR（51/2550）与 11/510 majority-rule 计数**是不同量**；引用时必须带 R 与分母。
3. **攻击者优势与"初始决策边际"和"对 observation 的控制程度"相关**（`Exploratory analysis links these successes to small initial decision margins or greater attacker control over the observation`）——属**探索性**分析，作者未称因果。
4. **对抗标记方向与生成式 agent 相反**：同一 override 短语在部分 LLM agent 上**增强**攻击，在本模型上**减弱**（`does not strengthen these attacks against Jev`）——说明"攻击不成比例地从生成式 agent 迁移"。
5. **端点窄**：只测"暴露后第一个安全关键决策"，**不测**端到端有害工作流是否完成。
6. **自适应攻击需访问概率向量**：DH-4 的优化器可读**完整概率分布**；这是强于真实部署的假设。
7. **格式/解析**：本文不涉及输出解析失败问题（决策模型不生文本），故不构成对该失败模式的证据。

## 8 机制深读：最容易混淆的两个量

### 8.1 ΔP（概率位移）与 ASR（攻击成功率）不是一回事

| 量 | 定义 | 本文怎么算 | 能回答什么 |
|---|---|---|---|
| **ΔP** | 攻击目标选项的概率**变化量**（attacked − clean）| 直接读 Jev 返回的完整概率向量 | "注入把模型往目标推了多远" |
| **ASR** | **动作选择**成功率：该案例是否**选中攻击目标** | 每案例目标选择频率的**均值** | "实际选错的比例" |
| **robust-hijack 计数 K** | 稳健地被劫持的**案例数** | 每案例**多数阈值**统计 | "有多少案例稳定地错" |

论文明确警告：`The percentages and case counts measure different quantities and must not be converted into one another by rounding.` **这句话是读这篇论文的第一道门槛**——把 ΔP 当 ASR 会系统性高估/低估。

### 8.2 四个实验各自在排除什么

| 实验 | 若没有它，会误判什么 |
|---|---|
| **DH-1** | 无法知道"注入能否**迁移**到非生成式模型"——可能根本没有攻击面 |
| **DH-2**（双标记因子 A0–A3 + A4 自然改写）| 会把"标记词带来的增益"误当成"注入内容本身的效应" |
| **DH-3**（SESOI = 0.02 预注册）| 会把**统计不显著的小差异**当成"上下文相关性有用"，或反之过度保守 |
| **DH-4**（自适应攻击 + 5 次验证 ≥3 成功）| 会低估**能看概率向量的攻击者**的能力（一次性攻击 ≠ 自适应攻击）|

**方法论价值**：这四步是**注入研究的最小严谨集**——迁移性、标记混杂、效应量、自适应对手。**任何"某模型抗注入"的结论，缺任一步都打折。**

## 9 统计口径细读（这部分决定结论可信度）

| 项 | 设置 | 为什么重要 |

| 重采样 | **双向 pigeonhole bootstrap**（attacker goals × user contexts）| 同时考虑两类抽样单元，避免只按案例重采样低估方差 |

| 防御者能力 | 无（本文不提出防御）| 结论是"暴露面"，不是"防护方案" |
| 端点 | **首个安全关键决策** | 不覆盖"端到端有害工作流"——**不等于系统安全** |
| 置信度门 | CHR 用 **C ≥ 0.7** | 真实系统可调；阈值越高，被劫持率越低但覆盖率也越低 |
| 模型版本 | **jev-1.13.0** | 结论绑定版本；换版本需重测 |

**结论**：它证明的是"**非生成式决策模型也有注入面**"，不是"Jev 不安全"，更不是"所有决策模型都同样脆弱"。

## 12 对系统设计的启示（我们提炼，非论文结论）

1. **不要暴露完整概率向量**：DH-4 的全部威力来自这个假设；只回 top-1 或加噪声能显著抬高攻击成本（需自测）。
2. **把置信度门当安全参数**：既是准确率参数，也是攻击面参数；两者要一起调。
3. **"非生成式"≠"免注入"**：闭集输出只消除"非法值"，不消除"被引导到错误选项"。
4. **端点评测要接端到端**：首个安全决策被劫持 ≠ 有害工作流完成；两者都要测。

## 13 失效边界（扩充）

1. **单模型单版本**：只在 jev-1.13.0 上测；跨模型/跨版本未验证。
2. **单数据集**：从 InjecAgent 重建 510 例；其它注入基准未覆盖。
3. **强攻击者假设**：DH-4 假定可读完整概率向量，估计的是**上界**。
4. **端点非端到端**：不测"攻击完成后是否真的造成危害"。
5. **无防御评估**：论文不比较任何防御（过滤、沙箱、二次确认）。
6. **统计口径与调用数不完全自洽**（§10）：总数与分项相加对不上，需以原文声明为准。
7. **人类基线缺失**：没有"人类在该决策上会不会被同样引导"的对照。

## 18 审稿式问答

**Q1：非生成式模型为什么也会被注入？**
A：因为**注入改变的是输入表示，不是输出格式**。闭集 softmax 只保证"答案在选项内"，不保证"选的是对的那个"。**DH-1 的作用就是证明这条迁移路径存在。**

**Q2：510 例够吗？**
A：够做**类别级**结论（direct-harm 的第一决策），**不够做"通用注入鲁棒性"结论**。分层 bootstrap 缓解了抽样方差，但**外部效度仍受限于 InjecAgent**。

**Q3：这对我们用决策模型有什么直接影响？**
A：**三件事**：① 不要在 API 里暴露完整概率向量；② 置信度门是安全参数不是纯准确率参数；③ 把"首个安全决策被劫持"写进威胁模型，别以为闭集输出就安全。

## 21 三句话结论

1. **注入面不因"非生成式"消失**：闭集输出只消除非法值，不消除被引导到错误选项；DH-1 证明了迁移性。
2. **严谨点在方法论**：双标记因子、预注册 SESOI、自适应攻击 + ≥3/5 验证、分层 bootstrap——这套设计可以作为同类研究的模板。
3. **引用要带三条边界**：jev-1.13.0、端点是首个决策（非端到端）、DH-4 是"可读完整概率向量"的强攻击者；且 **ΔP 与 ASR 不可互换**。

## 23 若要在自己的系统上复做这套实验（最小清单）

| 步 | 动作 | 本文参考值 | 注意 |
|---|---|---|---|
| 1 | 选攻击基准并**确定性重建**案例网格 | 30×17=510 | 重建脚本要可复现，不用随机采样 |
| 2 | 定义端点 = **暴露后首个安全关键决策** | 非端到端 | 端到端要另做，别混 |
| 3 | 设计**标记因子**（A0–A3 双标记 + A4 自然改写）| R=5 | 缺标记因子会把混杂算成效应 |
| 4 | 预注册**最小有意义效应量** | SESOI=0.02 | 事后挑阈值 = 结论无效 |
| 5 | 用**分层 bootstrap** 出区间 | 10,000 次 | 同时按 attacker goal 与 user context 分层 |
| 6 | 做**自适应攻击**（可读概率向量）| ≥3/5 验证 | 一次性攻击会低估风险 |
| 7 | 分开报 **ΔP / ASR / robust-K** | 三者不等价 | 禁止用四舍五入互相换算 |
| 8 | 固定模型版本并**按失败处理版本不匹配** | jev-1.13.0 | 避免"挑好的运行"偏差 |

**这份清单的用途**：任何"某模型抗注入"的结论，都可以按这 8 步验收；**缺第 3、4、5、6 步的，基本只能当探索性结果**。

## 24 一句话记住它

**闭集输出保证"答案合法"，不保证"答案正确"**——注入攻击打的正是后者；所以决策模型的安全评测必须单独做，不能因为"不生成文本"就跳过。
