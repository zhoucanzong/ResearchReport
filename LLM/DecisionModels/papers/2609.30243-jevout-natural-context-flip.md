## 1 方法

**研究对象**：四个暴露**有限类型化概率分布**的决策系统，在同一批自然语言决策题上的**目标翻转率（Targeted Flip Rate, TFR）**。

### 1.1 四个决策系统分别是哪些模型

| 系统 | 具体模型 / 形态 | 规格 | find 串 | 出处 |
|---|---|---|---|---|
| **Jev** | **Jev 1.13.0**，托管（hosted）商业决策模型，本文主系统 | 权重/架构未公开 | `Jev 1.13.0 is our primary hosted decision model` | §4.1 |
| **OpenSourceJev** | 开源 Jev 风格接口，**基于 Qwen3-1.7B Q8** | 1.7B，自回归 | `Qwen3-1.7B Q8` | §4.1 |
| **Von** | **Von 1.0**，**395M 非自回归**决策模型 | 395M，非自回归 | `a 395M non-autoregressive decision model` | §4.1 |
| **plain Qwen scorer** | **与 OpenSourceJev 共享同一套冻结权重**（Qwen3-1.7B Q8），但**直接对编号选项打分** | 1.7B，自回归，非 Jev 接口 | `options directly. This shared-backbone pair lets us examine different` | §4.1 |

- **共享 backbone 的设计**：`find: This shared-backbone pair lets us examine different` —— OpenSourceJev 与 plain Qwen 是**同一权重、不同决策接口**的对照对，用于把"接口差异"从"权重差异"中分离。
- **对照组而非目标系统的模型**：**Gemma4-12B** 负责提议上下文，并在**另一次 target-blind 调用**中检查语义约束（`find: The base Gemma4-12B model proposes context additions and, in a separate`；`find: target-blind call, checks their semantic constraints`）。**proposer 不是被翻转的对象**。

### 1.2 攻击面与两个核心定义

- **answer-preserving context addition（保答案上下文补充）**：引入背景或程序性细节，同时**保持决策问题完整**。渲染器 `x_z = R(x,z)` 保留**原有每一个字符及其顺序**，问题与选项不变。
- **target option**：在构造任何上下文**之前**，把**最可能的错误选项**固定为目标（`find: most probable wrong option before`）。
- **targeted flip（目标翻转）**：模型**只**在最终选中该固定目标选项时才算翻转。**改成另一个错误选项不算**；失败或被拒的提案**不会**把该 item 移出分母。
- **TFR**：在固定 target-evaluation 预算内，**初始答对**决策中被"至少一个已接受上下文"成功翻转的比例。多答案任务（SATA）被降解为**二元 option-membership 决策**，每题只保留一个初始答对的 unit。

### 1.3 probability-guided context optimization（概率引导上下文优化）的约束

**（a）信号**：用 option 分布计算 target 与最强竞争者的**对数概率边际** `m_u(z)`，正边际意味着 target 成为唯一最可能选项。与 label-only 相比，概率信号在**翻转真正发生之前**就给出有梯度的进展度量。

**（b）四类约束怎么定义**（§3.1 + Appendix B + Appendix F）：

| 约束 | 定义 | 检验方式 |
|---|---|---|
| **naturalness / natural-fit（自然性）** | 上下文须**自然贴合**原输入（local coherence） | **不是人工评审**：由**独立、target-blind 的 Gemma4-12B 调用**判定 `locally_coherent` 布尔字段 |
| **answer-preservation（保答案）** | 单答案题：原答案**仍唯一正确**；多答案题：**完整 gold set 不变** | 同一 target-blind 调用判定 `label_preserved`；判据是**结果层**（outcome-level） |
| **允许项** | 新事实、实例特有事实、对非 gold 选项的相关性、**强调转移**、间接证据 | 明确**不**作为拒绝理由（`New and instance-specific facts are allowed`） |
| **机械检查** | 合法插入位置、句子非空、归一化去重、**无显式选择短语**；迭代中还对已完成渲染状态做哈希以防重复 | `Mechanical checks enforce legal placement` |

**（c）接受谓词**：要求 `label_preserved` 与 `locally_coherent` 为真，且 `direct_decision_cue` 与 `new_decisive_evidence` 为假。`new_decisive_evidence` **只在**答案真的改变 / 产生实质并列 / gold 被推翻 / 下一步动作改变时为真——"证据新、具体、有影响力"**不算**。该自动谓词被作者自陈为对语义约束的**操作性近似**（operational approximation），非形式化保证。

**（d）预算如何分配**：archive 保存原始输入与全部已接受、已评估上下文；按 Gibbs 分布 `g^(r)`（最大化期望边际 + 熵项）重采样父节点，并以 `η` 混入均匀分配。**固定比例 slot 从原始输入重启**，使新的上下文方向能在后续迭代进入。构造在"某轮结束后出现超过阈值的目标翻转"或达到迭代上限时停止。

### 2.4 「每个决策 64 次已接受的 targeting evaluations」的确切含义

任务书问的"**each decision gets 64 accepted targeting evaluations**"这一口径在原文中应读作**上界，不是每题的实测值**：

1. **预算上界 = K×R = 64**：`K=16`（slots）× `R=4`（rounds）= 64。原文：`find: The total number of accepted target evaluations is at most`（`K=16`、`R=4` 见同段更早处），并明确 **不含**用于筛出 eligible item 的那次原始评测（`find: excluding the original evaluation used to select eligible items`）。
2. **"已接受（accepted）"指通过全部构造检查、因而**才**会被送去评测的候选**：`find: Only accepted, distinct contexts are evaluated by the target`。被机械检查或语义检查拒绝的提案**消耗生成资源但不消耗 target 调用**（`find: Rejected attempts use generation resources but no target calls`）。
3. **"target evaluation" 的具体含义**：向**目标决策系统**发一次前向调用、读取其**完整选项概率分布**，每个已接受上下文**只评一次**（`Every accepted context is evaluated once`），无论它是否改变了最终选择。
4. **TFR 的分母与"64"的关系**：TFR 统计的是**存在**某个在**前 B=64 次已接受调用之内**的上下文成功翻转（`find: accepted candidates among the first`）。**一个 item 只需成功一次即计入**（`find: counts an item once whenever any`）。
5. **实际远低于 64**：因早停与 slot 被拒，1,449 例平均只用了 **41.9** 次评测（`find: 41.9 evaluations per case`），作者明确解释 `find: evaluation count is below the 64-call maximum`。
6. **停止检查发生在整轮结束后**，因此同一轮中较早的成功**不会**取消该轮剩余 slot；预算曲线按"accepted-call 前缀"切分，**未必与轮边界对齐**。

> 一句话：**"64 次已接受 target evaluations"= 每个决策的评测预算上界（16 slots × 4 rounds），指被接受上下文送往目标模型读一次概率分布的调用总数；实际均值 41.9，一个 item 只要其中一次成功即算翻转。**

## 4 失效边界

### 4.1 naturalness 的强度

- **"自然"是模型判定的操作性约束，不是人类感知证据**：natural-fit 由 **Gemma4-12B 的独立 target-blind 调用**输出 `locally_coherent` 布尔字段决定。本文**没有**报告任何人类评审、人评一致性或"人类看不出异常"的实证。因此"这些补充仍算自然"是**管线定义**，不是**知觉事实**。
- 检查器**刻意不知道 target**（不含 target option / 概率 / 边际），这防止了"检查器配合攻击"，但也意味着它只能验证**结果层保答案**，无法保证补充文本在语义上"与选项无关"。
- **允许强调转移是设计选择**：`New and instance-specific facts are allowed`，且"对非 gold 选项的相关性、强调变化、间接证据"**明确不作为拒绝理由**。所以"自然"实际是**很宽的**口径——宽的正是攻击面。

### 4.2 answer-preservation 约束

- 定义为**结果层不变**：单答案题原答案仍唯一最优；多答案题完整 gold set 不变。对比是"把增补文本视为全真、独立解一遍"后比 gold。
- 作者自陈该自动谓词是 `find: It is an operational approximation to the`（对语义约束的操作性近似），**非形式化保证**。
- **answer-preserving ≠ answer-irrelevant**：补充的正是背景/程序性信息，对模型而言可能是**真实可用的线索**。所以本文证明的是"**答案没变，但模型的判断被周边上下文带走了**"，而不是"模型被无关噪声欺骗"。

### 4.3 哪些系统 / 任务未被有效翻转

- **没有任何目标–数据集组合是零翻转**：作者明确 `Every target–dataset combination yields successful redirections`。因此**不存在"未被有效翻转"的格子**；差异只在**幅度**。
- **低值端**：Jev 在法律推理（LAR-ECHR）最低，40.0%，与 MMLU-Pro 同属偏低；作者在两处都点名 `MMLU-Pro and LAR-ECHR have lower rates than the other tasks`。
- **其它系统的低值端**：OpenSourceJev 的 LAR-ECHR 最低（`whereas LAR-ECHR is lowest`）。
- **one-shot 对照并非单调占优**：OpenSourceJev 在 MuSR 上 **neutral 控制超过 target-aware 控制**（`on MuSR, the neutral control exceeds`）——说明"知道 target"并不总有利，单次添加的信号弱且不稳。
- **学习式生成远弱于迭代优化**：held-out 508 上最好的 V2 单次生成只有 21.9%、best-of-4 才 34.3%，**均明显低于**迭代优化的 61.4%。即"不用迭代反馈"时翻转能力大打折扣。

### 4.4 作者自陈局限（Appendix M "Scope and Generalization"）

1. **只适用于暴露有限类型化分布的系统**：`find: The current study targets systems that expose a finite, typed distribution and`。自由生成式 LLM 不在结论范围内。
2. **只在"初始答对"的决策上做条件分析**：`find: conditions analysis on decisions that begin correct`；TFR 描述的是**这个总体内、该评测流程下**的结果。
3. **TFR 是"有界优化器能挖出多少"的度量**，不是"任意上下文都会翻转"的比率：`find: TFR measures how often a`（"bounded optimizer uncovers" 在下一行）。
4. **明确留白的推广方向**：更大的模型规模、多语言上下文、连续动作、真实部署流（`find: Broader model scales, multilingual contexts, continuous actions, and`）。
5. **区间只描述固定评测样本**：`find: fixed evaluation sample, not variation across repeated optimizer seeds`。
6. **LAR-ECHR 的数据泄漏风险作者自己披露**：该数据集官方 split 把 **14 个底层法律案件**分散在 dev/eval 之间，**item split 不重叠但 case split 不重叠不成立**（`find: but it is not case-disjoint`）。作者做了 post hoc 敏感性分析：剔除这 14 案相关的 **15 个 eligible Jev 评测 item** 后剩 **493** 个决策，并强调该 493 人群与 **508** 头条人群**分开保留**。
7. **伦理章节自陈未做有害内容生成**：`find: The study focuses on decision redirection rather than`（"harmful-content generation" 在下一行）。
