## 1 方法

**问题设定**：事故数据集中的**调查员叙述**含有编码字段遗漏的信息；大规模编码叙述此前受阻于三件事——frontier LLM 在该规模上太贵、其生成文本**无法核验**、以及**没有规则**规定人工必须复核多少输出。

**本文的解法**：把叙述编码形式化为**门控的、类型化的决策（gated, typed decisions）**，由 **Jev** 回答——**返回分析师定义的选项上的概率、不生成任何文本**。

**两阶段流水线**：

| 阶段 | 规模 | schema |
|---|---|---|
| **筛查（screen）** | **499,500** 条 Texas 叙述 | **10 问** |
| **编码（code）** | **195,857** 条 | **完整 27 问**（其中 **16 个为 presence 问题**；命名实体从**闭合选项集**选择而非生成） |

**成本模型的核心发现**：**花费由 schema 规模决定，而非文本长度**——这**反转了**两阶段筛查设计的传统前提（`which reverses the premise behind two-stage screening designs`）。

**校准审计设计**：对**每一个变量**做独立的校准与选择性预测审计，参照两个来源——① 编码的 **CRIS 字段**（大规模一致性参照）；② **2,416 条盲人人工判断**（按**明确陈述的抽样设计**抽取）。

## 2 实验设置与条件

| 维度 | 具体设置 |
|---|---|
| **对照模型** | **两个来自不同厂商的 frontier 生成式模型**（跑在同一批记录上）；**成本对照**另用"三个商业档位的标价"构造**情景**（非 Table 9 的对照臂） |
| **缓存** | **未述跨请求缓存**；成本基于**实测 token 计数** |
| **工作负载** | 分析语料 **5,018,080** 条（2017–2025，去空/≤40 字符后）；筛查 **499,500**；编码 **195,857**（其中 **150,000** 构成随机框架） |
| **任务** | 10 问筛查 + 27 问编码（16 个 presence 问题开启细节子问题；命名实体从闭合选项集选择） |
| **人工参照** | **3 位**受研究生级交通安全训练的编码员，标 **2,465** 个 narrative-variable 对（共 **5,024** 条判断）；**2,371** 对双标、**94** 对三标；pairwise Cohen's κ **0.95–1.00（中位 0.95）**；原始一致率 **99.0%**；中位判断耗时 **7.4 s**；多数票裁决，剔除 unclear/平局 → **2,416** 条可用判断（48 个争议对、18 个 unclear） |
| **权重与设计效应** | 权重跨 **189 倍**，**设计效应 1.95** → 2,416 条判断**等效信息量约 1,265**；区间按**叙述（cluster）bootstrap**（B=1,000），因一条叙述最多供 **16** 条判断 |
| **模型版本** | **jev-1.13.0** |

## 4 失效边界

1. **校准被拒是本文的核心负面结果**：对**人工**参照，合并 ECE **0.0231** 被明确判为不达标；**未经重校准不可用于估计患病率**。
2. **失败方向与直觉相反**：这里是**向中部收缩 + 整体偏高**（斜率 1.63、均值 4.8% vs 基率 2.7%），**不是**神经网络的典型过度自信。**因此不能套用"降温/锐化"式补救**——重校准是**单调变换**，恰因其不改变排序才有效。
3. **5 个变量无法单独重校准**：正例 <20，**只能**在合并图下重校准；作者明示这是**参照集规模**的限制，不是方法的限制。
4. **人工参照由"清晰案例"定义**：多数票裁决并剔除 unclear/平局（剩 2,416）；作者自陈 `Scoring the model against a label the coders could not agree on would measure nothing`——因此该参照**不代表有争议的构念**。
5. **成本比较不是同臂对照**：`no statement in this paper attaches a cost to either of them`——frontier 臂**未**带 token 计数，故 52×/129×/26× 是**把标价套到本研究 token 计数上的情景**，作者明示 **两件事不得读作同一条曲线**。
6. **全语料编码未执行**：$774/5,018,080 条是**外推**，语料本身**未被全部编码**。
7. **依赖编码字段作一致性参照**：CRIS 字段**本身不完整**，故一致性度量的是**一致**而非**准确**；叙述提到而编码遗漏的因素会造成**表观假阳性**。
8. **叙述长度无关性有其适用范围**：来自 token 模型拟合（R²=0.987），外推到其它 schema/叙述风格需重验。

## 6 与 `report.md` 的差异或需要更正之处

- **已确证一致**：未校准判定（typed + 一个 frontier 分支）、**3.3×**、ECE **0.0231 → 0.0069**、\$0.154/千条、\$774、2,416 条人工判断。
- ⚠️ **需复核的表述**：`report.md` §7.3 写"校准**随模型而变而非随范式而变**"。本轮在正文定位到的是：**两个 frontier 分支的交付校准状态不同**（一个校准、一个未校准，`whichever`/`one ... the other`），这与"随模型而变"**方向一致**；但**未定位到**该概括句本身。**建议**：把该行改为可逐字支撑的形式——"**同一批记录上，typed 模型与其中一个 frontier 分支按交付状态未校准，另一 frontier 分支已校准**"，或明确标注该概括为**本报告的跨来源推断**。
- **建议补充**：§7.3 该行可补 **ECE 0.0231（CI [0.0212,0.0245]）→ 0.0069** 与 **斜率 1.63 → 0.97**，以说明"重校准修的是水平偏移、且因单调而不损排序"——这正是"为何不重训"的关键论据。
