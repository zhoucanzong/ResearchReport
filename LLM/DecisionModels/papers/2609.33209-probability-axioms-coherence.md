## 1 方法

**问题**：类型化决策模型的评测普遍报告**准确率与校准**，但**两者都不要求**模型对**逻辑相关的多个问题**给出的概率**逐项自洽**。而"对概率采取行动"的系统**依赖**这一性质。

**被检性质 = 一致性（coherence）**：概率在**逻辑相关问题之间**的一致性（`the agreement of probabilities across logically related questions`）。

**关键方法学优势（本文的核心贡献）**：一致性检验**不需要标签**——因此可以暴露"只在比较**问句形式**时才出现"的偏差，以及**同一条目内部**的不一致（`the checks need no labels, they expose biases that appear only when question forms are compared, and inconsistencies within items`）。

**实验素材**：**160 个条目**（来自 **ChaosNLI** 与 **PubMedQA**），每条有**三个互斥标签**。对每条问四种形式：① 标签是否为 X；② 是否为**非 X**；③ 是否为**另外两个标签之一**（析取）；④ 哪个标签适用（choice）。

**检验的公理族**：否定互补（`s_k + n_k = 1`）、**划分可加性**（partition additivity）、**析取可加性**、描述不变性、单调性。

**对照与最关键的实验控制**（决定结论强度）：
- **对照模型**：**Qwen3.8-27B**，从**官方 BF16 权重**运行，测**两种读出**——**first-token** 概率与**verbalized**（口头）概率；
- **三个控制**：① 仅在**两系统给出相近概率**的对上比较（|s_J − s_Q| ≤ 0.10），因为越自信的系统"看起来越一致"；② **移除双重否定的标签**；③ **对 Jev 的重复调用取平均**；
- **噪声地板**：测量 **repeat-noise floor**，并把每次违规与该地板比较（`the violation that a coherent system with the same repeat noise would show`）。

## 4 失效边界

1. **"Jev 比 LLM 读出更一致"≠"Jev 是一致的"**：本文明确 `Jev is not coherent either`——违规约为噪声地板 **5 倍**，且**系统性过度认可**单标签（和 **1.14**）。
2. **两个系统的失败**不可互相推断：Jev 的违规**集中在不确定处**；Qwen 的 first-token 读出**与自信程度无关**，且会**同时拒绝陈述与其否定**。
3. **越自信看起来越一致**是量测陷阱：概率接近 0/1 时 `|s+n−1|` 的余地本就小，故作者专门做"相近概率对"的匹配比较与 **logit 尺度**的次级检验。**logit 尺度依赖裁剪界 [0.01, 0.99]**，故仅作次级证据。
4. **无标签检验的代价**：一致性检验**不涉及**标签，故它**不能**告诉你哪个形式是"对的"——它只暴露**形式之间**的不一致。
5. **工作负载窄**：**160 条目 / 480 对**，来自两个数据集（ChaosNLI、PubMedQA），三个互斥标签；**不覆盖**多元（>3）或多问句链。
6. **社区审计的数值分散**（本文 §2 汇总）：complement 和在 **0.71–1.42** 之间，yes/no 与 choice 差 **0.125**（另一审计）、**0.055**（48 例）——**说明该类量测对协议高度敏感**，引用时应带上自家协议。
7. **探索性结论**：支持理论的两个模式（次可加性、unpacking）属**探索性分析**，作者未称因果。
8. **单模型**：类型化决策模型侧只测 **Jev**；"类型化决策模型类"的推广**未**经多模型验证。
