# JEV-as-a-Judge：费用优势、门控收益与样本扩容

> 2026-10-22 依据[固定版本正文](https://arxiv.org/html/2609.26550v5)重核。本文只提取作者实验，没有复跑；原文快照放在仓库外 `.paper-cache/research-audit-2026-10-22/2609.26550v5.html`，SHA-256 为 `e054dae9268010034f1dac992eb2f2a6bf0fd790d7fd05d190b6bda90b1f72cf`。

## 1. 一句话结论

JEV 在作者的评判任务中有费用与延迟优势，但推导型题目的准确率落后；冻结置信度门控能在指定任务混合上改善费用与准确率折中，收益依赖样本组成，不能把小样本或单调用费用比搬作整个级联的结果。

## 2. 问题与机制

JEV 只返回标签与概率，把置信度高的判断接受、其他转给推理型评判者。论文区分返回概率中的最大值 (q) 与产品原生的 `confidence`；二元题中二者单调相关，也不应混称为同一个数。[§4]

冻结双序策略先交换候选顺序取得两次概率，将对齐的概率平均，再以阈值门控。阈值在 pilot selection 对上确定，held-out 对上不重新调参。这与看完测试结果再选阈值的事后分析不同。[§8，式1，表3–4]

## 3. 设置、分母与费用口径

| 项目 | 本次取回正文的设置 |
|---|---|
| base判断 | 5,172；含1,500 RewardBench对、350 JudgeBench对、3,000 HaluEval答案及final-answer/controls |
| 比较配置 | 17个，含JEV与16个对照；生成式与reward model并存 |
| 单调用计时 | 120 judgments/hosted judge，40/public task；单一客户端位置和采集窗口 |
| 费用 | 采集时价格×reported usage，计缓存折扣、reasoning token；usage缺失作保守预留；是估算而非账单 |
| 冻结阈值 | 96 pilot selection pairs；双序τ=0.9 |
| held-out偏好对 | 1,610（1,340 RewardBench +270 JudgeBench）；83%来自RewardBench |
| 主门控结果 | 离线模拟，不是现场运行性能承诺 |

## 4. 关键结果：不要混同三个实验

| 实验/对照 | 结果 | 原文位置与边界 |
|---|---|---|
| 单评判，JEV vs GPT-6 Astra | RewardBench 92.5%/92.5%；JudgeBench 78.6%/93.1%；HaluEval 87.3%/88.4% | 表1；各任务分母见§3；不是所有任务都“只差三点” |
| 单评判费用与中位时延 | $0.044/$12.182 每千judgments；0.15/1.89s | §5，表1，120条timing panel；费用比约0.36%，不是级联费用比 |
| 冻结级联，全部1,610对 | 93.4% vs GPT-6 92.5%；差+0.93pp，95% source-cluster区间[0.24,1.66]；费比41.4%，保守上界44.0% | §8，表4；上抛31.5%；分布主要为RewardBench |
| 冻结级联，JudgeBench 270对 | 92.2% vs93.0%；差−0.74pp，区间[−2.22,+0.74]；费比66.8% | 表4；与RewardBench的收益形状不同，区间跨零不证明等效 |
| 历史510 held-out对子集 | 92.5% vs93.1%；费用56.8%（保守62.2%）；保留99.4%的比较者准确率 | §3 “Sample expansion and earlier reported figures”；仅原子集，不是1,610对的当前总计 |

论文明确解释：旧样本的JudgeBench占比53%，扩容后仅17%，因此聚合结果变化主要受组成影响。更强的推导/领域问题仍是失效面。不能只报告聚合的成本下降而隐藏困难子集。

## 5. 消融与方法学限制

双序平均本身的准确率变化很小且区间跨零，不能把全部级联收益归因于交换顺序。门控需要能识别“第一阶段容易、强模型仍有补益”的子集，还取决于两个评判者的错误互补性。[§8]

GPT-6是论文选定的参考比较者，并非每项基准最准确的模型。API费用只涵盖hosted配置，本地reward/LLM没有对应API报价，不能据此认定JEV比任何本地部署都便宜。[§5]

原文的人工标签审计覆盖先前990 public items的分歧，不能扩写为扩容后全部5,172条都经过人工盲审。supplied labels、人工裁定与现场任务结果应分别陈述。[§3 sample expansion；人工审计附录]

## 6. 旧分册的实质更正

- **0.36%**：本次取回的v5正文§1/§5可直接定位；旧分册末尾仍判“只在摘要”已失效，删除互相冲突的裁定。
- **92.2%/93.5%、87.5%/86.7%**：属于早期400 RewardBench/240 HaluEval样本，不能作为扩容后全量结果；本次采用表1的92.5/92.5、87.3/88.4。
- **94.0%**：表1中JEV的final-answer列，不是其RewardBench值。
- **保留99.4%@56.8%**：仍可追溯，但只适用于历史510对子集。主文与本分册同时补入当前1,610对条件。
- **“grep命中=精读通过”**：不成立；必须把数字对应到任务、样本、策略、费用统计方式和限制。当前分册按这些关系重整，未声称所有附录已逐项复核。

## 7. 未决项与来源

后续需按固定原始数据复现双序概率、pilot阈值、source-cluster区间与usage估算，另核现场复制实验和新工作负载。本文未完成这些复现，也不把离线门控结果当部署保证。
