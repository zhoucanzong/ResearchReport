## 1 方法

**研究设计（镜像评测）**：复用 Ziems et al. (2024) 的评测套件——**18 个 closed-choice CSS 分类任务**（find: `18 closed-choice classification tasks`）、同一 released test splits（class-stratified，**每任务至多 500 条**，**共 7,977 条**；find: `at most 500 instances per task`、`7,977 items in total`）、同一 gold labels 与其 prompting guidelines；Ziems 已发表的 FLAN-T5 / GPT-3 系列 / GPT-4 零样本结果与 fine-tuned RoBERTa-large 基线**仅作历史对照列，本文不重跑**（§3.1，find: `do not rerun their models`）。

**18 / 15 / 3 的确切口径**：18 个任务 = **10** 个 utterance-level + **6** 个 conversation-level + **2** 个 document-level（find: `ten utterance-level tasks`、`six conversation-level tasks`、`>Document-level tasks<`）；其中 **3 个 pilot 任务（stance、implicit hate、discourse acts）被排除在全部头部比较之外，头部比较只在其余 15 个 evaluation 任务上进行**（§3.1、§3.4；find: `The three pilot tasks are stance, implicit hate, and discourse acts`、`remaining 15 evaluation tasks carry every headline comparison`）。

**zero-shot 协议**：LLM 基线收到 Ziems 的 released prompts **逐字原文**，另追加一行要求给出 **0–100** 的 verbalized confidence（find: `verbalized confidence from 0 to 100`）；决策模型收到同一 instruction 文本与同一选项描述，**改写为 decisions API 的 typed choice question**。OpenAI 与 Gemini 基线 reasoning effort = "low"；Kimi K2.6 关闭 reasoning、GLM 5.3 用 "low"（二者首轮因 reasoning token 耗尽产生大面积空补全）；其余 LLM 基线 temperature = 0（§3.2）。追加置信度行不影响准确率比较：3 个 pilot 任务共 **48** 个 cell 上准确率中位变化 **+0.2** 点、中位绝对变化 **1.7** 点（§3.2、§A.6/Table 6；find: `48 pilot-task cells`、`alttext="+0.2"`、`median absolute change 1.7 points`）。

**被评模型清单与规模**：共 **22** 个（find: `all 22 models`）= **3 个决策类** —— ① **Jev 1.13**（TypeSafe，经 OpenRouter decisions endpoint；resolved version 记录为 **jev-1.13-20260917**，find: `jev-1.13-20260917`）；② **开源 0.6B RLCD 决策模型**（基于 Qwen3-0.6B-Base，本地大学 HPC 推理）；③ **同 base 的无训练 ablation**（对同一 vanilla base 施加完全相同的 letter-token constrained decoding，以隔离 RLCD 训练本身的效应）（find: `Jev 1.13 (TypeSafe, via the OpenRouter decisions endpoint`）；再加 **19 个 LLM 基线**（经 OpenRouter，覆盖 GPT-5.6、Claude、Gemini、Llama、Qwen、DeepSeek、Mistral、GLM、Kimi、Gemma 家族；find: `19 LLM baselines via the OpenRouter`）。全部运行日期 **2026-09-20**（Table 5；find: `All runs 2026-09-20`）。

**决策模型的调用方式**：typed question + 枚举 label set → 返回 choice、全 label set 上的概率分布、标量 confidence；**不生成自由文本**，"extraction errors impossible by construction"（find: `they do not generate free text`）。Jev 的官方输入价为 **$0.042 / 百万输入 token**（§1.3；find: `input pricing of $0.042 per million tokens`）。

**指标**：① accuracy 与 macro-F1（对 gold labels，同一测试项）；② 校准 —— ECE（**15 equal-width bins**，find: `expected calibration error with 15 equal-width bins`），决策模型用其返回的 confidence 与所选选项的概率，LLM 用同一次调用里的 verbalized confidence（19 个基线的 API **都未返回可用 token 概率**，find: `none of the 19 baseline APIs in our evaluation returned usable ones`），另给每任务 reliability diagrams；③ coverage–accuracy 路由曲线 —— 对阈值 **t ∈ {0.5, 0.6, 0.7, 0.8, 0.9, 0.95}**（find: `0.5,0.6,0.7,0.8,0.9,0.95`）给出 ≥ 阈值的项占比（coverage）与其中准确率；④ **实测成本** —— 任务级美元数与外推到每千条/每百万条，价格取研究期间（2026-09）的 per-call billing records（§3.3）。校准一律对**单一 adjudicated gold label**计算，因此本文说的是"对 benchmark gold standard 的校准"，不是对构念本身的校准（§3.3，find: `against the single adjudicated gold label per item`）。

**统计检验**：预注册 **AsPredicted #312,511**（find: `AsPredicted #312,511`），锁定完整 grid（tasks × models × metrics）、1 个 characterization question（**不做方向性预测**：Jev 在哪些任务上胜过 best LLM，估计 per-task ΔF1 并与 5 个任务特征相关）、3 个假设、以及 confidence-cascade 分析（路由规则、两条 partner 选择规则、阈值网格）。模型间 F1 差异用 **items 上的 paired bootstrap（10,000 resamples，固定种子）** 逐任务检验（find: `10,000 resamples, fixed seed`），并以 **Benjamini–Hochberg FDR 控制在 q = 0.05**；全 grid 共 **342** 个 task-by-comparison cell（find: `test all 342 task-by-comparison cells`），**194** 个校正后显著（find: `194 cells are significant after correction`）。

**三个预注册假设（后文失效分析用）**：(1) Jev 中位 ECE 低于**每一个** LLM 基线的 verbalized-confidence ECE；(2) 中位任务上 Jev confidence ≥ 0.9 的项达到 accuracy ≥ 0.85 且 coverage ≥ 0.15（find: `at least 0.85 at coverage of at least 0.15`）；(3) Jev 在 Indian English dialect 任务上的校准误差**高于**它在其余 utterance-family evaluation 任务上的中位数（§3.4）。

**摘要 vs 正文**：本文摘要里的每一个数字都在正文可逐字定位（14/15 与 11.6 → §4.1 与 §5；44× → §4.5；16/19 与 0.157 vs 0.066 → §4.2；0.815 → §4.4；empathy 高置信近随机 → §4.4/§5；1/4–1/2 成本 → §1.6/§4.5；18 任务/7,977 项/19 基线 → §3.1/§3.2）。**故本文件无「仅摘要，正文查无」条目。**

## 4 失效边界

### 4.1 作者自陈的局限（§5 末、§6）

1. **单厂商、单时点、单一语种快照**：本文是"一个商用决策模型 + **六个 0.4B–9B 开源同类** + **18 个英语**分类任务"的 2026 快照，**不构成**"决策模型在社会科学文本上普遍校准"的结论（§5 末；find: `This study is a 2026 snapshot of one commercial decision model`、`six open-weight counterparts between 0.4B and 9B parameters`、`18 English-language classification tasks`）。
2. **无法排除训练数据污染**：所有任务都是**先于被评模型发布**的公开基准（§5 末，find: `training-data contamination cannot be excluded`）。
3. **方言证据只有一个任务**：一个 dialect 测试不能证明公平性（§4.3，find: `One test on one dialect cannot certify fairness`）。
4. **校准的基准是 gold label 而非构念**：全篇 ECE 对单一 adjudicated gold label 计算，而 trained annotators 本身对构念有分歧（find: `against the single adjudicated gold label per item`）；唯一能对逐标注者分数检验的 politeness 任务上，**没有任何模型的 confidence 追踪人类分歧**（§B；find: `<mn>0.14</mn>`）。
5. **分级失效不可外推**：empathy 失效是否特异于该构念、frontier verbalized confidence 是否会随 post-training 变化而保持良好校准，均未确立（§5 末，find: `that the empathy failure is specific to that construct`）。
6. **开放生态结果不进注册比较**：5 个开源决策系统是注册后追加的探索（§B，find: `These runs were added after registration`）。
7. **无延迟/吞吐证据**：全文对 `latency`／`throughput` 检索 **0 命中**——本文只给成本，**不能**用于任何时延/速度主张（反证性检索，无 find 串）。
